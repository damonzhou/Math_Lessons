# 题源与原创命题规范｜v2.0 工作版

> 规范优先级以 `docs/standards/CURRENT.md` 为准。本文件用于日常 Lesson 编写。

核心原则：

> **课标/教材约束优先 + 权威一手真题优先 + 透明改编 + 有限原创 + 诊断价值 + 训练增益 + 解后推广。**

---

# 1. 先检查知识边界

选题之前先确认：

1. 教育部《义务教育数学课程标准（2022年版）》；
2. 人教版当前教材/教师用书顺序；
3. 学生截至本讲已正式学习的工具。

漂亮真题若明显超纲，应延后或适龄改编，不能偷偷使用后续公式。

---

# 2. 题目标签

- **TEXTBOOK-MODEL**：正式教材/教师用书模型依据，但不是教材原题；
- **SOURCE**：基本保留可核验真实考试/竞赛题数学结构；
- **ADAPTED**：明确真题核心结构改编；
- **SYNTHESIS**：融合两个或以上可追溯权威题源；
- **DESIGNED**：少量教学原创，只补重要教学空白。

不得把改编题称为原题。

---

# 3. 权威来源层级

## 3.1 课程与教材

原则上只使用：

- 教育部正式课程标准/课程方案；
- 人民教育出版社官方教材、教师用书、修订说明和官方资源；
- 用户提供的学校正式教材/试卷/讲义；
- 必要时其他教育主管部门正式文件。

## 3.2 国内真实考试

可使用：

- 学校正式期中/期末试卷；
- 区县市统一考试；
- 中考真题；
- 教育主管部门/考试机构正式原卷或可靠正式出版物。

至少记录年份、地区/学校/组织方、考试类型、题号和可靠来源。

来源不明的“某名校真题”不得标 `SOURCE`。

## 3.3 国际权威奥赛/竞赛

包括但不限于：

- **MAA**：AMC 8 / AMC 10 / AMC 12、AIME、USAJMO、USAMO；
- **IMO**：官方历年题、官方公开 Shortlist；
- **University of Waterloo CEMC**：Gauss 等；
- **UKMT**：JMC / JMO 等官方竞赛。

## 3.4 国内权威奥赛/竞赛

包括但不限于：

- **CMO（中国数学奥林匹克）**；
- 全国高中数学联赛；
- 中国女子数学奥林匹克；
- 中国数学会及其相关竞赛委员会正式组织的赛事；
- 其他具有明确主办方、正式赛制、可核验原题/正式出版物的权威赛事。

## 3.5 Informatics

优先参考：

- CSP-J / CSP-S；
- NOI / NOIP 等官方题目中的数学模型；
- 正式算法题中的整数、坐标、计数、递推、模运算结构。

---

# 4. 权威不等于适龄

选择题目不按赛事名气，而按：

```text
教学匹配度
+ 来源权威性
+ 当前可解性
+ 结构新颖度
+ 诊断区分度
+ 训练增益价值
+ 一般化价值
```

七年级通常最常直接使用 AMC 8、Gauss、JMC、教材/真实校内考试等适龄来源。

IMO、CMO、AIME、USAMO 等高阶赛事只有在：

- 当前知识可解；或
- 可以保留核心结构做透明适龄改编；

时才进入当前 Lesson。

**不能为了赛事名气而超纲。**

---

# 5. 三类高阶任务的题源角色｜v2.0

同一 Lesson 必须区分：

## 5.1 Ceiling Diagnostic｜测上限

题目要求：

- Core 已学完；
- 高阶方法尚未完整教学；
- 当前知识可解；
- 前文没有高度同构模板；
- 至少有一个真实突破口；
- 能区分独立发现、提示后完成和教学后掌握。

优先选择高质量 `SOURCE / ADAPTED / SYNTHESIS`；若权威题源没有足够匹配的题，允许 `DESIGNED`，但必须说明原创必要性。

## 5.2 Ceiling Builder｜提上限

Builder 不是“再找几道更难题”，而要训练具体能力。

题目应承担至少一种功能：

- 表示转换；
- 条件变化；
- 反例构造；
- 逆向构造；
- 多方法比较；
- 特殊到一般；
- 陌生表面迁移。

允许组合真实题源与透明原创变式，但必须说明：

> **这道题具体希望改变学生哪一种解题行为？**

## 5.3 Mastery / Final Challenge｜验迁移

高阶教学后用于检查：

- 方法是否真正学会；
- 表面改变后能否迁移；
- 是否能解释；
- 是否能一般化。

不能只是 Diagnostic 或 Builder 的数字替换版。

---

# 6. 禁止作为课程依据的来源

以下只能作为搜索线索，不能用于认证知识或真题：

- 新闻报道；
- 自媒体；
- 商业培训机构转载题库；
- 论坛/博客；
- 搜索引擎摘要；
- 无原始出处的“历年奥赛真题合集”。

搜索工具只用于定位官方一手资料。

---

# 7. provenance 必须记录

每讲维护：

```text
sources/XX-lesson-provenance.md
```

必须至少包含：

## 7.1 实际采用来源

对重要题记录：

- 类型标签；
- 赛事/考试/教材；
- 年份；
- 地区/组别/轮次；
- 题号；
- 官方页面/正式出版物；
- 改编内容；
- 当前知识边界；
- 教学目的；
- 若为 DESIGNED，为什么必须原创。

## 7.2 候选权威题源池审查

明确记录 AMC / IMO / CMO / CEMC / UKMT / 国内正式考试等相关池是否审查、是否选用、未选原因。

## 7.3 三类高阶任务映射

明确列出：

| 任务角色 | 题目 | 来源/标签 | 目标 |
|---|---|---|---|
| Ceiling Diagnostic |  |  | 测哪种独立发现能力 |
| Ceiling Builder |  |  | 提升哪种能力/习惯 |
| Mastery / Final |  |  | 检查哪种迁移/一般化 |

并说明三者是否存在过高同构风险。

---

# 8. Ceiling Builder 的训练增益审查

Builder 选题必须回答：

1. 这道题针对哪个 Ceiling Diagnostic 卡点或 H 标签？
2. 如果学生做对，只说明计算熟练，还是说明思维行为发生变化？
3. 能否迁移到不同表面结构？
4. 是否能设计 T1 和 T2 复测？
5. 是否存在更少题量但训练增益更高的替代设计？

**不以题量、赛事等级或运算复杂度作为“提高能力”的证据。**

---

# 9. 发布前题源 Review

每个 Lesson 发布前检查：

- 是否主动查看教材、国内考试、AMC/CEMC/UKMT/IMO/CMO 等权威池中有无更合适问题；
- 是否真正追溯到官方资料；
- 是否为了使用高级赛事而超纲；
- 是否把 ADAPTED 写成 SOURCE；
- 原创题是否有不可替代的教学目的；
- Ceiling Diagnostic 是否真能测冷启动上限；
- Ceiling Builder 是否针对真实卡点并具有训练增益；
- Mastery Challenge 是否与前述任务保持足够结构差异；
- 是否可通过 T0/T1/T2 观察能力变化。
