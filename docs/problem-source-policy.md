# 题源与原创命题规范

本仓库训练题采用：

> **课标/教材约束优先 + 国内外高质量真题并行 + 透明改编 + 有限原创 + 解后推广**

目标不是追求“真题比例最大化”，而是保证每一道重要题都知道：

- 为什么现在可以做；
- 为什么值得做；
- 它从哪里来；
- 改了什么；
- 做完以后应该学到什么。

---

# 1. 出题前先过“知识边界”检查

任何题源选择之前，先确认：

1. 《义务教育数学课程标准（2022年版）》对当前学段的要求；
2. 人教版当前教材章节的知识顺序与教学重点；
3. 学生截至本讲已经学过哪些工具。

因此：

- 课标和人教版决定 **Core 内容、顺序和最低掌握深度**；
- 竞赛题不能为了“难”而大量使用尚未学习的公式；
- 真题严重超出当前知识边界时，应延后或做结构化改编；
- `EXTENSION` 可以提前展示未来观点，但必须明确“不要求当前记忆/掌握”。

---

# 2. 五类题目标签

## TEXTBOOK-MODEL

有正式教材、教师用书或权威配套资源的知识/题型模型依据，但题目文字、数字或情境由课程重新组织。**不是教材原题。**

## SOURCE

基本保留真实考试或竞赛题的数学结构，只做翻译、单位、数值或表述上的轻微调整。

## ADAPTED

由明确真题的核心数学结构改编，情境、数字、问法或难度发生变化。

## SYNTHESIS

融合两个或以上可追溯题源的结构，再结合本讲知识重新设计。

## DESIGNED

教学原创。只有当教材和现有题库不能精确覆盖某个重要概念、反例、易错点、方法或迁移目标时使用。

---

# 3. 题源池

题源不按“国内 / 国外谁更高级”排序，而按：

1. 与当前知识和教学目标的匹配度；
2. 来源权威性和可追溯性；
3. 是否主要用当前已学知识可解；
4. 是否能带来高质量思考。

## 3.1 Core / Advanced：教材与历年真实考试题

优先参考：

1. 人教版教材；
2. 人教版教师教学用书；
3. 官方或可核验的校内期中、期末真题；
4. 区级 / 县级 / 市级统一考试真题；
5. 各地历年中考真题；
6. 具有明确学校、地区、年份、考试名称和题号的高质量真实试题。

### 最低追溯信息

国内考试题至少记录：

- 年份；
- 地区 / 学校 / 考试组织方；
- 年级或考试类型；
- 题号；
- 可核验来源链接、正式试卷或扫描件来源（若有）。

只有“某名校真题”“某地期末题”而无法核实具体出处的，不得标记为 `SOURCE`。

## 3.2 Olympiad：国内权威数学竞赛 / 奥赛真题

允许并鼓励使用**国内权威数学竞赛、奥赛、数学邀请赛的历年真题**，特别是：

- 与当前初中知识自然衔接；
- 有明确主办 / 承办 / 官方出版或可核验历史资料；
- 能训练数论、代数、组合、几何、构造、不变量、分类讨论等核心竞赛思想；
- 不依赖明显超前知识，或可以保持数学结构做适龄改编。

### 最低追溯信息

至少记录：

- 赛事正式名称；
- 年份；
- 组别 / 年级 / 轮次（如适用）；
- 题号；
- 主办方、官方资料、正式出版物或可靠可核验来源；
- 若改编，说明改动内容和原因。

### 不得直接标为 SOURCE 的情况

- 只有自媒体转载，无原始出处；
- 写着“历年奥赛真题”但无赛事、年份和题号；
- 多个题库互相转载，无法确认最初来源；
- 来源冲突或题目版本明显不同但未核实。

这类题即使数学价值不错，也只能先作为候选素材；核源前不得声称为真题。

## 3.3 国际竞赛：与国内题源并行

七、八年级继续重点参考：

- **MAA AMC 8**；
- CEMC Gauss；
- UKMT Junior Mathematical Challenge / Junior Mathematical Olympiad；
- 不依赖明显超前知识的 AMC 10。

使用规则：必须标赛事、年份、题号；改编后必须标 `ADAPTED`，不能写成原题。

同一知识点如果国内真题更贴近人教版表达和考试习惯，应优先国内题；如果 AMC / Gauss / UKMT 的问题结构更优秀，则使用国际题。**不机械设国内外优先级。**

## 3.4 Informatics

优先参考：

- CSP-J；
- NOI / NOIP 中适合当前阶段的数学模型；
- 正式算法题中的整数、坐标、计数、递推、模运算等结构。

如果当前只是建立“数学概念 ↔ 程序语义”的桥梁，可保留少量 `DESIGNED` 最小代码示例。

---

# 4. 真题采用前的六项检查

“是真题”本身不等于“适合课程”。采用前仍须检查：

1. 是否服务于当前概念？
2. 是否主要依靠已学知识可解？
3. 是否真正提高概念理解或问题解决能力？
4. 是否存在更适合当前目标的国内 / 国际真题？
5. 是否需要改编以降低超前工具依赖？
6. 题源是否真实可追溯？

---

# 5. 题源标记示例

```text
SOURCE · 2024 武汉市某区七年级期末 · Q18
ADAPTED · 某权威国内数学竞赛 20XX · 初中组 · Q5
ADAPTED · 2023 AMC 8 · Problem 3
SYNTHESIS · 国内中考真题 + AMC 8 + 本讲模型
```

若题目情境、数字、条件或问法发生实质变化，必须标 `ADAPTED` 或 `SYNTHESIS`，不能仍写成“原题”。

---

# 6. Po-Shen Loh（罗博深）的角色：方法论，不是题源标签

课程借鉴：陌生问题先独立探索、少做重复练习、逐级 hints、一题多解、解后一般化、鼓励学生自己创造策略。

原则：

> **先问题，后方法；先探索，后提示；先理解结构，后记技巧。**

除非题目确实来自其公开材料，否则不得把其他题标成“罗博深题”。

---

# 7. 原创比例原则

原创不是禁止，而是受控。

- Core：`TEXTBOOK-MODEL / SOURCE / ADAPTED` 为主；
- Advanced：真实考试 / 竞赛模型 + 必要方法题；
- Olympiad：优先 `SOURCE / ADAPTED / SYNTHESIS`；
- Informatics：有合适正式题源时优先，没有时再用最小教学原创；
- `DESIGNED` 主要补题库覆盖空白。

不设机械百分比。发布前必须能回答：

> 为什么这道原创题不能简单由已有真题替代？

---

# 8. Final Challenge｜每讲强制要求

每讲最后至少一道高强度综合题。

必须满足：

1. 当前知识可解；
2. 题面不直接暴露方法；
3. 存在真正突破口；
4. 题源可靠，优先 `SOURCE → ADAPTED → SYNTHESIS → DESIGNED`；
5. 有 Hint 1 → Hint 2 → Hint 3；
6. 必须“解后再思考”。

国内权威奥赛 / 竞赛题、历年高质量中考或统一考试压轴题、AMC / Gauss / UKMT 等，都可作为 Final Challenge 的直接来源或结构来源。

---

# 9. 题源审计文件

每讲发布前建立：

```text
sources/XX-lesson-name-provenance.md
```

必须记录：

- 题号 / 内容；
- 类型标签；
- 教材 / 赛事 / 考试 / 年份 / 地区 / 题号；
- 官方或可靠来源；
- 改编程度；
- 当前知识边界检查；
- 教学目的；
- 若为原创，为什么需要原创；
- Final Challenge 是否通过质量检查。

---

# 10. 发布前最后检查

每一道重要题至少问：

1. 这题是否服务于当前概念？
2. 是否需要尚未学过的知识？
3. 是否存在更权威、更经典、更贴近当前学生的国内或国际真题？
4. 来源是否能核验，而不是只有“真题”标签？
5. 如果原创，原创的必要性是什么？
6. 解答是否解释“为什么”，而不只给过程？
7. 做完以后学生获得的是“题型记忆”还是“可迁移方法”？

只有这些问题能回答清楚，题目才进入正式课程。
