# 题源与原创命题规范

本仓库的训练题采用“教材与真题优先、透明改编、有限原创”的原则。

## 1. 五类题目

- **TEXTBOOK-MODEL**：有正式教材、教师用书或权威配套资源的知识/题型模型依据，但题目文字和数字由课程重新组织；不是教材原题。
- **SOURCE**：基本保留真实考试或竞赛题的数学结构，仅做翻译、单位或数字微调。
- **ADAPTED**：由明确真题的核心结构改编，情境、数字或问法发生变化。
- **SYNTHESIS**：融合多个可追溯题源，并结合本讲知识重新设计。
- **DESIGNED**：教学原创。只用于现有教材与题库无法精确覆盖的重要概念、反例、易错点、方法或迁移目标。

## 2. 使用原则

1. Core 与常规应用题首先检查教材、教师用书和权威同步资源，能归入教材模型的，不随意标为原创。
2. Advanced / Olympiad 首先检索校内考试、CEMC、AMC、UKMT 等真实题源。
3. Informatics 数学首先检索 CSP-J/NOI 等正式题目；若当前阶段只是在建立数学—程序语义映射，可使用少量 `DESIGNED` 教学示例，但不得冒充竞赛题。
4. 不为了提高“真题比例”而引入与当前知识弱相关、需要大量超前知识的题。
5. 所有改编题保留教材/赛事名称、年份、组别和题号等可追溯信息。
6. 原创题必须明确标注 `DESIGNED`，并说明它补充了什么现有题源无法覆盖的教学目标。
7. 每讲的 Final Challenge 原则上使用 `SOURCE / ADAPTED / SYNTHESIS`；若确实需要原创，必须说明现有题源为何不足。
8. 题目正文尽量使用等价改写，避免大段复制受版权保护的原题文本。

## 3. 原创比例原则

原创题不是禁止，而应当**受控**。

理想结构是：

- Core：以 `TEXTBOOK-MODEL / SOURCE / ADAPTED` 为主；
- Advanced：以真实考试/竞赛模型和透明改编为主；
- Olympiad：尽量来源于正式竞赛题或其结构改编；
- Informatics：有合适正式题源时优先使用，没有时才用最小教学原创；
- `DESIGNED` 只补“现有题源覆盖空白”，而不是成为默认出题方式。

不设机械百分比，因为不同知识点的公开题源密度不同；但发布前必须解释为什么保留每一道重要原创题。

## 4. Final Challenge 标准

每讲最后至少保留一道高强度综合题，用于检验：

- 是否真正理解概念；
- 是否能在陌生情境中主动选择方法；
- 是否能把多个本讲结构综合起来；
- 是否能从个别量转向整体、不变量、分类或构造等更高层思维。

Final Challenge 的难度目标是“奥赛/高水平竞赛思维”，但原则上主要依靠本讲及此前已学知识解决，避免用尚未学习的高级公式直接碾压。

## 5. 题源审计

每讲发布前应建立或更新对应的 `sources/*-provenance.md`，记录：

- 题号；
- `TEXTBOOK-MODEL / SOURCE / ADAPTED / SYNTHESIS / DESIGNED` 类型；
- 官方或权威来源；
- 改编程度；
- 教学目的；
- 若为原创，说明为什么需要原创。

这样可以同时保证课程的可靠性、覆盖完整性和教学针对性。
