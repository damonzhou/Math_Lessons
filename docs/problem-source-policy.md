# 题源与原创命题规范

本仓库的训练题采用“真题优先、透明改编、有限原创”的原则。

## 1. 四类题目

- **SOURCE**：基本保留真实题目的数学结构，仅做翻译、单位或数字微调。
- **ADAPTED**：由明确真题的核心结构改编，情境、数字或问法发生变化。
- **SYNTHESIS**：融合多个可追溯题源，并结合本讲知识重新设计。
- **DESIGNED**：教学原创。只用于现有题目无法精确覆盖的重要概念、反例、易错点、方法或迁移目标。

## 2. 使用原则

1. 能找到高度匹配的教材题、考试题或竞赛题时，优先使用真实题源或等价改编。
2. 不为了提高“真题比例”而引入与当前知识弱相关、需要大量超前知识的题。
3. 所有改编题都必须保留赛事/教材名称、年份、组别和题号等可追溯信息。
4. 原创题不能冒充真题，必须明确标注 `DESIGNED`，并能说明它补充了什么现有题源无法覆盖的教学目标。
5. 每讲的 Final Challenge 原则上使用 `SOURCE / ADAPTED / SYNTHESIS`；若确实需要原创，必须说明现有题源为何不足。
6. 题目正文尽量使用等价改写，避免大段复制受版权保护的原题文本。

## 3. Final Challenge 标准

每讲最后至少保留一道高强度综合题，用于检验：

- 是否真正理解概念；
- 是否能在陌生情境中主动选择方法；
- 是否能把多个本讲结构综合起来；
- 是否能从个别量转向整体、不变量、分类或构造等更高层思维。

Final Challenge 的难度目标是“奥赛/高水平竞赛思维”，但原则上主要依靠本讲及此前已学知识解决，避免用尚未学习的高级公式直接碾压。

## 4. 题源审计

每讲发布前应建立或更新对应的 `sources/*-provenance.md`，记录：

- 题号；
- `SOURCE / ADAPTED / SYNTHESIS / DESIGNED` 类型；
- 官方或权威来源；
- 改编程度；
- 教学目的；
- 若为原创，说明为什么需要原创。

这样可以同时保证课程的可靠性、覆盖完整性和教学针对性。
