# 题源与原创命题规范｜v1.4 工作版

> 规范优先级以 `docs/standards/CURRENT.md` 为准。本文件用于日常 Lesson 编写。

核心原则：

> **课标/教材约束优先 + 权威一手真题优先 + 透明改编 + 有限原创 + 解后推广。**

---

# 1. 先检查知识边界

选题之前先确认：

1. 教育部《义务教育数学课程标准（2022年版）》；
2. 人教版当前教材/教师用书顺序；
3. 学生截至本讲已正式学习的工具。

漂亮真题若明显超纲，应延后或适龄改编，不能偷偷使用后续公式。

---

# 2. 题目标签

- **TEXTBOOK-MODEL**：正式教材/教师用书模型依据，但不是教材原题；
- **SOURCE**：基本保留可核验真实考试/竞赛题数学结构；
- **ADAPTED**：明确真题核心结构改编；
- **SYNTHESIS**：融合两个或以上可追溯权威题源；
- **DESIGNED**：少量教学原创，只补重要教学空白。

不得把改编题称为原题。

---

# 3. 权威来源层级

## 3.1 课程与教材

原则上只使用：

- 教育部正式课程标准/课程方案；
- 人民教育出版社官方教材、教师用书、修订说明和官方资源；
- 用户提供的学校正式教材/试卷/讲义；
- 必要时其他教育主管部门正式文件。

## 3.2 国内真实考试

可使用：

- 学校正式期中/期末试卷；
- 区县市统一考试；
- 中考真题；
- 教育主管部门/考试机构正式原卷或可靠正式出版物。

至少记录年份、地区/学校/组织方、考试类型、题号和可靠来源。

来源不明的“某名校真题”不得标 `SOURCE`。

## 3.3 国际权威奥赛/竞赛

包括但不限于：

- **MAA**：AMC 8 / AMC 10 / AMC 12、AIME、USAJMO、USAMO；
- **IMO**：官方历年题、官方公开 Shortlist；
- **University of Waterloo CEMC**：Gauss 等；
- **UKMT**：JMC / JMO 等官方竞赛。

## 3.4 国内权威奥赛/竞赛

包括但不限于：

- **CMO（中国数学奥林匹克）**；
- 全国高中数学联赛；
- 中国女子数学奥林匹克；
- 中国数学会及其相关竞赛委员会正式组织的赛事；
- 其他具有明确主办方、正式赛制、可核验原题/正式出版物的权威赛事。

## 3.5 Informatics

优先参考：

- CSP-J / CSP-S；
- NOI / NOIP 等官方题目中的数学模型；
- 正式算法题中的整数、坐标、计数、递推、模运算结构。

---

# 4. 权威不等于适龄

选择题目按：

$$
\boxed{\text{教学匹配度}+\text{来源权威性}+\text{当前可解性}+\text{思维价值}}
$$

综合判断。

七年级通常最常直接使用 AMC 8、Gauss、教材/真实校内考试等适龄来源。

IMO、CMO、AIME、USAMO 等高阶赛事只有在：

- 当前知识可解；或
- 可以保留核心结构做透明适龄改编；

时才进入当前 Lesson。

**不能为了赛事名气而超纲。**

---

# 5. 禁止作为课程依据的来源

以下只能作为搜索线索，不能用于认证知识或真题：

- 新闻报道；
- 自媒体；
- 商业培训机构转载题库；
- 论坛/博客；
- 搜索引擎摘要；
- 无原始出处的“历年奥赛真题合集”。

搜索工具只用于定位官方一手资料。

---

# 6. provenance 必须记录

每讲维护：

```text
sources/XX-lesson-provenance.md
```

对重要题至少记录：

- 类型标签；
- 赛事/考试/教材；
- 年份；
- 地区/组别/轮次；
- 题号；
- 官方页面、官方题目/解答或正式出版物；
- 改编内容；
- 当前知识边界；
- 教学目的；
- 若为 DESIGNED，为什么必须原创。

---

# 7. Final Challenge

优先顺序：

1. 高匹配度权威 `SOURCE`；
2. 当前知识可解的 `ADAPTED`；
3. 权威结构融合的 `SYNTHESIS`；
4. 确有教学空白才 `DESIGNED`。

必须当前知识可解、题面不泄露方法、有真正突破口、三级提示并能解后推广。

---

# 8. 发布前题源 Review

每个 Lesson 发布前检查：

- 是否主动查看教材、国内考试、AMC/CEMC/UKMT/IMO/CMO 等权威池中有无更合适问题；
- 是否真正追溯到官方资料；
- 是否为了使用高级赛事而超纲；
- 是否把 ADAPTED 写成 SOURCE；
- 原创题是否有不可替代的教学目的。
