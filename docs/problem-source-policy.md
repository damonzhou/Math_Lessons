# 题源与原创命题规范

本仓库训练题采用：

> **课标/教材约束优先 + 高质量真题优先 + 透明改编 + 有限原创 + 解后推广**

目标不是追求“真题比例最大化”，而是保证每一道重要题都知道：

- 为什么现在可以做；
- 为什么值得做；
- 它从哪里来；
- 改了什么；
- 做完以后应该学到什么。

---

# 1. 出题前先过“知识边界”检查

任何题源选择之前，先确认：

1. 《义务教育数学课程标准（2022年版）》对当前学段的要求；
2. 人教版当前教材章节的知识顺序与教学重点；
3. 学生截至本讲已经学过哪些工具。

因此：

- 课标和人教版决定 **Core 内容、顺序和最低掌握深度**；
- 竞赛题不能为了“难”而大量使用尚未学习的公式；
- 如果一道漂亮真题严重超出当前知识边界，应延后使用或做结构化改编；
- `EXTENSION` 可以提前展示未来观点，但必须明确“不要求当前记忆/掌握”。

官方基准：

- 教育部《义务教育数学课程标准（2022年版）》  
  https://www.moe.gov.cn/srcsite/A26/s8001/202204/W020220420582346895190.pdf
- 人民教育出版社教材/教师用书  
  https://www.pep.com.cn/

# 2. 五类题目标签

## TEXTBOOK-MODEL

有正式教材、教师用书或权威配套资源的知识/题型模型依据，但题目文字、数字或情境由课程重新组织。

**不是教材原题。**

## SOURCE

基本保留真实考试或竞赛题的数学结构，只做翻译、单位、数值或表述上的轻微调整。

## ADAPTED

由明确真题的核心数学结构改编，情境、数字、问法或难度发生变化。

## SYNTHESIS

融合两个或以上可追溯题源的结构，再结合本讲知识重新设计。

## DESIGNED

教学原创。只有当教材和现有题库不能精确覆盖某个重要概念、反例、易错点、方法或迁移目标时使用。

# 3. 题源优先池

## 3.1 Core / 校内主线

优先：

1. 人教版教材；
2. 人教版教师教学用书；
3. 权威同步资源；
4. 真实期中、期末、中考题型。

Core 题首先检查是否能归入 `TEXTBOOK-MODEL`，不要把教材典型模型误标为原创。

## 3.2 Olympiad / 高阶思维

优先级建议：

### AMC 8｜重点来源

AMC 8 面向 8 年级及以下学生，官方定位就是在中学数学范围内发展 problem solving，因此是本课程七、八年级非常重要的题源池。

官方入口：
https://maa.org/student-programs/amc/

官方样题示例：
https://maa.org/resource/sample-competition-2023-amc-8/

使用方式：

- 可作为 `SOURCE / ADAPTED / SYNTHESIS` 来源；
- 必须标年份和题号；
- 不大段复制原题；
- 需要改编时说明改编原因；
- 若原题用到尚未学习知识，应保留核心结构、降低工具门槛，而不是偷偷使用超前公式。

### CEMC Gauss

非常适合七、八年级，尤其适合作为数感、代数、平均数、规律、几何和综合思维来源。

官方历年题：
https://cemc.uwaterloo.ca/resources/past-contests

### UKMT JMC / JMO

用于逻辑、数论、几何、组合和更具“奥赛感”的问题。

### AMC 10｜选择性使用

只选择：

- 与当前知识高度相关；
- 不依赖大量高中工具；
- 使用当前知识可以发现漂亮解法的题。

不能因为 AMC 10 “更难”就机械提前。

## 3.3 Informatics

优先参考：

- CSP-J；
- NOI/NOIP 中适合当前阶段的数学模型；
- 正式算法题中的整数、坐标、计数、递推、模运算等结构。

若当前只是建立“数学概念 ↔ 程序语义”的桥梁，可保留少量 `DESIGNED` 最小代码示例。

# 4. AMC 使用与署名规则

MAA 官方 AMC 资料允许教育用途使用，并要求清楚注明赛事、年份与题号。课程仓库因此采取：

- 优先**等价改编/结构改编**而不是全文复制；
- 题源表写明例如：`2023 AMC 8, Problem 3`；
- 不把改编题写成“AMC 原题”；
- 若采用完整原题，需要明确署名并遵守 MAA 的版权/使用要求。

MAA 2023 AMC 8 官方解答说明：
https://maa.org/wp-content/uploads/2024/08/2023_AMC8_Solutions_.pdf

# 5. Po-Shen Loh（罗博深）的角色：方法论，不是题源标签

Po-Shen Loh 的 Daily Challenge 强调：

- 面对陌生问题先独立探索；
- 少做重复练习，多做需要 fresh creativity 的问题；
- 用 hints 帮助学生继续创造，而不是马上展示模板；
- 即使已经解出，也值得比较不同方法；
- 从具体问题继续发现更深结构。

参考：
https://daily.poshenloh.com/courses/0-introduction

因此本仓库借鉴以下**问题设计方法**：

1. 先问题，后方法；
2. 给独立思考时间；
3. 逐级提示；
4. 一题多解；
5. 解后一般化；
6. 少量高价值问题优先于大量同型题。

但：

> **Po-Shen Loh 是教学方法参考，不等于某道题的真实题源。**

除非题目确实来自其公开材料，否则不得把 `DESIGNED` 或其他竞赛题标成“罗博深题”。

# 6. 原创比例原则

原创不是禁止，而是受控。

理想结构：

- Core：`TEXTBOOK-MODEL / SOURCE / ADAPTED` 为主；
- Advanced：真实考试/竞赛模型 + 必要方法题；
- Olympiad：优先 `SOURCE / ADAPTED / SYNTHESIS`；
- Informatics：有合适正式题源时优先，没有时再用最小教学原创；
- `DESIGNED` 主要补题库覆盖空白。

不设机械百分比，因为不同知识点的公开题源密度不同。

发布前必须能回答：

> “为什么这道原创题不能简单由已有真题替代？”

# 7. Final Challenge｜每讲强制要求

每讲最后至少一道高强度综合题。

## 六条硬标准

### 1. 当前知识可解

主要依靠本讲和此前已经学习的知识。

### 2. 题面不直接暴露方法

学生必须自己识别结构，而不是看到题型名称就套模板。

### 3. 存在真正突破口

难点应来自：

- 观察；
- 转化；
- 整体；
- 分类；
- 构造；
- 不变量；
- 数形结合；

而不是单纯增加计算量。

### 4. 题源可靠

优先：

`SOURCE → ADAPTED → SYNTHESIS → DESIGNED`

若 Final Challenge 为原创，题源审计必须说明现有题源为什么不足。

### 5. 有三级提示

- **Hint 1**：只给观察方向；
- **Hint 2**：指出关键量/关系；
- **Hint 3**：给接近建模层面的提示；
- 最后才给完整解析。

### 6. 必须“解后再思考”

至少加入一项：

- 从数字推广到字母；
- 改变条件；
- 找第二种解法；
- 比较两种解法本质；
- 构造同类问题；
- 连接后续数学；
- 连接算法/信息学。

Final Challenge 的结束点不是“得出答案”，而是：

$$
\text{具体问题}\rightarrow\text{方法}\rightarrow\text{一般结构}
$$

# 8. 题源审计文件

每讲发布前建立：

```text
sources/XX-lesson-name-provenance.md
```

必须记录：

- 题号/内容；
- 类型标签；
- 教材/赛事/年份/题号；
- 官方链接；
- 改编程度；
- 当前知识边界检查；
- 教学目的；
- 若为原创，为什么需要原创；
- Final Challenge 是否通过六项质量检查。

---

# 9. 发布前最后检查

每一道重要题至少问：

1. 这题是否服务于当前概念？
2. 是否需要尚未学过的知识？
3. 是否存在更权威、更经典的真题模型？
4. 如果原创，原创的必要性是什么？
5. 解答是否解释“为什么”，而不只给过程？
6. 做完以后学生获得的是“题型记忆”还是“可迁移方法”？

只有这些问题能回答清楚，题目才进入正式课程。
