# 课程标准 v1.7｜教材映射与发布门禁

> **状态**：LOCKED / 增量标准  
> **生效日期**：2026-09-01  
> **基于**：v1.3 + v1.4 + v1.5 + v1.6

---

# 1. 为什么增加本标准

正式 Mainline Lesson 不仅要“内容正确、顺序合理”，还必须能够回答：

> **这一讲在人教版当前教材中对应哪个章、哪个知识节点？为什么需要拆成这一讲？**

此前出现“集合专题数学上有价值，但被误提升为正式 Lesson 3”的问题，说明只检查知识关联还不够。

从 v1.7 起，教材映射成为发布门禁的一部分。

---

# 2. 当前教材依据

七年级上册课程以 **依据《义务教育数学课程标准（2022年版）》修订的人教版初中数学教材** 为主线。

人民教育出版社官方新教材介绍已明确：

- 将原“有理数”拆分为“有理数”和“有理数的运算”；
- 新增“代数式”章；
- 整体结构按数学逻辑、连续性、整体性、关联性重新设计。

官方依据：

- 人教版义务教育数学（七～九年级）新教材介绍  
  https://www.pep.com.cn/xw/zt/hd/12/xjcjs/cz/202408/t20240826_1994351.html
- 李海东《突出数学本质 重视思维过程 发展核心素养》  
  https://www.pep.com.cn/xw/zt/hd/12/zbtjc/202410/t20241022_1996035.html
- 教育部《义务教育数学课程标准（2022年版）》

对于人教社官方公开页面未展示的新版细小节编号：

> **只记录能够权威核实的章名/知识节点，不猜测小节编号。**

旧版人教社教师用书可用于确认长期稳定的知识依赖（如“数轴→相反数→绝对值”），但不得冒充新版目录证据。

# 3. 36讲教材映射表

七上当前正式映射维护在：

`docs/textbook-mapping-grade-07-semester-1.md`

该文件是 Mainline 课程定位的工作依据。

每个 Mainline Lesson 必须记录：

1. 当前人教版章/知识群；
2. 对应核心知识节点；
3. 映射类型；
4. 为什么需要独立成讲；
5. 哪些内容属于 Advanced/Olympiad/Informatics，而不是教材 Core；
6. 与前后 Lesson 的教材依赖。

---

# 4. 映射类型

统一使用：

- **DIRECT**：基本对应一个教材知识节点；
- **SPLIT**：教材一个知识节点因概念深度/训练需要拆成多讲；
- **INTEGRATED**：教材多个已学节点的综合课，不对应独立小节；
- **BRIDGE**：教材正式内容之间必要的认知桥梁；
- **EXTENSION**：不是当前教材主线，不占正式 Lesson 编号。

`BRIDGE` 必须有明确教材依赖理由，不能成为把竞赛专题塞入 Mainline 的借口。

---

# 5. Release Review 新增 R0.5

从 v1.7 起，Mainline Lesson 的 Release Review 在 R0 后增加：

## R0.5｜教材映射

必须检查：

- [ ] 已在当前教材映射表中找到本 Lesson；
- [ ] 章/知识节点正确；
- [ ] DIRECT / SPLIT / INTEGRATED / BRIDGE 定位合理；
- [ ] Core 没有把 Extension 内容冒充教材内容；
- [ ] 若教材结构发生变化，先更新映射表，再发布 Lesson；
- [ ] 没有使用未经权威核实的新版小节编号。

R0.5 不通过时，Lesson 最高只能 `REVISE`。

---

# 6. 每个 Lesson 头部增加教材映射

Mainline Lesson 元数据增加：

```text
教材映射：当前人教版七上 · <章/知识群> · <知识节点>
映射类型：DIRECT / SPLIT / INTEGRATED / BRIDGE
```

若为综合课，应明确：

> 本讲不对应教材独立小节，而是对已经学习的教材节点做综合迁移。

---

# 7. 课程路线图变更规则

如果教材映射审计发现：

- Lesson 顺序与当前教材冲突；
- 某知识节点遗漏；
- 某综合课占据了更强主线的位置；
- 教材新版新增/拆分正式内容；

则应先调整路线图，再建设后续 Lesson。

不能因为已经写过旧路线图就继续错误编号。

---

# 8. 与 v1.5 / v1.6 的关系

v1.7 不改变：

- Mainline / Extension 分层；
- 权威题源体系；
- Final Challenge 规则；
- H1～H10 诊断体系；
- Markdown / LaTeX R11 检查。

它新增的是：

$$
\boxed{\text{教材映射成为 Mainline 发布的硬门槛}}
$$

完整 Review 顺序变为：

```text
R0   Mainline / Extension 定位
R0.5 教材映射
R1   课程逻辑
...
R10  前后衔接
R11  Markdown / LaTeX 渲染
```
