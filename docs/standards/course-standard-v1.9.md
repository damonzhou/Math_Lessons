# 课程标准 v1.9｜最高深度覆盖与能力上限诊断

> **状态**：LOCKED / 增量标准  
> **生效日期**：2026-09-02  
> **基于**：v1.3 + v1.4 + v1.5 + v1.6 + v1.7 + v1.8

# 1. 核心原则

课程不得以“达到课标最低要求”作为完成标准。

课标和教材首先确定：

- 学什么；
- 先后顺序；
- 概念边界；
- 不可遗漏的 Core。

但课程深度目标必须继续向上覆盖，直到当前知识边界内具有教学意义的最高层级。

统一原则：

> **课标是底线和边界，不是深度上限。**

课程最终目标仍然是：

```text
会认 → 会用 → 会解释 → 会迁移 → 能独立发现结构
```

---

# 2. “最高标准”怎样定义

“最高标准”不等于提前教授高中知识，也不等于机械使用 IMO/CMO 高难题。

本课程中的“最高标准”定义为：

> **只依赖本讲及此前已经正式学习的知识，在不引入隐藏后续知识的前提下，学生能够达到的最高概念深度、条件分析能力、陌生迁移能力和结构发现能力。**

因此必须同时满足：

1. 当前知识可解；
2. 不靠后续公式碾压；
3. 允许题面陌生、结构复杂；
4. 可以达到校内高档题、适龄竞赛甚至选择性改编的高阶竞赛结构；
5. 高难度来自思维，而不是来自未学知识。

公式：

```text
高深度 ≠ 超前知识
高深度 = 当前知识的深理解 + 陌生结构 + 独立发现 + 迁移
```

# 3. 每讲五层覆盖矩阵

从 v1.9 起，每个 Mainline Lesson 必须同时检查五层。

## L1｜教材完整层

不是“最低会做”，而是完整覆盖当前教材节点的：

- 定义；
- 性质；
- 表示；
- 正例；
- 反例；
- 边界；
- 规范表达；
- 典型应用。

## L2｜概念深度层

必须尽量覆盖：

- 为什么需要这个概念；
- 与相近概念区别；
- 多种表示之间的关系；
- 条件变化后什么仍成立、什么不成立；
- 特殊值/边界值；
- 能否给出反例；
- 能否用自己的语言解释。

## L3｜校内高阶层

至少包含若干：

- 逆向问题；
- 条件隐藏；
- 参数意识；
- 分类讨论；
- 多条件筛选；
- 数形结合；
- 综合应用；
- 常见压轴结构。

## L4｜竞赛/信息学迁移层

优先从权威来源池选择适龄结构：

- AMC / CEMC / UKMT；
- 国内正式考试/竞赛；
- 选择性使用 AIME / IMO / CMO / 全国高中数学联赛等当前知识可解的结构；
- CSP-J / NOI 等信息学数学结构。

重点是陌生表示、结构发现、一般化、算法化，而不是赛事名气。

## L5｜能力上限诊断层

必须存在至少一道 **Ceiling Diagnostic（上限诊断题）**，用于测量学生真实能力上限。

它不是普通练习，也不是教完方法后的同类题。

---

# 4. Ceiling Diagnostic 的硬规则

## 4.1 时机

原则上放在：

```text
Core 概念学习完成
→ Ceiling Diagnostic 冷启动
→ 再进入 Advanced / Olympiad 方法讲解
```

这样才能区分：

- 学生自己能发现；
- 经过提示能发现；
- 教过以后会做。

## 4.2 题面要求

Ceiling Diagnostic 必须：

1. 当前及此前知识足够；
2. 不直接提示方法；
3. 在此前例题中没有出现高度同构的完整模板；
4. 至少有一个真实突破口；
5. 最好能有多种方法或一般化；
6. 优先有权威真题/改编/结构来源；
7. 如果使用 DESIGNED，必须解释为什么现有权威题不足以完成诊断目标。

## 4.3 第一次作答禁止提示

第一次尝试建议 10～20 分钟：

- 不看答案；
- 不看 Hint；
- 不先复习同模板例题；
- 记录独立思考过程。

## 4.4 Hint 分级

独立尝试后才能依次开放：

- Hint 1：方向；
- Hint 2：关键关系/量；
- Hint 3：建模或核心结构；
- Full Solution。

---

# 5. 上限诊断记录

不能只记录“对/错”。

每次 Ceiling Diagnostic 至少记录：

| 结果 | 含义 |
|---|---|
| C5-A | 独立完成，能解释突破口并一般化 |
| C5-B | 独立找到核心结构，存在次要运算/表达问题 |
| C5-C | Hint 1 后完成 |
| C5-D | Hint 2 后完成 |
| C5-E | Hint 3 后完成 |
| C5-F | 看完整解答后才能理解 |

另外记录：

- 首个卡点；
- 使用了哪些已有知识；
- 是否出现 H1～H10 习惯错误；
- 是否能完成变式；
- 7天后是否能在不同表面结构中迁移。

这样才能判断学生真实情况，而不是只看正确率。

---

# 6. Mastery Challenge 与 Ceiling Diagnostic 必须区分

## Mastery Challenge

用途：

> 检查本讲经过教学后是否真正掌握并能迁移。

可以建立在本讲 Advanced/Olympiad 已教方法之上。

## Ceiling Diagnostic

用途：

> 检查在方法尚未被直接教授时，学生能否独立发现结构。

两者不能混为一谈。

一个现有 Final Challenge 如果在前文已经完整教过高度同构的方法，只能视为 Mastery Challenge，不能作为唯一的 Ceiling Diagnostic。

# 7. Release Review 新增 R3.5

从 v1.9 起，在 R3“概念深度”后增加：

## R3.5｜最高深度与能力上限诊断

必须检查：

- [ ] L1 教材完整层覆盖；
- [ ] L2 概念深度层覆盖；
- [ ] L3 校内高阶层覆盖；
- [ ] L4 竞赛/信息学迁移层覆盖；
- [ ] L5 Ceiling Diagnostic 已建立；
- [ ] Ceiling Diagnostic 在方法讲解前冷启动；
- [ ] 没有靠后续知识制造“假难度”；
- [ ] 题目不是刚教过模板的简单换皮；
- [ ] 有 Hint 分级但首次尝试不可见；
- [ ] 有 C5-A～F 结果记录标准；
- [ ] 有至少一个延迟迁移检查。

R3.5 不通过时，Lesson 可以作为普通教学稿使用，但不得标记为“最高深度覆盖完成”。

# 8. 对权威题源池的要求

v1.8 的候选题源池审查继续执行。

为了探测上限，provenance 除“实际采用”和“候选池审查”外，还要明确：

> **哪一道题承担 Ceiling Diagnostic，为什么它能区分学生能力层级。**

优先顺序不是赛事等级，而是：

```text
当前知识可解性
+ 结构新颖度
+ 诊断区分度
+ 权威性
+ 一般化价值
```

AMC 8 / Gauss / JMC 往往适合直接使用；AMC 10 / AIME / IMO / CMO 等只在当前知识足够时选择性使用或透明改编。

# 9. 对前4课的影响

Lesson 1～4 原有 Review 的 `PASS` 代表：

> 在当时标准下课程逻辑、Core、题源、训练和 Final Challenge 合格。

v1.9 生效后，需要额外进行“最高深度覆盖审计”。

如果原 Final Challenge 已被前文同构方法充分教学，则应：

- 保留为 Mastery Challenge；
- 另增 Ceiling Diagnostic；
- 不把原 PASS 误解释成已经完成上限诊断。

---

# 10. 发布原则

从 Lesson 5 开始，新课默认同时满足 v1.9。

Lesson 1～4 需要逐课补做 v1.9 兼容审计。

最终原则：

> **课程不仅要保证“不会漏教”，还要能够可靠地区分：学生只是会做、真正理解、能迁移，还是能独立发现新结构。**
