# 1｜当前课程定位

本课程不是从零开始讲教材的基础自学课。

默认学生已经学过当前教材基本内容，课程目标：

```text
教材知识点100%覆盖
→ Gap Check快速查漏
→ 只补真实漏洞
→ 概念本质与边界
→ 应用与陌生迁移
→ 校内中高阶
→ 适龄竞赛式拔高
→ 能力上限验证
→ 针对短板提升
```

必须同时做到：

1. 教材完整；
2. 已会基础不重复消耗课时；
3. 概念理解比教材例题更深；
4. 覆盖真实中高阶；
5. 能测试出学生当前能力上限；
6. Ceiling Builder 必须针对首个真实短板；
7. 难度来自结构，不来自长计算或超前知识。

```text

```

基础稳定时应更快进入高阶。

# 3｜难度分层

| 层级 | 难度 | 功能 |
|---|---|---|
| Gap Check | ★ | 快速检查教材基本内容 |
| Concept Deepening | ★★～★★★ | 本质、边界、反例、迁移 |
| School Advanced | ★★★ | 校内中高阶、综合、压轴结构 |
| Competition Transfer | ★★★～★★★★ | 适龄竞赛式陌生结构 |
| Elite / Final Challenge | ★★★★～★★★★★ | 15～30分钟独立突破、完整推理、一般化 |

Final 至少包含以下三项中的两项：

- 条件变化 / 删条件；
- 唯一性或穷尽性证明；
- 参数化 / 一般化。

# 4｜能力上限与短板提升硬规则

Ceiling Diagnostic 不是“再做一道稍难题”。

它必须能区分学生最早卡在：

```text
建模
条件使用
结构发现
分类/枚举
完整性证明
最少性证明
一般化
```

记录**首个卡点**，而不是只记录最后对错。

Ceiling Builder 必须按首个卡点分流：

```text
不会建模
→ 训练表示转换

条件不会用
→ 训练条件作用

会做但漏情况
→ 训练结构化枚举

会列全但不会证明
→ 训练完整性/唯一性

会给方案但不会证明最少
→ 训练上界 + 下界

全部稳定
→ 直接参数化/陌生迁移
```

如果学生 T0/Final 都明显低于目标耗时并独立一般化，不增加基础题，直接提高下一讲 Ceiling 难度。

# 5｜v2.2 思维深度仍为硬规则

每讲至少覆盖 D1～D6 中四类：

```text
D1 结构发现
D2 条件充分性 / 必要性
D3 反例与边界
D4 唯一性 / 穷尽性 / 分类完整性
D5 具体 → 参数 → 一般化
D6 表示转换与陌生迁移
```

至少有一处要求回答：

> **为什么答案只有这些？**

高阶题继续问：

> **如果把计算量大幅降低，这道题还剩下什么值得思考？**

若几乎没有，则不能算思维深度。

---

# 6｜Final Challenge v2.3 门槛

发布前必须同时满足：

1. 一个校内数学明显优秀、已经学过基础内容的七年级学生，很可能需要独立思考15～30分钟才能完整解决；
2. 大幅降低计算量后，题目仍有真实结构突破口。

不能靠：

- 大数字；
- 长计算；
- 更多分数；
- 超前公式；
- 高级赛事名称。

# 7｜Release Review 新门禁 R2.7

必须检查：

- 是否错误地把学生当第一次学习基础内容；
- 教材知识点是否100%覆盖；
- 是否用 Gap Check 替代不必要的基础重复；
- 主要增量是否落在概念深化、应用和中高阶；
- School Advanced 是否达到真实校内中高阶；
- Competition / Final 是否能拉开优秀学生差距；
- Final 是否有15～30分钟独立思考价值；
- Ceiling Diagnostic 是否能定位首个短板；
- Builder 是否真正针对短板；
- 难度是否来自结构。

R2.7 不通过，最高结论只能 `REVISE`。

# 8｜题源与链接

- 主线依据：教育部课标、人教版官方教材/教师资源；
- 高阶题源优先审查：CEMC Gauss 中后段、AMC 8、UKMT JMC/JMO、国内正式考试压轴、适龄正式竞赛、适合的 CSP-J 数学结构；
- AMC10/12、AIME、IMO、CMO 等只在年龄匹配、当前知识可解且结构有价值时使用；
- CEMC Gauss 前段题可用于 Gap Check / Bridge，但不能长期承担 Elite；
- `SOURCE / ADAPTED` 题题旁必须直接给官方原题和官方解答链接；
- `SYNTHESIS` 必须说明无单一原题并列结构来源；
- `DESIGNED` 不伪造真题来源；
- provenance 必须显式审查 AMC / IMO / CMO / CEMC / UKMT / 国内正式来源。

## Lesson 7｜v2.3 高阶升级

**已完成。**

旧 v2.2 最高层：

```text
0 < a < b
→ 镜像排序

重复绝对值
→ 相反数对
→ 负数个数筛选
```

已升级为：

```text
0 < |a| < |b| < |c|
→ 未知符号
→ 全部可能标签排序
→ 证明两种排列不可能
→ 从排名反推 b,c 符号
→ 证明 a 的符号不可恢复

四变量 Final
→ 最大绝对值占端点
→ 递归剥离
→ 不枚举16种符号组合得到全部8种排名
→ 从排名恢复 b,c,d
→ 最少1位额外方向信息
→ 同时证明0次不够、1次足够
→ 推广到5变量
```

最高难度来自极端结构、递归、反推、完整性和最少信息证明，不来自长计算。
