# 1. 当前课程定位

本课程不是“从零开始讲教材”的基础自学课。

默认学生已经学过当前教材的基本内容，课程目标是：

```text
教材知识点100%覆盖
→ 快速查漏补缺
→ 概念本质与边界
→ 应用与陌生迁移
→ 校内中高阶
→ 适龄竞赛式拔高
→ 能力上限验证
```

必须同时做到：

1. **教材完整**：定义、性质、基本方法、典型应用不能漏；
2. **基础不重复消耗课时**：已掌握内容通过 Gap Check 快速确认；
3. **概念更深**：解释为什么、什么时候不能用、边界在哪里；
4. **应用更强**：同一概念能迁移到陌生表面；
5. **难度够高**：覆盖真实校内中高阶和适龄竞赛式结构；
6. **思维而非蛮算**：难点来自结构、分类、条件、构造、逆向、证明完整性和一般化。

# 2. 课程默认节奏｜v2.3

```text
Gap Check
→ 发现漏洞则定点补讲
→ Concept Deepening
→ School Advanced
→ Ceiling Diagnostic
→ Ceiling Builder
→ Competition Transfer
→ Elite / Final Challenge
→ T1 / T2 迁移验证
```

设计重心建议：

```text
15%～25%  教材快速覆盖 / 查漏
25%～35%  概念深化与应用
25%～35%  校内中高阶 / 综合
15%～25%  竞赛迁移 / Final Challenge
```

不是机械分钟配额；基础稳定时应更快进入高阶。

---

# 3. 难度分层

| 层级 | 难度 | 功能 |
|---|---|---|
| Gap Check | ★ | 快速检查教材基本内容 |
| Concept Deepening | ★★～★★★ | 本质、边界、反例、迁移 |
| School Advanced | ★★★ | 校内中高阶、综合、压轴结构 |
| Competition Transfer | ★★★～★★★★ | 适龄竞赛式陌生结构 |
| Elite / Final Challenge | ★★★★～★★★★★ | 15～30分钟独立突破、完整推理、一般化 |

每讲除极少数过渡课外，至少应有：

- 1组 Gap Check；
- 1个 Concept Deepening 核心问题；
- 至少2个 School Advanced 问题，其中至少1个不是纯计算；
- 至少1个 Competition Transfer 或等价高价值综合题；
- 1个 Elite / Final Challenge。

Final Challenge 至少包含以下三项中的两项：

- 条件变化 / 删条件；
- 唯一性或穷尽性证明；
- 参数化 / 一般化。

# 4. v2.2 思维深度仍为硬规则

每讲从以下 D1～D6 中至少覆盖四类：

```text
D1 结构发现
D2 条件充分性 / 必要性
D3 反例与边界
D4 唯一性 / 穷尽性 / 分类完整性
D5 具体 → 参数 → 一般化
D6 表示转换与陌生迁移
```

至少有一处要求学生回答：

> **为什么答案只有这些？**

高阶题设计继续执行：

> **如果把计算量大幅降低，这道题还剩下什么值得思考？**

若几乎没有，则不能作为“思维深度”的核心题。

---

# 5. Final Challenge 新门槛｜v2.3

发布前必须同时回答：

1. **一个校内数学明显优秀、已经学过基础内容的七年级学生，是否很可能需要独立思考15～30分钟才能完整解决？**
2. **如果显著降低计算量，题目是否仍有真实结构突破口？**

若第1问明显为“否”，最高层难度不足；若第2问为“否”，只是计算难，不是高质量拔高。

Final Challenge 不能仅依赖：

- 大数字；
- 长计算；
- 更多分数；
- 复杂排版；
- 超前公式；
- 更高级赛事名称。

# 6. 新 Release Review 门禁 R2.7

## R2.7｜Audience / Advancement Fit

每讲必须检查：

- 是否错误地把学生当作第一次学习基础内容；
- 教材知识点是否仍100%覆盖；
- 是否用 Gap Check 替代不必要的长篇基础重复；
- 课程主要增量是否落在概念深化、应用和中高阶；
- School Advanced 是否达到真实校内中高阶；
- Competition / Final 是否能拉开优秀学生的能力差距；
- Final 是否有15～30分钟独立思考价值；
- 难度是否来自结构而不是长计算或超前知识。

R2.7 不通过，最高结论只能 `REVISE`。

# 7. 其他现行硬规则

- 主线由教育部课标、人教版官方教材/教师用书及真实知识依赖决定；
- 课标是知识边界和底线，不是深度上限；
- Mainline 必须完成 R0 主线定位与 R0.5 教材映射；
- 人教社未公开新版细小节编号时，不猜编号；
- Advanced / Olympiad / Informatics 不得反客为主改变主线；
- Extension 不得成为未提示的隐藏前置；
- Ceiling Diagnostic 必须在高阶方法完整教学前冷启动；
- Ceiling Builder 必须针对真实卡点，不得机械堆同模板；
- T0 / T1 / T2 用于观察独立突破和迁移变化；
- `SOURCE / ADAPTED` 题必须在题旁给官方原题链接，有官方解答则同时给解答链接；
- `SYNTHESIS` 必须明确“无单一原题”，有具体结构来源时题旁列官方链接；
- provenance 必须区分实际采用来源与候选权威题源池审查；
- AMC / IMO / CMO / CEMC / UKMT / 国内正式竞赛考试等相关候选池必须显式审查；
- 新闻、自媒体、商业题库、论坛、搜索摘要不得作为课程依据或真题认证依据；
- Markdown / LaTeX 必须通过渲染规范；
- 发布前必须通过：

```text
python3 tools/lint_markdown_rendering.py
python3 tools/lint_problem_source_links.py
```

# 8. 权威题源的难度用途

CEMC Gauss 前段、校内基础题可以用于 Gap Check / Concept Bridge，但不能长期承担最高层 Challenge。

高阶层优先审查：

```text
CEMC Gauss 中后段
AMC 8
UKMT JMC / JMO
国内权威正式考试压轴
国内适龄奥赛 / 数学竞赛
适合的 CSP-J 数学结构
```

AMC 10/12、AIME、IMO、CMO 等可作为结构来源，但必须同时满足年龄匹配、当前知识可解、无超前工具依赖和真实结构价值。
