# 1｜当前课程定位

本课程默认学生已经学过当前教材基本内容。

目标链：

```text
教材知识点100%覆盖
→ Gap Check快速查漏
→ 只补真实漏洞
→ 概念本质与边界
→ 灵活应用
→ 校内中高阶
→ 高水平竞赛式结构突破
→ 当前知识范围内的最高思维上限
→ T0/T1/T2迁移验证
```

必须同时做到：

1. 教材完整；
2. 已会基础不重复消耗课时；
3. 概念理解比教材例题更深；
4. 中高阶题达到真实综合难度；
5. 最高层优先考察知识灵活应用与思维深度；
6. 难度来自结构，不来自长计算；
7. 可以综合此前所有正式已学知识，但不能偷用未来工具。

---

# 2｜最高难度的定义｜v2.4

最高难度不再以“普通七年级学生能否做出”作为封顶标准。

> **适龄只约束可使用的知识工具，不约束思维上限。**

最高层应尽量逼近：

> **当前知识点 + 此前已学知识所能达到的最高灵活应用与思维深度。**

目标不是：

```text
对象更多
条件更多
数字更大
步骤更长
```

而是：

```text
知识选择不显然
+ 多知识点自然组合
+ 至少两个非显然思维节点
+ 反推 / 构造 / 极值 / 不变量 / 分类
+ 完整证明
+ 一般化 / 陌生迁移
```

---

# 3｜有效难度必须扣除“教学泄露”

```text
有效难度
=
原始结构难度
−
前文提示 / 同构模板 / 显式方法带来的降难度
```

Elite / Final 原则上必须：

- 题面不直接暴露方法；
- 前文没有完整同构模板；
- 或者必须跨较远表面重新识别结构；
- 第一突破之后仍有第二个非显然思维节点。

---

# 4｜最高层可使用哪些知识

可以使用：

```text
本讲正式知识
+
此前 Mainline 已正式学过的知识
+
已显式训练的一般数学思维工具
```

思维工具包括分类讨论、数形结合、对称、反例、逆向思考、极端/边界、不变量、完整枚举、唯一性证明、最少性证明、特殊到一般。

不能使用尚未正式学习的公式、定理、方程技巧、不等式体系、函数工具等作为关键突破。

原则：

```text
可以综合过去
不能偷用未来
```

---

# 5｜最高层选点原则

每讲最高层建议由：

```text
1个本讲核心知识核
+
2～4个自然相关的既有知识点
+
1～3个高价值思维工具
```

组成。

旧知识必须与本讲存在天然结构联系，并让本讲知识产生新的用法，不为了“综合”随机拼盘。

---

# 6｜难度分层

| 层级 | 功能 |
|---|---|
| Gap Check ★ | 快速检查教材基础 |
| Concept Deepening ★★～★★★ | 本质、边界、反例、表示转换 |
| School Advanced ★★★～★★★★ | 多条件综合、逆向、参数、校内压轴结构 |
| Competition Transfer ★★★★ | 陌生结构、灵活调用已学知识 |
| Elite / Final Challenge ★★★★★ | 当前知识范围内最高灵活应用与思维深度 |

Elite / Final 不以时间作为唯一尺度，但必须具有真实独立突破价值。

---

# 7｜思维深度六维继续生效

```text
D1 结构发现
D2 条件充分性 / 必要性
D3 反例与边界
D4 唯一性 / 穷尽性 / 分类完整性
D5 具体 → 参数 → 一般化
D6 表示转换与陌生迁移
```

---

# 8｜R3.8 Highest-Ceiling Authenticity｜硬门禁

最高层发布前必须检查：

- 是否真正逼近当前知识范围内的思维上限；
- 是否主要考查知识灵活应用，而不是熟练度；
- 是否原则上存在至少两个非显然思维节点；
- 是否扣除了前文教学泄露导致的降难度；
- 是否要求学生自行选择/组合知识；
- 是否包含反推、构造、极值、不变量、完整证明、最少性或一般化中的高价值任务；
- 是否只是增加对象数量、条件数量或计算长度；
- 是否错误地因为“七年级”降低思维标准；
- 是否错误地通过未来知识制造难度。

R3.8 不通过，最高结论只能 `REVISE`。

# 9｜题源策略

主线依据由教育部课标和人教版官方资料决定。

最高层优先审查 CEMC Gauss 中后段、AMC 8、UKMT JMC/JMO、国内权威正式考试压轴、适龄正式竞赛和适合的 CSP-J 数学结构；同时允许从更高赛事中筛选“知识门槛低、结构价值高”的问题或结构，前提是当前知识可解或可透明降阶改编。

赛事名气本身不构成难度证据。

`SOURCE / ADAPTED / SYNTHESIS` 继续执行题目级官方链接要求。
