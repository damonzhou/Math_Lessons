## 使用规则

1. 开始新 Lesson 或修改课程结构前，先读取本文件；
2. 再读取这里指向的版本化标准；
3. 不以聊天记忆、旧会话摘要或临时讨论替代仓库标准；
4. 用户明确修改标准时，新建版本文件，例如 `course-standard-v1.1.md`；
5. 只有新版本完整归档后，才更新本文件的当前版本指针；
6. 已归档版本不得覆盖修改。

如果当前会话中的一般性建议与这里的版本化标准冲突，以用户当前明确指令优先；否则以这里指向的标准为准。
