## 当前必须执行的核心规则

- 课程主线由教育部课标和人教版官方教材/教师用书决定；
- 每个 Lesson 首次发布或重大更新前必须整体 Review；
- Review 覆盖课程逻辑、知识覆盖、概念深度、应用、例题、题源、知识边界、错误习惯、Final Challenge 和前后衔接；
- 课程设计和真题认证必须回到权威一手来源；
- 奥赛题源池包括 AMC、CEMC、UKMT、IMO，以及 CMO / 中国数学会正式赛事等权威来源；
- 权威赛事题仍必须通过“当前知识可解 + 服务本讲核心”的适龄筛选；
- 新闻、自媒体、商业题库转载、论坛和搜索摘要不得作为课程依据或真题认证依据；
- 搜索工具只用于定位官方资料。

## 使用规则

1. 新 Lesson 或重大修改前先读取本文件；
2. 再读取 v1.3 和 v1.4；
3. 不以会话记忆替代仓库标准；
4. 全局规则变化创建新版本，不覆盖旧版本；
5. Lesson 标记完成前必须通过 Release Review。
