# 1｜当前课程定位

本课程默认学生已经学过当前教材基本内容。

```text
教材知识点100%覆盖
→ Gap Check快速查漏
→ 只补真实漏洞
→ 概念本质与边界
→ 灵活应用
→ 校内中高阶
→ 高水平竞赛式结构突破
→ 当前知识范围内最高思维上限
→ T0/T1/T2迁移验证
```

最高层：

> **适龄只约束可使用的知识工具，不约束思维上限。**

必须避免：

```text
对象更多 ≠ 更深
条件更多 ≠ 更深
数字更大 ≠ 更深
计算更长 ≠ 更深
```

真正的高阶来自：

```text
知识调用不显然
+ 至少两个非显然突破
+ 反推 / 构造 / 极值 / 不变量 / 分类
+ 完整证明
+ 必要性 / 最少性 / 唯一性
+ 一般化 / 陌生迁移
```

---

# 2｜有效难度必须扣除教学泄露

```text
有效难度
=
原始结构难度
−
前文提示 / 同构模板 / 显式方法带来的降难度
```

Elite / Final 原则上必须：

- 题面不直接暴露方法；
- 前文没有完整同构模板；
- 或需要跨较远表面重新识别结构；
- 第一突破之后仍有第二个非显然思维节点。

---

# 3｜可使用的知识

```text
本讲正式知识
+
此前 Mainline 已正式学过的知识
+
已训练的一般数学思维工具
```

可以使用：分类讨论、数形结合、对称、反例、逆向、极端/边界、不变量、完整枚举、唯一性、最少性、特殊到一般。

不能使用尚未正式学习的公式、定理、方程技巧、不等式体系、函数工具等作为关键突破。

原则：

```text
可以综合过去
不能偷用未来
```

# 4｜教材、优秀课程与高阶题源的角色分工

以后每讲 provenance / Review 均明确三层：

```text
教育部课标 + 当前人教版官方资料
→ 决定必须学什么、概念边界与主线顺序

公开可核验的优秀商业课程大纲 / 样课结构
→ 横向检查讲解颗粒度、综合主题与拓展宽度

官方竞赛真题 + 透明 DESIGNED / SYNTHESIS 高天花板题
→ 决定迁移强度与最高思维深度
```

商业课程只作为 **benchmark**：

- 不作为知识真伪的权威来源；
- 不复制受版权保护的讲义或题库；
- 不因市场课程没有讲某个结构就降低本课程思维上限；
- 优先使用公开官方课程页、大纲或合法公开样例。

当前已用于 Lesson 6～8 横向对标的公开课程包括猿辅导、新东方等公开课程大纲；具体链接保存在各讲 provenance。

# 6｜思维深度六维

```text
D1 结构发现
D2 条件充分性 / 必要性
D3 反例与边界
D4 唯一性 / 穷尽性 / 分类完整性
D5 具体 → 参数 → 一般化
D6 表示转换与陌生迁移
```

# 7｜R3.8 Highest-Ceiling Authenticity｜硬门禁

最高层发布前必须检查：

- 是否逼近当前知识范围内的思维上限；
- 是否主要考查灵活应用，而不是熟练度；
- 是否原则上存在至少两个非显然思维节点；
- 是否扣除教学泄露；
- 是否要求自行选择/组合知识；
- 是否包含反推、构造、极值、不变量、完整证明、最少性或一般化中的高价值任务；
- 是否只是增加对象数量、条件数量或计算长度；
- 是否错误地因为“七年级”降低思维标准；
- 是否错误地通过未来知识制造难度。

R3.8 不通过，最高结论只能 `REVISE`。

# 8｜题源策略

主线依据由教育部课标和人教版官方资料决定。

最高层优先审查：

```text
CEMC Gauss 中后段
AMC 8
UKMT JMC / JMO
国内权威正式考试压轴
适龄正式竞赛
CSP-J 中合适的数学结构
```

赛事名气本身不构成难度证据。

`SOURCE / ADAPTED / SYNTHESIS` 继续执行题目级官方链接要求。
