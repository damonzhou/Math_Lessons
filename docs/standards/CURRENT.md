## v1.1 相对 v1.0 的核心变化

- 国内权威数学竞赛 / 奥赛历年真题正式纳入 Olympiad 题源池；
- 校内、区市级、中考等可追溯历年真实考试题正式纳入 Core / Advanced 题源池；
- 国内外真题并行，不机械规定谁优先，以教学匹配度、可靠性和当前知识可解性决定；
- 来源不明的“网传真题”不得直接标记为 `SOURCE`。

## 使用规则

1. 开始新 Lesson 或修改课程结构前，先读取本文件；
2. 再读取这里指向的版本化标准；
3. 不以聊天记忆、旧会话摘要或临时讨论替代仓库标准；
4. 用户明确修改标准时，新建版本文件，例如 `course-standard-v1.2.md`；
5. 只有新版本完整归档后，才更新本文件的当前版本指针；
6. 已归档版本不得覆盖修改。

如果当前会话中的一般性建议与这里的版本化标准冲突，以用户当前明确指令优先；否则以这里指向的标准为准。
