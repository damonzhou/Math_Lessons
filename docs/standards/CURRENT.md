## v1.3 核心变化

- 每个 Lesson 首次发布或重大更新前必须做整体 Release Review；
- Review 必须覆盖课程逻辑、课标/教材覆盖、概念深度、知识边界、应用场景、例题梯度、题源质量、错误习惯、Final Challenge 和前后课程衔接；
- 课程设计依据必须优先使用权威一手来源；
- 教育部/人教社官方资料用于课程与教材边界；
- 竞赛题使用赛事主办方官方题目/官方解答或可靠正式出版物；
- 国内考试真题必须能追溯到正式试卷、教育主管部门/考试机构、学校原卷或可靠正式出版物；
- 新闻报道、自媒体、商业题库转载、论坛、搜索摘要不能作为课程设计事实依据或真题真实性依据；
- 搜索引擎只用于定位一手来源。

## 使用规则

1. 开始新 Lesson 或重大修改前，先读取本文件；
2. 再读取这里指向的版本化标准；
3. 不以聊天记忆、旧会话摘要或临时讨论替代仓库标准；
4. 用户明确修改全局规则时，新建标准版本，不覆盖旧版本；
5. 已归档版本不得覆盖修改；
6. Lesson 标记为完成前必须通过当前标准要求的 Release Review。

如果当前会话中的一般性建议与这里的版本化标准冲突，以用户当前明确指令优先；否则以这里指向的标准为准。
