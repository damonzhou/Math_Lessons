# 0. 规范优先级与防漂移规则

以后无论在同一会话、跨会话还是由不同工具生成课程，都应先读取 `docs/standards/CURRENT.md` 及其指向的当前版本。

发生冲突时，优先级为：

1. **用户当前明确指令**；
2. **`docs/standards/CURRENT.md` 指向的版本化课程标准**；
3. `docs/course-authoring-standard.md`；
4. `docs/problem-source-policy.md`；
5. `docs/student-learning-diagnostics.md`；
6. `templates/lesson-template.md`；
7. 单个 Lesson 中的局部约定。

除非用户明确要求修改课程标准，否则不得因为会话上下文变化、模型变化或一次性讨论而默默改变课程设计原则。

任何标准变更必须：

1. 明确说明改变了什么；
2. 新建版本文件，不覆盖旧版本；
3. 更新 `CURRENT.md`；
4. 必要时更新模板和相关规范；
5. 旧 Lesson 不自动重写，除非明确要求迁移到新标准。

# 1. 课程最终目标

课程不是为了“提前学完教材”或“刷很多题”，而是形成：

$$
\boxed{
\text{概念完全理解}
\rightarrow
\text{规范解决问题}
\rightarrow
\text{真实应用}
\rightarrow
\text{陌生问题迁移}
}
$$

学生对核心概念最终应达到：

$$
\text{会认}\rightarrow\text{会用}\rightarrow\text{会解释}\rightarrow\text{会迁移}
$$

- **Level 1 会认**：能识别定义和基本形式；
- **Level 2 会用**：能解决教材标准题；
- **Level 3 会解释**：能解释为什么、边界、反例、与相近概念的区别；
- **Level 4 会迁移**：能用于陌生题、真实应用、竞赛模型或程序/算法场景。

要求：**Core 最终稳定达到 Level 3；重要核心知识通过后续复习逐步达到 Level 4。**

# 2. 三层教学约束

## 2.1 课标约束

以《义务教育数学课程标准（2022年版）》作为最高教学边界依据，持续关注：

- 四基：基础知识、基本技能、基本思想、基本活动经验；
- 四能：发现问题、提出问题、分析问题、解决问题；
- 数学抽象、推理、运算、建模等核心素养。

## 2.2 人教版教材约束

人教版教材与教师用书决定：

- Core 的知识顺序；
- 概念出现方式；
- 当前阶段最低掌握深度；
- 典型教材模型；
- 常见错误点和评价边界。

**教材决定主线，但不决定课程深度上限。**

## 2.3 已学知识边界

任何 Advanced、Olympiad、Final Challenge 都必须先检查：

> 学生是否主要依靠本讲和此前已经正式学习的知识就能解决？

若必须依赖大量后续公式或高年级工具，应延后、改编为当前知识可解，或仅作为 `EXTENSION` 阅读。

# 3. 四轨课程体系

## Core｜课内主线

目标：教材知识无漏洞，概念不仅会用，而且能解释。

包括定义、性质、基本技能、规范表达、教材典型模型以及高频概念边界和错误辨析。

## Advanced｜校内拔高

目标：稳定解决条件变化、逆向、综合与校内高档题。

持续训练分类讨论、数形结合、整体思想、转化、方程思想、参数意识、一题多解和校内压轴模型。

## Olympiad｜奥数 / 竞赛思维

目标：面对陌生问题主动发现结构和突破口，而不是记竞赛模板。

重点发展整数与数论、代数结构、组合计数、构造、不变量、极端思想、几何推理、规律与递推。

## Informatics｜信息学数学

目标：理解数学为什么能进入程序和算法，而不是只记代码模板。

逐步连接 signed / unsigned、坐标与 offset、进制、整除与模运算、gcd / lcm、素数与筛法、快速幂、递推、组合计数、图论、算法证明与复杂度相关数学。

每讲至少包含：

1. 情境导入；
2. 概念为什么产生；
3. 正式定义；
4. 正例、反例和边界；
5. 概念扩展理解；
6. 递进例题链；
7. 真实应用；
8. 错误实验室；
9. 数学思想 / 方法；
10. Advanced；
11. Olympiad；
12. Informatics；
13. 当堂训练；
14. Final Challenge；
15. 错因与做题习惯诊断；
16. 掌握度检测；
17. 课后练习；
18. 24 小时 / 7 天复习；
19. 知识地图；
20. 下一讲连接。

# 5. 例题设计标准

例题应形成递进链条，而不是只换数字：

1. 直接应用；
2. 逆向读取；
3. 条件变化；
4. 综合应用；
5. 方法题；
6. 真实应用 / 陌生迁移。

重要例题解析必须尽量回答：从哪里入手、为什么这样做、哪个条件最关键、常见错误路径是什么、哪个检查点可以阻止错误、是否有第二种方法、能否推广。

---

# 6. 题源与命题标准

重要题目使用以下标签：

- **TEXTBOOK-MODEL**：有正式教材 / 教师用书模型依据，但不是教材原题；
- **SOURCE**：基本保留真实考试或竞赛题数学结构；
- **ADAPTED**：由明确真题核心结构改编；
- **SYNTHESIS**：融合两个或以上可追溯题源，再结合本讲知识重新设计；
- **DESIGNED**：少量教学原创，只用于现有题源不能精确覆盖的重要概念、反例、方法、错误诊断或迁移目标。

原则：

> **教材能覆盖先用教材模型；真题能覆盖优先真题；需要组合时做 SYNTHESIS；只有存在教学空白时才原创。**

原创不是禁止，但必须受控。发布前必须能解释：为什么这道 `DESIGNED` 题不能简单由现有教材 / 真题替代？

# 7. 真题来源池｜v1.1 扩展

题源选择不按“国内 / 国外谁更高级”排序，而按以下三项综合判断：

1. **与当前知识点和教学目标的匹配度**；
2. **来源权威性与可追溯性**；
3. **是否能用当前已学知识解决并产生高质量思考**。

## 7.1 教材与真实考试题｜Core / Advanced 重要来源

优先参考：

1. 人教版教材与教师用书；
2. 官方或可核验的校内期中、期末考试真题；
3. 区级 / 县级 / 市级统一考试真题；
4. 各地历年中考真题；
5. 具有明确学校、地区、年份、考试名称和题号的高质量真实试题。

用途：

- Core：检验课程是否与真实教学和考试要求一致；
- Advanced：选择高质量综合题、压轴题和条件变化题；
- DIAGNOSTIC：从真实考试高频错误中提取诊断模型。

### 国内考试题的最低追溯信息

题源审计至少记录：

- 年份；
- 地区 / 学校 / 考试组织方；
- 年级或考试类型；
- 题号；
- 可核验来源链接、正式试卷或扫描件来源（若有）。

若只有“某名校真题”“某地期末题”等模糊描述，无法核验具体出处，不得标为 `SOURCE`。

## 7.2 国内权威数学竞赛 / 奥赛真题｜Olympiad 重要来源

允许并鼓励使用**国内权威数学竞赛、奥赛及高质量数学邀请赛的历年真题**，特别是：

- 与七、八、九年级当前知识自然衔接的题；
- 有明确主办 / 承办 / 官方出版或可核验历史资料的题；
- 能训练数论、代数、组合、几何、构造、不变量、分类讨论等核心竞赛思想的题；
- 不依赖明显超前知识、或可以保持数学结构进行适龄改编的题。

### 国内竞赛题的最低追溯信息

题源审计至少记录：

- 赛事正式名称；
- 年份；
- 组别 / 年级 / 轮次（如适用）；
- 题号；
- 主办方、官方资料、正式出版物或其他可靠可核验来源；
- 若改编，说明改动内容和原因。

### 真实性规则

以下材料**不能直接作为 `SOURCE`**：

- 只有自媒体转载而没有原始出处；
- 标注“历年奥赛真题”但无赛事、年份、题号；
- 题库网站互相转载且无法确认最初来源；
- 来源冲突或题目版本存在明显差异且未核实。

这类题若数学价值高，可暂存为候选素材；正式进入课程前必须进一步核源。无法核实则只能按 `DESIGNED / UNKNOWN-PROVENANCE` 内部候选处理，不得声称为真题。

## 7.3 国际竞赛题源｜与国内题源并行

七、八年级继续重点参考：

1. **MAA AMC 8**；
2. CEMC Gauss；
3. UKMT Junior Mathematical Challenge / Junior Mathematical Olympiad；
4. 不依赖明显超前知识的 AMC 10。

这些与国内真题**并行使用，不存在强制优先级**。同一知识点若国内真题更贴近人教版表达或考试习惯，应优先国内题；若 AMC / Gauss / UKMT 的问题结构更优秀，则优先采用对应国际题源。

## 7.4 Informatics 题源

优先参考：

- CSP-J；
- NOI / NOIP 中适合当前阶段的数学模型；
- 正式算法题中的整数、坐标、计数、递推、模运算等结构。

若当前只是建立“数学概念 ↔ 程序语义”的桥梁，可以保留少量 `DESIGNED` 最小代码示例。

# 8. 真题选择规则

“是真题”只是入选条件之一，不等于“适合课程”。任何真题采用前仍须检查：

1. 与当前人教版知识是否高度相关；
2. 是否主要依靠已学知识可解；
3. 是否真正加深概念或问题解决能力；
4. 是否存在更适合当前目标的国内 / 国际真题；
5. 是否需要改编以降低超前工具依赖；
6. 题源是否可以真实追溯。

### 题源标记示例

```text
SOURCE · 2024 武汉市某区七年级期末 · Q18
ADAPTED · 某权威国内数学竞赛 20XX · 初中组 · Q5
ADAPTED · 2023 AMC 8 · Problem 3
SYNTHESIS · 国内中考真题 + AMC 8 + 本讲模型
```

只有数学结构保留但情境、数字、条件或问法发生实质变化时，应标 `ADAPTED`，不能写成“原题”。

# 9. Po-Shen Loh（罗博深）的角色

Po-Shen Loh 作为**问题设计与思维训练方法论参考**，不是默认题源标签。

借鉴：少做机械重复、陌生问题先独立探索、分层 hints、鼓励自创策略、一题多解、解后推广。

原则：

> **先问题，后方法；先探索，后提示；先理解结构，后记技巧。**

除非题目确实来自其公开材料，否则不得标记成“罗博深题”。

---

# 10. Final Challenge｜每讲强制要求

每讲最后至少一道奥赛 / 高水平竞赛思维综合挑战。

必须通过六项审核：

1. 当前知识可解；
2. 题面不泄露方法；
3. 存在真正突破口；
4. 题源可靠，优先 `SOURCE → ADAPTED → SYNTHESIS → DESIGNED`；
5. Hint 1 → Hint 2 → Hint 3；
6. 解后再思考：一般化、条件变化、第二种解法、方法比较、构造同类题、后续数学或算法连接至少一项。

Final Challenge 的结束点是：

$$
\boxed{\text{一道题}\rightarrow\text{一种方法}\rightarrow\text{一类结构}}
$$

在题源选择上，国内权威奥赛 / 竞赛题、历年高质量中考或统一考试压轴题、AMC / Gauss / UKMT 等均可作为 Final Challenge 的直接或结构来源。

# 11. 做题习惯是正式课程目标

统一五步做题流程：

$$
\boxed{
\text{提取条件}
\rightarrow
\text{明确所求}
\rightarrow
\text{建立关系}
\rightarrow
\text{执行检查}
\rightarrow
\text{回代核对}
}
$$

## H 标签

- **H1** 条件读取不准确；
- **H2** 未确认所求；
- **H3** 擅自假设图形位置 / 隐藏条件；
- **H4** 先套公式后分析关系；
- **H5** 分类条件筛选不完整；
- **H6** 符号检查不足；
- **H7** 局部与整体对象混淆；
- **H8** 估算后未验证；
- **H9** 陌生题过早套模板；
- **H10** 结果未回代 / 未做合理性检查。

每讲必须明确一个或多个“本讲习惯检查点”。

`DIAGNOSTIC-Hx` 是教学功能标签，不是题源标签。

每 4～6 讲应统计一次 H 标签变化，而不只看正确率。

# 12. 新错误习惯的处理规则

发现新错误时：

1. 先判断能否归入现有 H1～H10；
2. 若能归入，只补充案例和纠偏方法，不升级课程标准；
3. 若不能归入，先观察是否在不同题型 / 章节重复出现；
4. 若形成独立、长期、可纠正的通用习惯问题，再新增 H 标签并升级标准小版本。

原则：

> **新错误先记录，不急着增加标签；重复出现并形成独立模式，再升级标准。**

---

# 13. 错题复盘标准

典型错题不能只抄正确答案。

至少记录：知识错因 C 标签、做题习惯 H 标签、错误发生步骤、当时思路、下一次检查点，以及一道条件变化后的迁移题。

真正的进步标准：

> **下一道外观不同、结构相同的问题，不再因为同一种习惯而出错。**


规则：当堂训练题保留在主课正文；当堂训练答案独立；课后练习独立；课后答案独立；每讲维护题源审计；必要时建立习惯诊断专项文件。

# 15. 当堂训练、课后练习与复习

当堂训练按需要覆盖 Core、Advanced、Olympiad、Informatics、DIAGNOSTIC。

课后练习用于延迟回忆与迁移，不能只是当堂题换数字；至少保留一类“解释为什么”的题。

每讲至少设置：

- **24 小时复习**：主动回忆、重做关键题、复述方法、检查 H 标签；
- **7 天复习**：条件变化迁移题、重新解释核心概念、检查错误习惯是否再次出现。

# 16. LaTeX 与 GitHub 文档规则

课程保留标准 LaTeX，以 GitHub Web 正确渲染为准：

- 行内数学：`$...$`；
- 块级数学：`$$...$$`；
- 分数：`\frac{a}{b}`；
- 不使用 `\(...\)` 或 `\[...\]`；
- LaTeX 命令必须位于数学环境；
- 含 LaTeX 的完整答案不得放入 `<details>` 等原生 HTML 折叠容器。

对于标题中单个简单整数、负数等，如果 GitHub 行内数学出现不稳定渲染，可直接使用普通 Unicode 数学符号（如 `−5`），不改变“复杂数学表达保留 LaTeX”的总原则。
