# 1. v1.4 新增：权威奥赛题源池

Olympiad / Final Challenge / 高阶思维训练允许并鼓励从**国际、国内权威数学竞赛**中选择真实题目或核心结构。

## 国际权威来源

包括但不限于：

- **AMC 8 / AMC 10 / AMC 12** — Mathematical Association of America (MAA)；
- **AIME / USAJMO / USAMO** — MAA；
- **IMO（International Mathematical Olympiad）** 官方历年题、官方 Shortlist（在公开可用年份）；
- **CEMC Gauss** 及 University of Waterloo CEMC 其他适龄竞赛；
- **UKMT JMC / JMO** 及其他 UKMT 官方适龄竞赛。

官方来源优先使用赛事主办方网站、官方 Problem Set、Official Solutions、官方归档。

## 国内权威来源

包括但不限于：

- **CMO（中国数学奥林匹克 / 全国中学生数学奥林匹克竞赛决赛暨全国中学生数学冬令营）**；
- 全国高中数学联赛等由**中国数学会及其数学竞赛相关委员会**正式组织的赛事；
- 中国女子数学奥林匹克等中国数学会正式竞赛；
- 其他具有明确主办方、正式赛制、可核验原题/正式出版物的国内权威数学竞赛。

中国数学会官方资料应作为 CMO 等赛事身份和组织信息的优先依据。

# 2. “权威”不等于“适合当前 Lesson”

题目进入七年级课程前必须继续通过以下筛选：

$$
\boxed{\text{当前知识可解}+\text{服务本讲核心}+\text{来源可核验}+\text{思维价值}}
$$

因此：

- **AMC 8** 是七、八年级最常用的直接题源之一；
- AMC 10/12、AIME、USAJMO、USAMO、IMO、CMO 等难度更高的赛事，七年级阶段只选择**不依赖明显超前知识**的题，或保留其核心结构进行适龄 `ADAPTED / SYNTHESIS`；
- 不允许因为“IMO/CMO 更高级”就机械加入当前课程；
- 若原题必须依赖高中代数、复杂几何、系统数论等后续工具，应延后到相应课程，而不是提前给公式。

---

# 3. 题源标签与真实性

使用赛事题时必须明确：

- `SOURCE`：数学结构基本保持原题；
- `ADAPTED`：由明确赛事原题结构改编；
- `SYNTHESIS`：融合两个或以上可追溯权威题源；
- 不得因为“风格像 IMO/CMO”就标为 IMO/CMO 真题。

题源审计至少记录：

1. 赛事正式名称；
2. 年份；
3. 组别/轮次（如适用）；
4. 题号；
5. 主办方官方页面、官方题目/解答或可靠正式出版物；
6. 改编了什么；
7. 为什么适合当前知识边界。

---

# 4. 一手来源硬要求继续有效

以下材料不能单独用于认证 AMC / IMO / CMO 等题目来源：

- 新闻报道；
- 自媒体；
- 商业培训机构题库；
- 论坛/博客；
- 搜索摘要；
- 无原始出处的“历年奥赛真题合集”。

搜索工具只能帮助定位赛事官方资料，最终 provenance 必须回到官方原题、官方解答或可靠正式出版物。

---

# 5. Final Challenge 的题源选择

Final Challenge 优先级不是按赛事名气，而是：

1. 与本讲核心概念高度匹配的权威 `SOURCE`；
2. 当前知识可解的 `ADAPTED`；
3. 多个权威题源与本讲概念形成的 `SYNTHESIS`；
4. 确有教学空白时的 `DESIGNED`。

IMO/CMO 题如果能以当前知识形成真正的突破性思考，可以使用；如果只能靠后续知识解决，则保留到后续年级。

---

# 6. Release Review 新增检查项

R7 题源质量在 v1.4 进一步检查：

- 是否主动检查 AMC / CEMC / UKMT / IMO / CMO 等权威题源中有无更合适问题；
- 是否因为追求“高级赛事”而超纲；
- 是否把改编题误写成原题；
- 是否确实追溯到赛事官方资料；
- 国内外题源是否根据教学价值选择，而不是机械配额。

> **原则：权威来源保证题目质量底线；课程逻辑和知识边界决定题目是否真正适合学生。**
