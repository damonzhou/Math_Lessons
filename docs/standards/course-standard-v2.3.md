# 课程标准 v2.3｜查漏补缺 + 概念深化 + 中高阶拔高

> **适用对象**：已经学过当前教材基础内容的学生  
> **课程定位**：不是从零讲授型课程，而是“完整覆盖教材 + 快速查漏 + 深化理解 + 中高阶拔高”的进阶课程。  
> **继承**：v1.3～v2.2 全部有效规则继续生效；与本版本冲突时，以本版本对课程受众、节奏和难度分配的规定为准。

---

# 1. 课程总目标

本课程同时完成四个目标：

```text
A. 教材完整覆盖
B. 查漏补缺
C. 概念理解与应用深化
D. 中高阶难度与思维拔高
```

目标链条：

```text
教材知识点100%覆盖
→ 基础掌握快速诊断
→ 只补真实漏洞
→ 概念本质与边界
→ 典型应用与陌生迁移
→ 校内中高阶
→ 竞赛式结构突破
→ 能力上限验证
```

课程不能退化为：

```text
从定义开始长篇重复
→ 大量基础例题
→ 最后放1道稍难题
```

学生已经学过基础内容，因此课程的主要增量必须发生在“理解更深”和“问题更难”两部分。

---

# 2. 基础内容的处理方式

教材中的定义、性质、基本方法、典型题型必须全部覆盖，但默认采用：

```text
Quick Check
→ 已掌握：快速通过
→ 有漏洞：定点补讲
→ 立即进入深化与拔高
```

## 2.1 不允许因“学生已学过”而漏掉教材知识点

完整覆盖仍是硬要求。

## 2.2 不允许因“教材完整”而平均分配课时

基础内容已掌握时，应压缩讲解和重复训练，把时间让给：

- 易混概念；
- 边界与反例；
- 条件充分性/必要性；
- 逆向问题；
- 多解与穷尽；
- 参数与一般化；
- 综合应用；
- 校内压轴；
- 适龄竞赛迁移。

---

# 3. 推荐课时与题量重心

单讲默认不是“50%以上时间讲基础”。建议结构：

```text
15%～25%  教材快速覆盖 / 查漏
25%～35%  概念深化与应用
25%～35%  校内中高阶 / 综合
15%～25%  竞赛迁移 / Final Challenge
```

以上是设计重心，不是机械分钟配额。若基础漏洞明显，可以临时增加补漏；若基础稳定，应快速进入高阶。

---

# 4. 难度分层重新定义

每讲必须明确区分：

| 层级 | 难度 | 目的 |
|---|---|---|
| Gap Check | ★ | 检查教材基础是否有漏洞 |
| Concept Deepening | ★★～★★★ | 概念本质、边界、反例、应用 |
| School Advanced | ★★★ | 校内中高阶、综合、压轴结构 |
| Competition Transfer | ★★★～★★★★ | 适龄竞赛式陌生迁移与结构突破 |
| Elite / Final Challenge | ★★★★～★★★★★ | 持续15～30分钟思考、完整推理、唯一性/穷尽性/一般化 |

**难度高不等于计算长。**

高阶难度优先来自：

```text
结构发现
条件控制
逆向恢复
多情况分类
构造反例
不变量
完整枚举
唯一性证明
参数变化
一般化
陌生迁移
```

---

# 5. 每讲最低拔高要求

除极少数天然过渡课外，每个 Mainline Lesson 至少应包含：

1. 1组 **Gap Check**，覆盖教材 MUST；
2. 至少1个 **Concept Deepening** 核心问题；
3. 至少2个 **School Advanced** 问题，其中至少1个不是单纯计算题；
4. 至少1个 **Competition Transfer** 或等价水平的高价值原创/综合题；
5. 1个 **Elite / Final Challenge**，目标难度 ★★★★～★★★★★；
6. Final Challenge 至少包含以下三项中的两项：
   - 条件变化 / 删条件；
   - 唯一性或穷尽性证明；
   - 参数化 / 一般化；
7. 高阶题不能全部与前文高度同构。

---

# 6. Final Challenge 新门槛

发布前必须问：

> **一个校内数学明显优秀、已学过基础内容的七年级学生，是否很可能需要独立思考15～30分钟，才能完整解决？**

若明显不需要，则最高层难度不足。

同时必须通过第二个问题：

> **如果把计算量大幅降低，问题是否仍然有真实突破口？**

只有两者同时满足，才算高质量 Final Challenge。

Final Challenge 不能仅靠：

- 数字更大；
- 步骤更长；
- 分数更多；
- 表达更复杂；
- 提前学习后续公式；
- 赛事名称更高级。

---

# 7. 题源难度校准

CEMC Gauss 前段题、校内基础题可以用于 Gap Check / Concept Bridge，但不应长期承担最高层拔高。

高阶题源优先审查：

```text
CEMC Gauss 中后段
MAA AMC 8
UKMT JMC / JMO
国内权威正式考试压轴题
国内权威奥赛 / 数学竞赛适龄题
CSP-J 等适合的信息学数学结构
```

AMC 10/12、AIME、IMO、CMO 等可以作为结构来源，但必须经过：

```text
当前知识可解性
+ 年龄匹配
+ 无超前工具依赖
+ 结构价值
```

筛选，不因赛事名气硬塞。

---

# 8. 新发布门禁 R2.7｜受众与拔高匹配

每讲 Release Review 新增：

## R2.7｜Audience / Advancement Fit

必须检查：

- 是否把学生错误地当作第一次学习基础内容；
- 教材知识点是否仍100%覆盖；
- 是否通过 Gap Check 而不是大篇幅重复基础；
- 课程主要增量是否落在概念深化、应用和中高阶；
- School Advanced 是否达到真实校内中高阶；
- Competition / Final 是否能拉开优秀学生的能力差距；
- Final 是否有15～30分钟独立思考价值；
- 难度是否来自结构而不是长计算/超前知识。

若高阶层明显不足，最高只能 `REVISE`。

# 9. 对 Lesson 5～8 的直接影响

Lesson 5～8 当前 v2.2 版本完成了概念深化，但最高难度整体偏保守。

因此需要按 v2.3 重新审计并升级：

```text
Lesson 5  绝对值（一）
→ 多点信息恢复、顺序约束、最少附加信息、完整构型

Lesson 6  绝对值（二）
→ 多层绝对值、参数与解数变化、边界突变、完整分类

Lesson 7  大小比较
→ 部分信息排序、所有可能顺序、极值/逆向构造、必要充分条件

Lesson 8  数轴综合
→ 多点重建、未知尺度/未知原点、复杂动点、距离和、不变量、完整分类
```

Core 不需要推翻；重点升级 Advanced / Competition / Ceiling / Final 层。

---

# 10. 后续 Lesson 9+ 的默认设计

从 Lesson 9 起，默认学生已经学过对应基础教材内容。

每讲开头先做短诊断，快速确认：

```text
定义会不会？
基本法则会不会？
典型基础题会不会？
是否存在易错点？
```

然后把主要教学资源放在：

```text
为什么成立
什么时候不能用
怎么迁移
怎么综合
怎么在陌生题中发现结构
```

课程目标不是“讲完课本”，而是：

> **课本无漏洞，概念理解深，应用迁移稳，中高阶问题有突破能力。**
