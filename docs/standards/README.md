# 课程标准版本库

本目录用于保存 **Math_Lessons 的版本化课程标准**，目的是避免课程要求因会话内容、跨会话、模型变化或临时讨论而发生隐性漂移。

## 版本管理原则

1. 已归档版本只读，不覆盖；
2. 小幅规则升级创建 v1.1、v1.2……；
3. 课程理念、难度体系、题源策略或诊断体系发生实质改变时升级主版本，例如 v2.0；
4. `CURRENT.md` 只负责指出当前生效版本；
5. 每个版本必须包含变更摘要和生效日期；
6. 跨会话继续课程时，应以本目录为规范来源，而不是依赖聊天记忆。

## 与可变工作文档的关系

以下文件可以随着当前标准继续维护：

- `../course-authoring-standard.md`
- `../problem-source-policy.md`
- `../student-learning-diagnostics.md`
- `../../templates/lesson-template.md`

它们用于日常编写和模板化；**版本化标准文件用于锁定某一时点的完整规则。**

如果可变工作文档与当前版本化标准出现冲突，应先确认是否已经正式发布新标准版本；若没有，仍以 `CURRENT.md` 指向的版本为准。
