# 课程标准版本库

本目录保存 **Math_Lessons 的版本化课程标准**，用于避免课程要求因会话、模型或临时讨论发生隐性漂移。

## 版本管理原则

1. 已归档版本只读，不覆盖；
2. 细则升级创建 v1.x；
3. 课程理念、难度体系、主线或诊断体系发生实质变化时升级主版本；
4. `CURRENT.md` 唯一指定当前生效版本；
5. 每个版本必须包含变更摘要和生效日期；
6. 跨会话继续课程时，以本目录为规范来源，不依赖聊天记忆。

## 权威来源原则

从 v1.3 起，搜索引擎仅用于定位资料。课程依据必须尽量回到：

- 教育部、人教社等官方课程/教材资料；
- 赛事主办方官方题目和官方解答；
- 教育主管部门、考试机构、学校正式试卷或可核验正式出版物。

新闻、自媒体、商业题库转载、论坛和搜索摘要不得作为课程事实依据或真题认证依据。
