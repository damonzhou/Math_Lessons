# 1. v1.5 新增：正式主线与扩展专题必须分层

课程目标不是机械照抄教材目录，但正式编号 Lesson 的顺序必须优先保持：

$$
\boxed{\text{课标要求}+\text{人教版知识依赖}+\text{学生认知连续性}}
$$

Advanced / Olympiad / Informatics 内容可以明显加深课程，但**不能仅因为数学上有关联，就占用正式主线编号并打断更强的课内知识依赖**。

判断一个主题是否应成为正式 Lesson，发布前必须问：

1. 它是否是当前课标/教材主线中的正式知识节点？
2. 后续多个主线知识是否直接依赖它？
3. 此时单独学习它是否明显优于在需要时嵌入/调用？
4. 如果把它提前，是否会打断当前更自然的知识链？

若第1、2项较弱，而主题主要服务于竞赛、方法论或信息学，应优先放入 `extensions/`。

# 2. “理解更深”不等于“更早引入更抽象的术语”

课程追求概念深度，但概念深度优先来自：

- 为什么产生；
- 定义与边界；
- 正例、反例；
- 与相近概念的区别；
- 表示与对象的区别；
- 真实应用；
- 方法迁移。

不以提前引入更多抽象符号、术语或高年级形式化语言作为“深度”的替代品。

例如，在有理数分类中理解“整数整体是有理数的一部分”是必要深度；系统学习集合、属于、包含、相交、余数类与抽屉原理则可以作为后续扩展专题，而不必抢占数轴之前的正式主线。

---

# 3. 扩展专题的触发学习机制

`extensions/` 中的专题不是删除或降质，而是采用“**需要时提示学习**”机制。

未来 Lesson 若第一次明显依赖某个扩展概念，正文应给出显式提示：

> **前置扩展提示**：本题/本节会明显使用 ______ 思想。建议先学习：[专题链接]。

并标注学习级别：

- **OPTIONAL**：不学也不影响当前 Core；
- **RECOMMENDED**：能显著帮助 Advanced/Olympiad；
- **REQUIRED-FOR-EXTENSION**：只对当前拓展部分是必要前置，不影响 Core。

不得让未提示的扩展知识成为主课或 Final Challenge 的隐藏前置条件。

---

# 4. 集合/分类专题的定位

原正式 Lesson 3《分类是一种数学方法——集合、包含与“不重不漏”》调整为 Advanced/Olympiad Extension。

保留的价值包括：

- 集合与元素直觉；
- 属于与包含；
- 互斥 / 包含 / 相交；
- 分类“不重不漏”；
- 奇偶与余数分类；
- 多条件筛选；
- 抽屉原理；
- 程序条件分支。

这些内容数学上正确且对竞赛/信息学重要，但不再占据七上正式 Lesson 3。

后续出现以下场景时可提示学习该专题：

- 复杂分类讨论；
- 整除与余数类；
- 抽屉原理；
- 两个性质集合的重叠计数；
- 程序中互斥分支与独立布尔标签；
- 需要明确区分属于、包含、相交时。

# 5. 七上当前主线修订

当前数系部分正式顺序调整为：

```text
Lesson 1  正数和负数
Lesson 2  有理数的意义与分类
Lesson 3  数轴
Lesson 4  相反数
Lesson 5  绝对值（一）
Lesson 6  绝对值（二）/大小比较与分类讨论（按后续 Review 确定最终拆分）
...
```

核心依赖链保持：

$$
\text{有理数}\rightarrow\text{数轴}\rightarrow\text{相反数}\rightarrow\text{绝对值}\rightarrow\text{大小比较/运算}
$$

具体 Lesson 数量仍可通过 Release Review 调整，但不得再次为了非必要扩展打断上述依赖。

---

# 6. Release Review 新增 R0：主线定位审查

从 v1.5 起，每次 Release Review 在 R1 之前先做 **R0 主线定位**：

- 本讲是 Mainline 还是 Extension？
- 如果是 Mainline，为什么必须在当前位置学习？
- 如果教材没有独立章节，本讲是否仍存在足够强的知识依赖理由？
- 是否有更重要、更直接的后续知识应该先学？
- Advanced/Olympiad 内容是否反客为主，改变了 Core 顺序？

若定位错误，Review 最高只能为 `REVISE`，不能 `PASS`。

# 7. 当前调整的迁移规则

- 原 Lesson 3 集合/分类内容迁入 `grade-07/semester-1/extensions/`；
- 原 v1.4 Lesson 3 Review 作为历史审计，不再代表正式主线课程状态；
- 新正式 Lesson 3 为“数轴”；
- 路线图、README、主课链接、后续 Lesson 编号必须同步更新；
- 扩展专题以后由明确触发点提示，不依赖会话记忆。

> **原则：教材主线稳定，概念仍然讲深；竞赛思想保留，但在真正产生学习价值的位置出现。**
