# 课程标准 v2.2｜增加思维深度，而不是增加计算难度

> **生效日期**：2026-09-05  
> **类型**：增量标准  
> **继承**：v1.3～v1.9 + v2.0 + v2.1

---

# 1. 核心原则

课程继续提高难度，但“难”必须优先来自思维，而不是来自：

- 更长的计算；
- 更大的数字；
- 更多机械步骤；
- 提前使用后续公式、定理或竞赛工具；
- 为了出现 AMC / IMO / CMO 标签而人为抬高知识门槛。

正式原则：

```text
Deep Reasoning > Harder Arithmetic
```

中文解释：

> **增加思维深度，而不是单纯增加计算难度。**

课标和人教版决定当前知识边界；高阶部分应在这个边界内尽量提高思考上限。

---

# 2. 什么叫“思维更深”

一题如果主要要求学生完成更长的运算，不自动视为更深。

优先增加以下六类深度：

## D1｜结构发现

学生需要从条件中发现隐藏关系，而不是题目直接告诉方法。

例如：

```text
互为相反数
→ 原点是对称中心
→ 等距条件恢复尺度
```

而不是直接给出“先求中点再求步长”。

## D2｜条件充分性与必要性

学生必须回答：

- 哪个条件真正有用？
- 删除一个条件后还能推出吗？
- 条件够不够？
- 什么是必要条件，什么只是方便条件？

## D3｜反例与边界

面对一个断言，不只会判断对错，还要能：

- 找最小反例；
- 找边界情况；
- 说明为什么反例足以推翻无条件结论。

## D4｜唯一性、穷尽性与分类完整性

学生需要主动检查：

- 是否还有第二种可能；
- 是否漏掉0或另一侧；
- 是否能证明答案唯一；
- 若不唯一，是否能完整列出全部情况。

## D5｜一般化

题目不能停在一个数字答案。

至少在适当位置要求从：

```text
具体数字
→ 参数
→ 一般规律
```

并说明规律为什么成立、边界在哪里。

## D6｜表示转换与陌生迁移

同一数学结构要能在不同表面中识别：

- 数字 ↔ 数轴；
- 图形 ↔ 语言；
- 关系 ↔ 程序/算法；
- 具体情境 ↔ 抽象模型；
- 正向问题 ↔ 逆向问题。

目标是让学生学会“看到结构”，而不是“认出题型”。

---

# 3. 低门槛、高天花板

高阶题优先采用：

> **当前知识可进入，但需要真正突破才能走深。**

即：

```text
低知识门槛
+ 高思维天花板
```

这比“提前学高中公式后做难题”更符合本课程目标。

一题如果必须依赖尚未正式学习的工具，除非明确进入 Extension，否则不能用来证明 Mainline 的“思维深度”。

---

# 4. 每讲至少应出现的深度动作

从 Lesson 7 起，每个 Mainline Lesson 的完整课程中，至少包含以下五项中的四项：

1. **一个结构发现问题**：方法不直接写在题面；
2. **一个删/改条件问题**：检查条件充分性；
3. **一个反例或边界任务**；
4. **一个一般化任务**：具体 → 参数/规律；
5. **一个陌生表面迁移**：避免只认模板。

并且至少有一题要求学生解释：

> **“为什么答案只有这些？”**

即必须出现唯一性、穷尽性或完整性说明之一。

这些任务可以分布在 Ceiling Diagnostic、Ceiling Builder、Advanced/Olympiad、Mastery Challenge 中，不要求机械地各建一个新栏目。

---

# 5. 禁止把这些当作“增加深度”的证据

以下行为本身不能通过思维深度审查：

- 数字从两位数变成六位数；
- 分数变复杂；
- 连续计算步骤变多；
- 同一种题型重复10次；
- 提前引入未来公式后做所谓压轴题；
- 只因为题目来自更高级赛事就称为“更深”；
- 只增加题量而没有新的认知动作；
- 把证明要求简化成“写完整过程”，但过程仍只是机械运算。

---

# 6. 权威竞赛题的使用方式

AMC、CEMC、UKMT、IMO、CMO 等仍是正式权威题源池。

选择题目时新增一个问题：

> **这道题的价值来自结构突破，还是主要来自知识超前/计算复杂？**

优先选择：

- 当前知识可解；
- 表面不直接暴露方法；
- 有一个真正的突破口；
- 可以变条件、做反例或一般化；
- 解后能提炼成一类结构。

高级赛事的题如果需要大量超前工具，不直接进入 Mainline；可以作为未来 Extension 或只提取透明可追溯的结构。

---

# 7. Ceiling Diagnostic / Builder / Mastery 的深度分工

## Ceiling Diagnostic

重点测：

- 能否独立发现结构；
- 能否识别条件是否充分；
- 遇到不唯一时是否主动寻找第二种可能。

不能主要靠长计算制造卡点。

## Ceiling Builder

重点训练：

- 换表示；
- 删条件；
- 构造反例；
- 逆向构造；
- 一般化；
- 多方法比较。

Builder 的成功标志是**解题行为改变**，不是多做几道同类题。

## Mastery / Final Challenge

重点验证：

- 新表面下能否识别同一结构；
- 能否解释为什么；
- 能否证明答案完整/唯一；
- 能否推广到更一般情形。

# 8. 新增 Release Review 门禁：R3.7｜思维深度

从 v2.2 起新增：

## R3.7｜思维深度，而非计算难度

Review 必须回答：

1. 本讲高阶难度主要来自哪里？
2. 是否存在真实“突破口”，而不是运算堆叠？
3. 是否训练了结构发现？
4. 是否至少训练条件充分性 / 反例 / 边界中的一项？
5. 是否要求检查唯一性、穷尽性或分类完整性？
6. 是否存在具体 → 参数/一般规律的提升？
7. 是否至少有一次不同表面或不同表示的迁移？
8. 是否偷用了未来知识来制造难度？
9. 若使用竞赛题，其思维增益是什么？
10. 删除最复杂的计算后，题目是否仍然有值得保留的数学思考？

### PASS 条件

必须满足：

- 高阶部分的主要难点来自结构/条件/推理，而不是长计算；
- 不以超前知识作为 Mainline 深度来源；
- 至少覆盖 D1～D6 中四类；
- 至少一处明确要求完整性/唯一性说明；
- Mastery / Final Challenge 解后有方法提炼或一般化。

若不满足，Review 最大结论为：

> `REVISE`

---

# 9. 对已有 Lesson 3～6 的处理

不机械加题。

只在 Review 发现真实缺口时补强：

- Lesson 3 数轴：重点保持尺度恢复、删条件、唯一性；
- Lesson 4 相反数：重点保持对称、变换、不动点、参数边界；
- Lesson 5 绝对值（一）：重点保持信息丢失、逆向恢复、唯一性；
- Lesson 6 绝对值（二）：重点保持分类完整、边界0、反例、一般化。

这些 Lesson 当前已经具备较高思维深度，不为版本升级增加无效题量。

---

# 10. Lesson 7 及以后

Lesson 7《有理数大小比较》是第一个原生执行 v2.2 的新 Lesson。

设计重点不应只是：

```text
正数 > 0 > 负数
两个负数比较绝对值
```

而应进一步让学生统一理解：

```text
数轴位置
→ 左右顺序
→ 正负分类
→ 到0距离
→ 两个负数为何“离0越远反而越小”
```

并通过：

- 错误规则反例；
- 条件变化；
- 多表示比较；
- 参数排序；
- 完整排序与唯一性；
- 权威适龄竞赛迁移；

把“会比较”提升为“能解释比较规则为什么成立、何时成立、能否推广”。

---

# 11. 一句话检查

每次准备加一道高阶题前先问：

> **如果把计算量大幅降低，这道题还剩下什么值得学生思考？**

如果答案是“几乎没有”，它就不应作为本课程增加深度的核心题。
