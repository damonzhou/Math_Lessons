# 学习诊断、做题习惯与能力上限提升体系｜v2.0

本文件把实际做题过程中反复出现的问题转化为长期训练目标。课程不把错误只看成“这道题做错了”，也不把 Ceiling Diagnostic 当成给学生贴水平标签的工具。

目标是同时判断：

1. 是知识缺口还是解题习惯问题；
2. 学生当前独立发现的上限在哪里；
3. 课程应该怎样针对卡点训练；
4. 经过训练后，面对不同表面结构是否真正进步。

---

# 一、长期做题习惯 H1～H10

## H1｜条件读取不准确

典型表现：把“互余”看成“互补”；多条件题只使用部分条件；看到熟悉图形后按印象读题。

纠正：做题前先复述“已知什么、每个条件意味着什么、最终求什么”。

## H2｜没有先确认所求

中途算到相关量就停止，局部结果正确但没有回答原题。

纠正：开始时写“所求：____”；最后确认当前结果是否真正回答原题。

## H3｜擅自假设位置/隐藏条件

例如只知道 AB=12、BC=7，没有说明 B 在线段 AC 上时，AC 不能直接断言为19，还可能是5。

纠正：检查点顺序、在线段/直线上的区别、图形外观是否由题干保证，以及是否需要分类。

## H4｜先套公式，后分析关系

会公式但没有先理清对象和结构。

纠正：公式之前先画图、列表、命名对象或写核心关系。

> **公式只能计算已经看清的关系，不能替代关系分析。**

## H5｜分类讨论筛选不完整

知道要分类，但没有用已知条件排除不可能情况。

纠正：分界点 → 理论情况 → 已知条件筛选，做到不重、不漏。

## H6｜符号检查不足

去括号、去绝对值、移项、负号处理与前一步判断不一致。

纠正：设置明确“符号检查点”，写清变号依据。

## H7｜局部与整体/对象角色混淆

把组成部分当成整体，或把状态、变化、偏差、坐标、距离等对象混在一起。

纠正：关键对象命名，每个式子都说明表示谁。

## H8｜估算后未验证

估算得到候选后直接作为精确结论。

纠正：估算只负责发现候选，必须再用范围、回代、夹逼或边界验证。

## H9｜陌生题过早套模板

看到熟悉关键词就立即套常见套路。

纠正：陌生题开始时先问：

1. 什么量不变？
2. 什么量统一变化？
3. 是否存在基准、对称、整体、分类、周期或极端结构？
4. 是否可以换一种表示？
5. 为什么题目给这个条件？

## H10｜结果未回代/未做合理性检查

算出一个看似合理结果后直接结束，没有检查全部条件、唯一性、单位、边界和其他可能情况。

纠正：最后必须检查：

- 回答了真正所求吗？
- 满足全部条件吗？
- 是否唯一？
- 是否存在反例/另一种情况？
- 数值和单位合理吗？

# 二、统一五步做题流程

```text
提取条件
→ 明确所求
→ 建立关系
→ 执行检查
→ 回代核对
```

## Step 1｜提取条件

把题目条件转换成数学语言，不依赖图形外观补条件。

## Step 2｜明确所求

单独写清最终要求的量或结论。

## Step 3｜建立关系

先画图、列表、换表示、定义变量或写核心关系，再选方法。

## Step 4｜执行并设置检查点

主动检查分类、符号、单位、位置关系、关键条件和边界。

## Step 5｜回代与合理性检查

检查全部条件、唯一性和其他可能情况。

# 三、Ceiling Diagnostic｜测当前上限

Ceiling Diagnostic 不只记录“对/错”，而记录学生在高阶方法尚未完整教学时能独立走到哪里。

## C5-A～F

| 等级 | 表现 |
|---|---|
| C5-A | 独立完成，并能解释或一般化 |
| C5-B | 独立发现核心结构，有次要错误 |
| C5-C | Hint 1 后完成 |
| C5-D | Hint 2 后完成 |
| C5-E | Hint 3 后完成 |
| C5-F | 看完整解答后才能理解 |

同时必须记录：

- 第一个卡点；
- 当时尝试过哪些表示/方法；
- 哪个条件没有利用；
- 是否出现 H1～H10；
- 是“没想到入口”还是“想到入口但执行失败”。

**C5 等级不是固定能力标签，只是当前时点的诊断结果。**

# 四、Ceiling Builder｜针对卡点提高上限

诊断后不直接进入“老师讲标准解”。先根据卡点选择训练方式。

## 4.1 如果卡在条件读取 H1/H3

训练：

- 删除一个条件，结论还成立吗？
- 加什么最小条件后可以确定？
- 构造两个都满足现有条件但答案不同的反例。

目标：主动判断条件充分性，而不是相信图形或题型印象。

## 4.2 如果卡在表示/对象 H7

训练：

- 语言 ↔ 图 ↔ 数轴 ↔ 表格 ↔ 代数表达；
- 同一个对象用不同表示描述；
- 指出哪个量是状态、变化、距离、偏差、坐标等。

目标：遇到陌生题主动换表示。

## 4.3 如果卡在方法启动 H9

训练：

- 同一数学结构换三种完全不同表面；
- 比较两个方法为什么本质相同；
- 不给题型名称，让学生自己给问题分类。

目标：从“识别题型外观”转向“识别结构”。

## 4.4 如果卡在验证 H8/H10

训练：

- 构造边界值；
- 找反例；
- 检查唯一性；
- 由答案反推条件；
- 对估算结果做范围验证。

目标：把“验证”变成解题流程的一部分。

## 4.5 如果已经独立完成

不要简单增加计算量。进一步训练：

- 是否有第二种方法；
- 哪个条件可以弱化；
- 能否推广到变量；
- 能否自己构造同结构问题；
- 能否解释方法为什么必然有效。

目标：继续向一般化、构造和证明推进。

# 五、T0 / T1 / T2｜判断课程是否真正提高能力

## T0｜冷启动

Ceiling Diagnostic 第一次独立表现。

记录：C5等级、Hint、首个卡点、H标签。

## T1｜针对训练后的新题迁移

完成 Ceiling Builder / Advanced 教学后，用**不同表面结构**的新问题检查：

- 是否更早发现结构；
- 是否减少 Hint；
- 是否会主动换表示；
- 是否能构造反例；
- 是否能解释和一般化。

## T2｜约7天后的延迟迁移

再次换表面结构，避免把刚学过的短期记忆误认为能力提高。

### 能力提升的证据

至少出现一种：

- Hint 等级下降；
- 独立启动更快；
- 首个卡点后移；
- 能处理更陌生表面；
- 主动使用此前不会使用的表示；
- 能构造反例；
- 能进行一般化；
- 同类 H 错误减少。

# 六、课程如何使用诊断结果

## 1. 每讲设置本讲习惯检查点

不是罗列所有 H，而选择本讲最容易暴露的2～4项重点。

## 2. 重要例题展示错误路径

说明为什么错误看起来合理、哪个检查点能阻止它。

## 3. 当堂训练保留 DIAGNOSTIC 题

专门暴露条件不足、图形干扰、分类、唯一性、符号、对象混淆等问题。

## 4. Ceiling Builder 不机械统一

根据本讲 Ceiling Diagnostic 和长期 H 频率选择训练方式。

## 5. 错题复盘不只抄答案

至少记录：

- 错在哪一步；
- 为什么这样想；
- 应设置什么检查点；
- 下一道条件变化题；
- 是否需要进入某类 Ceiling Builder。

# 七、知识错因 C1～C8

- **C1** 概念错误
- **C2** 条件遗漏
- **C3** 符号错误
- **C4** 运算错误
- **C5** 建模困难
- **C6** 未分类讨论
- **C7** 方法选择不当
- **C8** 表达不规范

一道错题可同时记录知识标签和习惯标签，例如：

> `C6 + H5`：知道要分类，但条件筛选不完整。

---

# 八、阶段性评价

每4～6讲至少复盘：

- 哪个 H 标签最频繁；
- 同一标签是否下降；
- Ceiling Diagnostic 的 C5 等级是否变化；
- T2 延迟迁移是否保持；
- 是否开始主动换表示、构造反例、检查唯一性；
- 面对陌生题是否先分析结构而不是寻找模板；
- 学生能够独立处理的问题复杂度是否提高。

真正的进步标准不是“做过更多难题”，而是：

> **下一道外观不同、结构陌生的问题，学生比以前更有能力自己找到入口、验证路径并走得更远。**
