# 3. Lesson 1｜正数和负数

## 已达到的高深度

- 负数不是简单“减少”，区分状态、位置、余额、变化量、偏差；
- 正负号依赖基准和约定；
- 标准值 / 实际值 / 偏差关系；
- 换基准与整体偏差；
- AMC/CEMC 结构；
- delta / offset / signed integer；
- Final Challenge 使用“基准整体移动 → 偏差总和整体变化”。

## 为什么现有 Final Challenge 不足以单独承担 L5

前文已经系统教学：

- 基准法；
- 基准改变；
- 整体偏差；
- 平均数平衡基准。

Final Challenge 再要求利用“基准改变后所有偏差统一变化”，能很好验证掌握，但独立发现成分已经被前文削弱。

## 需要补的 Ceiling Diagnostic

应放在 Core 完成后、Advanced“基准法/整体偏差”讲解前。

诊断目标：

- 在陌生规则下识别基准；
- 区分状态/变化/偏差；
- 自己发现“统一改变基准会怎样影响多个记录”；
- 不要求预先知道平均数公式或后续运算法则。

优先来源：AMC 8 / Gauss / JMC / 国内正式七年级高档题；若无完全匹配题，再做透明 SYNTHESIS。

# 4. Lesson 2｜有理数的意义与分类

## 已达到的高深度

- 表达形式 ≠ 数学对象 ≠ 分类身份；
- 整数也能写成 p/q；
- 等价表示；
- 有限小数；
- 精确值 vs 近似显示；
- 设备显示反推范围；
- 程序中的整数/表示选择。

## 当前上限问题

Final Challenge“设备四舍五入显示0.38反推可能范围”非常适合概念迁移，但前文已经教学“精确/近似”和显示误差，因此主要测学习后的迁移。

## 需要补的 Ceiling Diagnostic

应在系统讲“精确值 vs 近似值”深化方法前冷启动。

诊断目标：

- 面对同一个数的多个写法，先判断数学对象而非外形；
- 识别信息是否足够确定唯一值；
- 主动发现“有限显示可能对应多个精确值”；
- 能给反例证明“不唯一”。

可从 CEMC / AMC 8 的等价表示、分数小数、测量显示结构中选题或综合。

# 5. Lesson 3｜数轴

## 已达到的高深度

- 数轴三要素；
- 数 ↔ 点；
- 点、坐标、距离区别；
- 左右顺序；
- 非单位刻度；
- 两锚点恢复尺度；
- 损坏数轴；
- CEMC 多个正式 Gauss 数轴结构；
- 一维程序坐标。

## 当前上限问题

Final Challenge“损坏数轴恢复”之前已经教学：

- 非单位刻度；
- 刻度恢复；
- 两锚点；
- 等距/中间位置。

因此 Final Challenge 是优秀的综合 Mastery Challenge，但不能单独代表冷启动上限。

## 需要补的 Ceiling Diagnostic

放在“刻度恢复”方法正式教学前。

诊断目标：

- 学生是否自己意识到先找顺序、再找尺度；
- 是否会拒绝“默认每格1”；
- 是否能从两条独立信息恢复一条数轴；
- 是否会检查唯一性。

优先采用 Gauss / AMC 8 / JMC 中无需后续知识的数轴推理结构。

# 6. Lesson 4｜相反数

## 已达到的高深度

- 相反数 = 关于原点对称；
- 0 的边界；
- a 与 −a；
- −a 不一定为负；
- 连续求相反数；
- 负号不同角色；
- 隐藏原点；
- 等距结构；
- unary minus；
- CEMC 数轴结构；
- AMC / IMO / CMO 等候选池审查已显式记录。

## 当前上限问题

主课第9部分已经直接教学：

> “对称中心不一定是一个标出的刻度”

并使用 8 个等距点、B/G 互为相反数的结构。

Final Challenge 再使用高度同构的 8 点结构，因此它可以测：

- 是否掌握；
- 是否能恢复尺度；
- 是否会参数推广。

但不能充分测：

> 学生在没被提示“隐藏原点”方法前，能否自己发现对称中心。

## 需要补的 Ceiling Diagnostic

应在“隐藏原点”专题讲解前给出一个不同表面结构的问题。

诊断目标：

- 独立发现“互为相反数 → 原点是对称中心”；
- 原点不一定是已标点；
- 不能从图形外观擅自补等距；
- 条件充分性；
- 能用反例处理“不一定”。

题面必须避免直接复刻现有 8 点模板。

# 7. 以后怎样判断学生真实水平

每讲同时保留两类高难题。

## A. Ceiling Diagnostic｜教学前上限探测

记录：

- C5-A：独立完成并一般化；
- C5-B：独立找到核心结构，有次要错误；
- C5-C：Hint 1 后完成；
- C5-D：Hint 2 后完成；
- C5-E：Hint 3 后完成；
- C5-F：看完整解答后理解。

## B. Mastery Challenge｜教学后综合迁移

检查：

- 方法是否真正学会；
- 是否能应用到变化条件；
- 是否能一般化；
- 7天后是否仍能迁移。

两种成绩不能混为一个“正确率”。
