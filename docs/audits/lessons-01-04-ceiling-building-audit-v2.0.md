# 3. Lesson 1｜正数和负数

## 已经具备的 Builder 成分

- 多种负数语义：状态 / 位置 / 变化 / 偏差；
- 换基准；
- 同一现实状态换规则后符号改变；
- 基准法；
- 整体偏差；
- delta / offset；
- Final Challenge 的整体平移。

这些实际已经在训练：

- 表示选择；
- 参照系意识；
- 局部 → 整体；
- 从现实语言抽象成数学模型。

## v2.0 缺口

目前没有明确记录：

1. 学生在学习“换基准/整体偏差”前能否自行发现结构；
2. 如果不能，卡在基准识别、对象区分还是整体关系；
3. 哪组训练专门针对该卡点；
4. 7天后换成完全不同情境是否仍能迁移。

## 建议 Ceiling Builder

### Builder A｜同一个事实，三种编码

给一个现实事实，让学生分别选择三个不同基准/正方向进行记录，再回答：

> 哪些东西改变了？哪些真实关系没有改变？

训练“表示变化 ≠ 对象变化”。

### Builder B｜反向设计

给出一组正负记录，让学生自己设计一个合理的现实基准和语义，使这些记录成立。

训练从数学表达逆向构造模型。

### Builder C｜整体变化一般化

先用3个对象，再换5个、n个对象，让学生自己描述“基准统一移动时总偏差如何变化”。

不要求先给公式，目标是自己形成一般结构。

# 4. Lesson 2｜有理数的意义与分类

## 已有 Builder 成分

- 表达形式 ≠ 数学对象 ≠ 分类身份；
- 6/2、2.0 等写法陷阱；
- 精确值 vs 近似显示；
- 有限显示反推范围；
- 程序整数表示。

已经在训练：

- 不从外形套标签；
- 信息充分性；
- 多表示意识。

## v2.0 缺口

需要把这些训练组织成“从表面分类 → 主动寻找不变量/对象本身”的行为改变。

## 建议 Ceiling Builder

### Builder A｜一数多写

给定同一个数，要求尽可能写出多种表示；再给多种写法，要求判断哪些其实是同一个对象。

最后让学生自己提出：

> 分类到底应该看“写法”还是“值”？

### Builder B｜信息是否足够

给设备显示、测量四舍五入、比例表示等问题，让学生判断：

- 能否唯一确定；
- 如果不能，构造两个不同反例。

训练“不能确定”必须用构造证明。

### Builder C｜自己设计陷阱

让学生设计一个“看起来像分数但实际是整数”的例子，以及一个“显示相同但精确值不同”的例子。

训练主动构造边界和反例。

# 5. Lesson 3｜数轴

## 已有 Builder 成分

- 非单位刻度；
- 损坏刻度；
- 两锚点恢复尺度；
- 点/坐标/距离区别；
- 等距结构；
- 一维程序坐标。

已经在训练：

- 从表示中读取结构；
- 拒绝默认每格1；
- 顺序 → 尺度 → 整体恢复。

## v2.0 缺口

现有方法基本都被直接教学，需要增加“自己选择表示和恢复策略”的过程。

## 建议 Ceiling Builder

### Builder A｜最少信息恢复

给一条没有数字的等距数轴，逐步增加信息，让学生判断：

- 1条信息能否恢复？
- 2条信息什么时候足够？
- 什么信息是冗余的？

训练信息充分性和唯一性。

### Builder B｜构造两种答案

如果条件不足，要求学生画出两条都满足条件但答案不同的数轴。

训练用反例证明“不能确定”。

### Builder C｜换表示

同一个位置问题分别用数轴、温度计、机器人坐标描述，让学生提取共同结构。

训练从情境中抽离数学模型。

# 6. Lesson 4｜相反数

## 已有 Builder 成分

- 相反数 = 原点对称；
- −a 不一定为负；
- 连续求相反数；
- 隐藏原点；
- 条件充分性；
- unary minus；
- 参数化恢复数轴。

已经在训练：

- 从符号回到几何结构；
- 参数分类；
- 对称中心；
- 反例意识。

## v2.0 缺口

“隐藏原点”目前先被教学，再做高度同构挑战；需要把训练重点转向“自己发现对称关系”和“条件是否足够”。

## 建议 Ceiling Builder

### Builder A｜条件删除

分别给：

1. A、D 互为相反数 + 四点等距；
2. 只有 A、D 互为相反数；

要求判断 B、C 是否必然互为相反数，并构造反例。

训练必要条件和 H3。

### Builder B｜自己构造隐藏原点

要求学生自己画一条数轴，使一对相反数的原点不落在任何已标点上，并说明为什么。

训练从“解题”转向“构造结构”。

### Builder C｜符号角色转换

把同一个“−”分别放在负数、取相反数、减法情境中，让学生设计例子说明三种角色不同。

训练符号语义和代数表达能力。

# 7. 每讲的 T0 / T1 / T2 方案

补建 Lesson 1～4 时统一记录：

## T0

独立 Ceiling Diagnostic，无 Hint。

## T1

完成针对性 Ceiling Builder 后，用**不同表面结构**的新题复测。

## T2

约7天后再用另一个不同表面结构复测。

不要求三次题目的数值难度完全相同，但要求测同一种核心能力。

# 8. 重点评价指标

前4讲最值得观察的不是“算得快不快”，而是：

- 是否主动确认基准/对象；
- 是否会质疑条件是否足够；
- 是否主动换一种表示；
- 是否能构造反例；
- 是否能从具体例子抽出一般结构；
- 是否能解释为什么方法有效；
- 面对换皮问题是否仍能启动；
- H3/H7/H9/H10 是否减少。

# 10. 最终判断

Lesson 1～4 已经不是“浅课程”。

v2.0 要解决的是更高一层的问题：

> **课程不能只把学生带到一个高难题的答案，而要训练学生下一次面对陌生题时，更可能自己找到入口。**

因此以后评价课程质量不仅问：

> “这讲讲了多深？”

还必须问：

> **“学完这讲之后，学生独立解决陌生问题的能力是否更强？”**
