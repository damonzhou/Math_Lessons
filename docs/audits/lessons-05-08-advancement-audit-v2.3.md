# Lesson 5～8 v2.3 拔高难度审计

> **标准**：v2.3  
> **结论**：Core / Concept Deepening 基本可保留；Advanced / Competition / Ceiling / Final 需要集中升级。  
> **目的**：把课程从“概念讲深”提升为“查漏补缺 + 概念深化 + 校内中高阶 + 适龄竞赛式拔高”。

---

# 1. 总体结论

Lesson 5～8 当前版本的主要优点：

- 教材知识点覆盖完整；
- 概念解释较深；
- 条件充分性、反例、唯一性和一般化已经开始出现；
- 题源可追溯性已经建立。

主要不足：

- 基础讲解占比仍偏高；
- 很多 Advanced 题实际只达到“基础概念迁移”；
- CEMC Gauss 前段题使用较多，适合作为 Bridge，但不足以代表最高难度；
- Ceiling Diagnostic 的结构突破不够强；
- Final Challenge 对数学明显优秀学生的区分度不足；
- 15～30分钟持续思考价值不稳定。

因此：

```text
概念深度：基本达标
中高阶难度：不足
最高层 Challenge：不足
```

# 2. Lesson 5｜绝对值（一）

## 保留

- 绝对值 = 到0距离；
- 坐标 / 方向 / 距离辨析；
- 信息丢失模型；
- 相反数同绝对值；
- 逆向位置与唯一性意识。

## 当前上限不足

“距离记录器”状态空间较小，一旦发现 ± 对称，后续主要是枚举。

## v2.3 升级方向

至少加入：

1. 多点绝对值信息 + 顺序关系联合恢复；
2. 给定一组绝对值和部分相对位置，求全部可能构型；
3. “最少需要增加多少条方向信息才能唯一恢复”的最小信息问题；
4. 条件冗余 / 必要性判断；
5. Final 必须要求完整构型证明，不只是列举。

目标难度：School Advanced ★★★；Competition ★★★～★★★★；Final ★★★★。

# 3. Lesson 6｜绝对值（二）

## 保留

- 含字母绝对值分类；
- 0边界；
- `|a| = a` / `|a| = −a` 的逆向条件；
- 分类完整性；
- 参数 t 的基础解数讨论。

## 当前上限不足

高阶结构仍以一级绝对值为主，分类层数少。

## v2.3 升级方向

在不使用后续不等式/函数工具的前提下，引入：

1. 嵌套绝对值的数轴解释，例如 `||x|−a| = b`；
2. 参数变化导致解的个数发生变化；
3. 边界值使4解→3解→2解→1解→0解的完整分类；
4. 多条件绝对值关系的构造与反例；
5. Final 需要学生自行找到分界点并证明分类没有遗漏。

目标难度：Competition ★★★★；Final ★★★★～★★★★★。

# 4. Lesson 7｜有理数大小比较

## 保留

- 数轴顺序统一规则；
- 负数比较的镜像解释；
- 原数大小 vs 到0距离；
- 条件充分性；
- 相反数反序的一般化。

## 当前上限不足

现有排序与符号恢复题，结构一旦识别后推理链较短。

## v2.3 升级方向

至少加入：

1. 部分比较信息恢复全部/部分顺序；
2. 只给绝对值关系、符号数量、部分大小条件，列全部合法顺序；
3. 必要条件 / 充分条件 / 充要条件辨析；
4. 构造满足指定排序性质的数集；
5. 极值问题：哪些条件足以确定最大/最小，哪些不足；
6. Final 要求“所有可能排序 + 穷尽证明 + 条件改变后的数量变化”。

目标难度：School Advanced ★★★；Competition ★★★～★★★★；Final ★★★★。

# 5. Lesson 8｜数轴综合

## 保留

- 坐标 / 距离 / 路径长度辨析；
- 中点 = 等距；
- 两锚点 + 等距恢复尺度；
- 动点的起点/方向/步长/步数；
- 条件删除与反例；
- 不提前使用 `|a-b|` 与中点公式。

## 当前上限不足

现有 Advanced 仍以单步中点、简单尺度恢复和同速相遇为主。

## v2.3 升级方向

至少加入：

1. 未知原点 + 未知单位长度的多点重建；
2. 标签互换 / 部分标签缺失的数轴恢复；
3. 多条件距离关系联立；
4. 动点相遇/追及的状态推理，但不依赖正式方程套路；
5. 总路程与最终位置之间的不变量/多路径问题；
6. 某些条件删除后完整分类所有可能模型；
7. Final 至少有“恢复模型 → 多解/唯一性 → 冗余条件 → 一般化”四层结构。

目标难度：Competition ★★★★；Final ★★★★～★★★★★。

# 6. 题源升级要求

Lesson 5～8 后续升级时，题源审查重点提高到：

```text
CEMC Gauss 中后段
AMC 8
UKMT JMC / JMO
国内权威正式考试压轴
国内适龄数学竞赛
```

低编号 Gauss 可以保留，但主要作为：

```text
Gap Check / Bridge / Concept Transfer
```

不再作为最高层难度的主要证据。

AMC 10/12、AIME、IMO、CMO 等只在“当前知识可解 + 年龄匹配 + 无超前工具”时抽取结构，不机械使用原题。

# 7. 升级完成标准

Lesson 5～8 每讲重新发布前必须：

- R2.7 PASS；
- 至少2个真实 School Advanced；
- 至少1个 Competition Transfer；
- Final 达到 ★★★★～★★★★★；
- Final 对优秀学生具有15～30分钟独立思考价值；
- 至少一次唯一性/穷尽性/完整分类证明；
- 高阶难度不是由长计算或超前知识制造；
- SOURCE / ADAPTED / SYNTHESIS 题旁官方链接完整；
- Markdown Render Lint / Problem Source Link Lint 全部通过。
