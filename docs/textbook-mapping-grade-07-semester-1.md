# 1. 权威依据与使用边界

本映射只使用权威一手资料确定课程结构。

## A. 人民教育出版社新版教材总体结构

官方资料：

1. 人教版义务教育数学（七～九年级）新教材介绍  
   https://www.pep.com.cn/xw/zt/hd/12/xjcjs/cz/202408/t20240826_1994351.html
2. 李海东《突出数学本质 重视思维过程 发展核心素养》  
   https://www.pep.com.cn/xw/zt/hd/12/zbtjc/202410/t20241022_1996035.html

官方明确确认：

- 原“有理数”拆分为 **“有理数”** 与 **“有理数的运算”**；
- 新增 **“代数式”** 章；
- 教材按数学逻辑、连续性、整体性、关联性重新组织；
- 一元一次方程仍是初中一次方程主线的重要正式章节。

## B. 课程标准

教育部《义务教育数学课程标准（2022年版）》第四学段明确要求：

- 理解负数、有理数；
- 数轴表示与大小比较；
- 借助数轴理解相反数和绝对值；
- 有理数五种运算与运算律；
- 字母表示数、代数式、列代数式、代数式的值；
- 整式及其加减等；
- 一元一次方程；
- 基础几何图形、线段、角等。

## C. 关于新版小节编号

人教社目前公开可检索的新版介绍可以确认**章级结构变化和知识主线**，但没有在同一官方页面完整公开2026七上所有细小节编号。

因此本表遵循：

> **能权威确认到章/知识节点，就写章/知识节点；不能确认的小节编号绝不猜。**

旧版人教社教师用书可辅助确认长期稳定的知识依赖，例如：

```text
有理数 → 数轴 → 相反数 → 绝对值
```

但旧版编号不冒充2026新版编号。

# 2. 映射类型

- **DIRECT**：直接对应教材正式知识节点；
- **SPLIT**：一个教材节点为讲透概念而拆为多讲；
- **INTEGRATED**：多个已学教材节点的综合训练；
- **BRIDGE**：两个正式教材节点之间必要的认知桥梁；
- **EXTENSION**：不属于当前教材主线，不占正式 Lesson 编号。

```text
有理数
→ 有理数的运算
→ 代数式
→ 整式及整式加减
```

- 教材正式知识节点均进入 Mainline；

- Extension 不占正式编号；
- 新版新增“代数式”得到明确独立覆盖；
- “集合”不再错误进入教材主线。

# 12. 每次发布如何使用本表

发布 Lesson X 前：

1. 找到本表对应行；
2. 把“教材映射 + 映射类型”写入 Lesson 元数据；
3. R0.5 检查 Core 是否覆盖正确；
4. 若课程设计与本表冲突，先 Review 本表，而不是直接写课；
5. 若人教社发布更完整的新版官方目录，以官方资料更新本表并建立新标准版本。
