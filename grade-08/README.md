# 八年级数学

本目录预留给八年级完整课程。

后续建议结构：

```text
grade-08/
├── README.md
├── semester-1/
│   ├── README.md
│   ├── 01-<module>/
```

八年级将在七年级已经建立的分类讨论、数形结合、整体思想、方程思想和几何语言基础上，继续强化函数意识、代数变形、几何证明与综合建模。

具体章节按所使用的人教版教材版本确定。
