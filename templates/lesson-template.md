# R2.7｜Audience / Advancement Fit

本课程默认学生已经学过基础内容。

写课前先回答：

1. 教材知识点是否100%覆盖？
2. 哪些内容只需要 Gap Check，不需要长篇重讲？
3. 哪些是本讲真正的概念难点/易混点？
4. 哪些内容属于校内中高阶？
5. 哪些题能进入高水平竞赛式拔高？
6. 最高层是否主要考查知识的灵活应用和思维深度？

# 0｜课程依据与知识边界

必须确认：

- 教育部课标；
- 人教版官方教材/教师用书；
- 当前学生已学工具；
- 权威一手题源；
- 不依赖未提示 Extension；
- 不用未来公式制造假难度。

> **课标是底线，不是深度上限。**

> **适龄只限制可使用的知识工具，不限制最高思维上限。**

原则：

```text
可以综合过去
不能偷用未来
```

# 1｜难度与学习层级

| 层级 | 难度 | 目标 |
|---|---|---|
| Gap Check | ★ | 快速检查教材基础是否有漏洞 |
| Concept Deepening | ★★～★★★ | 本质、边界、反例、应用 |
| School Advanced | ★★★～★★★★ | 校内中高阶、综合、压轴结构 |
| Competition Transfer | ★★★★ | 陌生结构、灵活调用已学知识 |
| Elite / Final Challenge | ★★★★★ | 当前知识范围内的最高灵活应用与思维深度 |

最高层不能靠对象更多、数字更大、步骤更长或未来知识制造难度。

# 2｜v2.2 思维深度地图

至少覆盖 D1～D6 中四类：

```text
D1 结构发现
D2 条件充分性 / 必要性
D3 反例与边界
D4 唯一性 / 穷尽性 / 分类完整性
D5 具体 → 参数 → 一般化
D6 表示转换与陌生迁移
```

至少有一处要求：

> **为什么答案只有这些？**

---

# 3｜Gap Check｜先查漏，不重复讲

用短题快速覆盖教材 MUST：定义、基本性质、基本方法、规范表达和高频易错点。

```text
全对 / 理由清楚 → 快速通过
有错 / 理由含糊 → 定点补讲
```

---

# 4｜概念深化｜Concept Deepening

围绕：

- 为什么成立；
- 本质区别；
- 边界；
- 条件不可删；
- 反例；
- 表示转换；
- 从具体推广到一般。

---

# 5｜School Advanced｜校内中高阶

至少2个高价值问题，优先：多条件综合、逆向问题、分类讨论、隐藏条件、多解/唯一性、参数和校内压轴结构。

---

# 6｜Ceiling Diagnostic｜T0 冷启动

首次独立，不开放 Hint。

要求：

- 当前及此前知识足够；
- 前文没有完整同构模板；
- 有真实突破口；
- 卡点来自结构而不是计算量；
- 记录首个卡点与 H1～H10；
- 独立尝试后才开放 Hint 1 → 2 → 3 → Full Solution。

---

# 7｜Ceiling Builder｜针对卡点提上限

至少选择一种：表示转换、删除/增加条件、反例构造、逆向构造、多方法比较、特殊到一般、陌生表面迁移。

Builder 必须针对真实卡点，不允许堆同模板题。

---

# 8｜Competition Transfer｜高水平竞赛迁移

优先审查：

```text
CEMC Gauss 中后段
AMC 8
UKMT JMC / JMO
国内权威正式考试压轴
国内适龄数学竞赛
适合的 CSP-J 数学结构
```

同时允许审查 AMC 10/12、AIME、IMO、CMO 等更高赛事中的低知识门槛高思维结构，只要当前知识可解或可透明降阶改编。

赛事名气本身不构成难度证据。

---

# 9｜权威题源与原题链接

标签：`TEXTBOOK-MODEL` / `SOURCE` / `ADAPTED` / `SYNTHESIS` / `DESIGNED`。

`SOURCE / ADAPTED` 题目标题下必须直接写：

```markdown
> 原题：[官方原题｜赛事 年份 组别 Qx](官方链接)  
> 官方解答：[官方解答](官方链接)
```

`SYNTHESIS` 必须明确“无单一原题”；有具体结构来源时题旁列官方链接。

---

# 10｜Elite / Final Challenge｜★★★★★最高层

最高层定义：

> **在不使用未来知识的前提下，尽量逼近本讲核心知识 + 此前已学知识能够达到的最高灵活应用与思维深度。**

必须检查：

1. 题面不泄露方法；
2. 学生需要自行选择/组合知识；
3. 原则上至少有两个非显然思维节点；
4. 至少包含一种反推、构造、极值、不变量、分类、最少性或一般化；
5. 至少有一项完整证明任务；
6. 不与前文高度同构；
7. 有 Hint 1 / 2 / 3 / Full Solution；
8. 解决后能提炼一般结构。

完整证明任务可为：

- 唯一性；
- 穷尽性；
- 不可能性；
- 必要/充分性；
- 最少性下界；
- 一般结论证明。

# R3.8｜Highest-Ceiling Authenticity｜v2.4

发布前必须单独审查最高层：

```text
是否真正逼近当前知识范围内的思维上限？
是否主要考查灵活应用，而不是重复熟练度？
是否至少有两个非显然思维节点？
是否扣除了前文教学泄露造成的降难度？
是否要求学生自行选择/组合知识？
是否存在完整证明负担？
是否只是增加对象数量/条件数量/计算长度？
是否错误地因为年级而降低思维标准？
是否错误地靠未来知识制造难度？
```

若 R3.8 不通过，最高只能 `REVISE`。

有效难度评价：

```text
有效难度
=
原始结构难度
−
前文提示 / 同构例题 / 显式方法造成的降难度
```

# 11｜最高层知识点选择

建议：

```text
1个本讲核心知识核
+
2～4个自然相关的既有知识点
+
1～3个高价值思维工具
```

每个旧知识必须回答：

1. 为什么与本讲存在天然联系？
2. 是否让本讲知识产生新的用法？
3. 删除它后题目的核心思维是否明显变浅？

不能为了“综合”随机拼知识点。

---

# 12｜错误实验室与习惯诊断

优先覆盖：条件读错、所求对象混淆、擅自补隐藏条件、漏分类/漏边界、局部/整体混淆、模板匹配过早、没有检查唯一性/合理性。

统一流程：

```text
提取条件
→ 明确所求
→ 建立关系
→ 执行检查
→ 回代核对
```
