## Markdown 数学公式规范

本仓库面向 GitHub Markdown 阅读，数学公式统一使用 GitHub 支持的数学定界符：

- 行内公式：使用 `$...$`，例如 `$x+1=3$`。
- 独立公式：使用 `$$...$$`，例如：

$$
\frac{a+b}{2}
$$

- 分数统一写成 `\frac{分子}{分母}`，例如 `$\frac{3}{5}$`。
- 不使用 `\(...\)` 或 `\[...\]` 作为公式定界符。
- LaTeX 命令必须放在 `$...$` 或 `$$...$$` 内，不能裸写 `\frac`、`\text`、`\boxed` 等命令。
- 简单数字可直接使用普通 Markdown 文本；只有确实需要数学排版时才使用公式环境。
