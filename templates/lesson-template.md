# R2.7｜Audience / Advancement Fit｜v2.3

本课程默认学生已经学过基础内容。

写课前先回答：

1. 教材知识点是否100%覆盖？
2. 哪些内容只需要 Gap Check，不需要长篇重讲？
3. 哪些是本讲真正的概念难点/易混点？

5. 哪些题能进入适龄竞赛式拔高？
6. Final Challenge 是否能让优秀学生独立思考15～30分钟？

# 0｜课程依据与知识边界

必须确认：

- 教育部课标；
- 人教版官方教材/教师用书；
- 当前学生已学工具；
- 权威一手题源；
- 不依赖未提示 Extension；
- 不用未来公式制造假难度。

> **课标是底线，不是深度上限。**

> **课程主要增量：查漏补缺 + 概念深化 + 应用迁移 + 中高阶拔高。**

---

# 1｜难度与学习层级

| 层级 | 难度 | 目标 |
|---|---|---|
| Gap Check | ★ | 快速检查教材基础是否有漏洞 |
| Concept Deepening | ★★～★★★ | 本质、边界、反例、应用 |
| School Advanced | ★★★ | 校内中高阶、综合、压轴结构 |
| Competition Transfer | ★★★～★★★★ | 适龄竞赛式陌生结构 |
| Elite / Final Challenge | ★★★★～★★★★★ | 15～30分钟独立突破、完整推理与一般化 |

除极少数过渡课外，每讲至少安排：

- 1组 Gap Check；
- 1个 Concept Deepening 核心问题；
- 至少2个 School Advanced 问题；
- 至少1个 Competition Transfer；
- 1个 Elite / Final Challenge。

---

# 2｜v2.2 思维深度地图

至少覆盖 D1～D6 中四类：

```text
D1 结构发现
D2 条件充分性 / 必要性
D3 反例与边界
D4 唯一性 / 穷尽性 / 分类完整性
D5 具体 → 参数 → 一般化
D6 表示转换与陌生迁移
```

至少有一处要求：

> **为什么答案只有这些？**

高阶题增加前先问：

> **如果把计算量大幅降低，这题还剩下什么值得思考？**

---

# 3｜Gap Check｜先查漏，不重复讲

用短题快速覆盖教材 MUST：定义、基本性质、基本方法、规范表达和高频易错点。

规则：

```text
全对 / 理由清楚 → 快速通过
有错 / 理由含糊 → 定点补讲
```

不要让已经掌握的基础内容占用主体课时。

---

# 4｜概念深化｜Concept Deepening

围绕：

- 为什么成立；
- 相近概念有什么本质区别；
- 边界在哪里；
- 哪些条件不可删；
- 能否构造反例；
- 能否换表示理解；
- 能否从具体推广到一般。

这一部分不能只是“再讲一遍定义”。

---

# 5｜School Advanced｜校内中高阶

至少2个高价值问题，优先：多条件综合、逆向问题、分类讨论、隐藏条件、多解/唯一性、参数和校内压轴结构。

至少1题不能主要靠长计算。

---

# 6｜Ceiling Diagnostic｜T0 冷启动

首次独立 10～20 分钟，不开放 Hint。

要求：

- 当前及此前知识足够；
- 前文没有完整同构模板；
- 有真实突破口；
- 卡点来自结构而不是计算量；
- 记录首个卡点与 H1～H10；
- 独立尝试后才开放 Hint 1 → 2 → 3 → Full Solution。

---

# 7｜Ceiling Builder｜针对卡点提上限

至少选择一种：表示转换、删除/增加条件、反例构造、逆向构造、多方法比较、特殊到一般、陌生表面迁移。

Builder 必须针对真实卡点，不允许堆同模板题。

---

# 8｜Competition Transfer｜适龄竞赛迁移

优先审查：

```text
CEMC Gauss 中后段
AMC 8
UKMT JMC / JMO
国内权威正式考试压轴
国内适龄数学竞赛
适合的 CSP-J 数学结构
```

AMC 10/12、AIME、IMO、CMO 可作结构来源，但必须年龄匹配、当前知识可解、无需超前工具。

低编号 Gauss/基础竞赛题可用于 Bridge，但不能长期承担最高层 Challenge。

---

# 9｜权威题源与原题链接

标签：`TEXTBOOK-MODEL` / `SOURCE` / `ADAPTED` / `SYNTHESIS` / `DESIGNED`。

`SOURCE / ADAPTED` 题目标题下必须直接写：

```markdown
> 原题：[官方原题｜赛事 年份 组别 Qx](官方链接)  
> 官方解答：[官方解答](官方链接)
```

`SYNTHESIS` 必须明确“无单一原题”；有具体结构来源时题旁列官方链接。

provenance 必须区分实际采用来源、候选权威题源池审查、Ceiling Diagnostic、Builder、Final Challenge 的来源/设计依据。

---

# 10｜Elite / Final Challenge｜最高层

必须满足：

- 当前知识可解；
- 题面不泄露方法；
- 有真实突破口；
- 优先权威题源/高质量综合结构；
- 有 Hint 1 / 2 / 3 / Full Solution；
- 不与 T0 高度同构；
- 至少包含以下三项中的两项：条件变化/删条件、唯一性/穷尽性证明、参数化/一般化。

发布前必须问：

> **一个明显优秀、已学过基础内容的七年级学生，是否很可能需要独立思考15～30分钟才能完整解决？**

若明显不需要，则 Final 难度不足。

---

# 11｜错误实验室与习惯诊断

优先覆盖：条件读错、所求对象混淆、擅自补隐藏条件、漏分类/漏边界、局部/整体混淆、模板匹配过早、没有检查唯一性/合理性。

统一流程：

```text
提取条件
→ 明确所求
→ 建立关系
→ 执行检查
→ 回代核对
```

---

# 12｜T0 / T1 / T2

T0 记录冷启动独立程度、首个卡点、Hint 等级；T1 用不同表面结构验证迁移；T2 约7天后再用陌生题检查保持。

# 14｜Markdown / LaTeX

- 标题不写 `$...$`；
- 简单数值、单位、变量、简单比较用普通文本；
- LaTeX 只用于真正需要数学结构的表达；
- 完整数学答案不放 `<details>`。

发布前必须通过：

```text
python3 tools/lint_markdown_rendering.py
python3 tools/lint_problem_source_links.py
```
