# 0. 课程依据与知识边界

每一讲必须先确认三件事：

1. 《义务教育数学课程标准（2022年版）》在当前学段要求什么；
2. 当前人教版教材和教师用书怎样安排该知识点；
3. 学生截至本讲已经正式学过哪些工具。

规则：

- **课标与人教版决定主线、顺序和 Core 深度下限；**
- 拓展可以超出教材，但不得依赖大量尚未学习的知识；
- 若一道题只能靠后续公式“碾压”解决，不应作为当前讲的主要挑战题；
- 对超前概念必须标记 `EXTENSION`，并说明是否要求记忆。

统一参考：

- 教育部《义务教育数学课程标准（2022年版）》
- 人民教育出版社对应教材与教师教学用书
- [课程编写统一标准](../docs/course-authoring-standard.md)
- [题源与原创命题规范](../docs/problem-source-policy.md)

# 2. 四轨目标

| 层级 | 目标 |
|---|---|
| **Core** | 教材概念、性质、规范表达无漏洞 |
| **Advanced** | 条件变化、逆向、综合、方法选择 |
| **Olympiad** | 面对陌生问题能发现结构、构造方法 |
| **Informatics** | 理解数学概念如何进入程序和算法 |

最终目标：

$$
\text{知道}\rightarrow\text{理解}\rightarrow\text{应用}\rightarrow\text{迁移}
$$

# 3. 题源标记规范

所有重要例题、训练题和挑战题使用下列标记之一：

- **TEXTBOOK-MODEL**：有教材/教师用书模型依据，但不是原题；
- **SOURCE**：基本保留真实考试或竞赛题数学结构；
- **ADAPTED**：由明确真题核心结构改编；
- **SYNTHESIS**：融合多个可追溯题源，再结合本讲知识重新设计；
- **DESIGNED**：少量教学原创，用于补足题库覆盖不到的重要目标。

每讲必须有：

```text
sources/XX-lesson-name-provenance.md
```

记录赛事、年份、题号、官方链接、改编程度和教学目的。

### 竞赛题源优先池

- **AMC 8**：七、八年级主力竞赛题源；
- CEMC Gauss；
- UKMT Junior Mathematical Challenge / Junior Mathematical Olympiad；
- AMC 10：只选择不依赖超前知识的高质量题；
- CSP-J / NOI：用于信息学数学连接。

不得为了提高“真题比例”而引入与当前知识弱相关的题。

# 第一部分：情境导入

至少使用 1～3 个真正服务于概念的实例。

实例应承担以下至少一种作用：

- 暴露旧知识的不足；
- 让学生发现共同结构；
- 形成猜想；
- 展示真实应用。

至少设置一个：

## 停下来想一想

要求学生先预测、比较、解释或构造，再继续阅读。

---

# 第二部分：概念为什么出现

必须回答：

- 为什么需要它？
- 没有它会在哪类问题中遇到困难？
- 它与旧知识是什么关系？
- 它怎样扩展原有结构？

必要时加入数学史，但历史内容必须服务于概念理解。

---

# 第三部分：核心定义、性质和边界

每个重要概念尽量同时给出：

1. 正式定义；
2. 通俗解释；
3. 数学表达；
4. 正例；
5. 反例；
6. 边界/特殊情况；
7. 与相近概念的区别。

目标不是“背定义”，而是能回答“为什么这个例子属于、那个例子不属于”。

---

# 第四部分：例题链

例题必须递进，不能只是换数字。

建议：

1. **直接应用**：验证定义；
2. **逆向读取**：由结果反推意义或条件；
3. **条件变化**：改变参照、位置、参数或问法；
4. **综合应用**：连接两个以上概念；
5. **方法题**：重点在发现方法；
6. **真实应用**：优先采用教材、AMC、Gauss 等高质量模型。

重要例题至少解释：

- 从哪里入手；
- 为什么这样做；
- 易错在哪里；
- 还能否换一种方法。

---

# 第五部分：错误实验室

选择真正高频的错误观点，逐项分析：

1. 错在哪里；
2. 为什么容易这样想；
3. 哪个反例可以立即推翻；
4. 正确检查流程是什么。

# 第六部分：数学思想 / 方法

本讲明确训练哪些可迁移方法，例如：

- 分类讨论；
- 数形结合；
- 转化；
- 整体；
- 方程；
- 从特殊到一般；
- 构造；
- 不变量；
- 基准与相对；
- 模型化。

必须结合本讲具体题目解释，不能只列名词。

# 第七部分：Advanced

安排 1～3 个自然提高主题。

要求：

- 仍然围绕本讲核心概念；
- 不机械超前；
- 为后续课程建立方法伏笔；
- 优先使用真实考试/竞赛模型。

---

# 第八部分：Olympiad

安排少量高价值问题。

重点不是题目数量，而是：

- 是否需要新的观察角度；
- 是否存在突破口；
- 是否能一题多解；
- 是否能推广。

### 问题设计方法参考

参考 Po-Shen Loh 的 invention-oriented 思路：

- 先给陌生问题；
- 给足独立思考时间；
- 不立即暴露方法；
- 必要时逐级提示；
- 解后比较方法和继续一般化。

这属于**教学方法参考**，不是题源标记。

# 第九部分：Informatics

说明当前数学概念怎样进入程序/算法。

推荐：

1. 数学模型；
2. 最小代码实例；
3. 数学符号与变量对应；
4. 后续算法中的用途。

不能为了“有代码”而加入无关代码。

# 第十一部分：Final Challenge｜每讲必须有

每一讲最后必须有至少一道高强度综合挑战。

## 六条硬标准

1. **知识边界合法**：主要依靠本讲和此前知识可解；
2. **题面不泄露方法**：学生必须自己识别结构；
3. **存在突破口**：难在观察、转化或构造，而非纯计算堆积；
4. **题源可靠**：优先 `SOURCE / ADAPTED / SYNTHESIS`，原创必须解释必要性；
5. **可以逐级提示**：至少 Hint 1 → Hint 2 → Hint 3；
6. **可以解后推广**：至少追问一个“如果条件改变/一般化会怎样”。

### 三级提示

- **Hint 1**：只指出观察方向；
- **Hint 2**：指出关键量或关键关系；
- **Hint 3**：给出接近建模层面的提示，但仍不直接给最终答案。

### 解后再思考

至少选择一项：

- 从具体数推广到字母；
- 改变一个条件重新判断；
- 寻找第二种解法；
- 比较哪种方法更本质；
- 构造同类问题；
- 连接后续数学或算法。
