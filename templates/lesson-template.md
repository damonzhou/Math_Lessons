每讲先确认：

1. 《义务教育数学课程标准（2022年版）》要求；

# 1. 学习层级

## MUST｜必须掌握

核心概念最终达到“会解释”。

## SHOULD｜建议掌握

重要方法、校内拔高和高频迁移。

## EXTENSION｜拓展理解

奥数、信息学和后续数学连接；第一次通常以理解为主，不要求背诵。

# 2. 四轨目标

| 层级 | 目标 |
|---|---|
| Core | 教材概念、性质、规范表达无漏洞 |
| Advanced | 条件变化、逆向、综合、方法选择 |
| Olympiad | 陌生问题中发现结构和突破口 |
| Informatics | 理解数学如何进入程序和算法 |

$$
\text{知道}\rightarrow\text{理解}\rightarrow\text{应用}\rightarrow\text{迁移}
$$

# 3. 本讲习惯检查点｜必须填写

从长期诊断标签 H1～H10 中选择本讲重点，例如：

- H1 条件读取；
- H2 确认所求；
- H3 不从图形擅自补条件；
- H4 先分析关系再套公式；
- H5 分类条件筛选；
- H6 符号检查；
- H7 局部/整体区分；
- H8 估算后验证；
- H9 陌生题不急于套模板；
- H10 回代与合理性检查。

本讲写明：

> **本讲重点纠偏：H__、H__**

并给出一条具体执行规则。

统一五步做题流程：

$$
\boxed{\text{提取条件}\rightarrow\text{明确所求}\rightarrow\text{建立关系}\rightarrow\text{执行检查}\rightarrow\text{回代核对}}
$$

# 4. 题源标记

重要例题、训练题和挑战题使用：

- `TEXTBOOK-MODEL`
- `SOURCE`
- `ADAPTED`
- `SYNTHESIS`
- `DESIGNED`

教学诊断题可额外标：

> `DIAGNOSTIC-Hx`

它表示这道题专门检查某种做题习惯，不改变题源标签。

## 题源池

### Core / Advanced

优先从以下可追溯来源寻找：

- 人教版教材 / 教师用书；
- 校内期中、期末历年真题；
- 区级 / 市级统一考试真题；
- 各地历年中考真题；
- 其他明确年份、地区 / 学校、考试名称和题号的真实试题。

### Olympiad

国内外并行：

- **国内权威数学竞赛 / 奥赛 / 数学邀请赛历年真题**；
- **AMC 8**；
- CEMC Gauss；
- UKMT JMC / JMO；
- 不依赖明显超前知识的 AMC 10；
- 其他来源可靠、适合当前知识边界的高质量竞赛题。

不机械规定国内或国外优先。以**教学目标匹配度、来源可靠性、当前知识可解性**决定。

国内竞赛 / 考试题必须记录赛事或考试名称、年份、组别 / 地区、题号及可靠来源。无法核验的“网传真题”不得标为 `SOURCE`。

### Informatics

优先参考 CSP-J / NOI / NOIP 等正式题目的数学模型。

每讲必须维护：

```text
sources/XX-lesson-name-provenance.md
```

记录教材 / 赛事 / 考试、年份、题号、官方或可靠来源、改编程度、知识边界与教学目的。

# 5. Markdown / LaTeX 与目录

公式：行内 `$...$`，块级 `$$...$$`；不使用 `\(...\)`、`\[...\]`；数学答案不放进 `<details>`。

标题中的单个简单整数、负数若 GitHub 行内数学渲染不稳定，可直接写普通文本，如 `−5`；复杂数学表达仍保留 LaTeX。

目录：

```text
module/
├── XX-lesson-name.md
├── exercises/XX-lesson-name-homework.md
├── solutions/XX-lesson-name-classroom.md
├── solutions/XX-lesson-name-homework.md
└── sources/XX-lesson-name-provenance.md
```

当堂训练题留在主课；答案、课后题、课后答案分开。

# 第一部分：情境导入

至少1～3个真正服务于概念的实例，用来暴露旧知识不足、发现共同结构、产生猜想或展示真实应用。

至少设置一次“停下来想一想”。

---

# 第二部分：概念为什么出现

回答：为什么需要它？没有它会遇到什么困难？它与旧知识是什么关系？它扩展了什么结构？

---

# 第三部分：核心定义、性质与边界

重要概念尽量同时给出：正式定义、通俗解释、数学表达、正例、反例、边界/特殊情况、相近概念区别。

---

# 第四部分：例题链

按递进组织：

1. 直接应用；
2. 逆向读取；
3. 条件变化；
4. 综合应用；
5. 方法题；
6. 真实应用/陌生迁移。

重要例题解析必须说明：

- 从哪里入手；
- 为什么这样做；
- 哪条条件最关键；
- 常见错误路径；
- 哪个习惯检查点能阻止错误；
- 必要时第二种方法。

---

# 第五部分：错误实验室

不只列“注意事项”，而要展示一个真实/高频错误路径：为什么会错、如何用反例或条件检查发现、下次在哪一步设置检查点。

---

# 第六部分：数学思想与 Advanced

明确本讲可迁移的方法：分类讨论、数形结合、转化、整体、方程、构造、不变量、基准、模型化等，并用题目解释。

Advanced 仍围绕当前核心，不机械超前。

---

# 第七部分：Olympiad

少量高价值问题优先于大量重复题。

可从国内权威竞赛 / 奥赛、AMC、Gauss、UKMT 等真实题源中选择最适合当前知识边界的问题。

参考 Po-Shen Loh 的问题设计方法：先给陌生问题、留独立思考时间、逐级提示、比较方法、解后推广。这里只作为方法论参考，不作为题源标签。

---

# 第八部分：Informatics

说明当前数学概念怎样进入程序/算法：数学模型 → 最小代码 → 变量对应 → 后续用途。

---

# 第十部分：Final Challenge｜每讲必须有

必须通过六项审核：

1. 当前知识可解；
2. 题面不泄露方法；
3. 存在真正突破口；
4. 优先有**国内权威竞赛 / 历年考试压轴题 / 国际竞赛**等可追溯真题或明确结构依据；
5. 有 Hint 1 → Hint 2 → Hint 3；
6. 解后能够一般化、改变条件、比较方法或连接后续知识。

答案结构：

```text
独立思考
↓
Hint 1：观察方向
↓
Hint 2：关键量
↓
Hint 3：关键关系
↓
完整解析
↓
方法提炼
↓
解后再思考
```

Final Challenge 的结束点是：

$$
\text{一道题}\rightarrow\text{一种方法}\rightarrow\text{一类结构}
$$

# 第十一部分：错因与习惯复盘

知识标签：C1～C8；习惯标签：H1～H10。

每道典型错题记录：

- 错误发生在哪一步；
- 为什么当时会这样想；
- 应设置什么检查点；
- 条件改变后能否迁移。

---

# 第十二部分：掌握度检测

设计5～10个不看讲义的口头问题。

- Level 1 会认
- Level 2 会用
- Level 3 会解释
- Level 4 会迁移

Core 最终稳定达到 Level 3；重要核心知识通过后续复习达到 Level 4。

---

# 第十三部分：课后练习、复习与知识地图

课后练习：基础巩固、理解应用、Olympiad、Informatics，至少一题要求解释“为什么”。

24小时复习：主动回忆 + 重做关键题。  
7天复习：条件变化后的迁移题 + 检查 H 标签是否改善。

最后给出知识地图和下一讲连接。
