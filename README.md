# Math Lessons

面向初中数学（七至九年级）的系统自学与进阶课程仓库。

课程以人教版教材为主线，但不止于课本知识点：每一讲同时覆盖概念来源、严格定义、典型例题、易错辨析、变式训练、数学思想、进阶问题与阶段检测，目标是建立可迁移的数学能力。

## 课程层级

每个知识模块按四层组织：

1. **L1 教材层**：定义、性质、公式、基本技能。
2. **L2 变式层**：易错、逆向、综合和校内中高档题。
3. **L3 方法层**：分类讨论、数形结合、整体、转化、方程等数学思想。
4. **L4 拓展层**：参数、动态、规律、新定义与适度压轴训练。
