# Math Lessons

面向初中数学（七至九年级）的系统自学、进阶、奥数与信息学数学课程仓库。

课程以人教版教材为主线，但不把教材目录当作能力上限。每一讲都尽量形成完整学习闭环：从真实问题和概念来源开始，经过定义、反例、例题链、数学思想、分层训练，再延伸到奥数和信息学中的同一数学结构。

## 课程总目标

课程希望建立这样的纵向路径：

$$
\text{课内主线}
\longrightarrow
\text{校内拔高}
\longrightarrow
\text{奥数/竞赛思维}
\longrightarrow
\text{信息学数学迁移}
$$

重点不是机械超前，而是让同一个概念在不同层次逐步加深。

## 四轨课程体系

### Core｜课内主线

定义、性质、公式、基本技能、教材典型题和规范表达。

目标：课内知识无漏洞。

### Advanced｜校内拔高

易错辨析、逆向问题、条件变化、参数意识、分类讨论、综合题和数学思想。

目标：能识别结构、选择方法并稳定解决校内中高档题。

### Olympiad｜奥数 / 竞赛思维

数论、代数技巧、组合、构造、不变量、极端思想、几何证明等内容，与当前课内知识自然衔接。

目标：建立竞赛思维，而不是单纯堆难题。

### Informatics｜信息学数学

把当前数学概念连接到程序和算法，例如：

- signed / unsigned；
- 坐标与 offset；
- 进制；
- 模运算；
- gcd / lcm；
- 递推；
- 组合计数；
- 图论；
- 算法复杂度中的数学。

目标：理解算法为什么成立，而不是只记代码模板。

## 单课必须具备的丰富度

每一讲原则上包含：

`学习方式 → 情境导入 → 概念来源 → 定义与反例 → 概念扩展 → 递进例题链 → 错误实验室 → 数学思想 → Advanced → Olympiad → Informatics → 当堂训练 → 课后作业 → 答案与提示 → 错因记录 → 掌握度检测 → 复习计划 → 知识地图 → 后续连接`

课程不采用“定义 + 两个例题 + 一页练习”的简略模式。

## 数学公式

仓库保留 LaTeX 数学表达，并以 GitHub Web 的公式渲染为准：

- 行内公式：`$...$`
- 独立公式：`$$...$$`

不为了 GitHub Mobile 当前的公式渲染限制而把复杂数学表达退化成纯文本，以保证后续奥数、代数、几何和信息学数学内容有足够的表达能力。
