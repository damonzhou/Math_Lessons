# 七年级数学

七年级课程的重点不是单纯提前学习，而是完成从小学算术到初中代数与几何语言的过渡。

## 上学期核心能力

- 数系扩张与分类意识；
- 数轴与数形结合；
- 有理数运算与符号意识；
- 从具体数到字母表示；
- 整体思想与整式运算；
- 方程思想与实际问题建模；
- 几何语言、位置关系与初步推理；
- 分类讨论与条件意识。

## v1.5 课程组织

正式 Mainline 优先保持：

$$
\boxed{\text{课标要求}+\text{人教版顺序}+\text{知识依赖}+\text{认知连续性}}
$$

Advanced / Olympiad / Informatics 会持续深入，但主要属于方法论或竞赛的专题优先放入 `semester-1/extensions/`，以后真正需要时由主课明确提示学习。

当前七上数系主线：

```text
正数和负数
→ 有理数
→ 数轴
→ 相反数
→ 绝对值
→ 有理数大小比较
→ 数轴综合
```

集合直觉、余数分类、抽屉原理等已保存在 Extension E1，不作为数轴前置。
