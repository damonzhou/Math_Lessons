# 七年级上册 · Extensions

这里保存**不占正式教材主线编号，但对 Advanced / Olympiad / Informatics 有长期价值**的专题。

这些专题不是“删掉的课”，而是采用 v1.5 的**需要时提示学习**机制。

## 使用规则

后续 Mainline Lesson 第一次明显依赖某个专题时，正文必须显式提示：

> **前置扩展提示（OPTIONAL / RECOMMENDED / REQUIRED-FOR-EXTENSION）**：本节会使用 ______ 思想。建议先学习：[专题链接]。

未提示的 Extension 不得成为 Core 或 Final Challenge 的隐藏前置。

## 当前专题

### E1｜[分类是一种数学方法——集合直觉、余数与抽屉原理](./classification-as-a-method.md)

来源：原正式 Lesson 3，经 v1.5 主线定位 Review 后迁入 Extension。

适合在以下场景出现时学习：

- **RECOMMENDED**：需要系统区分“属于 / 包含 / 相交”；
- **RECOMMENDED**：整数整除、奇偶和余数分类明显增多；
- **REQUIRED-FOR-EXTENSION**：首次正式使用抽屉原理；
- **RECOMMENDED**：处理两个性质集合的重复计数；
- **RECOMMENDED**：Informatics 中讨论互斥分支与多个布尔标签。

主要内容：

```text
分类标准
→ 不重不漏
→ 元素/集合直觉
→ 互斥 / 包含 / 相交
→ 奇偶 / 余数分类
→ 周期 / 筛选
→ 抽屉原理
→ 程序条件分支
```
