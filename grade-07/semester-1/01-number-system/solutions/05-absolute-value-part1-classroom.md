# A｜Gap Check

## G1｜绝对值是什么

绝对值表示：

> 一个数在数轴上对应的点到原点0的距离。

关键词：

```text
数轴
原点
距离
```

如果只说“去负号”，说明概念理解仍停留在表面操作。

## G2｜具体求值

```text
|7| = 7
|−9| = 9
|0| = 0
|−2.5| = 2.5
|3/4| = 3/4
```

## G3｜“绝对值就是把负号去掉”

不准确。

例如：

```text
|5| = 5
|0| = 0
```

这里没有负号可去。

正确原因始终是“到原点的距离”。

## G4｜点 P 的坐标 −6

```text
位置：原点左侧
距离：6
绝对值：6
```

## G5｜距离5能否唯一恢复

不能。

```text
−5，5
```

都到原点距离5。

## G6｜为什么绝对值不能是 −3

绝对值表示距离，而距离不能为负。

## G7｜两个不同数绝对值都是4

```text
−4，4
```

它们互为相反数。

## G8｜位置和距离

`−8` 是带方向的位置坐标；`|−8| = 8` 中的8只表示离原点8个单位。

# C｜School Advanced A1

题目：4个互不相同整数，绝对值依次为：

```text
4，1，4，6
```

设有序四元组为 `(a,b,c,d)`。

因为第1、第3个绝对值都为4，而且原数不同，所以：

```text
(a,c) = (−4,4)
```

或：

```text
(a,c) = (4,−4)
```

第二个数：

```text
b = −1 或1
```

第四个数：

```text
d = −6 或6
```

共有三个彼此独立的二选一：

```text
a/c方向
b方向
d方向
```

所以共有：

```text
2 × 2 × 2 = 8种
```

为什么不重不漏：每个仍未确定的方向选择都已覆盖，而且每个组合得到不同的有序四元组。

# D｜School Advanced A2

已知：

```text
|A| = 5
|B| = 2
A < B
```

候选：

```text
A = −5 或5
B = −2 或2
```

逐结构判断：

- 若 A = 5，无论 B = −2 还是2，都不满足 `A < B`；
- 所以 A 必须为 −5；
- B 仍可为 −2 或2。

全部合法：

```text
(A,B) = (−5,−2)
(A,B) = (−5,2)
```

增加 `A > 0` 会与原条件矛盾，因此不是“唯一”，而是**无解**。

这正是条件题的一个检查点：

> 新增条件可能唯一化，也可能把问题变成无解。

如果增加 `B < 0`，则：

```text
(A,B) = (−5,−2)
```

唯一。

# E｜Competition Bridge C1

数：

```text
−1，6/5，−3/4，0.85，1.1
```

到0距离：

```text
1，1.2，0.75，0.85，1.1
```

离0最近：

```text
−3/4
```

原数最小：

```text
−1
```

两个问题不同，因为：

```text
原数大小看数轴左右
距离大小看离0远近
```

# F｜Competition Bridge C2

数：

```text
−15，−11，4，12，14
```

结果：

```text
最大数：14
最小数：−15
离0最近：4
离0最远：−15
```

注意“最小数”和“离0最远”这次碰巧相同，但概念仍不同；换一组数时完全可能不同。
