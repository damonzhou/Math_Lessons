# A｜Gap Check

## G1｜绝对值是什么

绝对值表示：

> 一个数在数轴上对应的点到原点0的距离。

关键词：

```text
数轴
原点
距离
```

## G2｜具体求值

```text
|7| = 7
|−9| = 9
|0| = 0
|−2.5| = 2.5
|3/4| = 3/4
```

## G3｜“绝对值就是把负号去掉”

不准确。

例如：

```text
|5| = 5
|0| = 0
```

都不存在“去负号”。正确概念始终是到原点的距离。

## G4｜点 P 的坐标 −6

```text
位置：0左侧
距离：6
绝对值：6
```

## G5｜距离5能否唯一恢复

不能。

```text
−5，5
```

都到0距离5。

## G6｜为什么绝对值不能是 −3

绝对值表示距离，距离不能为负。

## G7｜两个不同数绝对值都是4

只能是：

```text
−4，4
```

因为数轴上到0距离4的位置只有左侧 −4 和右侧4，没有第三个位置。

## G8｜位置和距离

`−8` 是带方向的位置坐标；`|−8| = 8` 中的8只表示到0的距离。

# C｜School Advanced A1｜同侧能告诉多少

已知：

```text
|A| = 2
|B| = 5
```

且 A、B 同侧。

原本四个符号组合为：

```text
(−2,−5)
(−2,5)
(2,−5)
(2,5)
```

“同侧”排除一正一负的两组，只剩：

```text
(A,B) = (−2,−5)
(A,B) = (2,5)
```

所以同侧信息把4种压到2种，但仍不能决定整个系统究竟在左还是右。

再增加任意一个绝对方向信息即可唯一，例如：

```text
A > 0
```

则唯一为：

```text
(A,B) = (2,5)
```

# D｜School Advanced A2｜异侧 + 方向锚点

已知：

```text
|P| = 3
|Q| = 7
```

P、Q 异侧，并且：

```text
P > 0
```

所以：

```text
P = 3
Q = −7
```

如果删掉 `P > 0`，则有两组：

```text
(P,Q) = (3,−7)
(P,Q) = (−3,7)
```

两类信息作用不同：

- “异侧”告诉 P 与 Q 的**相对方向**；
- `P > 0` 告诉 P 的**绝对方向**。

有了二者，Q 的绝对方向也被传递出来。

# E｜School Advanced A3｜冗余条件

已知：

```text
|M| = |N| = 6
```

且 M、N 是两个不同的数。

数轴上到0距离6只有两个位置：

```text
−6，6
```

所以已经强制：

```text
{M,N} = {−6,6}
```

因此“M、N在0两侧”没有排除任何新候选，是冗余条件。

真正能决定“谁在右侧”的信息必须带绝对方向，例如：

```text
M > 0
```

则：

```text
M = 6，N = −6
```

# F｜Competition Bridge C1

数：

```text
−1，6/5，−3/4，0.85，1.1
```

到0距离：

```text
1，1.2，0.75，0.85，1.1
```

所以：

```text
原数最小：−1
离0最近：−3/4
```

原数大小看数轴位置；离0远近看绝对值。

# G｜Competition Bridge C2

数：

```text
−15，−11，4，12，14
```

结果：

```text
最大数：14
最小数：−15
离0最近：4
离0最远：−15
```

“最小”和“最远”这次碰巧相同，但比较对象不同。
