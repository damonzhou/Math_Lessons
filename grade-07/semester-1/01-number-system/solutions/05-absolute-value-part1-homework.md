# A组｜Core

## 1

绝对值是：

> 一个数在数轴上对应的点到原点的距离。

绝对值描述距离大小，不保存左右方向。

---

## 2

```text
|9| = 9
|−14| = 14
|0| = 0
|−0.75| = 0.75
|5/6| = 5/6
|−13/5| = 13/5
```

---

## 3

1. 错。绝对值不是位置，而是到原点的距离。
2. 对。
3. 错。距离不能为负。
4. 对。0就在原点。

---

## 4

点 P 表示 −7：

1. 坐标：−7；
2. 位于原点左侧；
3. 到原点距离：7；
4. `|−7|` 表示第3种信息，也就是距离。

---

## 5

距离6对应两个位置：

```text
−6，6
```

不能只写6，因为题目没有给方向。

如果再知道点在原点左边，则答案唯一为：

```text
−6
```

# B组｜理解与迁移

## 6｜CEMC 2019 结构改编

各数到0的距离：

```text
−8 → 8
−1.5 → 1.5
2 → 2
−3 → 3
4 → 4
```

最小距离为1.5，所以离0最近的是：

```text
−1.5
```

---

## 7｜CEMC 2022 结构改编

距离分别为：

```text
−1 → 1
6/5 → 6/5 = 1.2
−3/4 → 3/4 = 0.75
0.85 → 0.85
1.1 → 1.1
```

最小距离为0.75，所以离0最近的是：

```text
−3/4
```

“原数最小”和“离0最近”是不同问题。

例如 −1 比 −3/4 小，但 −3/4 离0更近。

---

## 8

绝对值为4.2的两个不同数只能是：

```text
−4.2，4.2
```

它们关于原点对称，互为相反数。

---

## 9

A 到0距离3：

```text
A = −3 或3
```

B 到0距离5：

```text
B = −5 或5
```

再使用“A在B右边”。

逐一检查：

```text
A=3，B=5      不成立
A=3，B=−5     成立
A=−3，B=5     不成立
A=−3，B=−5    成立
```

所以有两组：

```text
(A,B) = (3,−5)
(A,B) = (−3,−5)
```

不能唯一确定。

若再知道“A在0右边”，则唯一为 `(3,−5)`；若知道“A在0左边”，则唯一为 `(−3,−5)`。

# C组｜Ceiling Builder / Advanced

## 10

输出：

```text
3，0，3，5
```

4个输入不同。

- 输出0的输入唯一为0；
- 两个输出3来自两个不同整数，因此必须分别是 −3 和3；
- 输出5可能来自 −5 或5。

两个“3”的输入顺序有2种，最后“5”的方向有2种，所以共有：

```text
2 × 2 = 4组
```

---

## 11

删除“输入不同”后，两个输出3不必分别来自 −3 和3。

它们可以是：

```text
(−3,−3)
(−3,3)
(3,−3)
(3,3)
```

输出5还有2种方向，因此共有：

```text
4 × 2 = 8组
```

“输入不同”这条条件的作用是排除两个输入落在同一个原位置的情况。

---

## 12

若：

```text
y = abs(x) = 8
```

则：

```text
x = −8 或8
```

如果额外保存“x原来在0左边还是右边”，就能恢复x。

如果 y = 0，则原输入只能是0，不需要方向信息。

---

## 13

示例：

```text
−3/2，3/2，4
```

取绝对值后：

```text
3/2，3/2，4
```

只有两个不同输出，因为一对相反数 −3/2 与3/2 被映射到同一个距离3/2。

学生答案不唯一，只要满足题目条件即可。

---

## 14｜CEMC 2021 结构改编

距离分别为：

```text
1/2，1/8，1/3，1/6，1/9
```

其中最小的是1/9，所以离0最近的是：

```text
1/9
```

如果全部换成相反数，到0的距离完全不变。

原因：相反数关于原点对称，绝对值相同。

# D组｜综合挑战

## 15

绝对值0对应：

```text
0
```

绝对值3出现两次，而且4个整数互不相同，所以必须是：

```text
−3，3
```

目前已有1个负数：−3。

题目要求恰好2个负数，因此绝对值5对应的数必须是：

```text
−5
```

所以4个整数唯一为：

```text
−5，−3，0，3
```

如果删除“恰好有2个负数”，绝对值5可以是 −5 或5，所以有2种集合：

```text
{−5,−3,0,3}
{−3,0,3,5}
```

---

## 16

### 断言1

错误。

反例：

```text
−2 和2
```

绝对值都为2，但两个数不同。

### 断言2

正确。

两个不同的数绝对值相等，说明它们到原点距离相同又不是同一点，因此只能位于原点两侧的对称位置，互为相反数。

### 断言3

正确。

只有原点自己到原点的距离为0，所以绝对值为0的数只能是0。

# E组｜快速复测参考

1. 绝对值是距离，不是位置。
2. −10离原点10个单位，所以 `|−10| = 10`。
3. 一个正的绝对值通常对应两个原数：一正一负。
4. 0只对应原点一个位置。
5. `abs()` 保留幅度/距离，丢失符号/方向。
