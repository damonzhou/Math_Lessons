# 第5讲 课后练习答案｜绝对值（一）｜v2.4

> 先独立完成，再核对。重点核对：是否找到了真正自由度、是否证明不重不漏、是否把“足够”与“最少”区分开。

---

# A组｜Gap Check

## 1

绝对值表示一个数在数轴上对应的点到原点0的距离。

## 2

```text
|−12| = 12
|3.5| = 3.5
|0| = 0
|−7/9| = 7/9
|11/4| = 11/4
```

## 3

距离6.5对应：

```text
−6.5，6.5
```

一维数轴上从0出发固定正距离只有左、右两个位置。

增加“在0左侧”或“在0右侧”这样的绝对方向信息即可唯一恢复。

## 4

`|x| = 0` 只对应原点：

```text
x = 0
```

而 `|x| = 5` 对应：

```text
x = −5 或5
```

差别来自距离0没有方向二义性，而正距离有左右两个位置。

# B组｜Flexible Application

## 5｜重复绝对值不是三个自由符号

因为 A、B 不同且：

```text
|A| = |B| = 4
```

所以：

```text
(A,B) = (−4,4)
```

或：

```text
(A,B) = (4,−4)
```

A/B 整对只有2种有标签方向分配。

C 有：

```text
C = −7 或7
```

所以总配置：

```text
2 × 2 = 4种
```

不能写8种，因为 A、B 不能同时为4，也不能同时为 −4；“原数互不相同 + 相同正绝对值”已经把二者强制成相反数对。

## 6｜相对方向传播

关系：

```text
P、Q异侧
Q、R同侧
R、S异侧
```

一旦选定 R 的方向，其余全部确定。

例如 R > 0：

```text
R = 9
Q = 5
P = −2
S = −11
```

另一组是整体镜像：

```text
R = −9
Q = −5
P = 2
S = 11
```

所以没有绝对方向时恰好2组。

若再知道：

```text
R < 0
```

唯一为：

```text
(P,Q,R,S) = (2,−5,−9,11)
```

又因为 P 与 R 都和 Q 异侧，所以 P 与 R 同侧；S 与 R 异侧，因此 P 与 S 也异侧吗？重新沿关系检查：

- P 与 Q 异侧；
- Q 与 R 同侧，所以 P 与 R 异侧；
- R 与 S 异侧，所以 P 与 S 同侧。

因此 `P、S同侧` 已由前三条推出，是冗余信息。

## 7｜整体反向实验

例如取：

```text
(P,Q,R,S) = (−2,5,9,−11)
```

整体取相反数得到：

```text
(2,−5,−9,11)
```

改变的是：

```text
每个点究竟在左还是右
```

没有改变的是：

```text
每个绝对值
任意已知的同侧/异侧关系
```

所以相对方向信息可以非常丰富，却仍然可能缺少整个系统的绝对朝向。

## 8｜删一条关系

四条关系把五个标签联系成一个整体。

因此只剩整体朝左/朝右两种符号模式：

```text
2种
```

删除 `B、C异侧` 后，关系分成：

```text
A—B

C—D—E
```

两部分都可以独立整体翻转，所以：

```text
2 × 2 = 4种
```

不是因为“少一条条件所以随便多一种”，而是因为一个整体被切成了两个独立方向部分。

## 9｜什么信息能一定打破镜像

### A 再给一个点的绝对值

不能。绝对值在整体镜像下不变。

### B 再告诉两点同侧

不能保证。同侧关系在整体镜像下不变。

### C 再告诉两点异侧

不能保证。异侧关系同样在整体镜像下不变。

### D 告诉一个指定点在0右侧

能。关系已经把所有点联系成一个整体，一个绝对方向锚点即可决定整组朝向。

### E 告诉“至少有一个点在0右侧”

不能保证。

如果某合法配置本来就同时含正、负点，它的整体镜像也仍同时含正、负点，两组都会满足“至少一个在右”。

所以只有 D **一定**能打破整体镜像二义性。

# C组｜Competition Bridge

## 10

原数：

```text
−1.1，−7/8，0.82，5/6，1.05
```

距离约为：

```text
1.1，0.875，0.82，0.833...，1.05
```

所以：

```text
原数最小：−1.1
离0最近：0.82
```

一个比较数轴位置，一个比较到0距离。

## 11

距离分别为：

```text
1/2，1/8，1/3，1/6，1/9
```

最小距离是：

```text
1/9
```

所以离0最近的是 `1/9`。

全部取相反数后，每个点到0距离不变，因此距离排序不变。

# D组｜Elite Transfer

## 12.1｜重复距离先强制成对

绝对值2出现两次且点互不相同，所以必有：

```text
−2，2
```

绝对值5同理：

```text
−5，5
```

绝对值1只有一次：

```text
−1 或1
```

绝对值8只有一次：

```text
−8 或8
```

## 12.2｜全部合法有序坐标

四种单值符号组合中，按从左到右排序并检查第4个位置 D > 0。

合法三组：

```text
(−5,−2,−1,2,5,8)
(−8,−5,−2,1,2,5)
(−5,−2,1,2,5,8)
```

第四种：

```text
(−8,−5,−2,−1,2,5)
```

第4个位置为 −1，不满足 D > 0，因此排除。

所以恰好3组。

## 12.3｜为什么只问左右仍不能保证唯一

比较：

```text
(−5,−2,−1,2,5,8)
```

和：

```text
(−8,−5,−2,1,2,5)
```

它们对标签 A～F 的符号模式完全相同：

```text
负、负、负、正、正、正
```

因此无论继续问 A～F 中谁在左/右，两组回答都完全相同。

所以只问符号永远无法区分这两组。

## 12.4｜还丢失了什么

还丢失了：

> **标签与具体绝对值之间的对应关系。**

主课 Final 中这层对应关系是已知的，本题故意删除它。

## 12.5｜一种新的询问类型

例如问：

> `|A|` 是否等于8？

- 若是，选第二组；
- 若否，在这两个候选中选第一组。

也可以设计其他能够直接探测“标签—距离对应”的问题。

关键原则：

> 缺失哪类信息，就必须让询问能够区分哪类信息。

继续重复询问已经知道的符号模式没有用。

# E组｜High-Ceiling Proof

## 13.1｜最少相对关系

有6个彼此独立方向组，最终只允许1个绝对方向锚点。

要让一个锚点的方向能够传播到全部6组，所有方向组必须通过相对方向关系联系成一个整体。

最少需要：

```text
5条有效相对关系
```

## 13.2｜一个充分方案

把6组依次记为：

```text
G1，G2，G3，G4，G5，G6
```

保存：

```text
G1与G2的相对方向
G2与G3的相对方向
G3与G4的相对方向
G4与G5的相对方向
G5与G6的相对方向
```

再给 G1 一个绝对方向锚点。

即可沿链恢复所有组。

## 13.3｜为什么4条一定不够

开始有6个互不联系的方向部分。

每条**有效**相对关系最多把两个原本独立的部分合成一个，所以最多让独立部分数减少1。

4条之后至少还剩：

```text
6 − 4 = 2个独立部分
```

一个绝对方向锚点只能给其中一个部分定向；另一个部分仍可整体翻转。

因此4条不够，5条最少。

## 13.4｜若只有3条关系

至少剩：

```text
6 − 3 = 3个独立方向部分
```

## 13.5｜什么叫有效关系

如果一条新关系连接的是两个**此前已经能互相推知相对方向**的标签，它没有把两个独立部分合并，就没有减少新的自由度。

真正有效的关系应连接两个原本互不联系的方向部分。

# F组｜T2 延迟迁移

## 14

若5个传感器的相对方向关系已经把它们全部联系成一个整体，则选定任意一个传感器的绝对方向后，其余全部能沿关系恢复。

但在没有绝对方向锚点时：

- 一套合法方向配置；
- 把所有“偏高/偏低”同时反转后的配置；

会给出完全相同的“方向相同/相反”记录。

所以仍有整体反向二义性。

最少再保存：

```text
1条绝对方向信息
```

如果关系分成两个互不联系的部分，则两个部分可以分别独立整体反向，因此最少需要：

```text
2条绝对方向信息
```

即每个独立部分至少一个方向锚点。
