# A组｜Gap Check

## 1

绝对值表示一个数在数轴上对应的点到原点0的距离。

## 2

```text
|−12| = 12
|3.5| = 3.5
|0| = 0
|−7/9| = 7/9
|11/4| = 11/4
```

## 3

P 的坐标为 −9：

```text
方向：0左侧
距离：9
|−9|：表示到0距离9
```

## 4

距离6.5对应：

```text
−6.5，6.5
```

只有两个，因为一维数轴上从0出发固定距离只有左、右两个方向。

若再知道“点在0左侧”，唯一为 −6.5；若知道“点在0右侧”，唯一为6.5。

## 5

距离0只能停在原点，所以只有0。

正距离 d 可以向左或向右各走 d 个单位，所以通常对应两个位置。

# B组｜Concept / School Advanced

## 6

因为 a、c 不同且：

```text
|a| = |c| = 5
```

所以：

```text
{a,c} = {−5,5}
```

a/c 谁在左有2种；b 为 −2 或2有2种；d 为 −7 或7有2种。

因此：

```text
2 × 2 × 2 = 8种
```

完整性的理由：三个独立方向选择都已经覆盖，每个组合都得到不同有序四元组。

## 7

```text
|A| = 6
|B| = 4
A < B
```

若 A = 6，则 B = −4 或4，都不满足 `A < B`。

因此：

```text
A = −6
```

而 B 仍可以：

```text
−4 或4
```

全部两组：

```text
(A,B) = (−6,−4)
(A,B) = (−6,4)
```

增加 `B < 0` 后唯一：

```text
(A,B) = (−6,−4)
```

增加 `A > 0` 与原有 `A < B`、`|A|=6`、`|B|=4` 冲突，因此无解。

这提醒：新增条件不一定“帮助唯一化”，也可能让所有候选被排除。

## 8

```text
|P| = |R| = 8
```

且 P、R 不同，所以：

```text
{P,R} = {−8,8}
```

又因为 Q 只能为 −3 或3，而 `P < Q`，P 不可能为8。

所以：

```text
P = −8
R = 8
```

于是 `R > 0` 已经自动成立。

删除 `R > 0` 后答案不变，所以它是冗余条件。

冗余条件：在其他条件已经成立时，它不再排除任何新的候选。

## 9

```text
|P| = |R| = 1
|Q| = |T| = 4
|S| = 6
```

所以：

```text
{P,R} = {−1,1}
{Q,T} = {−4,4}
S = −6 或6
```

三个独立方向选择：

```text
P/R谁左
Q/T谁左
S方向
```

因此：

```text
2 × 2 × 2 = 8种配置
```

最少3次“左/右”询问。

一种方案：问 P、Q、S 的方向。

为什么2次不够：两次二选一最多产生4种回答组合，不能区分8种合法状态。

# C组｜Competition Bridge

## 10

原数：

```text
−1.1，−7/8，0.82，5/6，1.05
```

到0距离约为：

```text
1.1，0.875，0.82，0.833...，1.05
```

所以：

```text
原数最小：−1.1
离0最近：0.82
```

原数大小看数轴左右；离0远近看绝对值大小。

## 11

距离为：

```text
1/2，1/8，1/3，1/6，1/9
```

最小距离是1/9，所以离0最近的是：

```text
1/9
```

全部换成相反数后，每个数到0距离不变，因此距离排序完全不变。

# D组｜Elite Transfer

## 12.1｜先恢复重复绝对值

绝对值2出现两次，原点互不相同，所以必须出现：

```text
−2，2
```

绝对值5同理：

```text
−5，5
```

绝对值1只出现一次：

```text
−1 或1
```

绝对值8只出现一次：

```text
−8 或8
```

## 12.2｜使用 `D > 0`

分别组合单次出现的1和8并排序。

得到4个候选集合，其中只有以下3组满足第4个位置 D 为正数：

```text
情况1：−5，−2，−1，2，5，8
情况2：−8，−5，−2，1，2，5
情况3：−5，−2，1，2，5，8
```

所以：

```text
(A,B,C,D,E,F)
```

共有上面3种。

## 12.3｜为什么只有3种

重复值2和5已经固定为相反数对。

只剩两个独立符号选择：

```text
1取左还是右
8取左还是右
```

共4个原始组合。

逐一按从小到大排序并使用 `D > 0`，其中1个被排除，剩3个。

所以不漏。

## 12.4｜只问左右方向能否最终唯一恢复

不能保证。

比较情况1与情况2：

```text
情况1：−5，−2，−1，2，5，8
情况2：−8，−5，−2，1，2，5
```

它们的标签符号模式完全相同：

```text
A负，B负，C负，D正，E正，F正
```

所以无论问 A、B、C、D、E、F 中任何标签在左还是右，两组给出的回答都一样。

因此问再多“左右”问题也无法区分这两组。

## 12.5｜还丢掉了什么

记录器不仅丢了方向，还丢了：

> **哪个绝对值属于哪个标签。**

也就是“距离值与标签的对应关系”。

## 12.6｜一种可以完成恢复的询问方案

先问：

> C 在0左边还是右边？

- 若 C > 0，立即确定为情况3；
- 若 C < 0，还剩情况1、2。

再问：

> `|A|` 是否等于8？

- 是：情况2；
- 否：情况1。

所以允许“方向问题 + 标签对应距离问题”后，最坏2问可以区分3种状态。

关键不是死记这两问，而是发现：

> 信息缺失类型改变以后，询问类型也必须改变。

# E组｜短板定向复测

## 13A｜H3

例如：

```text
x = −4
x = 4
```

都满足 `|x| = 4`。

要唯一确定，可以增加：

```text
x > 0
```

或：

```text
x < 0
```

等方向信息。

## 13B｜H5/H10

```text
|P| = |R| = 2
```

且 P、R 不同，所以：

```text
(P,R) = (−2,2)
```

或：

```text
(P,R) = (2,−2)
```

Q 为 −5 或5。

所以共有4组：

```text
(−2,−5,2)
(−2,5,2)
(2,−5,−2)
(2,5,−2)
```

## 13C｜条件筛选

初始：

```text
A = −7 或7
B = −3 或3
```

`A < B` 强迫：

```text
A = −7
```

B 仍为 −3 或3。

再加 `B < 0`：唯一为 `(−7,−3)`。

若改加 `A > 0`：与 `A < B` 冲突，无解。

## 13D｜一般化

每一个不同正距离组：

- 出现一次：未知该标签在左还是右；
- 出现两次：两个标签占据左右两点，但未知谁左谁右。

所以每组都留下一个独立二选一。

# F组｜24小时复测要点

1. 绝对值保留离0距离，丢失左右方向。
2. 固定正距离在一维数轴上只有左、右两个位置。
3. 一个合法答案只说明“存在”；唯一还要排除所有其他合法答案。
4. 多个方向选择先找独立选择，再用表格/树组合并证明不漏。
5. 如果标签与距离的对应关系也被删除，仅问左右方向可能永远无法恢复原数据。
