# Lesson 4 Ceiling Diagnostic / Builder｜v2.0 答案与记录

## T0 Ceiling Diagnostic

P、Q、R、S、T 从左到右等距；Q 与 T 互为相反数；P 表示 −8。

Q 与 T 互为相反数，所以原点在 Q 与 T 的正中间。

Q 到 T 一共有3个相等间隔，因此原点位于 R 与 S 的正中间。

从 P 到原点一共跨：

```text
P→Q：1个间隔
Q→原点：1.5个间隔
合计：2.5个间隔
```

P 的坐标为 −8，到原点的数值变化为8，因此每个间隔表示：

$$
\frac{8}{2.5}=3.2
$$

所以：

```text
P  −8
Q  −4.8
R  −1.6
S   1.6
T   4.8
```

原点在 R 与 S 的中间，不是已标点。

### 删除“等距”后的反例

如果只保留 P = −8，Q 与 T 互为相反数，以及 P < Q < R < S < T，则可以有：

- 方案A：Q = −4，R = −1，S = 2，T = 4；
- 方案B：Q = −6，R = −2，S = 3，T = 6。

两组都满足条件，但中间点不同，所以无法唯一恢复尺度。

## Hints

### Hint 1

互为相反数的两个点，0应该位于它们的什么位置？

### Hint 2

Q 到 T 有3个相等间隔，Q 到0相当于几个间隔？

### Hint 3

从 P 到0一共是2.5个间隔，而数值变化总共是8。

## Ceiling Builder 关键结论

### Builder 1

“−a 一定是负数”必须用三类例子检查：

- a 为正；
- a = 0；
- a 为负。

这比只给一个反例更完整，因为它形成参数分类意识。

### Builder 2

“互为相反数”足以定位两点的对称中心为0，但不能单独决定中间刻度数值。尺度需要额外条件。

### Builder 3

逆向设计隐藏原点时，必须同时控制：

- 对称关系；
- 等距尺度；
- 已知坐标数量。

### Builder 4

把“求相反数”看作操作 R：

- 做2次回到原数；
- 偶数次回到原数；
- 奇数次得到相反数；
- 唯一做1次不变的数是0。
