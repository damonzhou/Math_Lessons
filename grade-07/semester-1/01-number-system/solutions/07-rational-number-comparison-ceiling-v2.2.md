# T0｜镜像以后，顺序发生了什么？

已知：

```text
0 < a < b
```

四张卡片：

```text
a，b，−a，−b
```

## Hint 1

先只画 a、b 在0右侧的位置，再把它们关于原点对称。

## Hint 2

b 比 a 离0更远，因此 b 的镜像也比 a 的镜像离0更远，但两者都在0左侧。

## Hint 3

左侧离0更远的位置更靠左，所以先确定 −b 与 −a 的顺序，再把0、a、b补进去。

## 完整解答

### 1. 从小到大

```text
−b < −a < a < b
```

若把0也作为参照：

```text
−b < −a < 0 < a < b
```

### 2. 为什么 −b < −a

因为 0 < a < b，所以 b 在 a 的右侧，且离0更远。

关于原点对称后：

- b 的像是 −b；
- a 的像是 −a；
- 两个像都在0左侧；
- −b 离0更远，所以更靠左。

因此：

```text
−b < −a
```

### 3. 谁离0最近

a 与 −a 离0距离相同，都是 a。

由于 a < b，所以 a、−a 比 b、−b 更接近0。

因此“最近”有两个：

```text
a 和 −a
```

不是唯一。

### 4. 谁离0最远

同理，b 与 −b 到0距离相同且更大。

所以“最远”有两个：

```text
b 和 −b
```

也不是唯一。

### 5. 删除“a、b都是正数”后

只保留 a < b，原固定排列不再成立。

例如：

```text
a = −3，b = 1
```

则：

```text
−a = 3，−b = −1
```

四个数的顺序为：

```text
−3 < −1 < 1 < 3
```

与“−b < −a < a < b”不同。

所以正数条件不是装饰，而是确定四个点分处原点两侧结构的关键条件。

### 6. 一般规律

如果数轴上 a 在 b 左边，那么同时取相反数后，a 的像会在 b 的像右边。

也就是：

> **取相反数会把两个不同数的顺序反转。**

本讲把它理解为数轴镜像事实，不要求背成后续不等式变形口诀。

# Final Challenge｜排序器丢掉了符号

绝对值整理后：

```text
1，2，2，4，4
```

5个原数互不相同。

## Hint 1

同一个正绝对值出现两次，又要求原数不同，这两个原数只能位于原点两侧。

## Hint 2

绝对值2和4各自出现两次，所以它们已经固定贡献几对相反数、几个负数？

## Hint 3

先确定 ±2、±4，再用“负数总个数”决定绝对值1对应的符号，最后排序。

---

# 第一层｜恰好2个负数

## 1～2. 重复绝对值

因为原数互不相同：

```text
绝对值为2 → −2 和2
绝对值为4 → −4 和4
```

两对已经产生两个负数：−2、−4。

## 3. 绝对值1的数

题目说恰好2个负数，因此绝对值1对应的数不能再是负数，只能是：

```text
1
```

## 4. 从小到大

```text
−4 < −2 < 1 < 2 < 4
```

## 5. 为什么唯一

逐步检查：

1. 绝对值2出现两次且原数不同，因此只能是 −2、2；没有第三种选择。
2. 绝对值4同理，只能是 −4、4。
3. 这两对已经恰好提供2个负数。
4. 绝对值1只能取1，否则若取 −1 就会有3个负数。
5. 一旦5个原数确定，数轴从小到大顺序也唯一。

所以不存在第二组满足全部条件的原数集合。

---

# 第二层｜改成“至少2个负数”

±2、±4仍然固定，所以至少已经有两个负数。

绝对值1可以取：

```text
1 或 −1
```

因此共有两种原数集合。

### 情况A

```text
−4，−2，1，2，4
```

排序：

```text
−4 < −2 < 1 < 2 < 4
```

### 情况B

```text
−4，−2，−1，2，4
```

排序：

```text
−4 < −2 < −1 < 2 < 4
```

## 为什么已经列完

唯一未确定符号的是绝对值1对应的那个数，而它只有 +1、−1 两个可能。

这两个可能都满足“至少2个负数”。

因此恰好两种，没有第三种。

# 第三层｜一般化

已知：

```text
0 < c < a < b
```

绝对值为：

```text
c，a，a，b，b
```

## 9. 为什么 a、b 必须各成相反数对

绝对值 a 出现两次，原数互不相同。

数轴上到0距离为 a 的位置只有：

```text
−a 和 a
```

所以必须同时出现。

b 同理。

## 10. 恰好2个负数时 c 的符号

±a、±b 已经各贡献一个负数，共2个负数。

因此 c 对应的原数必须为：

```text
c
```

## 11. 恰好2个负数时的一般顺序

因为 0 < c < a < b：

负数一侧：

```text
−b < −a
```

正数一侧：

```text
c < a < b
```

合起来：

```text
−b < −a < c < a < b
```

## 12. 恰好3个负数时

此时 c 对应的原数必须是 −c。

负数区内部，绝对值越大越小：

```text
−b < −a < −c
```

再接正数：

```text
−b < −a < −c < a < b
```

# 方法提炼

本题真正结构：

```text
重复绝对值
→ 恢复相反数对
→ 统计已确定的负数数量
→ 用剩余条件确定单独项符号
→ 按数轴顺序排列
→ 检查每个分支是否已穷尽
```

这是一种“恢复信息 → 条件筛选 → 排序 → 完整性证明”的通用方法。

# Further Thinking

1. 如果绝对值列表改成：

```text
0，a，a，b，b
```

还需要“负数个数”条件吗？为什么0的符号没有二义性？

2. 如果绝对值列表为：

```text
c，a，a，b，b
```

但不告诉负数个数，一共可能有多少个不同原数集合？

答案：只有 c 的符号有两种选择，所以有2种。

3. 如果有更多重复正绝对值，每个出现两次且原数互异，每一对仍会强制恢复成一个负数和一个正数。这是由数轴关于原点的两点结构决定的。
