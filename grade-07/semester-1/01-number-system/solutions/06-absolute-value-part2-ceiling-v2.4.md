# 一｜T0：A/R 操作日志

定义：A=取绝对值，R=取相反数；操作从左到右执行。

题目日志：

```text
① R R A R R
② A R R
③ R A R
④ A R
```

## Hint 1

不要从第一个字符开始一直算。先找每条日志中**最后一次 A**。

## Hint 2

一旦执行 A，当前值只剩“距离”，之前到底经历了几次 R 已经看不出来。

## Hint 3

最后一次 A 以后只剩 R；只需判断 R 是奇数次还是偶数次。

## 完整解答

① `R R` 后无论得到 x，随后 A 得 `|x|`；最后 `R R` 抵消，输出 `|x|`。

② A 后得 `|x|`，`R R` 抵消，也输出 `|x|`。

③ 前面的 R 把 x 变成 −x，但随后 A 得 `|−x|=|x|`；最后一个 R 得 `−|x|`。

④ A 得 `|x|`，再 R 得 `−|x|`。

所以：

```text
① ≡ ②
③ ≡ ④
```

关键规律：

- 没有 A：只看 R 总次数奇偶；
- 有 A：最后一次 A 以前的方向历史全部被抹掉；最后一次 A 以后只看 R 次数奇偶。

# 三｜Final：四类定理

## Hint 1｜先分“有没有 A”

这是覆盖所有操作串的第一层分类。

## Hint 2｜没有 A

只有 R：偶数次回到 x，奇数次得到 −x。

## Hint 3｜有 A

看最后一次 A。它之前发生什么不再影响方向；它之后只有 R，仍只看奇偶。

## 完整证明

### 情况1：操作串中没有 A

整串只有 R。

- R 出现偶数次：每两次互相抵消，得到 `x`，即 I 类；
- R 出现奇数次：得到 `−x`，即 R 类。

### 情况2：操作串中至少有一次 A

找到最后一次 A。

无论它之前的当前值是 x 还是 −x，甚至之前经历了多少次 A/R，最后一次 A 之后当前值一定是：

```text
|x|
```

因为此前所有操作只能改变符号或把值变成绝对值，绝对距离仍是 `|x|`。

最后一次 A 后只剩 R：

- R 偶数次 → `|x|`，即 A 类；
- R 奇数次 → `−|x|`，即 RA 类。

所以所有有限串都进入：

```text
I，R，A，RA
```

四类之一，分类完整。

## 为什么四类真的不同

只测试正数不够。例如 x=2：

```text
I(2)=2
A(2)=2
R(2)=−2
RA(2)=−2
```

只分成两组。

再看负数 x=−2：

```text
I(−2)=−2
RA(−2)=−2
R(−2)=2
A(−2)=2
```

结合一个正输入和一个负输入，四类输出对分别为：

```text
I  : ( 2,−2)
R  : (−2, 2)
A  : ( 2, 2)
RA : (−2,−2)
```

四组互不相同。

# 四｜最少测试为什么是2

## 上界：2次足够

测试一个正数，例如2；再测试一个负数，例如−2。上表显示四类完全区分。

## 下界：1次一定不够

任取一个测试输入 x。

- 若 x=0，四类输出全是0，更不可能区分；
- 若 x>0，I 与 A 输出相同，R 与 RA 输出相同；
- 若 x<0，I 与 RA 输出相同，R 与 A 输出相同。

所以任何单次输入都至少留下两类无法区分。

因此：

```text
1次不够
2次足够
```

最少为2次。

# 五｜方法提炼

这讲最高层真正要带走的是：

```text
长过程
→ 找“信息被重置”的操作
→ 删除无效历史
→ 只保留决定最终状态的少量信息
→ 分类覆盖所有情况
→ 再做最少性证明
```

A 与 R 的区别：

- R 可逆，方向信息仍在，只是翻转；
- A 把 x 与 −x 压成同一输出，方向信息丢失，因此会“抹历史”。
