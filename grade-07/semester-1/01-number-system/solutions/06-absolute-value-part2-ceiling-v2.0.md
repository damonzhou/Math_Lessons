# 一、T0 Ceiling Diagnostic｜四张卡片到底有几个不同的数

四张卡片：

```text
A：a
B：−a
C：|a|
D：−|a|
```

## 第1问｜a > 0

因为 a 为正数：

```text
|a| = a
−|a| = −a
```

所以：

```text
A = C = a
B = D = −a
```

且 a ≠ 0，因此 a 与 −a 不相等。

结论：恰好两个不同的数。

---

## 第2问｜a < 0

因为 a 为负数：

```text
|a| = −a
−|a| = a
```

所以：

```text
A = D = a
B = C = −a
```

仍然恰好两个不同的数。

---

## 第3问｜a = 0

```text
A = B = C = D = 0
```

只有一个不同的数。

这一步是整个问题的边界。

---

## 第4问｜只知道 a ≠ 0

虽然不知道 a 是正还是负，但只有两种情况：

```text
a > 0：A = C，B = D

a < 0：A = D，B = C
```

两种情况都只有：

```text
a 和 −a
```

这两个数。

所以可以证明：

> **当 a ≠ 0 时，四张卡片恰好表示两个不同的数。**

---

## 第5问｜两个不同的数是什么关系

它们是：

```text
a 与 −a
```

所以互为相反数。

---

## 第6问｜为什么 `|a|` 总是非负的那个

绝对值是距离，所以 `|a|` 一定非负。

当 a ≠ 0 时，`|a|` 实际为正数；`−|a|` 则为负数。

因此四张卡片虽然配对方式取决于 a 的符号，但：

```text
C：|a|      永远对应正的那个数
D：−|a|     永远对应负的那个数
```

这是一条比具体分类更稳定的结构。

---

## 第7问｜操作 A 与 R

定义：

```text
A(x) = |x|
R(x) = −x
```

从非零 a 出发，一旦至少做过一次 A，当前值就会变成 `|a|`。

之后：

- 再做 A，仍是 `|a|`；
- 做 R，变成 `−|a|`；
- 对 `−|a|` 再做 A，又回到 `|a|`；
- 再做 R，又变成 `−|a|`。

因此以后所有可能输出只剩两个：

```text
|a|
−|a|
```

可以理解为：

> 第一次绝对值把原来的“a 到底在左还是右”信息压缩掉，以后的状态只在“正距离”和“它的相反数”之间切换。

这也是一个简单的“状态压缩”模型。


## Hint 2｜关键关系

```text
|a|

```

到底等于 a 还是 −a。

## Hint 3｜一般化

研究 A/R 时，先问：

> 做过一次 A 后，原来的符号信息还存在吗？

# 四、Ceiling Builder 解答要点

## Builder 1｜删除条件

原结论：

```text
|a| = −a
```

### 条件 a ≤ 0

一定成立。

- a < 0 时成立；
- a = 0 时也成立。

### 条件 a ≠ 0

不一定成立。

反例：a = 3。

```text
|a| = 3
−a = −3
```

### 条件 a 是有理数

更不够。

因为有理数可能为正、0、负。

**训练结论**：条件越弱，越不能随意删除绝对值符号。

---

## Builder 2｜从结论反推条件

```text
|a| = a  ⇔  a ≥ 0
```

因为正数和0成立，负数不成立。

```text
|a| = −a  ⇔  a ≤ 0
```

因为负数和0成立，正数不成立。

公共边界：a = 0。

---

## Builder 3｜同绝对值

### a = b 的例子

```text
a = 4，b = 4
```

### a ≠ b 的例子

```text
a = 4，b = −4
```

若：

```text
|a| = |b|
且 a ≠ b
```

则 a、b 必须是原点两侧的对称点，所以互为相反数。

不会有第三种位置关系，因为数轴上到0同一正距离只有左右两个位置；距离0为0时又只有一个位置。

---

## Builder 4｜两分支程序

写法一：

```text
if x < 0:
    return −x
else:
    return x
```

写法二：

```text
if x > 0:
    return x
else:
    return −x
```

两种都正确。

区别在于：

- 第一种把0放在 `else`；
- 第二种也把0放在 `else`，但返回 `−0` 仍是0。

也可以使用 `x ≥ 0` / `x ≤ 0` 的两分法。

### 必测边界

至少测试：

```text
一个负数
0
一个正数
```

例如 −5、0、5。

---

## Builder 5｜从具体到一般

### `|a| = 4`

```text
a = 4 或 a = −4
```

### `|a| = 0`

```text
a = 0
```

### `|a| = −4`

无解。

### 推广到 t

```text
t > 0：a = t 或 a = −t，共两个可能

t = 0：a = 0，共一个可能

t < 0：无解
```

依据不是方程套路，而是“数轴上距离0为 t 的位置数量”。

# 五、T1 Mastery / Final Challenge 解答

条件：

```text
|x| = t
|y| = t
x ≠ y
|z| = z
|z| = −z
```

## 第1问｜t 能否为负

不能。

因为 `|x|` 是距离，不可能为负。

所以若存在 x，必有 t ≥ 0。

---

## 第2问｜t = 0

如果 t = 0：

```text
|x| = 0 → x = 0
|y| = 0 → y = 0
```

于是 x = y，与 x ≠ y 矛盾。

所以 t = 0 时不存在满足全部条件的 x、y。

---

## 第3问｜t > 0

数轴上到0距离为 t 的位置恰好两个：

```text
t
−t
```

又因为 x ≠ y，所以 x、y 必须分别取这两个位置。

有序可能为：

```text
(x,y) = (t,−t)
或
(x,y) = (−t,t)
```

再看 z：

```text
|z| = z  → z ≥ 0
|z| = −z → z ≤ 0
```

同时非负且非正，只能：

```text
z = 0
```

所以全部有序三元组为：

```text
(t,−t,0)
(−t,t,0)
```

---

## 第4问｜三个两两不同的数绝对值都等于同一个正数 t

不可能。

因为数轴上距离0为正数 t 的位置只有：

```text
t 和 −t
```

最多只能放两个不同的数。

---

## 第5问｜t = 0

只有原点一个位置，所以最多只有1个不同的数满足：

```text
|u| = 0
```

---

## 第6问｜一般结论

对给定非负数 t：

```text
t > 0：满足 |u| = t 的不同有理数恰有2个，即 t 与 −t

t = 0：只有1个，即0
```

若把范围扩大到任意有理数 t：

```text
t < 0：0个

t = 0：1个

t > 0：2个
```

这是一个很有价值的“0、1、2”结构。

---

# 六、Mastery 方法提炼

本题突破顺序：

```text
先问 t 是否可能为负
→ 处理边界 t = 0
→ 再处理 t > 0
→ 用“同一正距离只有两个位置”解决 x、y
→ 用两个逆向条件夹出 z = 0
→ 从3个变量推广到一般个数
```

关键不是计算，而是：

> **先找分界点，再把边界单独检查，最后推广。**
