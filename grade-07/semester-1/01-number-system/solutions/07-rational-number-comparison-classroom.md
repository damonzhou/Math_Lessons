# A. 基础比较

## 1. −3 与2

```text
−3 < 2
```

因为 −3 在0左侧，2在0右侧。

## 2. 0 与 −0.01

```text
0 > −0.01
```

任何负数都在0左侧。

## 3. −4 与 −7

```text
−7 < −4
```

−7 在数轴上更靠左。也可以说：

```text
|−7| > |−4|
```

两个负数中，绝对值大的更小。

## 4. −0.6 与 −2/3

```text
−2/3 ≈ −0.666...
```

所以：

```text
−2/3 < −0.6
```

## 5. 从小到大

```text
−5 < −1 < 0 < 2 < 4
```

## 6. 从大到小

```text
3/2 > 0 > −1.02 > −1.2 > −3/2
```

因为：

```text
−1.02 > −1.2 > −1.5
```

# B. 概念解释

## 7. 为什么 0.01 > −1000

0.01 是正数，在0右侧；−1000 是负数，在0左侧。

原数大小由数轴左右位置决定，不由离0远近决定。

## 8. 为什么两个负数中绝对值大的反而小

两个负数都在0左侧。离0越远，就越靠左，因此原数越小。

例如：

```text
|−8| > |−3|
但 −8 < −3
```

## 9. “绝对值越大，原数越大”

错误。

反例：

```text
|−10| > |−2|
但 −10 < −2
```

如果增加“两个数都非负”这个条件，则绝对值越大，原数越大。

## 10. “两个负数中，离0近的数更大”

正确。

因为两个负数都在0左侧，离0近意味着位置更靠右，所以数更大。

## 11. a > 0 时比较 a 与 −a

```text
a > −a
```

因为 a 在0右侧，−a 在0左侧。

## 12. a < 0 时比较 a 与 −a

```text
a < −a
```

因为 a 在0左侧，而 −a 为正数，在0右侧。

# 当堂综合训练答案

## 1

```text
−4 < −3 < −1 < 0 < 2 < 5
```

## 2. −0.45 与 −4/9

```text
−4/9 ≈ −0.444...
```

所以：

```text
−0.45 < −4/9
```

## 3. a > 0

```text
−a < 0 < a
```

## 4. 0 < a < b

```text
−b < −a < 0 < a < b
```

## 5. “如果 |a| > |b|，那么 a > b”

不能无条件成立。

例如：

```text
a = 5，b = 2
```

有 a > b。

但：

```text
a = −5，b = −2
```

虽然仍有 |a| > |b|，却有 a < b。

说明还需要符号条件。

## 6. a、b 都是负数且 |a| < |b|

```text
a > b
```

因为两个负数中，离0近的更大。

## 7. −2 与 −1 之间

示例：

```text
分数：−3/2，−5/4
小数：−1.2，−1.8
```

都满足：

```text
−2 < x < −1
```

## 8. 三个负数

绝对值：

```text
0.8 < 1.2 < 1.5
```

负数原值从大到小与绝对值从小到大对应：

```text
−0.8 > −1.2 > −3/2
```

## 9. 为什么取相反数会反转顺序

数轴关于原点镜像。原来在左边的点镜像后会跑到右边，原来在右边的点镜像后会跑到左边，因此两个不同点的左右次序反转。

## 10. 构造“最大数”和“离0最远数”不同

例如：

```text
−20，−3，0，5，8
```

最大数是8，离0最远的是 −20。

# 本讲检查重点

若出现错误，优先标记原因：

- 把距离大小当原数大小：`C7 + H7/H9`；
- 两个负数比较方向写反：`C3/C7 + H6/H9`；
- 混合表示未统一：`C4/C7 + H9`；
- 排序漏项：`C6 + H5/H10`；
- 条件不足仍强行下结论：`C2 + H3/H10`。
