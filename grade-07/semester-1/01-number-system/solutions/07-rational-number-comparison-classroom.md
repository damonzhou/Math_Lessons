# Gap Check

## G1｜−7 与 −3

```text
−7 < −3
```

因为 −7 在数轴上更靠左。

## G2｜−0.72 与 −7/10

```text
−7/10 = −0.7
```

所以：

```text
−0.72 < −0.7
```

即：

```text
−0.72 < −7/10
```

## G3｜排序

```text
−4 < −1 < 0 < 2 < 5
```

## G4｜“绝对值越大，原数越大”

错误。

反例：

```text
|−10| > |−2|
但 −10 < −2
```

必须先知道符号区间，才能把绝对值大小可靠地转换成原数大小。

## G5｜为什么 0.001 > −10000

0.001 在0右边，−10000 在0左边。

比较原数大小看数轴左右位置，不看谁离0更远。

## G6｜两个负数

已知：

```text
|x| < |y|
```

且 x、y 都负，所以 x 离0更近、更靠右。

因此：

```text
x > y
```

## G7｜−3 与 −2 之间

示例：

```text
分数：−5/2
小数：−2.4
```

都满足：

```text
−3 < x < −2
```

## G8｜最大数 vs 离0最远

- 最大数：比较数轴上的左右位置；
- 离0最远：比较到原点的距离，也就是绝对值大小。

二者可能不是同一个对象。

---

# Concept Deepening 核心结论

```text
原数大小 → 看左右
绝对值大小 → 看离0距离
```

对于两个负数：

```text
离0越远
→ 越靠左
→ 原数越小
```

# School Advanced 答案

## A1｜在 0 < |a| < |b| 下的四个结论

### 1. b > 0 → a < b

成立。

- a > 0：因为 |a| < |b|，所以 a < b；
- a < 0：负数 a 当然小于正数 b。

因此不需要知道 a 的符号。

### 2. b < 0 → a > b

成立。

- a > 0：正数 a > 负数 b；
- a < 0：因为 |a| < |b|，a 更靠近0、更靠右，所以 a > b。

### 3. a < b → b > 0

成立。

反证式理解：若 b < 0，由前面已经知道必有 a > b，与 a < b 冲突。

### 4. a > b → b < 0

同理成立。

所以在前提：

```text
0 < |a| < |b|
```

下，可以用中文表述：

> **a < b 与 b > 0 是等价条件；a > b 与 b < 0 是等价条件。**

这里的重点不是记“等价”，而是理解：绝对值更大的 b 的符号控制两者的左右顺序。

## A2｜已知 b < a < c

条件：

```text
0 < |a| < |b| < |c|
```

因为 c 绝对值最大且排在最右，所以：

```text
c > 0
```

去掉 c 后，b、a 满足 |a| < |b|，且：

```text
b < a
```

所以：

```text
b < 0
```

而 a 的符号不能由排序确定。

两组验证：

```text
a = 1，b = −2，c = 3
```

以及：

```text
a = −1，b = −2，c = 3
```

都满足：

```text
b < a < c
```

---

## A3｜最少附加信息

应该问：

> **a > 0 吗？**

因为 b、c 的符号已经由排序确定；再问 b 或 c 只是在询问已知信息。

问 a 一次即可补齐唯一缺失的符号信息。

---

## A4｜不可能排序示例

例如设：

```text
0 < |p| < |q| < |r|
```

设计目标：

```text
p < r < q
```

这是不可能的。

原因：|r| 最大。

- r > 0 时，r 必须最大；
- r < 0 时，r 必须最小。

所以 r 不能处在 p、q 中间。

# 本讲课堂检查重点

若出现错误，优先记录：

- 把绝对值大小当原数大小：`C7 + H7/H9`；
- 仍靠逐个试值，不找最大绝对值结构：`C7 + H9`；
- 能列情况但漏一种：`C6 + H5/H10`；
- 找到4种排序但不能证明另外2种不可能：`C5/C6 + H10`；
- 从排名反推符号时把最小绝对值标签也强行确定：`C2/C7 + H3/H10`；
- 最少信息题只给方案、不证明少一次不够：`C5 + H10`。
