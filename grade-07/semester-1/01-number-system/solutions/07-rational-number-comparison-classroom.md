# A｜Gap Check

## 1

```text
−7 < −3
```

因为数轴上 −7 在 −3 左边。

## 2

`−0.72 < −0.7 = −7/10`，所以：

```text
−0.72 < −7/10
```

## 3

```text
−4 < −1 < 0 < 2 < 5
```

## 4

“绝对值越大，原数越大”错误。例如：

```text
|−10| > |−2|
但 −10 < −2
```

## 5

x、y 都负且 `|x|<|y|`，说明 x 离0更近，因此：

```text
x > y
```

## 6

任何正数都大于任何负数，所以：

```text
0.001 > −10000
```

与绝对值大小无关。

## 7

“最大数”比较左右位置；“离0最远”比较绝对值。两者不是同一对象。

# B｜School Advanced

## A1｜最大绝对值元素为什么不能在中间

若：

```text
0<|a|<|b|<|c|
```

- c>0：c 比 a、b 都更靠右，所以 c 最大；
- c<0：c 比 a、b 都更靠左，所以 c 最小。

因此 c 一定在排序两端，不可能居中。

## A2｜由 `c<a<b` 反推

c 在最左端，所以 c<0。

在剩余 a、b 中 `|a|<|b|`，而 b 在右端，所以 b>0。

a 的正负不能由此唯一确定：只要 `|a|` 最小，a=±|a| 都会落在 c 与 b 之间。

## A3｜不可能结构

`a<c<b` 与 `b<c<a` 都让 c 位于中间，与“最大绝对值元素必须在全局一端”矛盾，因此不可能。

# C｜进入 T0 前检查

学生应稳定：

- 不混淆原数顺序与距离顺序；
- 能用数轴解释两个负数比较；
- 能从最大绝对值推“占一端”；
- 能从最终顺序反推部分符号。

但此时不要提前给出：

```text
重复绝对值组的递归外放
最小组单点/相反数对的计数公式
```

这些是 T0 / Final 的有效突破口。
