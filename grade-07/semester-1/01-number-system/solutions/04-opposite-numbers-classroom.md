# A. Core

## 1. 求相反数

- 7 的相反数：−7；
- −3 的相反数：3；
- 0 的相反数：0；
- 2.5 的相反数：−2.5；
- −3/4 的相反数：3/4。

核心不是“看见符号就改”，而是关于原点对称。

## 2. 为什么0的相反数仍是0

0就在原点。

原点关于原点对称后位置不变，所以0的相反数仍是0。

## 3. 已知 a 的具体值

当 a = 5 时，−a = −5。

当 a = −5 时，−a = 5。

因此 −a 的符号不能只看外形判断。

## 4. “−a 一定是负数”是否正确

错误。

反例：a = −2 时，−a = 2，是正数。

边界：a = 0 时，−a = 0。

完整判断：

- a > 0 → −a < 0；
- a = 0 → −a = 0；
- a < 0 → −a > 0。

## 5. 为什么 −(−a)=a 不是本讲的“负负得正”

这里没有进行两个负数的乘法。

外层“−”表示：取里面这个数的相反数。

所以先从 a 得到 −a，再求一次相反数，就回到 a。

## 6. 原点左侧4个单位的点

它表示 −4。

它的相反数对应原点右侧4个单位，即4。

## 7. 连续求5次相反数

次数为奇数，所以最终得到原数的相反数。

如果连续求偶数次，则回到原数。

# Mastery Challenge｜相反变换机器

定义操作 R：每次把输入数变成它的相反数。

## 1. 输入 −7，执行2026次

2026是偶数。

每执行2次就回到原数，所以最终仍为 −7。

## 2. 执行2025次后得到正数

2025是奇数，因此最终结果是原数的相反数。

结果为正数，说明原数为负数。

## 3. 执行一次后不变的数

只有0。

因为0关于原点对称后仍在原点；任何非零数都会被映射到另一侧。

## 4. 偶数次与奇数次规律

- 2次：回到原数；
- 每增加2次，只是在“回到原数”后再做一整轮；
- 所以所有偶数次都回到原数；
- 所有奇数次等价于“若干完整2次循环 + 最后1次”，因此得到原数的相反数。

## 5. 只记“两个负号消掉”够不够

不够。

这种口号只能覆盖某些书写形式，无法稳定处理：

- 字母符号未知；
- 多次操作；
- 原点对称；
- 唯一不动点；
- 逆向判断。

更可靠的理解是：

> **R 是“关于原点对称”的变换，R 做两次等于回到原位置。**

# 方法复盘

遇到相反数问题：

```text
先找原数
→ 回到原点对称定义
→ 字母先判断可能符号
→ 多次操作看奇偶
→ 条件不足时构造反例
```
