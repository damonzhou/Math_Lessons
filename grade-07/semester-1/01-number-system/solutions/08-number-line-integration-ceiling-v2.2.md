# T0｜一个点同时满足两种“等距”条件

已知：

```text
A = −6
B = 4
M 在 A、B 之间
MA = MB
XM = 3
```

## Hint 1

先不要想公式。

从 A 到 B 一共有10个单位。M 把这一段分成两个同样长的部分。

## Hint 2

每一半是5个单位。先从 A 向右走5个单位找 M。

然后从 M 向左、向右各找距离3的位置。

## Hint 3

要解释“为什么只有两个 X”，请问：

> 从一个固定点出发，在一条直线上，距离固定为正数时有几个方向？

---

## 完整解答

### 1. 求 M

A 到 B：

```text
−6 → 4
```

共10个单位。

因为：

```text
MA = MB
```

所以每段为5个单位。

从 A = −6 向右5个单位：

```text
M = −1
```

### 2. 求 X 的全部可能

X 到 M = −1 的距离为3。

向左3个单位：

```text
X = −4
```

向右3个单位：

```text
X = 2
```

所以全部可能：

```text
X = −4 或 X = 2
```

### 3. 为什么恰好两个

数轴是一条直线。

从固定点 M 出发，距离3的方向只有：

- 左；
- 右。

每个方向上距离3的位置唯一。

因此恰好两个，不可能有第三个。

### 4. 增加“X 在 M 右侧”

只保留右侧位置：

```text
X = 2
```

这条方向信息把“两解”筛成“一解”。

### 5. 删除“M 位于 A、B 之间”

在数轴上仍只有一个点到 A、B 距离相等，即 −1。

原因：

- 在 A 左边，离 B 总比离 A 更远；
- 在 B 右边，离 A 总比离 B 更远；
- 只有 A、B 之间可能相等；
- 在 A、B 之间，两段距离一增一减，只在正中间相等。

所以“位于 A、B 之间”在这个具体一维问题中其实可由等距关系推出，是一个**可省略但帮助理解的条件**。

这是一处重要的“必要性”审查。

### 6. 一般化

任意两个不同的数轴点 A、B，都只有一个点到它们距离相等。

它就是 AB 的中点。

### 7. 条件角色

```text
A、B 的位置：确定两端
MA = MB：确定中心
XM = 3：确定 X 到中心的半径/距离
X 在 M 右侧：确定方向，因此把两解变成唯一解
```

# Final Challenge｜脱落标签、隐藏中心与两个候选点

数轴上：

```text
A，B，C，D，E，F，G
```

连续等距，从左到右。

B、F 标签是 −7 和5，但归属未知。

## Hint 1

先只用顺序：

```text
B 在 F 左边
→ B < F
```

所以两张标签的归属已经被顺序确定。

## Hint 2

B 到 F 有4个相同间隔，而 −7 到5 总变化为12。

## Hint 3

第4问中先算 C 与 E 之间跨2个间隔，再把同样距离从 D 向左、向右各走一次。

---

## 完整解答

### 1. 标签归属

因为 B 在 F 左边，数轴上左边的数更小。

两张标签中：

```text
−7 < 5
```

所以：

```text
B = −7
F = 5
```

只有这一种分配。

若反过来 B = 5、F = −7，会违反 B < F。

### 2. 恢复 A～G

B 到 F 跨4个相同间隔：

```text
B→C
C→D
D→E
E→F
```

总变化：

```text
−7 → 5：12
```

每格：

```text
12 ÷ 4 = 3
```

所以：

```text
A = −10
B = −7
C = −4
D = −1
E = 2
F = 5
G = 8
```

### 3. B、F 的中点

B 到 F 有4个等间隔，中间正好在走2格的位置 D。

B 到 D：6个单位；D 到 F：6个单位。

所以 D 是中点，坐标：

```text
D = −1
```

### 4. 求 X

C = −4，E = 2。

C 到 E 跨2格，每格3，所以距离为6。

X 到 D = −1 的距离也为6。

从 D：

- 向左6 → −7；
- 向右6 → 5。

所以：

```text
X = −7 或 5
```

即 X 恰好落在 B 或 F。

### 5. 为什么只有这些

数轴上从 D 出发，固定正距离6只有左右两个方向。

每个方向上距离6的位置唯一。

因此只有 B、F 两个位置，没有第三个。

### 6. 增加“X 在 D 左侧”

只保留左侧：

```text
X = −7
```

“X 在 D 左侧”提供方向信息，使答案唯一。

### 7. 删除“连续等距”

仍然可以确定：

- B 在 F 左边；
- 所以 B = −7、F = 5。

不能再唯一确定：

- A、C、D、E、G 的具体坐标；
- D 是否为 B、F 的中点；
- C、E 之间具体距离；
- 第4问的 X。

反例：

在保持顺序的前提下，可以取：

```text
方案1：A = −10，B = −7，C = −4，D = −1，E = 2，F = 5，G = 8
```

也可以取：

```text
方案2：A = −9，B = −7，C = −6，D = 0，E = 4，F = 5，G = 9
```

两者都满足 A < B < C < D < E < F < G，以及 B = −7、F = 5，但内部结构不同。

所以“等距”负责的是尺度与中间位置的可恢复性。

### 8. 一般化

若第 i 个点和第 j 个点坐标已知，并且中间标点连续等距：

1. 数一数 i 到 j 一共有多少个相同间隔；
2. 求两个已知坐标之间的总变化；
3. 把总变化平均分到这些间隔；
4. 从任一锚点按间隔数逐步恢复其他点。

暂时不需要把它压缩成代数公式。

# Final Challenge 方法提炼

这道题的结构不是“算几个坐标”，而是：

```text
左右顺序
→ 标签归属唯一
→ 两锚点 + 等距
→ 恢复尺度
→ 中点 = 等距中心
→ 固定距离 = 左右两个候选
→ 方向条件筛成唯一
→ 删除等距后检查哪些结论失效
```

可以压缩为一句：

> **先问每条条件控制什么，再问答案为什么唯一。**
