# A. Core 巩固

## 1

- 12 → −12；
- −7 → 7；
- 0 → 0；
- 5/8 → −5/8；
- −2.75 → 2.75。

## 2

互为相反数：

1. 4 与 −4：是；
2. −3 与1/3：不是；
3. 0 与0：是，0的相反数仍是0；
4. 1.2 与 −1.2：是；
5. 5 与 −6：不是。

必须同时满足关于原点对称，而不是只看“一正一负”。

## 3

0就在原点。原点关于原点对称以后位置不变，所以0的相反数仍是0。

## 4

A = 3/2，因此 B = −3/2。

A、B 到0的距离相等；A 在右侧，B 在左侧。

## 5

“−x 一定是负数”错误。

- 使它为负：x = 2，则 −x = −2；
- 反例：x = −2，则 −x = 2；
- 边界：x = 0，则 −x = 0。

# B. Ceiling Builder 迁移

## 6

- a > 0 → −a < 0；
- a = 0 → −a = 0；
- a < 0 → −a > 0。

一般结论：−a 的符号由 a 的符号决定，不能从字符外观直接判断。

## 7

从最里面的 −3 开始逐次取相反数：

```text
−3 → 3 → −3 → 3
```

所以整个表达式结果为3。

连续取2025次相反数：奇数次，得到原数的相反数。

连续取2026次：偶数次，回到原数。

## 8

只知道 A、D 互为相反数，不能推出 B、C 互为相反数。

反例：

```text
A = −4，B = −3，C = 1，D = 4
```

A、D互为相反数，但 B、C 不是。

若再增加“四点等距”，则 B、C 必然关于0对称，因此互为相反数。

## 9

一种设计：5个等距点坐标为：

```text
−5，−3，−1，1，3
```

原点在 −1 与1之间，不是标点；−3 与3互为相反数。如果再给出 −5 这一坐标和等距条件，可以恢复全部位置。

答案不唯一，关键是验证所有条件。

# C. Advanced / Competition / Informatics

## 10

甲偏差 +0.8 g，乙偏差 −0.8 g，二者互为相反数。

丙 −0.6 g 与甲方向相反，但大小不同，所以不互为相反数。

## 11

设相邻坐标变化为 d，B 的坐标为 b。

因为 C = −2：

$$
b+d=-2
$$

B 与 E 相差3个间隔，而 E = −b，所以：

$$
b+3d=-b
$$

联立得到 d = 4，b = −6。

因此：

```text
A = −10
B = −6
C = −2
D = 2
E = 6
F = 10
```

原点在 C 与 D 的中间。

删除“等距”后，B 与 E 互为相反数这一对称中心结论仍成立，但 D、A、F 等具体坐标不能唯一恢复。

## 12

- `flip(flip(7)) = 7`；
- 偶数次执行回到原数；
- 奇数次执行得到原数的相反数；
- 唯一执行一次后不变的数是0。

# D. T2

## 13

偏差 +6：

- 连续 flip 5次：奇数次 → −6；
- 连续 flip 2026次：偶数次 → +6；
- flip 后不变：0；
- 一般规律：偶数次回到原偏差，奇数次得到相反偏差。
