# A. Core

## 1

已知 a > 0：

```text
|a| = a
|−a| = a
−|a| = −a
```

## 2

已知 a < 0：

```text
|a| = −a
|−a| = −a
−|a| = a
```

## 3

已知 a = 0：

```text
|a| = 0
−a = 0
|−a| = 0
−|a| = 0
```

## 4

一定成立：B、C。

- A 不一定：a = −2 时失败；
- B 一定：a 与 −a 到0距离相同；
- C 一定：`|a|` 已非负；
- D 不一定：a = 2 时失败。

---

# B. 边界与逆向

## 5

原断言错误。

a = 0 时：

```text
|a| = a
```

但 a 不是正数。

正确：a ≥ 0。

## 6

原断言错误。

a = 0 时：

```text
|a| = −a
```

正确：a ≤ 0。

## 7

```text
|a| = a   ⇔ a ≥ 0
|a| = −a  ⇔ a ≤ 0
```

## 8

因为 a = 0 时：

```text
a = −a = |a| = 0
```

所以0是两种结论共同包含的边界值。

---

# C. 同绝对值

## 9

例如：

```text
a = 3，b = 3
```

有 `|a| = |b|` 且 a = b。

又如：

```text
a = 3，b = −3
```

有 `|a| = |b|` 且 a ≠ b。

## 10

若绝对值相等且原数不同，只能位于原点两侧同距离处，所以 a、b 互为相反数。

## 11

漏掉“关于原点对称”的可能。

最小反例可取：

```text
a = 1，b = −1
```

---

# D. 距离逆向

## 12

```text
x = 9 或 x = −9
```

## 13

```text
x = 0
```

## 14

不存在。

因为绝对值是距离，不可能为 −2。

## 15

```text
t > 0：2个，x = t 或 x = −t

t = 0：1个，x = 0

t < 0：0个
```

---

# E. 条件充分性

## 16

### a ≤ 0

能保证 `|a| = −a`。

### a ≠ 0

不能。

反例：a = 2。

### a 是整数

不能。

反例仍可取 a = 2。

结论：知道“对象属于哪种数”不等于知道“它在0哪一侧”。

## 17

- A a > 0：足够；
- B a ≥ 0：足够；
- C a ≠ 0：不够，a = −1 反例；
- D a = 0：足够；
- E a 是正整数：足够。

## 18

一种构造：

```text
p = 4
q = −5
r = 0
```

则：

```text
|p| = p
|q| = −q
|r| = r = −r = 0
```

# F. 稳定结构

## 19

对所有有理数 a 成立。

原因：a 与 −a 到0距离相同。

## 20

对所有有理数 a 成立。

因为 `|a|` 非负。

## 21

若 a ≠ 0：

```text
a，−a，|a|，−|a|
```

恰好只有2个不同值：a 与 −a。

所以最大值个数和最小值个数都为2。

若 a = 0，则四个表达式全为0，只有1个不同值。

# G. Informatics

## 22

正确。

- x > 0：返回 x；
- x < 0：进入 else，返回 −x；
- x = 0：进入 else，返回 −0 = 0。

## 23

也正确。

- x < 0：返回 −x；
- x ≥ 0：进入 else，返回 x。

0进入 else 分支。

## 24

因为绝对值规则的行为在0两侧不同，而0又是边界。

只测正数和负数可能发现不了“0分支写错”；只测0也无法验证两侧。

最小的代表性测试应覆盖：

```text
负区间
边界0
正区间
```

# H. Olympiad / Advanced

## 25

候选的到0距离：

```text
−14 → 14
−11 → 11
5   → 5
12  → 12
13  → 13
```

所以离0最远的是 −14。

实际比较的是绝对值，也就是到0的距离。

如果全部换成相反数，各自绝对值不变，因此“最远距离”不变。

## 26

到0距离为8的不同位置只有8和 −8。

有序可能：

```text
(a,b) = (8,−8)
(a,b) = (−8,8)
```

## 27

不能。

距离0为5的不同位置只有5和 −5，最多两个不同数。

## 28

由：

```text
|a| = a
```

知 a ≥ 0。

由：

```text
|a| = −a
```

知 a ≤ 0。

同时满足只能：

```text
a = 0
```

# I. 综合

## 29

```text
t < 0：0个

t = 0：1个

t > 0：2个
```

## 30

### m = 7

```text
x = 7 或 x = −7
```

### m = 0

```text
x = 0
```

### 符号位何时必要

m > 0 时，原输入有左右两个可能，需要方向信息区分。

m = 0 时只有原点一个可能，方向信息冗余。
