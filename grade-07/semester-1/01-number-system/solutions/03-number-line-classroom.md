# A. Core

## 1. 数轴三要素

必须有：

- 原点；
- 正方向；
- 单位长度。

缺少其中任何一个，就不能唯一确定数与位置的对应。

## 2. 表示 −3、0、2、1/2、1.5

在正方向向右、单位长度为1的数轴上：

- −3 在原点左侧3个单位；
- 0 在原点；
- 2 在原点右侧2个单位；
- 1/2 在0和1的中点；
- 1.5 在1和2的中点。

重点：分数和小数同样能对应数轴位置。

## 3. A 左2个单位，B 右1个单位

A 的坐标是 −2，B 的坐标是1。

因为 A 在 B 左边，所以：

```text
−2 < 1
```

## 4. 为什么 −2 > −5

正方向向右时，−2 位于 −5 的右侧。

数轴上右边的数更大，因此 −2 > −5。

当前不需要借助绝对值规则解释。

## 5. 每格0.5，原点右边第3格

表示：1.5。

典型错误是默认每格1。

## 6. 点 P 坐标 −4

- 坐标：−4；
- 到0的距离：4个单位。

坐标带有方向/位置意义，距离只表示长度。

## 7. 能否仅凭示意图判断 A < B

不能。

如果题干没有保证图按比例，也没有给出真实位置关系，示意图外观不能替代数学条件。

这是 H3 的重要检查点。

# Mastery Challenge｜脱落的标签

数轴上从左到右有7个等距点 A、B、C、D、E、F、G，正方向向右。

B、E 原来的数字标签脱落，只找到两张标签：−5 和4，但不知道分别属于哪个点。

## 1. 哪张标签属于 B，哪张属于 E

因为 B 在 E 左边，而正方向向右，所以 B 表示的数小于 E。

因此：

```text
B = −5
E = 4
```

## 2. 每格表示多少

B 到 E 跨3个相等间隔，总数值变化：

$$
4-(-5)=9
$$

所以每格表示3。

## 3. 恢复全部坐标

```text
A  −8
B  −5
C  −2
D   1
E   4
F   7
G  10
```

## 4. 原点在哪里

0 位于 C 与 D 之间。

从 C = −2 到 D = 1，一个完整间隔表示3，所以0不在中点，而位于从 C 向 D 走2/3个间隔的位置。

这再次说明：原点不必是已有刻度点，也不必恰在两个点中间。

## 5. 如果删除“等距”条件

仍然可以根据左右顺序判断：

```text
B = −5，E = 4
```

但不能唯一恢复 C、D、F、G 的具体坐标。

例如 C 可以是 −4，也可以是 −1，只要保持：

```text
−5 < C < D < 4
```

并满足全部左右顺序即可。

所以：

- 左右顺序负责标签归属；
- 等距条件负责尺度恢复。

# 方法复盘

遇到数轴恢复题，建议按：

```text
先读方向与顺序
→ 再确认是否等距
→ 用锚点恢复尺度
→ 恢复其余位置
→ 检查0和唯一性
→ 删除一个条件试着构造反例
```

重点习惯：H1、H3、H7、H9、H10。
