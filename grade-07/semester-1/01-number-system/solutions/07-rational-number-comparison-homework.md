# B. 条件、反例与边界

## 6

原断言错误。

两个负数反例：

```text
|−10| > |−2|
但 −10 < −2
```

一正一负反例：

```text
|−100| > |1|
但 −100 < 1
```

如果两个数都非负，则“绝对值大的原数更大”成立。

## 7

已知 |a| < |b|：

1. a、b 都正：a < b。
2. a、b 都负：a > b。
3. a < 0 < b：必有 a < b，与绝对值关系无关。
4. 不知道符号：不能唯一比较。

反例：

```text
a = 2，b = 5 → a < b

a = −2，b = −5 → a > b
```

## 8

```text
−0.51 < −1/2 < −0.49 < 0 < 0.48 < 1/2
```

六个原数都恰好出现一次，因此无漏项、无重复。

## 9

若共同绝对值为正数 t：

```text
x = t，y = −t
```

所以 x > y。

若共同绝对值为0：

```text
x = y = 0
```

所以相等。

# C. 镜像与一般化

## 10

已知 0 < p < q：

```text
−q < −p < 0 < p < q
```

因为 q 离0比 p 远，镜像后 −q 在左侧也更远、更靠左。

## 11

不能。

例如 p = 1，q = 3 时是一种结构；p = −3，q = 1 时四个数的分区结构不同。

只知道 p < q 不足以确定 p、q 是否同侧。

## 12

示例：

```text
x = −5/2，y = −1.5，z = −0.4
```

有：

```text
x < y < z < 0
```

且：

```text
|x| > |y| > |z|
```

一般原因：负数区间越向左，绝对值越大，原数越小。

# E. Informatics

## 15. 比较流程

一种清晰流程：

```text
如果 x = y：输出相等
否则先看符号

x ≥ 0 且 y < 0：x > y
x < 0 且 y ≥ 0：x < y

都非负：直接比较大小
都为负：比较绝对值；绝对值小的原数大
```

## 16. 测试示例

```text
3 与 −2
−5 与 −1
2 与7
0 与 −1
4 与4
−0.6 与 −2/3
```

这些数据覆盖不同分支、边界和表示形式，能暴露比较器是否漏分类。

# F. 综合挑战

## 17

绝对值：

```text
2，3，3，7，7
```

互不相同意味着：

```text
−3、3、−7、7
```

必须同时出现。

它们已经产生两个负数。

### 恰好3个负数

绝对值2对应 −2。

原数集合：

```text
−7，−3，−2，3，7
```

排序同上。

唯一性：±3、±7 被重复绝对值强制确定；为了达到3个负数，2只能取 −2。

### 恰好2个负数

2必须取正：

```text
−7 < −3 < 2 < 3 < 7
```

两种条件下中间数分别是 −2 和2，符号相反。

## 18

设：

```text
0 < a < b
```

四个数为：

```text
−b，−a，a，b
```

排序唯一为：

```text
−b < −a < a < b
```

原因：相反数对决定左右两侧；0 < a < b 决定正侧顺序；镜像决定负侧顺序反转，没有其他位置可能。

# G. T2

绝对值：

```text
10，30，30，70，70
```

重复绝对值强制得到：

```text
−30，30，−70，70
```

已经有两个负数。

### 恰好2个低于海平面

10必须为 +10。

排序：

```text
−70 < −30 < 10 < 30 < 70
```

唯一。

### 至少2个低于海平面

10可以为 +10 或 −10。

两种：

```text
−70 < −30 < 10 < 30 < 70
```

或：

```text
−70 < −30 < −10 < 30 < 70
```

没有第三种，因为唯一未确定符号的绝对值10只有正、负两个可能。
