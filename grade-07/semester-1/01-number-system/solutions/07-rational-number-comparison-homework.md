# B｜School Advanced

## 5｜0 < |p| < |q|

### q > 0

- 若 p > 0，因为 |p| < |q|，所以 p < q；
- 若 p < 0，负数 p 也一定小于正数 q。

因此：

```text
q > 0 → p < q
```

### q < 0

- 若 p > 0，则 q < p；
- 若 p < 0，因为 |q| > |p|，q 更靠左，所以 q < p。

因此：

```text
q < 0 → q < p
```

p 的符号只会使 p 在0左侧或右侧移动，但由于 |p| 更小，它始终处在 q 与“另一端”之间，因此不改变 p、q 的标签先后。

## 6｜从 p < q 反推

在：

```text
0 < |p| < |q|
```

下，若 p < q，则 q 不可能为负。

因为 q < 0 时由第5题必有 q < p。

所以：

```text
q > 0
```

而 p 可以正也可以负。

例如：

```text
p = 1，q = 2
```

与：

```text
p = −1，q = 2
```

都满足条件与 p < q。

## 7｜r < p < q

由于 |r| 最大且 r 在最左：

```text
r < 0
```

去掉 r 后，|q| > |p| 且 p < q，因此：

```text
q > 0
```

p 无法确定。

两组：

```text
p = 1，q = 2，r = −3
```

```text
p = −1，q = 2，r = −3
```

都满足：

```text
r < p < q
```

## 8｜p < r < q 是否可能

不可能。

因为 |r| 最大。

- r > 0 时，r 必须最大；
- r < 0 时，r 必须最小。

所以 r 不可能排在 p、q 中间。

# C｜High Ceiling

## 9｜s < q < p < r

条件：

```text
0 < |p| < |q| < |r| < |s|
```

- s 绝对值最大且在最左，所以 s < 0；
- 删除 s 后，r 在剩余最右，所以 r > 0；
- 删除 r 后，q < p 且 |q| > |p|，所以 q < 0；
- p 的符号不能由排名确定。

两组验证：

```text
p = 1，q = −2，r = 3，s = −4
```

```text
p = −1，q = −2，r = 3，s = −4
```

均有：

```text
s < q < p < r
```

## 10｜q < p < s < r

不可能。

因为 |s| 最大，而 s 却被放在中间。

绝对值最大的非零数若为正必须最大，若为负必须最小，因此不可能处在中间。

## 11｜四变量全部顺序

从 |s| 最大开始：

```text
s 放最左或最右
→ 删除 s
r 放剩余最左或最右
→ 删除 r
q 放剩余最左或最右
→ p 落最后位置
```

得到8种：

```text
s < r < q < p
s < r < p < q
s < q < p < r
s < p < q < r
r < q < p < s
r < p < q < s
q < p < r < s
p < q < r < s
```

p 的正负不会再产生新排名，因为 p 的绝对值最小。它无论在0左还是右，都落在“较大绝对值负数”和“较大绝对值正数”的中央接口位置。

完整性来自每一步都穷尽“当前最大绝对值标签只能放最左或最右”这两个可能。

## 12｜最少信息

排名可以依次恢复：

```text
s、r、q
```

的符号。

不能恢复：

```text
p
```

所以只需再问：

> p > 0 吗？

0次不够，因为 p 与 −p 会产生同一个标签排名；1次足够，因为其他符号都已由排名确定。

## 13｜五变量

加入 t 后：

```text
t → s → r → q
```

依次作为当前最大绝对值标签，按各自符号放到剩余序列最左或最右；p 最后落在中央接口。

不同标签排名共16种。

排名可以恢复：

```text
q、r、s、t
```

的符号，仍不能恢复 p 的符号。

# E｜T2

## 16｜D < B < A < C

条件：

```text
0 < |A| < |B| < |C| < |D|
```

- D 在最左，故 D < 0；
- 删除 D，C 在剩余最右，故 C > 0；
- 删除 C，B < A 且 |B| > |A|，故 B < 0；
- A 可正可负。

只需额外保存1位关于 A 的方向信息。

0位不够，因为 A 正、A 负会产生相同排名；1位足够，因为 B、C、D 已可由排名恢复。

加入 |E| 最大的 E 后：

- E > 0 → E 加到整个排名最右；
- E < 0 → E 加到整个排名最左。

# 方法复盘

这套作业不应靠符号表硬枚举。

标准策略：

```text
找最大绝对值
→ 放最左/最右
→ 删除
→ 对剩余重复
→ 从外到内恢复符号
→ 最后检查最小绝对值标签的信息是否丢失
```
