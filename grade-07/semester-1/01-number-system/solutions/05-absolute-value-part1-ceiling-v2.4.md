# 一｜T0 Ceiling Diagnostic｜六个点只留下相对方向

已知：

```text
|A| = 1
|B| = 3
|C| = 4
|D| = 6
|E| = 8
|F| = 10
```

并有：

```text
A、B同侧
B、C异侧
C、D同侧
D、E异侧
E、F同侧
```

没有任何一个点的绝对方向信息。

## Hint 1｜不要枚举64种

先临时假设：

```text
A > 0
```

沿着“同侧保持、异侧翻转”一路推出 B、C、D、E、F。

然后再问：如果最初假设 `A < 0` 会发生什么？

## Hint 2｜比较两组答案

把第一组答案中的每个数都取相反数。

检查两件事：

1. 每个绝对值是否改变？
2. 任意两个点的“同侧/异侧”关系是否改变？

## Hint 3｜删除中间一条关系以后

删掉 `C、D同侧` 后，不要把六个点继续看成一个整体。

看成：

```text
A—B—C

D—E—F
```

问：这两部分能不能分别独立整体翻转？

# 二｜T0 完整解答

## 1｜从 A 的方向传播全部关系

先假设：

```text
A = 1
```

因为 A、B 同侧：

```text
B = 3
```

B、C 异侧：

```text
C = −4
```

C、D 同侧：

```text
D = −6
```

D、E 异侧：

```text
E = 8
```

E、F 同侧：

```text
F = 10
```

得到：

```text
(1, 3, −4, −6, 8, 10)
```

若一开始 A 在左侧，则沿完全相同的关系传播：

```text
(−1, −3, 4, 6, −8, −10)
```

所以至少有两组。

## 2｜为什么恰好两组

关键不是“试完了”。

5条关系已经把六个标签连成一条完整关系链。

一旦 A 的方向确定：

- B 被“同侧”确定；
- C 被“异侧”确定；
- D 被“同侧”确定；
- E 被“异侧”确定；
- F 被“同侧”确定。

所以只有 A 的方向是自由选择。

A 只有：

```text
右侧
左侧
```

两种。

因此合法配置**恰好两组**。

## 3｜两组之间的变换

第二组正好是第一组中每个坐标同时取相反数：

```text
x → −x
```

也就是把整套配置关于原点0整体镜像。

## 4｜为什么所有已知信息在整体镜像后不变

### 绝对值

任意非零数 x 与 −x 到0距离相同，所以：

```text
|x| = |−x|
```

### 同侧/异侧

如果两个点原来同在右侧，整体镜像后都到左侧，仍然同侧。

如果原来一左一右，镜像后左右交换，仍然异侧。

因此整体镜像不会改变：

```text
绝对值
同侧关系
异侧关系
```

## 5｜为什么再增加任意多条同类信息也无法区分

假设有一组配置满足所有这些信息。

把所有坐标同时取相反数，得到它的整体镜像。

根据上一问：

- 每个绝对值不变；
- 每条同侧/异侧关系不变。

所以镜像配置仍满足**所有**同类信息。

因此，只要信息类型始终限定为：

```text
绝对值
+
同侧/异侧
```

就不可能告诉我们“整个系统究竟朝哪一边”。

这不是信息数量不足，而是**信息类型本身具有镜像不变性**。

## 6｜最少需要几次绝对方向询问

答案：

```text
1次
```

### 充分性

例如只问：

> A 是否在0右侧？

- 若是，选第一组；
- 若否，选第二组。

因为关系链已经把其他五个标签的相对方向全部锁定，所以知道 A 就知道全部。

### 必要性

若一次也不问，则前面的两组整体镜像配置始终无法区分。

所以：

```text
0次不够
1次足够
```

最少是1次。

## 7｜删除 `C、D同侧` 后

剩余关系分成两个互不联系的部分：

```text
A—B—C
D—E—F
```

第一部分内部一旦选定 A 的方向，B、C 都确定；但整块可以整体翻转。

第二部分内部一旦选定 D 的方向，E、F 都确定；这一块也可以独立整体翻转。

所以出现两个彼此独立的二选一：

```text
第一块方向：2种
第二块方向：2种
```

总数：

```text
2 × 2 = 4种
```

## 8｜真正突破口

不是：

> “每个绝对值都有正负两种。”

更深的结构是：

```text
相对方向关系可以把多个符号绑定在一起
但整体镜像不改变任何相对关系
```

所以要同时看：

```text
哪些对象已经绑定成一个整体？
这个整体还剩几个可以独立翻转的方向自由度？
```

# 四｜Builder 答案要点

## Builder A｜关系传播

原则：

```text
同侧 → 下一点方向不变
异侧 → 下一点方向翻转
```

选定任意一个起点的方向后，若关系链能一路连接其他点，就不必逐点枚举。

## Builder B｜整体镜像

对任意合法配置：

```text
(x1, x2, ..., xn)
```

整体取相反数：

```text
(−x1, −x2, ..., −xn)
```

所有绝对值与同侧/异侧关系保持不变。

因此只靠这种相对信息，最多把所有方向确定到“整体翻转”这一层。

## Builder C｜多个独立部分

若关系不能把所有标签联系成一个整体，而是分成 c 个彼此没有关系的部分，那么每部分都可以独立整体翻转。

所以留下 c 个独立二选一。

在没有绝对方向锚点时，共有：

```text
2 × 2 × ... × 2
```

共 c 个2。

不要求此处记指数记号，重点是理解“每个互不联系的部分都能独立翻转”。

## Builder D｜最少性

必须同时写：

```text
充分：给出具体方案
必要：构造/证明更少信息时仍有至少两组无法区分
```

## Builder E｜一般化

如果相对关系已经把 n 个标签连成一个整体，则所有符号只剩一个全局方向自由度。

因此：

```text
没有绝对方向锚点 → 至少两组整体镜像
加入任意一个标签的方向 → 全部方向确定
```

# 五｜Final Challenge｜最少关系设计

绝对值信息：

```text
|A| = |B| = 1
|C| = |D| = 4
|E| = 6
|F| = 9
|G| = |H| = 12
```

8个原数互不相同。

可保存：

```text
类型Ⅰ：两个标签同侧/异侧
类型Ⅱ：一个标签在左侧/右侧
```

最终只允许1条类型Ⅱ。

## Hint 1｜先不要数8个标签

因为 A、B 不同且绝对值同为1：

```text
{A,B} = {−1,1}
```

所以 A/B 内部已经天然“异侧”。

C/D、G/H 同理。

问：真正还能独立选择方向的单位究竟有几个？

## Hint 2｜把每个独立方向单位看成一个“块”

五个方向块：

```text
AB块
CD块
E块
F块
GH块
```

一条有效类型Ⅰ关系如果把两个原本互不联系的块联系起来，最多能让独立块的数量减少多少？

## Hint 3｜证明4条最少

先给出4条关系把5个方向块串成一条链，再加1个绝对方向锚点。

然后反过来证明：只有3条类型Ⅰ时，5个块至少还会剩两个彼此独立的部分；1条类型Ⅱ只能给其中一个部分定绝对方向，另一个仍可整体翻转。

# 六｜Final 完整解答

## 1｜初始共有多少配置

### A/B

```text
|A| = |B| = 1
```

且 A、B 不同，所以只能是：

```text
(A,B) = (1,−1)
```

或：

```text
(A,B) = (−1,1)
```

这是一个方向选择，而不是两个独立选择。

C/D 同理，是一个方向选择。

G/H 同理，是一个方向选择。

E 单独有：

```text
E = −6 或6
```

F 单独有：

```text
F = −9 或9
```

所以真正独立的方向组是：

```text
AB
CD
E
F
GH
```

共5组。

每组有两个方向，因此初始配置数为：

```text
2 × 2 × 2 × 2 × 2 = 32种
```

关键不是 `2^8`，因为重复绝对值已经自动绑定了三对标签。

## 2｜为什么重复绝对值组仍有一个方向自由度

例如 A/B 必须一正一负，但只知道：

```text
{A,B} = {−1,1}
```

还不知道：

```text
谁正谁负
```

所以整对仍有一个“翻转自由度”。

## 3｜真正独立的方向组

恰好5个：

```text
AB块、CD块、E块、F块、GH块
```

---

## 4｜最少需要多少条类型Ⅰ

答案：

```text
4条
```

然后再加题目允许的1条类型Ⅱ。

## 5｜一套4 + 1的具体方案

例如保存：

```text
Ⅰ1：A 与 C 同侧
Ⅰ2：C 与 E 异侧
Ⅰ3：E 与 F 同侧
Ⅰ4：F 与 G 异侧
```

再保存：

```text
Ⅱ1：A 在0右侧
```

现在恢复：

A 在右：

```text
A = 1，B = −1
```

A/C 同侧：

```text
C = 4，D = −4
```

C/E 异侧：

```text
E = −6
```

E/F 同侧：

```text
F = −9
```

F/G 异侧：

```text
G = 12，H = −12
```

全部唯一恢复：

```text
A=1，B=−1，C=4，D=−4，E=−6，F=−9，G=12，H=−12
```

因此4条类型Ⅰ**足够**。

---

## 6｜为什么3条类型Ⅰ一定不够

这是 Final 最重要的下界证明之一。

开始时有5个彼此独立的方向组。

一条类型Ⅰ关系如果有效地连接两个原本互不联系的方向组，最多只能把：

```text
两个独立部分
```

合成：

```text
一个更大的相对方向部分
```

所以一条有效关系最多让“互不联系的部分数”减少1。

从5个独立部分开始：

- 1条关系后，至少还剩4部分；
- 2条关系后，至少还剩3部分；
- 3条关系后，至少还剩2部分。

题目只允许1条类型Ⅱ绝对方向信息。

这1条信息只能给其中一个部分确定绝对朝向。

另一个没有绝对方向锚点的部分仍可以整体翻转，同时保持：

- 所有绝对值；
- 所有组内相反关系；
- 所有类型Ⅰ同侧/异侧关系。

因此至少仍有两组配置无法区分。

所以：

```text
3条类型Ⅰ不够
4条类型Ⅰ足够
```

最少为4条。

注意：如果某条类型Ⅰ关系只连接同一块内部，或重复已有关系，它连“减少1个独立部分”都做不到，因此不会比4更省。

---

## 7｜为什么类型Ⅱ不能完全省略

假设所有5个方向组已经被类型Ⅰ关系联系成一个整体。

取任意一组合法配置，把8个坐标全部取相反数。

整体镜像后：

- 每个绝对值不变；
- 每个重复绝对值组仍一正一负；
- 所有同侧/异侧关系不变。

所以纯类型Ⅰ信息永远无法区分一组配置与它的整体镜像。

因此至少需要一条能够提供**绝对方向**的信息。

---

## 8｜构造无法被类型Ⅰ区分的另一组

若一组配置为：

```text
(A,B,C,D,E,F,G,H)
```

则：

```text
(−A,−B,−C,−D,−E,−F,−G,−H)
```

与它有完全相同的绝对值、同侧/异侧数据。

只要没有类型Ⅱ，两者不可区分。

# 七｜Final 一般化

## 9｜为什么 k 个不同正绝对值对应 k 个方向组

设一个正绝对值 d 出现：

### 一次

对应标签只能是：

```text
−d 或 d
```

留下一个方向选择。

### 两次

由于原数互不相同，只能占据：

```text
−d 和 d
```

虽然两个坐标值都确定了，但“哪个标签在右”仍有两种，因此整组仍留下一个方向选择。

所以每一个不同的正绝对值都对应一个可整体翻转的方向组。

若共有 k 个不同正绝对值，就有 k 个初始方向组。

## 10｜只允许1条绝对方向信息时，最少多少条相对关系

结论：

```text
最少 k − 1 条有效的同侧/异侧关系
+
1条绝对方向信息
```

### 充分性

把 k 个方向组排成一条链，用 k−1 条类型Ⅰ关系依次联系：

```text
组1—组2—组3—...—组k
```

再给组1中任一标签一个绝对方向。

从组1出发可以沿整条链传播，最终确定所有组。

所以 k−1 条足够。

### 必要性

开始有 k 个独立方向组。

每加入一条有效类型Ⅰ关系，最多把两个原本独立的部分合成一个，因此最多减少1个独立部分。

若只有 k−2 条，则至少还剩：

```text
k − (k−2) = 2
```

个彼此独立的部分。

一条类型Ⅱ只能锚定其中一个，另一个仍可整体翻转。

所以 k−2 条不够。

因此 k−1 是最少值。

---

## 11｜另一种总记录数同样最少的方案

最直接方案：

> 对每个方向组，各保存1条类型Ⅱ绝对方向信息。

共有 k 组，所以需要：

```text
k条类型Ⅱ
0条类型Ⅰ
```

另一方案是：

```text
k−1条类型Ⅰ
+
1条类型Ⅱ
=
k条二选一记录
```

两种方案总记录数相同，但结构不同：

- 全类型Ⅱ：每组单独定向；
- 链式方案：大量保存相对关系，只用一个绝对方向锚点。

更一般地，若把 k 组分成 c 个彼此独立的已连接部分，可以使用：

```text
k−c 条有效类型Ⅰ
+
c 条类型Ⅱ
=
k 条记录
```

每个部分只需一个绝对方向锚点。

### 为什么总数不能少于 k

最初有 k 个独立二选一方向。

无论类型Ⅰ还是类型Ⅱ，每条记录都只有两种结果。

要保证区分所有独立方向组合，至少需要足够的信息逐一消除这 k 个自由方向。

这里不要求使用正式信息论术语；关键是理解：

> 每条二选一记录最多消除一个独立二选一自由度。

