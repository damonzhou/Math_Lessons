# Lesson 3 Ceiling Diagnostic / Builder｜v2.0 答案与记录

## T0 Ceiling Diagnostic

A、B、C、D、E、F 从左到右等距，B 表示 −1，E 表示5。

B 到 E 一共有3个相等间隔，而数值总变化为：

$$
5-(-1)=6
$$

所以每个间隔表示2。

因此：

```text
A  −3
B  −1
C   1
D   3
E   5
F   7
```

原点0在 B 与 C 的正中间，不是已标出的点。

### 为什么应先确定尺度

点的左右顺序已经给出，但具体坐标取决于“每个间隔代表多少”。两个可靠锚点和等距条件一起确定尺度，然后才能恢复其余点。

### 删除“等距”后的反例

若不要求等距，只要求：

```text
A < B < C < D < E < F
B = −1
E = 5
```

可以有：

- 方案A：A = −3，C = 0，D = 2，F = 7；
- 方案B：A = −2，C = 1，D = 4，F = 8。

两种都满足已知条件，所以其余点不唯一。

---

## Hints

### Hint 1

先数 B 到 E 有几个**间隔**，不要数点的个数。

### Hint 2

B 到 E 的数值总变化是多少？把它平均分到相等间隔。

### Hint 3

恢复所有点后，检查0是否恰好落在某个已标点上。

---

## Ceiling Builder 关键结论

### Builder 1

两个锚点 + 等距条件，可以确定每个间隔的统一变化量。

### Builder 2

删除等距条件后，中间点一般不唯一；必须用反例证明，而不是凭感觉说“条件不够”。

### Builder 3

逆向设计时，必须保证给出的两个锚点足以唯一恢复尺度；如果只给一个坐标，通常还缺尺度信息。

### Builder 4

等距数轴本质是“起点 + 间隔数 × 每格变化”的一维线性结构。这个思想以后会连接坐标、函数和程序中的 offset。
