# Lesson 8 当堂训练答案｜数轴综合｜v2.2

# 1. A = −5，B = 2

A、B 分居0两侧。

```text
−5 → 0：5个单位
0 → 2：2个单位
```

所以两点距离为7个单位。

检查：问的是“两点距离”，不是 B 的坐标2。

---

# 2. C = −8，D = −3

两点都在0左侧。

C 到0距离8，D 到0距离3，所以：

```text
CD = 8 − 3 = 5
```

不是11。11相当于把两个到0距离错误相加。

---

# 3. 从 −4 到3，再到1

第一段：

```text
−4 → 3：7个单位
```

第二段：

```text
3 → 1：2个单位
```

所以：

- 最终位置：1；
- 起点 −4 到终点1的直接距离：5；
- 实际路径长度：9。

三个量必须分开。

---

# 4. A = −7，M = −2，M 是 AB 中点

A 到 M：

```text
−7 → −2：5个单位
```

因为 M 是中点，所以 MB 也为5个单位。

从 −2 向右5个单位到3。

所以：

```text
B = 3
```

---

# 5. A = −6，B = 4，找等距点

A 到 B 总共10个单位。

把这10个单位平均分成两段，每段5个单位。

从 −6 向右5个单位到 −1。

所以唯一等距点为：

```text
M = −1
```

为什么唯一：沿 A 到 B 移动时，到 A 的距离逐渐增加，到 B 的距离逐渐减小，只在两段都为5时相等。

---

# 6. A、B、C、D 连续等距，A = −5，D = 4

A 到 D 跨3个相等间隔，总变化为9，所以每格3。

```text
A = −5
B = −2
C = 1
D = 4
```

---

# 7. 删除“连续等距”

不能唯一确定 B、C。

例如都满足 A < B < C < D：

```text
方案1：A = −5，B = −2，C = 1，D = 4
方案2：A = −5，B = −4，C = 3，D = 4
```

所以“等距”是确定尺度的关键条件。

---

# 8. 到0距离为6

可能位置：

```text
−6，6
```

为什么只有两个：数轴上从0出发，距离6只有左右两个方向；每个方向上距离6的位置唯一。

---

# 9. 到 −2 的距离为3

从 −2 向左3个单位：

```text
−5
```

从 −2 向右3个单位：

```text
1
```

全部可能为：

```text
−5，1
```

---

# 10. 两机器人从 −6 和4同时、同速、相向运动

因为：

```text
同时出发
+ 相同速度
+ 相遇时经历相同时间
→ 两者走过距离相同
```

所以相遇点到两个起点距离相同，即为两起点的中点。

−6 到4共10个单位，一半为5，所以相遇点是 −1。

如果右边机器人更快，两边走过距离不再相同，因此不能直接断言相遇点是中点。

# 本讲课堂检查重点

错误出现时建议记录：

- 坐标和距离混淆：`C7 + H7`；
- 路径长度与直接距离混淆：`C2/C7 + H2/H7`；
- 看图默认中点/等距：`C2 + H3/H9`；
- 逆向距离只写一个位置：`C6 + H5/H10`；
- 相遇题漏“同速”条件：`C2 + H1/H3`；
- 找到答案但不证明唯一：`C6 + H10`。
