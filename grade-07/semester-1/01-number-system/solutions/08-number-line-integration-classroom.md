# A｜Gap Check

## 1

A=−4：

```text
坐标：−4
到0距离：4
方向：原点左侧
```

## 2

−3 与5 分居0两侧：

```text
3 + 5 = 8
```

相距8个单位。

## 3

−7 与−2 同在左侧，到0距离分别7和2，所以两点相距：

```text
7−2=5
```

## 4

路径：

```text
−3 → 5 → 1
```

- 最终位置：1；
- 起点到终点直接距离：4；
- 实际路径：8+4=12。

## 5

A=−6、M=−1，AM=5。M 是中点，所以 MB=5，从−1向右5到：

```text
B=4
```

## 6

B=−5、E=4，B 到 E 跨3个相同间隔，总长度9，所以每格3：

```text
A=−8
B=−5
C=−2
D=1
E=4
```

## 7

删除“等距”后不唯一。例如仍满足顺序 `A<B<C<D<E`、B=−5、E=4 时：

```text
C=−2，D=1
```

可以；

```text
C=−4，D=3
```

也可以。

# B｜School Advanced

## A1｜同速相遇

同时从两端相向、速度相同，意味着相同时间内两边走的距离相等，所以相遇点到两起点等距，即为中点。

若速度不同，两边走的距离不同，不能默认中点。

## A2｜距离5的逆向

只知道到0距离5：

```text
P=−5 或5
```

增加“P在0左侧/右侧”或“P>0/P<0”等方向信息可唯一。

## A3｜到两点等距与中点

在一维数轴上，对两个不同点 A、B，唯一同时到 A、B 等距的位置位于两者之间，因此它就是中点。

但定义表达时仍应区分：

```text
中点 = 在线段AB上 + 到两端等距
```

不能把“到两点等距”无条件推广到所有几何环境。

# C｜进入 T0 前检查

学生应稳定区分：

```text
坐标 / 到0距离 / 两点距离 / 路径长度
```

并会：

- 用等距恢复尺度；
- 检查点的左右顺序；
- 识别删条件后的不唯一；
- 不把“看起来等距”当题目条件。

此时不要提前讲“无标签全部两两距离如何重建”或“平移/镜像不变量”的系统算法。
