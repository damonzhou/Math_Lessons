# A｜Gap Check

## 1｜a > 0

```text
|a| = a
|−a| = a
−|a| = −a
```

## 2｜a < 0

```text
|a| = −a
|−a| = −a
−|a| = a
```

注意：此时 `−a > 0`。

## 3｜“|a|=a，所以 a>0”

错误。a=0 也成立。

完整条件：

```text
|a| = a  ⇔  a ≥ 0
```

## 4｜“|a|=−a，所以 a<0”

错误。a=0 也成立。

```text
|a| = −a  ⇔  a ≤ 0
```

## 5｜恒等关系

对所有有理数 a：

```text
|−a| = |a|
||a|| = |a|
```

## 6｜三个绝对值方程

```text
|x| = 7   → x = −7 或7，共2个
|x| = 0   → x = 0，共1个
|x| = −2  → 无解
```

## 7｜为什么检查0

0是正/负两区的分界，并且：

```text
0 = −0
```

许多“严格正/严格负”的逆向结论都会在0处失效。

# B｜Concept / School Advanced

## A1｜充分与完整条件

保证 `|a|=a`：

- `a>0`：足够，但没包含0；
- `a=0`：足够；
- `a≥0`：恰好覆盖全部情况；
- `a≠0`：不足够，反例 a=−1。

## A2｜两条关系同时成立

```text
|a| = a   → a ≥ 0
|a| = −a  → a ≤ 0
```

只有同时满足：

```text
a = 0
```

## A3｜表达式外形

```text
−a < 0
```

不恒真；若 a<0，则 −a>0。

```text
|−a| = −a
```

不恒真；它等价于 `a≤0`。

```text
−|a| ≤ 0
```

恒真，因为 `|a|≥0`。

# C｜参数分类

对 `|x|=t`：

```text
t>0  → 2个解
t=0  → 1个解
t<0  → 0个解
```

完整性来自 t 的正、零、负三分类。

---

# D｜进入 T0 前检查

学生至少应稳定做到：

- 不把 `−a` 默认当负数；
- 会主动检查0；
- 会区分“足够条件”和“全部情况”；
- 理解 `|−a|=|a|`、`||a||=|a|`；
- 能解释 `|x|=t` 的0/1/2解结构。

但此时**不要提前告诉**学生“任意 A/R 操作串只有四类”或“最后一次 A 决定历史压缩”。那是 T0 / Final 的真实突破口。
