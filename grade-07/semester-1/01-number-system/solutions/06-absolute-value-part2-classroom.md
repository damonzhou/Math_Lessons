# A. 基础与概念

## 1. 已知 a > 0

```text
|a| = a
|−a| = a
```

因为 a 在0右边，而 −a 在0左边，两者到0的距离都为 a。

---

## 2. 已知 a < 0

```text
|a| = −a
|−a| = −a
```

这里 −a 是正数，因为它是负数 a 的相反数。

---

## 3. 已知 a = 0

```text
|a| = 0
−a = 0
|−a| = 0
```

0的相反数仍是0，0到原点的距离也是0。

---

## 4. 只知道 a 是有理数，能否直接写 `|a| = a`

不能。

因为 a 可能是正数、0或负数。

例如：

```text
a = 3  时，|a| = a

a = −3 时，|a| ≠ a
```

**检查点**：条件是否足以判断 a 的符号？

---

## 5. “如果 `|a| = a`，那么 a 一定是正数”

错误。

反例：a = 0。

此时：

```text
|a| = a = 0
```

正确结论是：a 为非负数，即 a ≥ 0。

---

## 6. “如果 `|a| = −a`，那么 a 一定是负数”

错误。

反例：a = 0。

正确结论是：a 为非正数，即 a ≤ 0。

---

## 7. 为什么 `|−a| = |a|` 不需要知道 a 的符号

因为 a 与 −a 在数轴上关于原点对称，到原点距离相同。

所以无论 a 是正数、0还是负数，都有：

```text
|−a| = |a|
```

---

## 8. 为什么 `||a|| = |a|`

`|a|` 已经是一个距离，所以一定非负。

非负数的绝对值就是它本身，因此：

```text
||a|| = |a|
```

---

# B. 分类与边界

## 9. 补全规则

```text
当 a ≥ 0 时，|a| = a
当 a < 0 时，|a| = −a
```

0归入第一类。

---

## 10. 另一种两分法是否正确

```text
当 a > 0 时，|a| = a
当 a ≤ 0 时，|a| = −a
```

正确。

关键在 a = 0 时：

```text
a = −a = 0
```

所以0放在任意一支都不会改变绝对值结果。

---

## 11. 已知 `|a| = |b|` 且 a ≠ b

a 与 b 必须互为相反数。

理由：同一距离在数轴上最多对应原点两侧两个对称位置。如果不是同一个位置，就只能是对称位置。

---

## 12. 已知 `|a| = 6`

```text
a = 6 或 a = −6
```

因为数轴上到0距离为6的点有两个。

---

## 13. `|a| = 0`

只有：

```text
a = 0
```

原点是唯一到0距离为0的位置。

---

## 14. `|a| = −3`

无解。

因为绝对值表示距离，而距离不可能为负数。

---

# 当堂综合训练答案

## 1. x > 0

```text
|x| = x
|−x| = x
−|x| = −x
```

---

## 2. x < 0

```text
|x| = −x
|−x| = −x
−|x| = x
```

最后一项：`−|x| = −(−x) = x`。

---

## 3. 只知道 x ≠ 0

不能唯一把 `|x|` 写成 x 或 −x。

因为：

- x > 0 时，`|x| = x`；
- x < 0 时，`|x| = −x`。

还需要知道 x 的符号。

---

## 4. `|x| = x`

推出：

```text
x ≥ 0
```

---

## 5. `|x| = −x`

推出：

```text
x ≤ 0
```

---

## 6. `|x| = |−x|`

对所有有理数 x 成立。

原因：x 与 −x 到0距离相同。

---

## 7. `||x|| = |x|`

对所有有理数 x 成立。

因为 `|x|` 已经非负。

---

## 8. `|x| = 7`

```text
x = 7 或 x = −7
```

---

## 9. `|x| = 0`

```text
x = 0
```

---

## 10. `|x| = −7`

无解，因为绝对值不能为负。

---

## 11. `|x| = |y|` 且 x ≠ y

x、y 互为相反数。

---

## 12. 反例

取：

```text
x = −2
```

虽然 x ≠ 0，但：

```text
|x| = 2 ≠ −2 = x
```

所以原断言不成立。

---

## 13. 两分支 `abs(x)`

一种正确规则：

```text
if x < 0:
    return −x
else:
    return x
```

测试：

```text
x = −5 → 5
x = 0  → 0
x = 5  → 5
```

边界0必须测试。

---

## 14. 一般化

```text
t > 0：|x| = t 有两个可能值，x = t 或 x = −t

t = 0：只有 x = 0

t < 0：无解
```

真正依据始终是：绝对值是到0的距离。
