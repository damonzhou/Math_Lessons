# A. Core 巩固

## 1

数轴三要素：

- 原点：确定基准位置；
- 正方向：确定哪边表示数增大；
- 单位长度：确定“1个数值单位”对应多长。

缺任何一个都不能唯一建立数与位置的对应。

## 2

按正方向向右、单位长度为1绘图即可：−4、−1.5、0、3/4、2分别放在对应位置。

关键是分数和小数也能上数轴。

## 3

每格0.2，左侧第4格：

```text
−0.8
```

不能写成 −4，因为“第4格”是间隔数量，不是数值本身。

## 4

从小到大：

```text
−3 < −2.5 < −1/4 < 0 < 1/2
```

−2.5 位于 −3 的右侧，所以 −2.5 > −3。

## 5

- 点 A：几何对象；
- −3：点 A 的坐标，是一个数；
- 到原点的距离：3个单位，是长度。

三者不能混为同一个对象。

# B. Ceiling Builder 迁移

## 6

离0最远：−15，对应距离15。

离0最近：8，对应距离8。

## 7

A = −2，D = 4，A 到 D 有3个相等间隔。

总变化6，所以每格变化2。

因此：

```text
A = −2
B = 0
C = 2
D = 4
```

删除“等距”后，B、C不能唯一确定。

## 8

不能确定 C 的坐标，只能知道：

```text
−2 < C < 5
```

例如 C = 0 或 C = 4 都合法。

所以示意图上“看起来在中间”不能成为数学条件。

## 9

一种设计：5个等距点坐标为：

```text
−3，−1，1，3，5
```

每格变化2；原点在 −1 与1之间；若给第1点 −3 和第5点5，别人可以唯一恢复全部点。

答案不唯一，只要满足题设即可。

# C. Advanced / Competition / Informatics

## 10

位于 −2 与 −1 之间的是：

$$
-\frac32,\quad-1.2,\quad-\frac74
$$

因为分别等于 −1.5、−1.2、−1.75。

−5/2 = −2.5 太小；−0.8 太大。

## 11

L = −4，P = 8，L 到 P 跨3个等距间隔。

总变化12，所以每格变化4。

```text
K = −8
L = −4
M = 0
N = 4
P = 8
```

原点恰好是 M。

删除等距后，只知道 L、P 坐标和左右顺序，K/M/N 的坐标不唯一。

## 12

- 新坐标：97；
- offset：97 − 100 = −3；
- 坐标97描述绝对位置；offset −3描述相对起点的位移/偏移。

数值和语义层级不同。

# D. T2

## 13

第2点 = −4，第5点 = 8，中间有3个等距间隔。

每格变化：

$$
\frac{8-(-4)}{3}=4
$$

所以5个点依次为：

```text
−8，−4，0，4，8
```

0恰好是第3个检测点。

若删除“等距”，只能保留第2、第5点坐标和左右顺序，其余点不唯一。例如第3点可取0，也可取2，只要保持顺序即可。
