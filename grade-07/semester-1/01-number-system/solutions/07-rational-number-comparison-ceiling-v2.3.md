# T0｜三个标签只有绝对值顺序

已知：

```text
0 < |a| < |b| < |c|
```

## Hint 1

先不要管 a、b。

只问：c 的绝对值最大。

- 如果 c > 0，它和任何绝对值更小的数相比会怎样？
- 如果 c < 0，又会怎样？

## Hint 2

你应发现：

```text
c > 0 → c 一定最大
c < 0 → c 一定最小
```

因此 c 绝不可能排在中间。

去掉 c 后，再对 a、b 做同样的思考：谁的绝对值更大？

## Hint 3

在 `|a| < |b|` 下：

```text
b > 0 → a < b
b < 0 → b < a
```

a 自己的符号不会改变 a、b 的标签顺序。

把 b、c 的正负两种选择组合起来即可，不需要枚举 a 的符号。

---

# T0 完整解答

## 1｜先抓住最大绝对值 c

因为：

```text
|c| > |a|
|c| > |b|
```

### c > 0

若 a、b 为正，它们都比 c 更接近0，因此都小于 c。

若 a、b 为负，它们更直接小于正数 c。

所以无论 a、b 的符号是什么：

```text
c > a 且 c > b
```

即 c 一定最大。

### c < 0

若 a、b 为负，由于它们绝对值都小于 |c|，它们都比 c 更靠近0、更靠右，因此都大于 c。

若 a、b 为正，也当然大于负数 c。

所以：

```text
c < a 且 c < b
```

即 c 一定最小。

因此得到第一个全局结构：

> **绝对值最大的非零数，它的符号决定它占据最左端还是最右端；它永远不可能在中间。**

所以6种理论排列中，凡是 c 在中间的都不可能：

```text
a < c < b
b < c < a
```

---

## 2｜再看 a 与 b

有：

```text
|a| < |b|
```

### b > 0

无论 a > 0 还是 a < 0，都有：

```text
a < b
```

原因：

- a > 0 时，a 的正距离更小，所以 a < b；
- a < 0 时，负数 a 当然小于正数 b。

### b < 0

无论 a > 0 还是 a < 0，都有：

```text
b < a
```

原因：

- a > 0 时，b < a；
- a < 0 时，|b| > |a|，所以 b 更靠左，b < a。

因此：

> 在 `|a| < |b|` 的前提下，a、b 谁大，只由 b 的符号决定。

---

## 3｜四种可能排序

把 b、c 的符号组合起来。

### 情况A｜c > 0，b > 0

c 最大；a < b。

```text
a < b < c
```

### 情况B｜c > 0，b < 0

c 最大；b < a。

```text
b < a < c
```

### 情况C｜c < 0，b > 0

c 最小；a < b。

```text
c < a < b
```

### 情况D｜c < 0，b < 0

c 最小；b < a。

```text
c < b < a
```

所以全部可能且仅可能：

```text
a < b < c
b < a < c
c < a < b
c < b < a
```

一共4种。

---

## 4｜为什么 b、c 的符号能从排序反推

观察：

- c 在最右端 → c > 0；
- c 在最左端 → c < 0。

确定 c 后，看 a、b：

- a < b → b > 0；
- b < a → b < 0。

因此每一种标签排序都唯一决定 b、c 的符号。

对应关系：

| 排序 | b | c |
|---|---|---|
| a < b < c | 正 | 正 |
| b < a < c | 负 | 正 |
| c < a < b | 正 | 负 |
| c < b < a | 负 | 负 |

---

## 5｜为什么 a 的符号无法由排序确定

关键是：

```text
|a| 最小
```

所以 a 离0最近。

- 若 a < 0，它是所有这些不同绝对值中的“最靠近0的负数”；
- 若 a > 0，它是“最靠近0的正数”。

不论 a 在0左还是右，它都处在：

```text
所有绝对值更大的负数
和
所有绝对值更大的正数
```

之间的那个“中央接口位置”。

例如同一种排序：

```text
a < b < c
```

可以取：

```text
a = 1，b = 2，c = 3
```

也可以取：

```text
a = −1，b = 2，c = 3
```

两组都满足 `0 < |a| < |b| < |c|`，标签排序也都仍是：

```text
a < b < c
```

所以排序看不见 a 的符号。

---

## 6｜为什么8种符号组合只产生4种标签排序

b、c 的两个符号各自真正改变标签顺序：

```text
b 的符号：决定 a、b 谁在前
c 的符号：决定 c 在最左还是最右
```

而 a 的符号不改变标签排名。

因此把 a 变号时，两种符号组合会落到同一个标签排序结构中。

“丢失”的那一位信息就是：

> **最小绝对值标签 a 的方向。**

---

## 7｜不重不漏证明

不用枚举8种符号组合，只做两层结构判断：

1. c 绝对值最大，因此只可能最左或最右，共2种结构；
2. 去掉 c 后，b 在 a、b 中绝对值最大，因此 b 只可能在 a 左边或右边，共2种结构；
3. 两层组合得到4种标签顺序；
4. 每一层都已经穷尽该最大绝对值标签的全部符号可能，因此没有遗漏；
5. 每个最终顺序中 c 的端点位置或 a/b 相对位置不同，因此四种互不重复。

所以4种排序不重不漏。

# Builder 核心结论

## 两变量结构

在：

```text
0 < |a| < |b|
```

下：

```text
b > 0 → a < b
b < 0 → a > b
```

反过来也成立：

```text
a < b → b > 0
a > b → b < 0
```

因此可以用中文说：

> **在两个绝对值不同的非零数中，绝对值更大的那个数的符号，完全决定两者的大小顺序。**

这是后面多变量递归结构的最小单元。

# Final Challenge｜四个标签的顺序密码

已知：

```text
0 < |a| < |b| < |c| < |d|
```

## Hint 1

先别碰 a、b、c。

只看 d：它的绝对值最大。

证明：

```text
d > 0 → d 一定最大
d < 0 → d 一定最小
```

## Hint 2

把 d 暂时删掉。

剩下：

```text
0 < |a| < |b| < |c|
```

所以 c 又是剩余标签中绝对值最大的，继续放到剩余顺序的最左或最右。

## Hint 3

继续删 c，再处理 b。

你不需要讨论 a 的符号，因为最后只剩 a 一个标签。

于是：

```text
d 左/右
× c 左/右
× b 左/右
```

构造出全部标签顺序。

---

# Final 完整解答

## 第一层｜d 一定在最左或最右

因为 |d| 最大。

- d > 0：任何正的 a、b、c 都因绝对值更小而小于 d；任何负数也小于 d，所以 d 最大。
- d < 0：任何负的 a、b、c 都因绝对值更小而更靠右、大于 d；任何正数也大于 d，所以 d 最小。

因此 d 不可能在中间。

去掉 d 后，同理：c 在剩余三个标签中必为最左或最右。

再去掉 c 后，b 在 a、b 中也由自己的符号决定左/右。

---

## 2｜全部8种标签顺序

按照 d、c、b 的符号逐层放置：

```text
1. d < c < b < a
2. d < c < a < b
3. d < b < a < c
4. d < a < b < c
5. c < b < a < d
6. c < a < b < d
7. b < a < c < d
8. a < b < c < d
```

这8种都能实现。

例如直接取：

```text
|a| = 1，|b| = 2，|c| = 3，|d| = 4
```

再按所需左右端结构给 b、c、d 选符号即可；a 正负任选，不改变标签顺序。

---

## 3｜为什么只有8种，不需要枚举16种符号

递归结构：

```text
d：放最左或最右
↓
c：在剩余位置中放最左或最右
↓
b：在剩余位置中放最左或最右
↓
a：最后剩下唯一位置
```

每一步都来自当前“剩余标签中绝对值最大者”的符号。

因此所有可能都由3个二选一决定：

```text
d 的符号
c 的符号
b 的符号
```

a 的符号不会产生新的标签顺序。

这既说明没有遗漏，也说明为什么16种符号组合只对应8种标签排序。

---

## 4｜从标签顺序反推 b、c、d 的符号

递归倒推：

- 看 d 在最左还是最右，可知 d 负或正；
- 删除 d，看 c 在剩余标签的最左还是最右，可知 c 负或正；
- 删除 c，看 b 在 a、b 中的左右关系，可知 b 负或正。

所以最终标签顺序唯一决定：

```text
b、c、d 的符号
```

---

## 5｜为什么 a 的符号仍然不可恢复

因为 a 的绝对值最小。

它无论取：

```text
a = |a|
```

还是：

```text
a = −|a|
```

都处在“所有较大绝对值负数”和“所有较大绝对值正数”的交界处。

因此它的标签位置不改变。

所以 a 是唯一无法由标签排名恢复符号的变量。

# 指定排名

给出：

```text
d < b < a < c
```

### d

d 在最左，因此：

```text
d < 0
```

### c

删除 d 后，剩余顺序：

```text
b < a < c
```

c 在剩余最右，因此：

```text
c > 0
```

### b

再删除 c，剩下：

```text
b < a
```

而 |b| > |a|，所以：

```text
b < 0
```

### a

无法确定，可正可负。

两组验证：

```text
a = 1，b = −2，c = 3，d = −4
```

以及：

```text
a = −1，b = −2，c = 3，d = −4
```

两组都满足：

```text
d < b < a < c
```

---

# 最少信息

标签顺序已经确定 b、c、d 的符号，只剩 a。

所以只需问一次：

> **a > 0 吗？**

即可恢复全部符号。

### 为什么一次足够

因为其他三个符号已经由排序唯一确定，这一问直接补上唯一缺失信息。

### 为什么一次必要

不问时，至少存在：

```text
a = |a|
```

和：

```text
a = −|a|
```

两组不同符号状态产生完全相同标签排序。

因此仅靠排名无法区分它们。

所以：

```text
0次不够
1次足够
```

最少就是1次。

---

# 五变量一般化

加入 e：

```text
0 < |a| < |b| < |c| < |d| < |e|
```

不需要列32种符号组合。

做法仍然是：

```text
e 按符号放最左/最右
→ 删除 e
d 按符号放剩余最左/最右
→ 删除 d
c 同理
→ b 同理
→ a 落在最后唯一位置
```

因此：

- 排名可以恢复 b、c、d、e 的符号；
- a 的符号仍然不可恢复；
- 不同标签排序数量从2变量的2种、3变量的4种、4变量的8种，继续变成5变量的16种。

一般规律可以用语言描述：

> **每增加一个“新的最大绝对值标签”，它的正负会提供“放最左还是最右”这一个新的二选一；最小绝对值标签的正负始终不会改变标签排名。**

本讲不要求使用后续乘方记号表达这一计数规律。

# 方法提炼

遇到：

```text
0 < |x1| < |x2| < ... < |xn|
```

不要从最小的开始猜。

优先执行：

```text
① 找当前绝对值最大的标签
② 判断它只能占最左或最右
③ 暂时删除它
④ 对剩余标签重复
⑤ 最后检查最小绝对值标签的信息是否仍可恢复
```

这是一种：

> **极端元素 → 剥离 → 递归恢复 → 信息缺失检查**

的高阶结构。
