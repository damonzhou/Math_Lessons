# A｜基础综合

## 1

A=−8、B=3。

```text
A到0：8
B到0：3
AB：8+3=11
```

中点到两端各 `11/2=5.5`。从−8向右5.5到：

```text
−2.5
```

## 2

```text
−5→4：9
4→−1：5
−1→2：3
```

最终位置2；起终点直接距离7；实际路径：

```text
9+5+3=17
```

## 3

A=−7、D=5，总跨度12，分3个相等间隔，每格4：

```text
A=−7，B=−3，C=1，D=5
```

没有“等距”，B/C 可在大量位置变化，不能恢复尺度。

# B｜条件与逆向

## 4

```text
P=±6
Q=±2
```

满足 P<Q 的只有：

```text
(−6,−2)
(−6,2)
```

四种符号组合已全部检查，因此无遗漏。

## 5

最大距离8是两端，归一化为0和8。内部点必须同时产生另外两条距离3和5，因此：

```text
{0,3,8}
或
{0,5,8}
```

两者关于中点4镜像，所以在平移/镜像意义下是同一个形状。

# C｜4点重建

## 6

最大距离6锁定端点0、6。

若内部点在3，会产生两个端点距离3，但记录中3只出现一次，所以内部点不能在3。

剩余端点距离必须使用互补对：

```text
1+5=6
2+4=6
```

内部两点之间还应留下距离3。

只有：

```text
1和4：差3
2和5：差3
```

因此：

```text
{0,1,4,6}
{0,2,5,6}
```

两组互为关于3的镜像，没有第三组。

## 7

最左点固定为−10后：

```text
{−10,−9,−6,−4}
{−10,−8,−5,−4}
```

仍两组。

若再知道“从左第2点=−9”，只剩第一组。

# D｜不变量与信息充分性

## 8

平移时所有点增加同一长度，两点间隔不变；镜像时左右方向同时反转，但任意两点之间的长度不变。

因此无标签距离天然丢失：

```text
绝对位置
左右朝向
```

## 9

A、B 的全部无标签两两距离完全相同，因此只挑若干“距离数值”永远无法区分。

真正能区分的是额外结构，例如从左到右相邻间隔：

```text
A：1，3，6，2，5
B：1，7，3，2，4
```

但“相邻”与“顺序”正是原无标签距离数据库没有保存的信息。

## 10

方案B一定可以唯一恢复归一化点集。

固定最左点0，若相邻间隔依次为：

```text
g1，g2，...，g(n−1)
```

则从左到右依次走这些长度即可得到所有点。

方案A不保证唯一，主课6点反例已经证明。

# E｜CEMC 2026 G8 Q25

## 11

最大距离16固定最外两点，可归一化为0和16。

利用 `x ↔ 16−x` 的镜像，可以只分析一半对称分支。沿官方解答的候选排除，可把关键内点（取一侧代表）固定到13，再枚举剩余可行位置。

最终只有三类配置，例如：

```text
{0,4,11,13,16}  → 额外距离 n=12
{0,7,11,13,16}  → n=6
{0,9,11,13,16}  → n=2
```

它们的十个距离分别正好是题目给定九个距离再加：

```text
12，6，2
```

其余候选会产生至少两个题目列表外的新距离，或造成不允许的重复结构，因此被排除。

所以：

```text
n ∈ {2,6,12}
```

共有：

```text
3种
```

完整官方分支证明见题旁 CEMC 官方解答。

# F｜动点综合

## 12

同一时刻出发且速度相同，才保证相遇前两者走过距离相同，因此相遇点是中点。

删除同速可构造反例：起点0与10，左边速度1、右边速度4，同时相向，二者相遇时左边只走2、右边走8，相遇点为2，不是中点5。

仅知道“最终相遇”不能反推出路程相同；相遇只说明最终位置相同。
