# A. Core 巩固

## 1

- 坐标：−6；
- 到0距离：6；
- 到坐标2的点的距离：8。

分别回答“在哪里”“离0多远”“两个位置相隔多远”。

## 2

P = −7，Q = 3，分居0两侧：

```text
7 + 3 = 10
```

所以 PQ = 10。

## 3

M = −9，N = −4，同在0左侧。

到0距离分别为9和4，因此：

```text
MN = 9 − 4 = 5
```

## 4

```text
−5 → 4：9
4 → 1：3
```

- 最终位置：1；
- 起点到终点直接距离：6；
- 总路程：12。

## 5

A = −8，M = −3，所以 AM = 5。

M 是中点，因此 MB = 5。

从 −3 向右5个单位：

```text
B = 2
```

# B. 条件与唯一性

## 6

B 不一定是0。

只要求：

```text
−5 < B < 5
```

例如：

```text
B = −3，0，4
```

都合法。

## 7

增加 AB = BC 后，B 是 A、C 的中点。

−5 到5共10个单位，两半各5，所以：

```text
B = 0
```

唯一。

## 8

M = 2，距离5：

```text
X = −3 或 7
```

只有两个，因为从固定点出发固定正距离只有左右两个方向。

例如增加“X > 2”，即可唯一得到 X = 7。

## 9

B = −8，E = 1，跨3个相同间隔，总变化9，所以每格3。

```text
A = −11
B = −8
C = −5
D = −2
E = 1
```

0不在任何标点上。

## 10

仍能确定：B = −8，E = 1，以及点的左右顺序。

不能确定 A、C、D 的具体坐标。

例如：

```text
A = −10，B = −8，C = −4，D = 0，E = 1
```

也满足顺序，但不是原等距答案。

# C. 动点与路径

## 11

同时、同速、相向运动，意味着相遇前两者走过相同距离，因此相遇点到两个起点等距，是中点。

−10 到6共16个单位，一半8。

从 −10 向右8：

```text
相遇点 = −2
```

关键条件至少包括：

- 同时出发；
- 速度相同。

在本模型还默认持续相向运动直到相遇。

## 12

不一定。

例如两点相距6格，左机器人每次走2格，右机器人每次走1格，同时相向：

第一轮后共缩短3格；第二轮相遇时左边共走4格、右边共走2格。

相遇点显然不在中点。

这说明“同速”是中点结论的关键条件。

# D. 权威竞赛迁移

## 13

−6 ℃ 到2 ℃：

```text
−6 → 0：6
0 → 2：2
```

升高8 ℃。

不是4，因为4只是把数字外形错误地做局部处理，没有表示数轴上的完整变化。

- 2 ℃：下午的温度值/位置；
- 8 ℃：温度变化量。

## 14

P = −9，Q = −2。

PQ = 7，所以 QR = 7。

从 −2 向右7：

```text
R = 5
```

若 R、Q 已知且 Q 为中点，也可从 Q 向另一方向复制相同距离恢复 P。

删除“Q 是中点”后，R 不唯一。

## 15

R = −4，U = 8，R 到 U 跨3格，总变化12，每格4。

```text
P = −12
Q = −8
R = −4
S = 0
T = 4
U = 8
```

S 最接近0，而且就是0，唯一。

删除等距后：

- 每格变化不能确定；
- P、Q、S、T 不能恢复；
- 最接近0的点也不能由已知信息唯一判断。

# E. Ceiling Builder

## 16

开放题，示例：

```text
A = −7
B = −4
C = −1
D = 2
E = 5
F = 8
```

每格3，原点不在标点。

若给 B = −4、E = 5，可由3个间隔恢复每格3，再恢复全部点。

C 是 A、E? 不是。可指出 C 是 A、E 中点时需重设计。一个满足中点要求的示例：

```text
A = −8
B = −5
C = −2
D = 1
E = 4
F = 7
```

C 是 A、E 的中点，因为 A 到 C 6、C 到 E 6。

## 17

固定点 M、正距离 d：

- 向左 d 有一个点；
- 向右 d 有一个点；
- 直线上没有第三个方向。

所以正距离对应两个点。

当 d = 0 时，左右移动都退化为不移动，因此只有 M 本身一个点。

# F. Mastery Challenge

## 18

A = −11，E = 5。

A 到 E 跨4个相同间隔，总变化16，所以每格4。

```text
A = −11
B = −7
C = −3
D = 1
E = 5
F = 9
```

B 到 E 跨3格：

```text
BE = 12
```

X 到 C = −3 的距离为12，所以：

```text
X = −15 或 9
```

为什么只有两个：固定正距离对应左右两个方向，每方向唯一。

若 X > C，则：

```text
X = 9
```

删除连续等距后，只能保留 A = −11、E = 5 和点的顺序；B、C、D、F、BE 和 X 都不能唯一恢复。

# G. T2

## 19

L = −6，P = 6，L 到 P 跨3格，总变化12，每格4。

```text
K = −10
L = −6
M = −2
N = 2
P = 6
```

机器人：

```text
M = −2 → K = −10：8
K = −10 → N = 2：12
```

总路程：20。

起点 M 到终点 N 的直接距离：4。

不同原因：总路程记录实际经过的路径，直接距离只看起终点最短间隔。

删除等距后，除 L、P 及顺序外，其余站点坐标、两段路程、总路程和直接距离都不能唯一确定。

# 复盘重点

如果答案正确但没有做以下检查，仍建议标记为“过程未稳定”：

- 固定距离是否检查左右两侧；
- 中点是否真正使用了等距条件；
- 相遇中点是否检查同速；
- 总路程是否与直接距离分开；
- 删除等距后是否拒绝继续使用原尺度；
- 多解题是否说明为什么已经列完。
