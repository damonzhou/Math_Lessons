# 一｜T0 Ceiling Diagnostic

## 题目结构

7个互不相同整数 P、Q、R、S、T、U、V 满足：

```text
|P| = 6
|Q| = 3
|R| = 6
|S| = 1
|T| = 3
|U| = 4
|V| = 2
```

并有：

```text
P < Q
R > S
T < U
V > 0
```

---

## Hint 1｜先按“绝对值组”思考

不要7个标签逐个猜。

先问：

```text
绝对值6出现两次，且原数不同，会发生什么？
绝对值3出现两次，且原数不同，会发生什么？
```

把它们分别看成一组。

---

## Hint 2｜让大小条件决定方向

由 `|P| = |R| = 6` 且 P、R 不同：

```text
{P,R} = {−6,6}
```

再使用 `P < Q`，其中 Q 只能是 −3 或3。

类似地，用 `T < U` 判断 U 能否是 −4。

---

## Hint 3｜最后不要逐条乱列

前面条件处理后，只剩两个独立选择：

```text
选择A：Q/T 中谁是 −3
选择B：S 是 −1 还是1
```

做一个 2 × 2 选择表。

# 二｜T0 完整解答

## 1. 先处理重复绝对值

因为7个原数互不相同，而绝对值6出现两次，所以：

```text
{P,R} = {−6,6}
```

绝对值3同理：

```text
{Q,T} = {−3,3}
```

另外：

```text
S = −1 或1
U = −4 或4
V = −2 或2
```

## 2. 使用 `P < Q`

如果 P = 6，那么 Q 只能为 −3 或3，都不满足 6 < Q。

因此：

```text
P = −6
R = 6
```

此时 `R > S` 自动成立，因为：

```text
6 > −1
6 > 1
```

所以 `R > S` 在剩余条件下没有继续减少候选，是一条**冗余条件**。

## 3. 使用 `T < U`

如果 U = −4，那么 T 为 −3 或3，都不满足：

```text
T < −4
```

因此：

```text
U = 4
```

而 T 仍可为 −3 或3。

因为 Q、T 必须分别占据 −3 和3，所以：

```text
(Q,T) = (−3,3)
```

或：

```text
(Q,T) = (3,−3)
```

## 4. 使用 `V > 0`

因为 `|V| = 2`：

```text
V = 2
```

## 5. 剩余自由选择

S 仍可：

```text
S = −1 或1
```

所以只剩两个彼此独立的二选一：

```text
A：Q/T 的方向分配
B：S 的方向
```

## 6. 全部4种合法配置

```text
1. (P,Q,R,S,T,U,V) = (−6,−3,6,−1, 3,4,2)
2. (P,Q,R,S,T,U,V) = (−6,−3,6, 1, 3,4,2)
3. (P,Q,R,S,T,U,V) = (−6, 3,6,−1,−3,4,2)
4. (P,Q,R,S,T,U,V) = (−6, 3,6, 1,−3,4,2)
```

## 7. 为什么不重不漏

所有可能性已经被压缩为：

```text
Q/T方向：2种
S方向：2种
```

其他5个坐标均已由条件强迫确定。

所以总状态恰好是：

```text
2 × 2 = 4种
```

选择表中的每一格对应一种不同配置，因此不重；每个仍未确定的自由选择都已覆盖，因此不漏。

## 8. 最少需要几次“左/右”询问

需要2次。

一种方案：

1. 问 Q 在0左边还是右边；
2. 问 S 在0左边还是右边。

知道 Q 的方向后，T 自动确定；知道 S 的方向后，所有点均确定。

### 为什么1次不够

当前有4种合法状态。

一次只能回答“左/右”，最多把4种状态分成两组，回答后至少还会剩2种不能区分。

所以：

```text
1问不够
2问足够
```

因此最少是2问。

## 9. 删除 `V > 0`

原来 V 被固定为2。

删除后：

```text
V = −2 或2
```

它成为第三个独立二选一。

所以合法状态从：

```text
2 × 2 = 4
```

变为：

```text
2 × 2 × 2 = 8
```

# 四｜Builder 分流答案要点

## Builder A｜逆向模型

核心必须形成：

```text
正距离 d
→ 左边一个位置
→ 右边一个位置
```

若同一正距离对应两个不同标签，则两个标签必须分别占据左右两个位置。

## Builder B｜条件筛选

建议做“候选数变化表”。

T0 中：

```text
初始：32种方向分配的表面组合
重复绝对值 + 互异：压缩成少数绝对值组选择
P < Q：固定 P/R 的方向
T < U：固定 U 的方向
V > 0：固定 V
```

重点不是机械数32，而是说清每条条件具体消除了哪一个自由选择。

## Builder C｜完整枚举

只保留独立选择：

```text
Q/T方向
S方向
```

画成：

| Q/T | S = −1 | S = 1 |
|---|---|---|
| Q = −3，T = 3 | 状态1 | 状态2 |
| Q = 3，T = −3 | 状态3 | 状态4 |

## Builder D｜最少信息

4个状态至少需要两次二选一询问。

两问方案不唯一，例如：

```text
问Q方向 + 问S方向
```

或：

```text
问T方向 + 问S方向
```

## Builder E｜一般化

对互不相同非零数：

- 同一个正绝对值若出现一次：还剩“左/右”一个二选一；
- 若出现两次：两个标签必须是一左一右，但还剩“谁左谁右”一个二选一；
- 因为数轴只有左右两个固定距离位置，同一正绝对值不可能对应三个不同原数。

因此每一个**不同的正绝对值组**，在没有额外顺序信息时，都贡献一个独立方向选择。

# 五｜Final Challenge

## 题目回顾

```text
|A| = 8
|B| = 3
|C| = 1
|D| = 8
|E| = 5
|F| = 3
|G| = 1
|H| = 2
```

8个原数互不相同，并且：

```text
A < B
D > E
F < G
```

---

## Hint 1｜先锁定重复绝对值组

因为原数互不相同：

```text
{A,D} = {−8,8}
{B,F} = {−3,3}
{C,G} = {−1,1}
```

不要先处理 E、H。

---

## Hint 2｜哪些比较条件真正强迫方向

如果 A = 8，能否满足 `A < B`？

如果 F = 3，能否满足 `F < G`？

处理后再看 `D > E` 是否还提供新信息。

---

## Hint 3｜把剩余不确定性写成3个开关

处理比较条件后，剩余：

```text
开关1：C/G谁是 −1
开关2：E是 −5 还是5
开关3：H是 −2 还是2
```

不要逐个乱列8种；用三个二选一说明完整性。

---

# 六｜Final Challenge 完整解答

## 1. 确定 A、D

因为：

```text
{A,D} = {−8,8}
```

而 B 只能是 −3 或3。

条件：

```text
A < B
```

若 A = 8，不可能小于 −3 或3。

因此：

```text
A = −8
D = 8
```

## 2. 检查 `D > E`

E 为 −5 或5。

D 已经是8，所以无论 E 取哪一个：

```text
8 > E
```

因此在已有 `A < B` 的前提下：

> `D > E` 是冗余条件，没有继续减少合法配置。

反过来，如果保留 `D > E` 而删除 `A < B`：

若 D = −8，不可能大于 −5 或5，所以仍会推出：

```text
D = 8
A = −8
```

因此 `A < B` 与 `D > E` 在确定 A/D 方向这件事上是两条互相可替代的信息。

## 3. 确定 B、F

```text
{B,F} = {−3,3}
{C,G} = {−1,1}
```

条件：

```text
F < G
```

如果 F = 3，那么 G 只能为 −1 或1，都不满足 3 < G。

所以：

```text
F = −3
B = 3
```

## 4. 剩余三个独立选择

### C/G

```text
(C,G) = (−1,1)
```

或：

```text
(C,G) = (1,−1)
```

### E

```text
E = −5 或5
```

### H

```text
H = −2 或2
```

所以有：

```text
2 × 2 × 2 = 8种
```

合法配置。

## 5. 为什么恰好8种

其他标签 A、B、D、F 已固定。

剩余只有三个彼此独立的二选一开关。

每个开关两种，所有组合都不会产生坐标重复，也不会违反已知比较条件。

所以8种全部合法且互不相同。

## 6. 删除条件的影响

### 删除 `A < B`

仍保留 `D > E`。

`D > E` 仍强迫：

```text
D = 8，A = −8
```

因此合法配置仍为8种。

### 删除 `D > E`

仍保留 `A < B`，同样仍能确定 A、D。

合法配置仍为8种。

### 删除 `F < G`

B/F 的方向重新成为一个独立二选一。

所以从3个开关增加为4个开关：

```text
2 × 2 × 2 × 2 = 16种
```

因此 `F < G` 是真正减少状态数的必要信息，而前两条关于 A/D 的比较条件存在冗余。

## 7. 最少还需要几次左/右询问

当前有3个独立二选一：

```text
C/G方向
E方向
H方向
```

所以3问足够，例如：

1. 问 C 在0哪边；
2. 问 E 在0哪边；
3. 问 H 在0哪边。

### 为什么2问不够

当前共有8种合法状态。

两次“左/右”询问最多产生：

```text
2 × 2 = 4种回答组合
```

不足以区分8种状态。

因此：

```text
3问足够
2问不够
```

最少为3问。

## 8. 一般化

有 n 个互不相同的非零数，已知每个标签的绝对值。

设这些绝对值中共有 k 个不同的正距离。

由于原数互不相同，同一个正距离：

- 若只出现一次，未知的是这个标签在左还是右；
- 若出现两次，两个标签必占据左右两个位置，未知的是谁左谁右；
- 不可能出现三次，因为固定正距离在数轴上只有两个位置。

因此在没有额外顺序信息时，每个不同正距离组都留下一个独立二选一。

所以最坏情况下：

> **至少需要 k 个左/右询问。**

而逐组问一个标签方向就能完成恢复，所以 k 个也足够。

因此最少询问数就是：

```text
k
```

# 八｜T2 陌生迁移建议

7天后，不出现“绝对值”字样。

例如：

> 一组传感器的真实偏差可能向上或向下，系统只保存偏差幅度。已知部分传感器大小关系，恢复全部可能真实偏差，并判断最少还需要询问多少个方向。

如果学生能主动把“幅度”翻译成“到0距离”，并建立独立二选一结构，则说明迁移稳定。
