# 一、Ceiling Diagnostic｜T0

## 题目回顾

4个互不相同的整数位置 P、Q、R、S 都在 −5 到5之间。

距离记录器只保存到0的距离：

```text
P → 4
Q → 0
R → 2
S → 4
```

---

## Hint 1｜方向

距离只告诉你“离0多远”，没有告诉你“在0哪一边”。

先分别写出：

```text
距离4可能对应哪些位置？
距离2可能对应哪些位置？
距离0可能对应哪些位置？
```

不要急着选唯一答案。

---

## Hint 2｜关键条件

P 与 S 的距离都为4，但题目还说4个原位置互不相同。

问：

> P 和 S 能不能同时都是4？能不能同时都是 −4？

这条条件会把哪些情况排除？

---

## Hint 3｜建模

先得到：

```text
Q = 0
P、S 必须分别占据 −4 和4
R 可以是 −2 或2
```

然后把“P/S的左右交换”和“R的左右选择”组合起来。

---

# 二、T0 完整解答

## 1. 哪一个坐标可以立刻唯一确定

Q 的记录是0。

只有原点到原点的距离为0，所以：

```text
Q = 0
```

这是唯一确定的。

## 2. 每个点的候选位置

距离4对应：

```text
−4，4
```

所以 P、S 都只能从这两个位置中选择。

距离2对应：

```text
−2，2
```

所以 R 有两个候选。

## 3. 使用“互不相同”

P 与 S 都离0为4，而且不能取同一个位置，因此：

```text
(P,S) = (−4,4)
```

或：

```text
(P,S) = (4,−4)
```

R 独立地可以为 −2 或2。

因此全部4种可能是：

```text
(P,Q,R,S) = (−4,0,−2,4)
(P,Q,R,S) = (−4,0, 2,4)
(P,Q,R,S) = ( 4,0,−2,−4)
(P,Q,R,S) = ( 4,0, 2,−4)
```

## 4. 为什么不能唯一恢复

记录器保存了距离，却删除了左右方向。

所以相同输出可能来自原点两侧不同输入。

仅凭：

```text
4，0，2，4
```

无法知道：

- P 在左还是右；
- R 在左还是右。

## 5. 最少需要哪些额外左右信息

一种最简单方案：

1. 询问 P 在0左边还是右边；
2. 询问 R 在0左边还是右边。

知道 P 的方向后，因为 P、S 不同且都离0为4，S 的方向自动确定。

知道 R 的方向后，R 也唯一确定。

为什么一条还不够？

因为有两个彼此独立的方向选择：

```text
P/S 谁在左边
R 在左还是右
```

只知道其中一个，另一个仍有两种可能。

## 6. 信息抽象

绝对值/距离记录器：

```text
保留：离0多远，也就是幅度
丢失：在0哪一侧，也就是方向/符号
```

这就是本题最重要的结构。

# 四、Ceiling Builder 参考结论

## Builder 1｜正向与逆向

### 正向

```text
位置 −6 → 距离6
位置 2 → 距离2
位置 0 → 距离0
位置 −3/2 → 距离3/2
```

### 逆向

```text
距离6 → −6 或6
距离2 → −2 或2
距离0 → 0
距离3/2 → −3/2 或3/2
```

关键总结：

> 正向求绝对值通常是唯一的；逆向由绝对值恢复原数通常不唯一。

---

## Builder 2｜删除“互不相同”

删除后：

- P 可为 −4 或4；
- S 也可独立为 −4 或4；
- R 可为 −2 或2；
- Q 仍只能为0。

P、S 有4种组合，R有2种选择，所以共有：

```text
4 × 2 = 8种
```

这里的“互不相同”把 P、S 同点的两类组合排除，最终从8种降为4种。

训练重点不是乘法计数，而是：

> **看清一条条件具体排除了什么。**

---

## Builder 3｜反例

断言：

> 两个数绝对值相等，所以这两个数一定相等。

错误。

最简单反例：

```text
−1 和1
```

分数反例：

```text
−3/5 和3/5
```

如果再加条件“两个数不同”，那么它们位于原点两侧且到0距离相同，因此互为相反数。

---

## Builder 4｜一般规律

- 一个正的距离对应数轴上左右两个位置；
- 距离0只对应原点一个位置；
- 两个不同的数若绝对值相同，它们互为相反数。

本讲先用语言和数轴建立这个规律；Lesson 6 再把它与含字母表达和分类讨论连接。

---

## Builder 5｜设计信息丢失机器

示例输入：

```text
−4，4，−2，1，0
```

输出：

```text
4，4，2，1，0
```

其中：

- 输出4无法判断原输入是 −4 还是4；
- 输出0可唯一恢复为0；
- 如果只保留输出而不保留顺序/符号，原输入不能完整恢复。

学生自己的设计只要满足题目三条要求即可，不要求与示例相同。

# 五、Mastery Challenge

## Hint 1｜重复绝对值意味着什么

5个原位置互不相同。

绝对值4出现两次。

数轴上离0为4只有两个位置，所以这两个位置必须全部出现。

对绝对值2做同样思考。

---

## Hint 2｜先恢复4个确定位置

由重复值先得到：

```text
−4，4
−2，2
```

还剩一个绝对值1，对应：

```text
−1 或1
```

把两种可能分别按从左到右排序。

---

## Hint 3｜使用 C 的方向

如果最后一个位置取 −1，排序后中间点 C 在0左侧。

如果取1，排序后中间点 C 在0右侧。

用题目给出的“C在原点右侧”筛选。

---

# 六、Mastery Challenge 完整解答

绝对值集合为：

```text
1，2，2，4，4
```

5个原位置互不相同。

## 1. 绝对值4

离0为4只有：

```text
−4，4
```

因为绝对值4出现两次，而且原位置不同，所以这两个位置都必须出现。

## 2. 绝对值2

同理，必须出现：

```text
−2，2
```

## 3. 绝对值1

只出现一次，因此可能是：

```text
−1
```

也可能是：

```text
1
```

## 4. 分两种情况排序

### 情况一：取 −1

从左到右：

```text
−4，−2，−1，2，4
```

于是 C = −1，在原点左侧，不符合题意。

### 情况二：取1

从左到右：

```text
−4，−2，1，2，4
```

于是 C = 1，在原点右侧，符合题意。

所以唯一答案：

```text
A = −4
B = −2
C = 1
D = 2
E = 4
```

## 5. 删除“C在原点右侧”

两种情况都合法：

```text
−4，−2，−1，2，4
```

或：

```text
−4，−2，1，2，4
```

所以答案不再唯一。

## 6. 信息角色

- “绝对值集合”告诉我们离0的距离；
- “互不相同 + 重复绝对值”迫使某些相反位置同时出现；
- “从左到右”恢复排序；
- “C在原点右侧”最终恢复绝对值1的方向。

## 7. 推广

如果一组互不相同的数中，同一个正绝对值出现两次，那么这两个数只能位于原点两侧同样远的位置，所以它们互为相反数。

注意“正绝对值”这一条件：绝对值0只有一个原数0，不可能由两个不同数产生。

# 七、Mastery 方法提炼

本题不是“看到绝对值就改符号”，而是：

```text
重复距离
→ 恢复左右对称位置
→ 用顺序排列
→ 用额外方向条件筛选
→ 检查唯一性
```

这套思路以后会迁移到：

- 绝对值含字母分类；
- 数轴距离问题；
- 条件不足与反例；
- 信息恢复问题。

# 九、T2 参考答案｜折叠数轴

折叠相当于把原点左右同样远的位置压到同一距离上。

## 1. 距离5的“双点”

因为明确知道有两个原点重合，所以原位置为：

```text
−5 和5
```

## 2. 距离1和3

各只有一个原点，所以：

```text
距离1：−1 或1
距离3：−3 或3
```

## 3. 是否唯一

不唯一。

两个单点各自仍缺少方向信息。

## 4. 最少还需要什么

需要分别知道：

- 距离1的原点在0哪一侧；
- 距离3的原点在0哪一侧。

知道这两条方向信息后即可完全恢复。

## 5. 与绝对值的关系

折叠模型直观展示：

```text
绝对值保留到0的距离
绝对值丢失左右方向
```

如果 T2 能在没有“绝对值”提示时主动认出这一结构，说明迁移比单纯记住定义更稳定。
