# 一｜T0：重复绝对值组

已知：

```text
0 < |A| = |B| < |C| < |D| = |E|
```

五个数两两不同。

## Hint 1

固定一个正距离 r，数轴上只有 `−r` 与 `r` 两个位置。两个不同数绝对值都为 r 时，会发生什么？

## Hint 2

先不要管 A/B。先看最大绝对值的 D/E：它们能不能都在排序中间？

## Hint 3

把小绝对值的一负一正记为 `L−, L+`，大绝对值的一负一正记为 `H−, H+`。只讨论 C<0 与 C>0 两种。

## 完整解答

因为 A、B 不同且绝对值相同：

```text
{A,B} = {−r1,r1}
```

所以 A、B 互为相反数。同理 D、E 互为相反数。

设：

```text
0 < r1 < r2 < r3
```

其中 A/B 的绝对值为 r1，C 的绝对值为 r2，D/E 的绝对值为 r3。

记：

```text
L− = −r1，L+ = r1
H− = −r3，H+ = r3
```

最大绝对值对必为：

```text
H− = 全局最小
H+ = 全局最大
```

若 C<0，即 C=−r2，则：

```text
H− < C < L− < L+ < H+
```

若 C>0，即 C=r2，则：

```text
H− < L− < L+ < C < H+
```

这就是全部结构模板。

标签层面：

- A/B 谁是 L−：2种；
- D/E 谁是 H−：2种；
- C 正/负：2种。

所以共有：

```text
2 × 2 × 2 = 8
```

种不同标签排序。

为什么不重不漏：三个选择彼此独立；每一种选择都给出一个合法且不同的标签排序；反过来任何合法排序都必须确定这三个选择。

### 符号是否全部可恢复？

可以。

- D/E 中排最左者必负、最右者必正；
- A/B 中靠左者必负、靠右者必正；
- C 若位于 H− 与 L− 之间则负；若位于 L+ 与 H+ 之间则正。

所以五个符号全部由标签排名恢复。

这与三个单点组 `0<|a|<|b|<|c|` 不同：最小绝对值单点 a 最后只剩中心唯一位置，无论 a 正负，标签顺序不变，所以 a 的符号不可见。

# 二｜Builder 核心

## 最大组外放

按绝对值从大到小处理：

- 单点组：若负，放当前最左；若正，放当前最右；
- 相反数对：负标签放当前最左，正标签放当前最右。

处理完一组后，剩余标签的相对问题完全缩小成同类问题。

## 最小组特殊

所有更大组都放完后：

- 最小单点组只剩一个中心位置，正/负不改变标签排名；
- 最小相反数对还剩两个中心位置，谁负谁正在标签排名中可见。

# 三｜Final 一般定理

设不同绝对值组：

```text
r1 < r2 < ... < rk
```

每组1个或2个标签。

## 1. 生成所有排序

从 rk 开始向 r1 处理。

对于任意 i>1：

- 若 ri 是单点组，该标签只能放当前最左或最右，共2种；
- 若 ri 是相反数对，两标签必须占当前两端，谁左谁右共2种。

每处理一组，就删除当前外层，继续内部。

## 2. 为什么完整

任意合法数轴排序中，绝对值最大的未处理组一定占当前最外层：

- 单点为正就比所有剩余数大，为负就比所有剩余数小；
- 相反数对的一负一正分别比所有剩余数更左、更右。

所以任何合法排序都必须遵守该递归，绝无第三种放法。

## 3. 为什么不重复

两个不同的左右选择序列，第一次不同选择发生时，就会把某个标签放到不同的一端，因此最终标签排序不同。

## 4. 计数

### 最小组是单点

对于 r2 到 rk，共 k−1 个组，每组贡献一个可见二选一：

```text
2^(k−1)
```

最后 r1 单点只剩一个位置，它正负不同却不改变标签排名，因此不再乘2。

### 最小组是相反数对

r2 到 rk 贡献 `2^(k−1)`；最后 r1 的两个标签谁负谁正仍有2种可见排序，因此：

```text
2^k
```

## 5. 哪些符号可恢复

- 所有非最小组：可恢复；
- 最小组若为相反数对：也可恢复；
- 唯一不可由标签排名恢复的情况：**最小绝对值组是单点**，该标签的正负不可见。

# 四｜自造例验证

例如四组绝对值：

```text
1：单点 A
3：相反数对 B,C
5：单点 D
8：相反数对 E,F
```

最小组为单点，k=4，因此合法标签排序：

```text
2^(4−1)=8种
```

A 的符号无法从排名恢复；B/C、D、E/F 的符号均可由各自在排序中的外层位置恢复。

# 五｜方法提炼

```text
绝对值大小
→ 决定离0层级
→ 最大层只能占当前外端
→ 递归剥离
→ 统计“真正会改变标签排名”的二选一
→ 识别最中心不可见信息
```

这比把所有符号组合逐一试完更短，也更容易推广。
