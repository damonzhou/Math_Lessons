# A. Core｜基本比较

## 1｜TEXTBOOK-MODEL

比较：

```text
−8 与3
0 与 −5/9
−6 与 −2
0.7 与7/10
```

## 2｜TEXTBOOK-MODEL

按从小到大排列：

```text
−2，4，−5，0，1，−1
```

## 3｜混合表示

比较：

```text
−0.72 与 −7/10
−5/6 与 −0.82
```

要求说明怎样统一表示。

## 4｜概念解释

为什么：

```text
0.0001 > −100000
```

不能用“因为正数当然大”一句带过，要写数轴理由。


# B. 思维深度｜条件、反例与边界

## 6｜D3 反例

判断：

> “两个数中，绝对值大的那个数更大。”

如果错误：

1. 给两个负数反例；
2. 给一个一正一负的反例；
3. 说明加什么条件后这句话可以成立。

## 7｜D2 条件充分性

已知：

```text
|a| < |b|
```

分别在下面条件下比较 a、b：

1. a、b 都是正数；
2. a、b 都是负数；
3. a < 0 < b；
4. 不知道符号。

哪些可以唯一比较？哪些不能？不能的必须给反例。

## 8｜D4 完整排序

按从小到大排列：

```text
−0.49，1/2，−0.51，0，0.48，−1/2
```

最后写一句：为什么你的排序没有漏项或重复？

## 9｜边界0

已知：

```text
|x| = |y|
```

并且 x ≥ 0、y ≤ 0。

能否唯一确定 x、y 谁大？

分别讨论：

- 绝对值为正数；
- 绝对值为0。

# C. 镜像与一般化

## 10｜D1/D5

已知：

```text
0 < p < q
```

把下面5个数从小到大排列：

```text
p，q，−p，−q，0
```

要求解释为什么 −q < −p。

## 11｜删条件

把第10题条件改成只知道：

```text
p < q
```

原来的固定排序还能保证吗？构造两个不同符号情形说明。

## 12｜逆向构造

构造三个负有理数：

```text
x < y < z < 0
```

并使它们的绝对值满足：

```text
|x| > |y| > |z|
```

至少一个数必须是分数。

然后说明为什么这一定是负数区间的一般规律。

# F. 综合挑战

## 17｜SYNTHESIS · 排序与唯一性

> **无单一原题。**  
> 结构依据：[CEMC 2018 G7 Q6｜区间/顺序](https://cemc.uwaterloo.ca/sites/default/files/documents/2024/2018Gauss7Contest.html) 与 [CEMC 2026 G7 Q3｜距离与数值辨析](https://cemc.uwaterloo.ca/sites/default/files/documents/2026/2026Gauss7Contest.html)。

5个互不相同的有理数，其绝对值为：

```text
2，3，3，7，7
```

且恰好有3个负数。

1. 恢复这5个数；
2. 从小到大排列；
3. 证明答案唯一；
4. 如果改成“恰好2个负数”，重新求解；
5. 比较两种条件下中间那个数的符号。

## 18｜D4 穷尽性

有4个互不相同的非零有理数，两两组成两对相反数。

已知其中一个正数比另一个正数小。

1. 用 a、b 表示这两个正数并写出条件；
2. 写出全部4个数的一般排序；
3. 为什么只有这一种排序结构？
