# B｜结构比较

## 4
若 `0<|a|<|b|`：

1. b>0 时证明 a<b；
2. b<0 时证明 b<a；
3. 用一句话总结谁控制相对顺序。

## 5
若 `0<|a|<|b|<|c|<|d|`，证明 d 必在四个数排序的一端；删除 d 后说明剩余三个数仍有同类结构。

## 6
若实际排序为：

```text
d < b < a < c
```

判断 d、c 的符号；再分析 a、b 哪些符号能确定、哪些不能。

# C｜重复绝对值组

## 7
A、B、C 三个不同非零有理数满足：

```text
|A|=|B|<|C|
```

1. A、B 是什么关系？
2. 全部可能的标签排序有多少种？
3. 从最终标签排序能否恢复 A、B、C 的全部符号？

## 8
四个不同非零数满足：

```text
|A|<|B|=|C|<|D|
```

不要枚举16种符号，使用“从最大绝对值向内放置”的方法研究所有可能排序结构。

## 9｜为什么最小组特殊
比较两种结构：

```text
结构甲：0<|A|<|B|<|C|
结构乙：0<|A|=|B|<|C|
```

说明为什么甲中 A 的符号可能无法由标签排名恢复，而乙中 A/B 的符号可以由排名恢复。

# D｜Elite Transfer

## 10｜四个绝对值组
有7个不同非零有理数：

```text
|A| = 1
|B| = |C| = 3
|D| = 5
|E| = |F| = 8
|G| = 13
```

1. 有几个不同绝对值组？
2. 最小组是单点还是相反数对？
3. 不列全部排序，求合法标签排序总数并证明。
4. 哪些标签的符号能从最终排名恢复？哪个标签可能不能？

## 11｜把最小组改成相反数对
在第10题基础上再加入 H，满足：

```text
|H|=|A|=1
```

且8个数两两不同。

重新回答排序总数和符号可恢复性，并解释为什么只增加一个标签，排序数量却多出一个二选一因子。

## 12｜逆向判断
某组数据的不同绝对值共有5组。已知最终合法标签排序数是16。

1. 最小绝对值组可能是哪一种类型？
2. 若排序数是32，又说明什么？
3. 你的结论依赖什么前提？

## 13｜自造问题
自己设计一个包含：

```text
至少2个单点组
至少2个相反数对
```

的绝对值结构。先预测合法标签排序数，再任选一种排序构造具体有理数验证。
