# B｜School Advanced｜谁控制顺序

## 5｜关键结构
已知：

```text
0 < |p| < |q|
```

证明：

1. q > 0 时一定有 p < q；
2. q < 0 时一定有 q < p；
3. p 的符号为什么不影响 p、q 的标签顺序？

## 6｜逆向反推
仍有：

```text
0 < |p| < |q|
```

若知道：

```text
p < q
```

q 的符号能否唯一确定？p 呢？证明你的结论。

## 7｜三变量排名密码
已知：

```text
0 < |p| < |q| < |r|
```

实际排名为：

```text
r < p < q
```

1. 判断 q、r 的符号；
2. p 的符号能否确定？
3. 构造两组只改变 p 符号、排名仍相同的数据；
4. 说明为什么你的两个例子不是巧合。

## 8｜不可能排序
在：

```text
0 < |p| < |q| < |r|
```

下，能否出现：

```text
p < r < q
```

不得枚举符号，必须用一个全局结构证明。

# C｜High Ceiling｜四变量与信息恢复

## 9｜从排名恢复符号
已知：

```text
0 < |p| < |q| < |r| < |s|
```

而实际从小到大为：

```text
s < q < p < r
```

回答：

1. s、r、q 分别是什么符号？
2. p 为什么仍有两种符号可能？
3. 各构造一组 p > 0 与 p < 0 的具体数据验证。

## 10｜快速判定“不可能”
仍满足：

```text
0 < |p| < |q| < |r| < |s|
```

某人声称实际排序可能是：

```text
q < p < s < r
```

只用1～3句话给出严格否定理由。

## 11｜不用16格符号表
在四变量条件下：

1. 说明如何从 |s| 最大开始“从外到内”生成所有可能标签顺序；
2. 一共有多少种不同标签顺序？
3. 为什么 p 的正负不会让数量再翻倍？
4. 说明你的方法为什么不会漏掉任何一种。

## 12｜最少信息
只知道：

```text
0 < |p| < |q| < |r| < |s|
```

以及四个标签的最终排名。

1. 哪些变量的符号一定可由排名恢复？
2. 哪个符号不能恢复？
3. 如果只允许再问一次“某变量是否大于0”，应该问谁？
4. 证明0次不够、1次足够。

## 13｜五变量推广
再加入 t：

```text
0 < |p| < |q| < |r| < |s| < |t|
```

不列32种符号组合：

1. 描述生成全部排名的递归方法；
2. 不同标签排名共有多少种？
3. 哪些变量的符号可从排名恢复？
4. 哪个变量仍保持“符号不可见”？

# E｜T2 陌生迁移

## 16｜带方向误差排名

四个传感器 A、B、C、D 的误差都非0，只知道：

```text
0 < |A| < |B| < |C| < |D|
```

系统不再保存具体误差，只保存四个标签从“小误差值”到“大误差值”的真实数值排名。

某次排名为：

```text
D < B < A < C
```

1. 判断 B、C、D 是正误差还是负误差；
2. A 的方向为什么无法由排名确定？
3. 最少再保存几位“正/负方向信息”才能恢复全部方向？
4. 证明你的信息量是最少的。
5. 若增加第五个传感器 E，且 |E| 最大，说明为什么 E 的方向只决定它加入排名的哪一端。
