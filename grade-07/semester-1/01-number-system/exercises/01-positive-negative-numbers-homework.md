# B. Ceiling Builder 迁移

## 5｜DESIGNED · BUILDER · H1/H7

现实事实：“实际用电量比计划多12度”。

分别设计两种合理的正负编码规则，使同一个现实事实在一种规则下记为 +12，在另一种规则下记为 −12。

回答：真实事实变了吗？变的是什么？

## 6｜DESIGNED · BUILDER · COUNTEREXAMPLE

有4个数，它们相对20的偏差总和为0。

同学甲说：“所以这4个数一定都是20。”

1. 判断对错；
2. 若错误，构造两组不同的反例；
3. 说明“总体平衡”和“每个个体都等于基准”为什么不是一回事。

## 7｜DESIGNED · BUILDER · REVERSE

自己设计5个数，使它们相对100的偏差总和为 +10，并满足：

- 至少一个数小于100；
- 至少一个数大于100；
- 5个数不能全部相同。

再设计第二组不同答案。

# C. Advanced / Olympiad / Informatics

## 8｜SYNTHESIS · MASTERY TRANSFER

同一批数据以40为基准时，总偏差为 +35；改以45为基准时，总偏差为 −15。

1. 一共有多少个数据？
2. 不恢复任何一个具体数据，解释突破口。
3. 如果只知道第一条信息，能否确定所有具体数据？用反例说明。

## 9｜ADAPTED · AMC 8 STRUCTURE

某简化模型为：

$$
W=T-0.7v
$$

当 T = 4、v = 20 时，求 W，并解释所得负数表示“状态”还是“变化量”。

## 10｜INFORMATICS · H7

程序中：

```cpp
int baseline = 80;
int current = 74;
int delta = current - baseline;
```

1. `delta` 是多少？
2. `current = -6` 和 `delta = -6` 即使数值相同，数学语义是否一定相同？解释。
