# A. Core｜含字母绝对值

## 1

已知 a > 0，化简：

```text
|a|
|−a|
−|a|
```

## 2

已知 a < 0，化简同样三个表达式。

## 3

已知 a = 0，求：

```text
|a|
−a
|−a|
−|a|
```

## 4

只知道 a 是有理数，下面哪些一定成立？

A. `|a| = a`  
B. `|−a| = |a|`  
C. `||a|| = |a|`  
D. `|a| = −a`

要求逐项说明理由。


## 8

# C. 同绝对值与反例

## 9

构造两个例子说明：

```text
|a| = |b|
```

既可能有 a = b，也可能有 a ≠ b。

## 10

```text
|a| = |b|
且 a ≠ b
```

说明 a、b 的关系，并用数轴语言解释。

## 11｜诊断 H10

指出他的推理漏掉了什么可能，并写一个最小反例。

# E. 条件充分性与反例

## 16｜Ceiling Builder

已知 a < 0 时：

```text
|a| = −a
```

把条件依次改成：

1. a ≤ 0；
2. a ≠ 0；
3. a 是整数。

哪些仍能保证结论？不能保证的请给反例。

## 17｜Ceiling Builder

要保证：

```text
|a| = a
```

下面哪些条件足够？

A. a > 0  
B. a ≥ 0  
C. a ≠ 0  
D. a = 0  
E. a 是正整数

说明每一个判断。

## 18｜逆向构造
