# A. Core｜含字母绝对值

## 1

已知 a > 0，化简：

```text
|a|
|−a|
−|a|
```

## 2

已知 a < 0，化简同样三个表达式。

## 3

已知 a = 0，求：

```text
|a|
−a
|−a|
−|a|
```

## 4

只知道 a 是有理数，下面哪些一定成立？

A. `|a| = a`  
B. `|−a| = |a|`  
C. `||a|| = |a|`  
D. `|a| = −a`

要求逐项说明理由。

# B. 边界与逆向

## 6｜诊断 H5

> 如果 `|a| = −a`，那么 a < 0。

```text
|a| = −a
```

并说明为什么你的条件已经覆盖全部有理数情况。

## 8

# C. 同绝对值与反例

## 9

构造两个例子说明：

```text
|a| = |b|
```

既可能有 a = b，也可能有 a ≠ b。

## 10

已知：

```text
|a| = |b|
且 a ≠ b
```

说明 a、b 的关系，并用数轴语言解释为什么没有第三种可能。

## 11｜诊断 H10

某同学由 `|a| = |b|` 直接写 a = b。

指出他的推理漏掉了什么可能，并写一个最小反例。

# D. 距离的逆向

## 12

求全部可能值：

```text
|x| = 9
```

并说明为什么只有这些值。

## 13

求：

```text
|x| = 0
```

为什么只有一个解？

## 14

判断：

```text
|x| = −2
```

是否存在有理数解？说明原因。

## 15

把12～14题推广为：

```text
|x| = t
```

按 t > 0、t = 0、t < 0 分类说明可能值个数，并说明三类已经穷尽所有 t。

# E. 条件充分性与反例

## 16｜Ceiling Builder

已知 a < 0 时：

```text
|a| = −a
```

把条件依次改成：

1. a ≤ 0；
2. a ≠ 0；
3. a 是整数。

哪些仍能保证结论？不能保证的请给反例。

## 17｜Ceiling Builder

要保证：

```text
|a| = a
```

下面哪些条件足够？

A. a > 0  
B. a ≥ 0  
C. a ≠ 0  
D. a = 0  
E. a 是正整数

说明每一个判断，并区分“足够条件”和“恰好刻画全部情况的条件”。

## 18｜逆向构造

自己构造三个数 p、q、r，使：

```text
|p| = p
|q| = −q
|r| = r = −r
```

并说明每个数为什么满足条件，以及为什么第三个条件只能由 r = 0 满足。
