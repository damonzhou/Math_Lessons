# 第6讲 课后练习｜绝对值（二）｜v2.4

> A组稳定时直接进入B～D组。高阶重点不是长计算，而是分类、规则压缩、证明完整和最少性。

# A｜Gap Check

## 1
分别在 `a>0`、`a=0`、`a<0` 时化简：

```text
|a|，|−a|，−|a|
```

## 2
写出下列关系成立的全部条件：

```text
|a| = a
|a| = −a
```

## 3
研究 `|x|=t` 在 `t>0`、`t=0`、`t<0` 时的解数，并说明分类为什么完整。

## 4
反驳：

> “只要表达式前面有负号，这个数就是负数。”

至少给两个结构不同的反例。

# B｜School Advanced

## 5｜边界反推
若：

```text
|a| = a
且
|a| = −a
```

证明 a 只能为0。

## 6｜条件强弱
要保证 `|a|=a`，比较：

```text
a>0，a≥0，a≠0，a是整数，a=0
```

哪些足够？哪个恰好刻画全部情况？不足够的必须给反例。

## 7｜稳定结构
证明对所有有理数 a：

```text
|−a| = |a|
||a|| = |a|
```

要求用数轴/距离语言，不只做符号操作。

---

# C｜A/R 操作串

定义：

```text
A：取绝对值
R：取相反数
```

从左到右执行。

## 8
不代具体数字，判断下列日志最终属于 `x`、`−x`、`|x|`、`−|x|` 中哪一类：

```text
R R R
A R R R
R A R R
R R A R
A A R A R R
```

## 9｜等价日志
自己写出三条长度不同、但对每个有理数输入都等价于 `|x|` 的日志，并证明。

## 10｜历史删除
构造两条很长的日志，使它们最后一次 A 以前完全不同，但对每个输入仍得到同一规则。解释为什么这些差异已经“不再可见”。

## 11｜不可能有第五类？
用“有没有A + 最后一次A后的R奇偶”给出完整分类框架。此题先写证明提纲，不抄 Final 解答。

# D｜Elite Transfer

## 12｜黑箱最少测试
一个黑箱已知属于：

```text
I：x
R：−x
A：|x|
RA：−|x|
```

你可选择输入并观察输出。

1. 为什么任何一次测试都不可能保证区分四类？
2. 给出两次测试方案。
3. 证明两次最少。
4. 两次都选正数为什么失败？两次都选负数呢？

## 13｜测试方案设计
除了 `2` 和 `−2`，再设计三组不同的“两次测试输入”，都能区分四类。写出你认为必要的共同条件。

## 14｜反向设计
若目标规则是：

```text
I，R，A，RA
```

分别给出一个最短操作串。再说明为什么不需要更长。

## 15｜一般化文字题
一个系统有两种按钮：

- “镜像”：位置变成关于0对称的位置；
- “距离化”：只保留到0的距离。

给出任意长按钮记录。设计一个不用逐步模拟每一步、只扫描记录就能判断最终规则的方法。
