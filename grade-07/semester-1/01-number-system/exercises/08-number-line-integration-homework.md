# A. Core 巩固

## 1｜对象辨析

点 A 的坐标为 −6。

分别写出：

1. A 的坐标；
2. A 到0的距离；
3. A 与坐标2的点之间距离。

说明三个答案分别在回答什么问题。

## 2｜跨0距离

点 P = −7，Q = 3。

不用两点距离公式，求 PQ，并画出经过0的分段过程。

## 3｜同侧距离

点 M = −9，N = −4。

求 MN，并说明为什么不应把9和4相加。

## 4｜路径与直接距离

机器人从 −5 出发，先到4，再返回1。

求：

1. 最终位置；
2. 起点到终点的直接距离；
3. 实际总路程。

## 5｜中点

A = −8，M = −3，M 是 AB 的中点。

求 B。必须用“AM = MB”解释，不使用中点公式。

# B. 条件与唯一性

## 6｜DIAGNOSTIC-H3

A、B、C 三点从左到右排列。

只知道 A = −5，C = 5，B 在 A、C 之间。

B 一定是0吗？

如果不是，给3个不同合法值。

## 7｜中点条件

在第6题基础上增加：

```text
AB = BC
```

现在 B 是否唯一？为什么？

## 8｜固定距离的全部位置

点 M = 2。

点 X 到 M 的距离为5。

1. 求 X 的全部可能；
2. 为什么没有第三种？
3. 增加什么最简单的方向条件可使答案唯一？

## 9｜等距刻度

A、B、C、D、E 连续等距，B = −8，E = 1。

1. 每格代表多少？
2. 恢复全部坐标；
3. 0是否恰好是某个标点？

## 10｜删掉等距

删除第9题“连续等距”。

哪些坐标仍能确定？哪些不能？给一个与第9题答案不同但合法的模型。

# F. Mastery Challenge

## 18｜SYNTHESIS · 无单一原题

> 结构来源：[CEMC 2016 Gauss G7 Q10｜中点](https://cemc.uwaterloo.ca/sites/default/files/documents/2016/2016Gauss7Contest.html) + [CEMC 2020 Gauss G7 Q8｜等距数轴](https://cemc.uwaterloo.ca/sites/default/files/documents/2020/2020Gauss7Contest.html)。

数轴上从左到右有6个连续等距点：

```text
A，B，C，D，E，F
```

A = −11，E = 5。

另有点 X 满足：

```text
X 到 C 的距离 = B 到 E 的距离
```

回答：

1. 恢复 A～F；
2. 求 B 到 E 的距离；
3. 求 X 的全部可能位置；
4. 证明没有第三种；
5. 若再知 X > C，答案如何变化？
6. 删除“连续等距”后，哪些结论不再唯一？
