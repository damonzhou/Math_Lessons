# A组｜Gap Check｜★

## 1｜定义

不用“去掉负号”解释：什么是一个数的绝对值？

## 2｜求值

求：

```text
|−12|，|3.5|，|0|，|−7/9|，|11/4|
```

## 3｜对象辨析

点 P 的坐标是 −9。

分别写出：

- P 在0哪侧；
- P 到0距离；
- `|−9|` 表示什么。

## 4｜逆向

一个点到0距离为6.5。

1. 全部可能坐标是什么？
2. 为什么只有这些？
3. 哪一条方向信息可以使答案唯一？

## 5｜边界

为什么绝对值为0只有一个原数，而绝对值为正数通常有两个原数？

> A组如果出现2处以上概念性错误，先回主课 Gap Check；否则直接进入B组。

# B组｜Concept / School Advanced｜★★～★★★

## 6｜重复输出

4个互不相同整数 a、b、c、d 满足：

```text
|a| = 5
|b| = 2
|c| = 5
|d| = 7
```

1. a、c 必须是什么关系？
2. 在没有其他条件时，共有多少种有序四元组 `(a,b,c,d)`？
3. 不逐个乱列，用“独立选择”解释为什么已经数全。

## 7｜条件筛选

已知：

```text
|A| = 6
|B| = 4
A < B
```

1. 列出全部 `(A,B)`；
2. 为什么 A 的方向已经被确定，而 B 的方向还没有？
3. 再加 `B < 0` 后是否唯一？
4. 再加 `A > 0` 会发生什么？

## 8｜冗余条件

3个互不相同整数 P、Q、R 满足：

```text
|P| = 8
|Q| = 3
|R| = 8
P < Q
R > 0
```

1. 求 P、R；
2. `R > 0` 是否真的提供了新信息？
3. 删除它以后答案是否改变？
4. 用一句话解释什么叫“冗余条件”。

## 9｜最少方向信息

5个互不相同非零整数的标签及绝对值已经一一对应：

```text
|P| = 1
|Q| = 4
|R| = 1
|S| = 6
|T| = 4
```

没有任何其他信息。

1. 哪些标签形成相反数对？
2. 一共有多少种原坐标配置？
3. 如果只能询问某个标签“在0左边还是右边”，最少要问几次才能唯一恢复？
4. 证明少一次不够。

# D组｜Elite Transfer｜★★★★～★★★★★

## 12｜无序距离记录：丢掉的不只是方向

> **DESIGNED · Elite Transfer**

数轴上有6个互不相同的整数点，从左到右依次记为：

```text
A < B < C < D < E < F
```

记录器不仅丢掉了正负号，还把标签和距离的对应关系打乱。

现在只知道6个绝对值整理后为：

```text
1，2，2，5，5，8
```

并且：

```text
D > 0
```

回答：

1. 绝对值2和5为什么一定各形成一对相反数？
2. 列出所有可能的 `(A,B,C,D,E,F)`。
3. 为什么恰好只有这些情况？
4. 只继续询问“某个点在0左边还是右边”，能否保证最终唯一恢复全部坐标？
5. 如果不能，给出两组具有**完全相同左右符号模式**但坐标仍不同的合法配置。
6. 这说明记录器除了方向以外还丢掉了什么信息？
7. 设计一种新的最少信息类型，使剩余情况可以继续被区分。这里不要求一定是“左/右”问题。

### 这题测什么

如果学生已经习惯主课里的“问几个方向就能恢复”，这题会检查她是否会机械套用。

真正需要发现：

> **当“绝对值属于哪个标签”也丢失时，缺失信息已经不只是符号。**

# E组｜短板定向复测

根据主课 T0 首个卡点选做，不机械全做。

## 13A｜若 H3：擅自补条件

给出三个不同的例子，证明：

```text
|x| = 4
```

不能直接写“x就是4”。

然后写出什么额外条件足以唯一确定 x。

## 13B｜若 H5/H10：漏情况 / 不检查唯一性

为下面问题画完整选择表：

```text
|P| = 2
|Q| = 5
|R| = 2
```

P、Q、R互不相同。

要求列全所有有序三元组，并证明完整。

## 13C｜若条件筛选弱

已知：

```text
|A| = 7
|B| = 3
A < B
```

依次加入：

```text
B < 0
A > 0
```

分别分析答案怎样变化，并说明每条条件排除了什么。

## 13D｜若 T0 已很强

有 n 个互不相同非零数，标签与绝对值一一对应。绝对值中共有 k 个不同正距离。

不用正式组合数学术语解释：

> 为什么在没有其他顺序信息时，每个不同正距离组都留下一个独立“左右选择”？
