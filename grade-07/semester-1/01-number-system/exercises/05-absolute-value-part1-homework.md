# A组｜Core 完整掌握

## 1｜TEXTBOOK-MODEL

不用“去掉负号”解释绝对值。

请用“数轴、原点、距离”三个词说明：

> 什么是一个数的绝对值？

---

## 2｜TEXTBOOK-MODEL

求：

```text
|9|
|−14|
|0|
|−0.75|
|5/6|
|−13/5|
```

每题至少选择其中两题用数轴距离解释。

## 3｜DIAGNOSTIC-H7

判断并说明理由：

1. 绝对值表示一个数所在的位置；
2. 绝对值表示这个位置到原点的距离；
3. 距离可能是负数；
4. 0的绝对值是0。

---

## 4｜对象辨析

点 P 表示 −7。

分别回答：

1. P 的坐标是什么？
2. P 在原点哪一侧？
3. P 到原点的距离是多少？
4. `|−7|` 表示的是上面哪一种信息？

---

## 5｜逆向

一个点到原点的距离为6。

1. 这个点可能表示哪些数？
2. 为什么不能只写6？
3. 如果再告诉你这个点在原点左边，答案是什么？
4. 为什么第1问只有两个可能，而不是三个或更多？

1. 这两个数分别是什么？
2. 它们在数轴上有什么关系？
3. 它们是什么关系的两个数？
4. 为什么不会有第三个不同的有理数也满足绝对值为4.2？

3. 增加哪一条简单的左右信息，可以使答案唯一？

# C组｜Ceiling Builder / Advanced

## 10｜信息丢失

一台机器只保存输入整数的绝对值。

输入依次为4个不同整数，输出为：

```text
3，0，3，5
```

1. 哪个输入可以唯一恢复？
2. 前两个输出3对应的两个不同输入必须是什么？
3. 输出5对应的原输入有几个可能？
4. 一共有几组可能的原输入？
5. 为什么你的组合已经穷尽全部情况？

---

## 11｜删除条件

把第10题的“4个输入不同”删除。

1. 两个输出3还必须来自 −3 和3吗？
2. 原输入组合为什么会增加？
3. 用一句话说明“输入不同”这一条件的作用。

---

## 12｜Informatics

某程序执行：

```text
y = abs(x)
```

现在只知道：

```text
y = 8
```

1. x 有哪些可能？
2. 如果程序还额外保存一位信息：“x 原来在0左边还是右边”，是否能恢复x？
3. 如果 y = 0，还需要额外方向信息吗？为什么？
4. 为什么当 y > 0 时，一位“左右信息”已经足够恢复，而不需要更多信息？

---

## 13｜逆向构造

自己设计3个不同有理数，使它们经过“取绝对值”以后只得到2个不同结果。

要求：

- 至少有一对原数互为相反数；
- 至少有一个原数不是整数；
- 说明为什么输出结果少于输入结果。

# D组｜综合挑战

## 15｜DESIGNED · 条件筛选

4个互不相同的整数，其绝对值整理后为：

```text
0，3，3，5
```

并且已知这4个整数中恰好有2个负数。

1. 绝对值为3的两个数分别是什么？
2. 绝对值为5的数是5还是 −5？
3. 唯一确定这4个整数。
4. 如果把“恰好有2个负数”删除，答案还有几种？
5. 为什么第3问的条件足以唯一确定，而第4问不再唯一？

---

## 16｜反例与边界

判断下面三个断言。错误的必须给反例，正确的必须解释：

1. 两个数绝对值相等，这两个数一定相等；
2. 两个不同的数绝对值相等，这两个数互为相反数；
3. 一个数绝对值为0，这个数一定是0。

对第2、3条正确结论，还要说明为什么不存在其他可能。
