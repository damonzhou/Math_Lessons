# A组｜Gap Check｜★

## 1｜定义

不用“去掉负号”解释绝对值。

## 2｜求值

求：

```text
|−12|，|3.5|，|0|，|−7/9|，|11/4|
```

## 3｜逆向

一个点到0距离为6.5。

1. 全部可能坐标是什么？
2. 为什么只有这些？
3. 什么类型的信息能使答案唯一？

## 4｜0边界

为什么 `|x| = 0` 与 `|x| = 5` 的逆向恢复结构不同？

# B组｜Flexible Application｜★★★～★★★★

## 5｜重复绝对值不是两个自由符号

A、B、C 为三个互不相同非零整数：

```text
|A| = |B| = 4
|C| = 7
```

1. A、B 有多少种有标签分配？
2. C 有多少种方向？
3. 总配置数是多少？
4. 为什么不能按“3个标签各有正负”直接得到8种？

## 6｜相对方向能传播多远

已知：

```text
|P| = 2
|Q| = 5
|R| = 9
|S| = 11
```

并有：

```text
P、Q异侧
Q、R同侧
R、S异侧
```

1. 不给任何绝对方向时共有几组配置？
2. 若再知道 `R < 0`，能否唯一恢复？
3. 如果只知道 `P、S同侧`，这条信息是否提供了新约束？为什么？

## 7｜整体反向实验

自己构造一组满足第6题全部“绝对值 + 同侧/异侧”条件的数据。

然后把所有数同时取相反数。

回答：

1. 哪些记录改变了？
2. 哪些记录没改变？
3. 由此能否说明“相对方向信息再多也未必给出绝对方向”？

## 8｜删一条关系

五个点 A、B、C、D、E 的绝对值两两不同，并满足：

```text
A、B同侧
B、C异侧
C、D同侧
D、E异侧
```

不需要知道具体绝对值。

1. 若没有任何绝对方向信息，符号模式共有几种？
2. 删除 `B、C异侧` 后变成几种？
3. 不枚举，解释数量为什么发生这个变化。

## 9｜什么信息能真正打破镜像

对于一组已由相对方向关系完全联系起来的非零点，判断下列附加信息是否一定能打破整体镜像二义性，并说明理由：

```text
A. 再给一个点的绝对值
B. 再告诉两点同侧
C. 再告诉两点异侧
D. 告诉一个指定点在0右侧
E. 告诉“至少有一个点在0右侧”
```

注意：题目问的是“**一定**能打破”。

# D组｜Elite Transfer｜★★★★★

## 12｜记录器同时丢了“方向”和“标签对应”

> **DESIGNED · Elite Transfer**  
> 与主课 Final 不同：主课保留“标签—绝对值对应”；本题故意把这层信息也删除。

数轴上6个互不相同整数点从左到右依次记为：

```text
A < B < C < D < E < F
```

记录器只保存了无序绝对值多重集：

```text
1，2，2，5，5，8
```

并知道：

```text
D > 0
```

1. 绝对值2和5为什么一定各形成一对相反数？
2. 列出所有可能的 `(A,B,C,D,E,F)`，并证明已经列完。
3. 只继续询问每个标签“在0左边还是右边”，能否保证最终唯一恢复全部坐标？
4. 如果不能，找出两组**符号模式完全相同但坐标仍不同**的合法配置。
5. 这说明记录器除了方向之外，还丢失了什么信息？
6. 设计一种新的询问类型，使第4问中的两组能够被区分。
7. 进一步思考：为什么“询问类型”必须针对实际丢失的信息，而不能机械沿用主课的方向询问？

# E组｜High-Ceiling Proof｜★★★★★

## 13｜六个独立方向组，最少保存多少关系

有若干互不相同非零有理数，绝对值信息已经把它们压缩成 **6个彼此独立的方向组**。系统最终只允许再保存1条“某组中指定标签在左还是右”的绝对方向信息。

额外关系只能记录：

> 两个指定标签同侧还是异侧。

回答：

1. 最少需要多少条**有效**相对方向关系，才能保证最后1条绝对方向信息足以恢复全部方向？
2. 给出一套关系设计。
3. 证明再少一条一定不够。
4. 若只设计了3条相对关系，至少还会剩多少个彼此独立的方向部分？
5. 用自己的话解释这里的“有效关系”是什么意思。

不得使用“因为主课公式说是 k−1”作为证明。

# F组｜T2 延迟迁移｜约7天后

## 14｜传感器误差

5个传感器的误差都非0。系统保存了每个传感器的“误差幅度”，还保存若干条：

```text
两个传感器误差方向相同 / 相反
```

但没有保存任何一个误差究竟是“偏高”还是“偏低”。

1. 如果这些相对关系已经把5个传感器全部联系成一个整体，为什么仍不能唯一恢复全部误差方向？
2. 最少再保存几条“指定传感器偏高/偏低”的信息即可？
3. 如果相对关系实际上分成两个互不联系的部分，答案怎样变化？
4. 不使用“绝对值”“相反数”术语解释你的理由。
