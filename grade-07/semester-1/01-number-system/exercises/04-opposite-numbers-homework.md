# A. Core 巩固

## 1｜TEXTBOOK-MODEL

写出下列各数的相反数：12、−7、0、5/8、−2.75。

## 2｜TEXTBOOK-MODEL

判断哪些互为相反数，并说明理由：

1. 4 与 −4；
2. −3 与 1/3；
3. 0 与0；
4. 1.2 与 −1.2；
5. 5 与 −6。

## 3｜CONCEPT

为什么0的相反数仍是0？要求使用“原点对称”，不能只说“规定如此”。

## 4｜NUMBER LINE

点 A 表示 3/2，点 B 与 A 关于原点对称。

1. B 表示什么数？
2. A、B 到0的距离有什么关系？
3. 两点分别位于0哪一侧？

## 5｜DIAGNOSTIC-H3/H10

判断：

> “−x 一定是负数。”

要求给出：

- 一个使断言看起来成立的例子；
- 一个反例；
- 一个边界例子。

# B. Ceiling Builder 迁移

## 6｜DESIGNED · BUILDER · PARAMETER

分别讨论 a > 0、a = 0、a < 0 时 −a 的符号。

最后用一句完整的一般性结论总结，而不是只列三个例子。

## 7｜DESIGNED · BUILDER · OPERATION

逐次解释下面的操作，不要只写最后结果：

$$
-(-(-(-3)))
$$

然后回答：连续取相反数2025次与2026次，结果分别与原数是什么关系？

## 8｜DESIGNED · BUILDER · CONDITION

数轴上4个点 A、B、C、D 从左到右排列，A 与 D 互为相反数。

只知道这些条件，能否推出 B 与 C 也互为相反数？

如果不能，构造一个反例。

再增加“4点等距”条件后重新判断。

## 9｜DESIGNED · BUILDER · REVERSE

自己设计一条数轴，满足：

- 有5个等距标点；
- 原点不落在任何标点上；
- 至少一对标点互为相反数；
- 再给出一个已知坐标后，可以唯一恢复全部点。

写出你的设计和验证过程。

# C. Advanced / Competition / Informatics

## 10｜REAL CONTEXT

以标准重量为0偏差：

- 甲偏重0.8 g；
- 乙偏轻0.8 g；
- 丙偏轻0.6 g。

哪些偏差互为相反数？为什么“方向相反”还不够，还需要什么？

## 11｜SYNTHESIS · NUMBER-LINE TRANSFER

数轴上6个点 A～F 从左到右等距。B 与 E 互为相反数，C = −2。

1. 原点在哪里？
2. D 的坐标是多少？
3. 每格坐标变化是多少？
4. 恢复 A、B、E、F；
5. 删除“等距”后，哪些结论仍然成立？

## 12｜INFORMATICS

定义程序操作 `flip(x)`：返回 x 的相反数。

1. `flip(flip(7))` 是多少？
2. 连续执行偶数次和奇数次各有什么规律？
3. 哪个数执行一次 `flip` 后不变？

# D. T2 延迟迁移｜约7天后

## 13｜T2

某校准系统规定 `flip`：把“高于基准的偏差”变为同样大小的“低于基准偏差”，反之亦然。

不提示“这是相反数”，回答：

1. 偏差 +6 连续 flip 5次后是多少？
2. 连续 flip 2026次呢？
3. 哪个偏差 flip 后不变？
4. 用一般语言说明奇数次和偶数次规律。
