# R0. 为什么 Lesson 6 必须紧接绝对值（一）

Lesson 5 已经建立：

```text
绝对值 = 数轴上的点到原点0的距离
```

对具体数，我们能直接判断它在0的哪一边，因此可以直接求绝对值。

但遇到字母 a 时，新的困难出现了：

```text
|a| 到底等于 a，还是等于 −a？
```

如果不知道 a 的符号，就不能凭外形决定。

因此 Lesson 6 的核心不是“再算更多绝对值”，而是：

> **当一个结论取决于条件时，必须先判断条件，再分类处理。**

这会成为以后代数、方程、不等式、函数以及算法分支的重要思维基础。

# 第一部分：从具体数走向字母

## 3. 同一个符号，结果为什么会不同

先看三个具体例子：

```text
|5| = 5
|0| = 0
|−5| = 5
```

如果把具体数字换成 a：

```text
|a|
```

我们暂时不知道 a：

- 在原点右边；
- 就在原点；
- 还是在原点左边。

所以不能直接确定结果写成 a 还是 −a。

这说明：

> **字母不是“一个神秘数字”，而是可能代表不同取值。含字母结论必须尊重它的取值条件。**

# 第二部分：绝对值的分类规则

## 4. 三种情况从哪里来

数轴被原点0分成三类位置：

```text
左边        原点        右边
 a < 0      a = 0       a > 0
```

因此：

```text
当 a > 0 时，|a| = a
当 a = 0 时，|a| = 0
当 a < 0 时，|a| = −a
```

这不是需要死记的三句话，而是从“到0的距离”得到。

### 为什么 a < 0 时写 −a

若 a 是负数，那么 −a 是 a 的相反数，对应原点右侧与 a 等距离的正数。

例如 a = −7：

```text
−a = 7
|a| = 7
```

所以当 a < 0 时，`|a| = −a`。

注意：

> 这里的 `−a` 不是“一个负数”，而是“a 的相反数”。

---

# 第三部分：0为什么是最容易被漏掉的边界

## 5. 三分类可以怎样合并成两分类

因为0满足：

```text
|0| = 0
```

所以可以把三种情况合并成常用的两分法：

```text
当 a ≥ 0 时，|a| = a
当 a < 0 时，|a| = −a
```

也可以写成：

```text
当 a > 0 时，|a| = a
当 a ≤ 0 时，|a| = −a
```

两种写法都正确。

为什么？

因为 a = 0 时：

```text
 a  = 0
−a  = 0
```

0放在哪一边都不会改变结果。

### 边界意识

以后遇到分类问题，不要只问：

> “正还是负？”

还要问：

> **“等号落在哪里？边界值0有没有被覆盖？”**

# 第四部分：有条件时怎样化简

## 6. 已知 a > 0

因为 a 在原点右边：

```text
|a| = a
```

而 −a 在原点左边，因此：

```text
|−a| = a
```

注意第二个结论不是“删掉两个负号”，而是：

1. a > 0；
2. 所以 −a < 0；
3. `|−a|` 表示 −a 到0的距离；
4. 距离为 a。

## 7. 已知 a < 0

因为 a 在原点左边：

```text
|a| = −a
```

此时 −a 在原点右边，所以：

```text
|−a| = −a
```

这里最容易犯错的是“看到 −a 就认为它一定是负数”。

Lesson 4 已经学过：

> **−a 的符号由 a 决定。**

## 8. 只知道 a 是有理数

如果题目没有告诉 a 的符号，也没有其他条件能判断符号，那么：

```text
|a|
```

一般不能进一步写成 a 或 −a。

正确做法是：

> **保留绝对值符号，或者明确分类讨论。**

“不能化简”有时就是最正确、最完整的结论。

# 第五部分：从正向规则走向逆向判断

## 9. 什么时候 `|a| = a`

如果 a 是正数，成立；如果 a = 0，也成立。

所以：

```text
|a| = a  ⇔  a ≥ 0
```

这里 `⇔` 可以读作“当且仅当”。

如果暂时不熟悉这个符号，可以用中文理解：

> `|a| = a` 成立的全部情况，恰好是 a 为非负数。

## 10. 什么时候 `|a| = −a`

如果 a 是负数，成立；如果 a = 0，也成立。

所以：

```text
|a| = −a  ⇔  a ≤ 0
```

### 一个重要边界

当 a = 0 时：

```text
|a| = a
|a| = −a
```

两句话同时成立。

因此：

> 从 `|a| = a` 不能推出 a 一定是正数；只能推出 a 是非负数。

> 从 `|a| = −a` 不能推出 a 一定是负数；只能推出 a 是非正数。

# 第六部分：几个必须理解而不是背的结构

## 11. 相反数的绝对值为什么总相等

无论 a 在原点哪一侧，a 与 −a 关于原点对称，到原点距离相同。

因此总有：

```text
|−a| = |a|
```

这是一条**与 a 的符号无关**的稳定关系。

## 12. 再取一次绝对值会发生什么

`|a|` 本身已经是一个距离，因此一定非负。

所以：

```text
||a|| = |a|
```

换句话说：

> 绝对值处理一次以后，再处理一次不会继续改变结果。

这在程序和数学中都叫一种“稳定”现象。

## 13. 两个数绝对值相等意味着什么

如果两个数到原点的距离相同，那么在数轴上有两种可能：

1. 它们是同一个位置；
2. 它们分别在原点两侧的对称位置。

所以：

```text
如果 |a| = |b|，那么 a = b 或 a 与 b 互为相反数。
```

如果再知道 a 与 b 不相等，那么只能是第二种情况。

# 第十部分：应用与迁移

## 15. 测量偏差

设测量误差为 e。

- e > 0 表示测量值偏高；
- e < 0 表示测量值偏低；
- `|e|` 只表示误差幅度。

如果只知道 `|e| = 0.3`，不能判断偏高还是偏低。

这与 Lesson 5 的“距离会丢失方向”连接起来，但本讲进一步要求：

> 给出额外符号条件后，能够正确分类恢复 e。

## 16. 程序中的 abs

一个典型的绝对值算法可以写成：

```text
if x < 0:
    return −x
else:
    return x
```

这里真正重要的不是语法，而是：

```text
判断条件
→ 分支
→ 边界0归入某一支
→ 两个分支覆盖全部输入
```

这就是数学分类讨论与程序 `if/else` 的同一结构。

### 三个重要测试性质

对任意输入 x，应满足：

```text
abs(x) 不为负
abs(−x) = abs(x)
abs(abs(x)) = abs(x)
```

这些性质可以用来检查程序是否写错。

# 第十一部分：Advanced / Olympiad

## 17. 绝对值等于一个给定距离

从数轴看：

```text
|a| = 5
```

表示 a 对应的点到0距离为5，因此：

```text
a = 5 或 a = −5
```

这不是背“正负两个答案”，而是找出数轴上距离0为5的全部点。

### 三种边界

```text
|a| = 正数  → 通常有两个相反的位置
|a| = 0     → 只有原点一个位置
|a| = 负数  → 不可能，因为距离不能为负
```

复杂绝对值方程不在本讲 Core。

## 18. 同绝对值关系是一种“折叠”

想象把数轴沿原点折叠：

- a 与 −a 会重合；
- 0保持不动；
- 原来左右两侧的信息被压到右侧的距离上。

因此：

```text
|a| = |b|
```

只说明它们折叠后落在同一点。

原来可能：

- 就是同一点；
- 或者是关于原点对称的两点。

## 19. 竞赛桥梁｜最远离0与绝对值

CEMC 2026 Gauss Grade 7 Q3 的官方结构要求从若干正负数中判断哪个在数轴上离0最远。

本讲不复制作原题，而做一个透明改编：

```text
候选数：−12，−9，4，10，11
```

问：哪个数对应的点离0最远？

可以把问题改写成：

> 哪个候选数的绝对值最大？

这说明绝对值能够把“左右方向不同的位置”统一转换成可比较的距离。

系统的有理数大小比较仍留到 Lesson 7。

# 第十四部分：Mastery / Final Challenge｜T1

## 参数距离与互不相同

> **SYNTHESIS · Mastery Challenge**

有理数 t 与三个有理数 x、y、z 满足：

```text
|x| = t
|y| = t
x ≠ y
|z| = z
|z| = −z
```

回答：

1. t 能否为负数？为什么？
2. t = 0 时，是否存在满足条件的 x、y？
3. t > 0 时，求 x、y 的全部有序可能，并求 z。
4. 如果有三个**两两不同**的有理数都满足绝对值等于同一个正数 t，可能吗？为什么？
5. 如果把“正数 t”改成0，最多能有多少个互不相同的数满足绝对值等于 t？
6. 把结论推广：对于给定的非负数 t，满足 `|u| = t` 的不同有理数最多有几个？什么时候达到这个最大值？

### Hint 1

先把 `|u| = t` 翻译成：

> 点 u 到0的距离是 t。

### Hint 2

数轴上距离0为正数 t 的位置有几个？距离0为0的位置又有几个？

### Hint 3

利用 x ≠ y 排除“两个变量取同一个位置”，再处理 z 同时满足两条关系的边界情况。

完整解答见：[Ceiling / Mastery 解答](./solutions/06-absolute-value-part2-ceiling-v2.0.md)。

### 本题希望验证

- 是否主动按 t 的符号分类；
- 是否能处理 t = 0 边界；
- 是否理解同一正绝对值最多对应两个相反位置；
- 是否能从三个变量推广到一般结论；
- 是否减少 H5/H10 类型遗漏。

## T2｜约7天后陌生迁移

### 符号位恢复器

一个程序保存两个信息：

```text
m = |x|
s = x 是否在0左边
```

给出三组数据：

```text
A：m = 6，s = 是
B：m = 6，s = 否
C：m = 0，s = 否
```

要求：

1. 恢复 x；
2. 解释为什么 m > 0 时方向信息是必要的；
3. 解释为什么 m = 0 时方向信息是冗余的；
4. 如果程序只保存 m，不保存 s，最多会有几个不同原输入对应同一个输出？

目标：检查学生能否把“绝对值分类与边界”迁移到信息学表面，而不是记住本讲题型。

# 第十六部分：掌握度检查

## Level 1｜会认

- 知道绝对值按符号分类；
- 知道0是边界。

## Level 2｜会用

- 给出 a 的符号后能正确化简；
- 会处理 `|a| = 常数` 的简单距离问题。

## Level 3｜会解释

能够解释：

- 为什么 a < 0 时 `|a| = −a`；
- 为什么 `|−a| = |a|`；
- 为什么 `||a|| = |a|`；
- 为什么 `|a| = |b|` 不一定推出 a = b。

## Level 4｜会迁移

- 能用绝对值解决陌生的对称/距离/信息问题；
- 能把分类讨论转化为程序分支。

## Level 5｜能独立发现

- 自己找到分界点；
- 主动检查边界0；
- 能构造反例；
- 能从具体条件推广一般结论。

## Level 6｜能力上限提高

T2 中面对新表面时：

- 更少依赖提示；
- 不再漏0；
- 能主动判断信息是否充分；
- 能把数学分类转成算法分支。
