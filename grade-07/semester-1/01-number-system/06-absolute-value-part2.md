# R0｜本讲真正要学什么

Lesson 5 已经建立：

```text
绝对值 = 到0的距离
```

Lesson 6 不再把重点放在“多算几道绝对值”。真正的升级是：

```text
字母符号未知
→ 结论依赖条件
→ 找分界点
→ 分类必须完整
→ 边界0不能漏
→ 从结果反推条件
→ 多次“相反数/绝对值”操作后还能否看出结构
```

核心习惯：

> **先判断条件，再决定规则；不能从表达式外形猜符号。**

# R0.5｜教材覆盖底线与知识边界

本讲必须保证：

- `a > 0 / a = 0 / a < 0` 时会正确处理 `|a|`；
- 理解 `−a` 表示 a 的相反数，不保证是负数；
- 知道 `|a| = a` 恰好对应 `a ≥ 0`；
- 知道 `|a| = −a` 恰好对应 `a ≤ 0`；
- 理解 `|−a| = |a|` 与 `||a|| = |a|`；
- 能研究 `|x| = t` 在 t 不同情况下有几个解。

本讲最高层仍不依赖：

- 有理数加减法则；
- 系统不等式变形；
- 函数图象；
- 正式方程理论；
- 组合数学或自动机术语。

可以使用 Lesson 1～5 已正式学过的数轴、相反数、绝对值和分类思维。

# 3｜Concept Deepening｜分类为什么成立

## 3.1 三分类来自数轴，而不是口诀

```text
a > 0  → |a| = a
a = 0  → |a| = 0
a < 0  → |a| = −a
```

当 a < 0 时，`−a` 是正数，因为它是 a 关于0的镜像位置。

因此常用两分法可以写成：

```text
a ≥ 0 → |a| = a
a < 0 → |a| = −a
```

也可以：

```text
a > 0 → |a| = a
a ≤ 0 → |a| = −a
```

0 放在哪一支都可以，因为 a=0 时 `a = −a = 0`。

## 3.2 从正向规则反推条件

```text
|a| = a   恰好说明 a ≥ 0
|a| = −a  恰好说明 a ≤ 0
```

注意：

- `a > 0` 是 `|a|=a` 的充分条件，但不是全部情况；
- `a ≥ 0` 才完整刻画全部情况；
- 0 同时满足 `|a|=a` 与 `|a|=−a`。

## 3.3 两条稳定关系

对所有有理数 a：

```text
|−a| = |a|
||a|| = |a|
```

第一条来自原点对称距离不变；第二条来自第一次绝对值后结果已经非负。

## 3.4 参数 t 决定 `|x|=t` 的解数

```text
t > 0 → 两个解：−t，t
t = 0 → 一个解：0
t < 0 → 无解
```

为什么完整？因为任意有理数 t 只有正、零、负三类。

# 4｜School Advanced｜条件不是装饰

## A1｜足够条件与完整条件

要保证 `|a| = a`：

- `a > 0` 足够；
- `a = 0` 也足够；
- `a ≥ 0` 恰好覆盖全部情况；
- `a ≠ 0` 不足够。

要求每个“不足够”结论必须给反例。

## A2｜两个条件同时成立意味着什么

若：

```text
|a| = a
|a| = −a
```

由第一条得 a ≥ 0，由第二条得 a ≤ 0，因此只有：

```text
a = 0
```

这里不要求使用不等式运算法则，只用数轴位置分类。

## A3｜表达式外形会骗人

对未知 a，判断以下说法是否恒真，并解释：

```text
−a < 0
|−a| = −a
−|a| ≤ 0
```

重点：负号是“取相反数”或“放在非负距离前”，不是看到负号就能判原对象为负。

# 5｜Ceiling Diagnostic｜T0 冷启动：两台机器 A 与 R

定义两种操作：

```text
A：把当前数变成它的绝对值
R：把当前数变成它的相反数
```

操作从左到右依次执行。例如：

```text
输入 x
A R
表示先 A，再 R
```

> **DESIGNED · Ceiling Diagnostic · ★★★★**  
> 首次独立25～30分钟；不要先看 Hint。

研究下面四条操作日志：

```text
① R R A R R
② A R R
③ R A R
④ A R
```

回答：

1. 哪些日志对**每一个有理数输入 x**都会得到相同输出？不能只代一个数字。
2. 尝试不用逐步化简整串操作，找出一种“只看少量关键信息”的方法。
3. 如果一条日志中出现过 A，那么第一次 A 之前发生过多少次 R 还重要吗？为什么？
4. 真正应该关注“第一次 A”还是“最后一次 A”？解释。
5. 如果最后一次 A 后又有若干个 R，什么信息决定最终符号？
6. 没有 A 的日志又由什么决定？
7. 你能否猜出：任意长的 A/R 操作串，对所有输入而言究竟可能有多少种不同规则？先猜，不要求此时完成证明。

### 首个卡点记录

```text
P1 逐步代数计算，不能压缩历史
P2 发现 A 会抹去方向，但选错关键 A
P3 找到“最后一次A”，不会处理之后的 R
P4 能分类，但不会证明覆盖所有操作串
P5 能分类，不会证明不同类别真的不同
P6 全部完成，并能思考最少测试
```

完整 Hint / 解答见：[Ceiling v2.4](./solutions/06-absolute-value-part2-ceiling-v2.4.md)。

# 6｜Ceiling Builder｜从具体操作串到一般规则

## Builder A｜历史什么时候被抹掉

如果当前值先经历若干次 R，然后执行一次 A：

```text
x 或 −x
→ A
→ |x|
```

所以这次 A 之前的所有“方向历史”都被抹掉。

## Builder B｜为什么看“最后一次 A”

最后一次 A 执行以后，不会再出现新的 A 去抹掉信息。

因此：

```text
最后一次A之前：只需知道它存在，不需追踪全部R
最后一次A之后：只需看R出现奇数次还是偶数次
```

## Builder C｜没有 A 的情况

若整串只有 R：

```text
R 次数偶数 → x
R 次数奇数 → −x
```

## Builder D｜证明而不是观察

不能用“我试了十几个串都如此”作为完整证明。

要把所有操作串分成：

```text
无A
有A
```

再在每一类中按 R 的奇偶继续分类，证明分类覆盖所有可能。

# 8｜Elite / Final Challenge｜任意操作串究竟只有几类规则？

> **DESIGNED · Elite / Final Challenge · ★★★★★**  
> 无单一原题；结构依据见 provenance。  
> 建议先独立30～45分钟。

仍使用：

```text
A：取绝对值
R：取相反数
```

允许任意有限长度的操作串，也允许空串（什么都不做）。

完成以下任务：

1. 证明所有操作串作为“对任意有理数输入的规则”，最终只可能等价于以下四类之一：

```text
I：x
R：−x
A：|x|
RA：−|x|
```

2. 给出一个只观察操作串本身、无需代入具体 x 的分类算法。
3. 证明你的分类**完整**：任何有限操作串都一定进入四类之一。
4. 证明四类规则两两并不完全相同。不能只说“看起来不同”，必须给能区分它们的输入。
5. 系统要识别一个未知黑箱究竟是哪一类。你可以选择输入有理数并观察输出。
   - 一个测试输入能否保证区分四类？证明。
   - 设计两个测试输入，使四类一定被完全区分。
   - 证明“两次测试”是最少的。
6. 为什么一个正输入和一个负输入是自然选择？若两个测试都选正数会发生什么？
7. 一般化总结：本题中 A 为什么是一种“抹除历史信息”的操作，而 R 不是？

### Final 的两个关键突破

```text
突破1：最后一次A以前的方向历史被全部抹掉
突破2：没有A / 有A，再由最后阶段R的奇偶，恰好形成4类
```

最少测试部分还需要第三层思维：

```text
给出两次测试方案 = 证明足够
+
证明一次测试最多只能看到 ±|x| 两种输出 = 证明更少不够
```

# 9｜错误实验室

重点检查：

- 把 `−a` 默认当负数；
- 把充分条件误当必要条件；
- 分类漏掉0；
- 看到长操作串只会逐步算，不找信息被抹掉的位置；
- 用若干例子代替完整证明；
- 找到可行测试方案，却没有证明最少性。

固定结束问题：

```text
① 我的分类覆盖所有情况吗？
② 边界0是否检查？
③ 哪些历史信息其实已经被后续操作抹掉？
④ 我证明的是“足够”，还是也证明了“最少”？
```
