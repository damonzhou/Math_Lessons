# R0. 为什么第8讲必须是一节综合课

Lesson 3～7 已经分别学习：

```text
数轴：数 ↔ 位置
相反数：关于原点对称
绝对值：到原点的距离
大小比较：左右顺序
```

真实问题不会告诉你：

> “这是一道相反数题。”

它更可能同时给出：

- 两个或多个点的位置；
- 谁在谁的中间；
- 哪些距离相等；
- 点如何移动；
- 某个条件删除后是否仍能唯一确定答案。

因此本讲真正要训练的是：

> **把分散知识重新组织成一个一维位置模型。**

这也是进入“有理数的运算”之前的一次阶段性思维峰值训练。

# R0.5. 教材映射与知识边界

本讲不是当前教材中的独立小节，而是对“有理数”章已学节点的综合迁移。

本讲允许综合：

- 数轴上的位置与顺序；
- 点到原点的距离；
- 两点之间的距离直觉；
- 中点“到两端距离相等”的定义；
- 等距刻度与尺度恢复；
- 简单动点与路径；
- 条件充分性、反例和唯一性。

本讲**不把后续运算法则偷渡进来**：

- 不把 `|a-b|` 当成 Core 两点距离公式；

- 不正式教授有理数加减法则；
- 不使用方程作为主要求解工具；
- 不系统讲速度方程、绝对值方程或不等式。

目标是先理解结构，后续 Lesson 9～10 学完加减法后再把这些结构压缩成公式。

# 第一部分：四个容易混在一起的量

## 4. 坐标

坐标回答：

> **点在哪里？**

例如点 A 的坐标是 −4，表示 A 在原点左边4个单位。

## 5. 到原点的距离

回答：

> **这个点离0多远？**

A 的坐标 −4，但 A 到0的距离为4。

## 6. 两点之间的距离

回答：

> **从一个点沿数轴走到另一个点，最短要跨多少单位长度？**

例如 A 在 −3，B 在5。

可以把路分成：

```text
A → 0：3个单位
0 → B：5个单位
```

所以 A、B 相距8个单位。

这里不需要先背 `|a-b|`。

## 7. 路径长度

如果一个机器人从 −3 先到5，再返回1：

- 最终位置是1；
- −3与1的直接距离是4；
- 实际走过的路径却是 `8 + 4 = 12` 个单位。

所以：

> **最终位置、两点直接距离、实际路径长度不是同一个量。**

这正是 H2/H7 最容易出错的地方。

# 第二部分：两点距离先看它们是否跨过0

## 8. 位于0两侧

例如 −4 和3。

两点之间必须经过0：

```text
−4 → 0：4
0 → 3：3
总距离：7
```

结构是：

> **两侧 → 两段到0距离相加。**

## 9. 位于0同侧

例如 −7 和 −2。

两点都在0左边。

它们到0分别是7和2，因此两点间只差：

```text
7 − 2 = 5
```

结构是：

> **同侧 → 比较两个到0距离，较大减较小。**

不要机械背“同号减、异号加”。先画位置。

# 第三部分：中点不是一个公式，而是一种等距关系

## 10. 中点的定义

如果点 M 在线段 AB 上，并且：

```text
AM = MB
```

那么 M 是 AB 的中点。

关键词有两个：

1. M 在 A、B 之间；
2. M 到两端距离相等。

只有“到A、B距离相等”但没有说明在一维直线上时，需要结合题目对象继续判断；在本讲的数轴模型里，两个不同点之间只有一个这样的中间位置。

## 11. 不用中点公式也能求

A 在 −6，M 在 −1，M 是 AB 的中点。

A 到 M 有5个单位。

因为：

```text
AM = MB
```

所以从 M 再向右5个单位到 B，得到 B = 4。

核心是：

```text
一半已知
→ 另一半同长
```

而不是先套未来公式。

## 12. 为什么中点唯一

设 A 在左、B 在右。

从 A 向 B 移动时：

- 离 A 越来越远；
- 离 B 越来越近。

只有在中间某一个位置，两段距离恰好相等。

如果说有两个不同中点，就会出现“同一条线段被两种不同位置同时平分”，与等长分段矛盾。

本讲要求学生能用位置和距离解释唯一性，而不是只写“中点唯一”。

# 第四部分：等距刻度把局部信息变成整体尺度

## 13. 两个锚点恢复尺度

数轴上 A、B、C、D、E 连续等距。

若 B = −5，E = 4，则 B 到 E 跨3个相同间隔，而总变化为9。

所以每个间隔代表3。

于是：

```text
A = −8
B = −5
C = −2
D = 1
E = 4
```

这延续 Lesson 3 的核心结构：

```text
两个锚点
+ 等距
→ 恢复尺度
→ 恢复全部位置
```

## 14. 删除“等距”会发生什么

如果只知道：

```text
A < B < C < D < E
B = −5
E = 4
```

就不能确定 C、D 的具体坐标。

例如 C 可以是 −2，也可以是0；只要仍满足顺序即可。

所以“等距”不是装饰条件，而是恢复尺度的关键条件。

# 第五部分：动点题先把“每一步”翻译成位置变化

## 15. 最简单的动点模型

机器人从坐标 −3 出发，每次向右移动2个单位。

不要急着写运算式，先画过程：

```text
−3 → −1 → 1 → 3 → 5
```

第4次移动后到5。

如果改为向左，则方向相反。

### 动点四问

```text
起点在哪里？
方向是什么？
每一步多长？
一共走几步？
```

## 16. 相遇问题的核心

两点从数轴两端相向移动时，“相遇”意味着：

> **它们最终到达同一个位置。**

如果速度相同、同时出发，那么它们走过的距离相同，因此相遇点就是两起点的中点。

这不是速度公式，而是：

```text
同时
+ 同速
→ 两边走的一样远
→ 相遇点到两起点等距
```

若速度不同，就不能擅自把相遇点当中点。

这是典型 D2 条件充分性问题。

# 第七部分：Ceiling Diagnostic｜T0 冷启动

## 一个点同时满足两种“等距”条件

> **DESIGNED · Ceiling Diagnostic**  
> **首次独立20分钟，不看 Hint。**

数轴上 A、B 两点的坐标分别为：

```text
A = −6
B = 4
```

点 M 位于 A、B 之间，并满足：

```text
MA = MB
```

另有一点 X 满足：

```text
XM = 3
```

回答：

1. 不使用中点公式，求 M 的坐标。
2. 求 X 的全部可能坐标。
3. 为什么 X 恰好有两个可能，而不是一个或三个？
4. 如果再增加条件“X 在 M 的右侧”，X 是否唯一？
5. 删除“M 位于 A、B 之间”，只保留 `MA = MB`，在数轴上是否还会出现另一个 M？说明理由。
6. 把 A、B 换成任意两个不同点。你认为“到 A、B 距离相等的数轴点”有几个？为什么？
7. 这道题里，哪些条件负责确定中心，哪些条件负责确定方向，哪些条件负责唯一性？

### T0 诊断目标

观察学生是否会：

- 把中点翻译成两段等长；
- 不依赖 `(a+b)/2`；
- 逆向距离时主动检查左右两个位置；
- 解释“为什么只有两个”；
- 区分中心条件与方向条件；
- 从具体数字推广到一般结论。

重点记录：H2、H3、H5、H7、H9、H10。

# 第八部分：Ceiling Builder｜把“会画数轴”提升为“会控制条件”

## Builder 1｜同侧、异侧不是口诀

分别构造：

- 两点都在0左侧，距离为5；
- 两点分居0两侧，距离也为5。

说明同一个“两点距离5”为什么不能反推出唯一坐标。

**训练能力**：D3 反例 + D4 多解。

## Builder 2｜删掉中点条件

A = −6，B = 4，点 M 只知道在 A、B 之间。

问：

- M 能否唯一？
- 至少给3个合法位置；
- “在中间”与“是中点”差别在哪里？

**训练能力**：D2 条件充分性。

## Builder 3｜删掉同速条件

两机器人从 A、B 同时相向出发。

若只知道“同时出发”但速度不同：

- 相遇点一定是中点吗？
- 构造一个反例。

再恢复“速度相同”，说明为什么中点结论恢复。

**训练能力**：D2 + D3。

## Builder 4｜逆向构造损坏数轴

自己设计6个等距标点，要求：

- 原点不在任何标点；
- 给两个非相邻点坐标后能唯一恢复尺度；
- 至少有一对点关于某个中间位置等距；
- 删除“等距”后答案不唯一。

交换给同学求解。

**训练能力**：D1 + D2 + D6。

## Builder 5｜一般化“等距中心唯一”

任选两个不同点 A、B。

不用字母公式，解释：

1. 为什么从 A 到 B 的最短路径只有一段；
2. 为什么把这段分成两个同样长的部分只得到一个分界点；
3. 因而为什么数轴上到 A、B 等距的点唯一。

**训练能力**：D4 + D5。

# 第十部分：Informatics 迁移｜一维状态模拟

## 20. 位置状态与路径累计

程序模拟机器人：

```text
start = −3
moves = 右2，右2，左1，右3
```

数学上要分清两个状态：

```text
position：当前在哪里
travel：一共走了多远
```

最终位置和累计路径是不同变量。

如果程序只保存最终 `position`，就不能反推出机器人实际走过的完整路径。

### 迁移问题

两条不同移动序列能否有相同最终位置但不同总路程？

请构造一个最简单例子。

**训练能力**：同一终态不代表同一路径，连接算法中的状态与历史信息。

# 第十一部分：错误实验室

1. **“坐标为 −5，所以距离也是 −5。”**——错，坐标带方向，距离不带方向。
2. **“从 −4 到3只差1。”**——错，把符号外形当作空间距离，应分段经过0。
3. **“在 A、B 之间就是中点。”**——错，中点还要求到两端等距。
4. **“图上画在正中央，所以一定是中点。”**——错，必须有条件。
5. **“两个机器人相向同时出发，一定在中点相遇。”**——还缺同速条件。
6. **“一个点离 M 三个单位，所以就在 M 右边3。”**——漏了左边位置。
7. **“找到两个答案就算完。”**——还要证明没有第三个位置。
8. **“最终位置相同，所以路程相同。”**——错，路径历史可以不同。

# 第十二部分：Mastery / Final Challenge｜脱落标签、隐藏中心与两个候选点

> **SYNTHESIS · Mastery / Final Challenge**  
> **无单一原题。**  
> 结构来源：[CEMC 2016 Gauss G7 Q10｜中点](https://cemc.uwaterloo.ca/sites/default/files/documents/2016/2016Gauss7Contest.html) + [CEMC 2020 Gauss G7 Q8｜等距数轴](https://cemc.uwaterloo.ca/sites/default/files/documents/2020/2020Gauss7Contest.html)。

数轴上从左到右有7个连续等距点：

```text
A，B，C，D，E，F，G
```

B 和 F 原来的数字标签脱落。找到两张标签：

```text
−7 和 5
```

但不知道分别属于 B 还是 F。

回答：

1. 判断两张标签分别属于哪个点，并说明为什么只有这一种分配。
2. 恢复 A～G 的全部坐标。
3. B、F 的中点是哪一个已标点？它的坐标是多少？不用中点公式。
4. 点 X 到 D 的距离，等于 C 与 E 之间的距离。求 X 的全部可能位置。
5. 为什么第4问只有这些位置？
6. 若再告诉“X 在 D 左侧”，结果如何变化？哪条信息负责唯一化？
7. 删除“7个点连续等距”，只保留左右顺序以及 B、F 的两张标签，哪些结论还能确定？哪些不能？给出反例或不同模型。
8. 推广：一条等距数轴上，若第 i 个点和第 j 个点坐标已知，怎样用“总变化平均分到相同间隔”恢复任意中间点？先用语言说明，不要求写未来代数公式。

### Hint 1

先利用：

```text
B 在 F 左边
→ B 的数一定小于 F
```

### Hint 2

B 到 F 跨4个相同间隔。两张标签之间的总变化平均分给这4个间隔。

### Hint 3

第4问先求 C、E 之间跨几个间隔，再把同样的距离从 D 向左、向右各找一次。

完整解答与方法提炼见：[Lesson 8 Ceiling v2.2](./solutions/08-number-line-integration-ceiling-v2.2.md)。
