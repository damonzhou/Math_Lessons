# R0. 为什么绝对值之后进入大小比较

Lesson 3 已经建立最根本的顺序原则：

> **数轴上越靠右的数越大。**

Lesson 5～6 又把绝对值解释成“到原点0的距离”。

现在要把这两件事统一起来：

```text
位置顺序
+
正负关系
+
到0距离
→
有理数大小比较
```

本讲的重点不是记三条规则，而是回答：

> **为什么这些规则一定成立？**

# 第一部分：所有规则的根只有一个——数轴顺序

## 4. 最根本原则

规定数轴正方向向右：

> **右边的数大，左边的数小。**

例如：

```text
−5 < −2 < 0 < 3 < 7
```

这不是五条规则，而是一条空间顺序。

如果忘了任何比较口诀，都可以回到数轴。

---

# 第二部分：正数、0、负数之间怎么比较

## 5. 正数一定大于0

正数在0右边，所以：

```text
正数 > 0
```

## 6. 负数一定小于0

负数在0左边，所以：

```text
负数 < 0
```

于是自然得到：

```text
正数 > 0 > 负数
```

因此一个正数和一个负数比较时，不需要比较绝对值大小：

```text
0.01 > −1000
```

虽然0.01离0很近，−1000离0很远，但正数仍然更大。

这说明：

> **数值大小和离0距离是两件不同的事。**

---

# 第三部分：两个正数为什么正常比较大小

两个正数都在0右边。

距离0更远的那个点也更靠右，因此更大。

例如：

```text
2 < 5
```

同时：

```text
|2| < |5|
```

对于两个正数：

> **绝对值越大，原数越大。**

但这句话有条件：两个数都为正数（或更一般地都非负）。

不能把它无条件推广到所有有理数。

---

# 第四部分：两个负数为什么“绝对值大的反而小”

## 7. 从具体例子看

比较 −2 和 −5。

```text
←────●────────●────────0────→
    −5       −2
```

−5 在 −2 左边，所以：

```text
−5 < −2
```

但：

```text
|−5| = 5
|−2| = 2
```

于是两个负数中：

```text
绝对值较大的负数，位置更靠左，原数反而更小。
```

## 8. 为什么会“反过来”

把正数2和5关于原点对称：

```text
2  → −2
5  → −5
```

原来：

```text
2 < 5
```

镜像以后：

```text
−5 < −2
```

原因不是“负号有魔法”，而是：

> **关于原点对称会把右侧的左右次序镜像到左侧。**

这就是负数比较规则的结构来源。

---

# 第五部分：比较规则总结，但不要脱离原因

## 9. 两个有理数比较的决策顺序

### 情况A｜符号不同

```text
正数 > 0 > 负数
```

先看它们位于0哪一侧。

### 情况B｜同为正数

按原来的数值大小比较；也可以比较绝对值，绝对值大的更大。

### 情况C｜同为负数

比较绝对值：

> **绝对值大的负数反而小。**

但最好在脑中补一句：

> 因为它离0更远、在数轴上更靠左。

---

# 第六部分：不同表示形式怎样比较

## 10. 不要被“长相”骗了

例如比较：

```text
−0.8 和 −3/4
```

把它们统一为小数：

```text
−3/4 = −0.75
```

于是：

```text
−0.8 < −0.75
```

因为 −0.8 更靠左。

也可以比较绝对值：

```text
0.8 > 0.75
```

所以负数中 −0.8 更小。

### 统一表示只是工具

真正的问题仍是：

> 哪个点在数轴上更靠右？

# 第十部分：Advanced｜从规则走向一般结构

## 13. 镜像会反转左右顺序

T0 已经观察到：

```text
0 < a < b
```

时：

```text
−b < −a < 0 < a < b
```

更一般地，如果数轴上 a 在 b 左边，那么把两点同时关于原点对称后，a 的像会出现在 b 的像右边。

因此“取相反数”会反转顺序。

这里先把它理解为数轴几何事实，不提前进入系统不等式变形。

## 14. 绝对值大小不能单独决定原数大小

只知道：

```text
|a| > |b|
```

不能直接推出 a > b 或 a < b。

例如：

```text
a = 5，b = 2  → a > b

a = −5，b = −2 → a < b

a = 5，b = −2 → a > b
```

真正需要结合：

> **符号 + 距离。**

# 第十二部分：Informatics｜一个有理数比较器怎样分支

程序如果要比较 x、y，不应该写一堆互相冲突的口诀。

可以建立决策树：

```text
先判断 x、y 是否分处0两侧
    ↓
异号：正数大
    ↓
同为非负：直接比较
    ↓
同为负：比较绝对值，绝对值小的原数大
```

这不是要求现在写代码，而是理解：

> **数学分类讨论本身就是算法结构。**

测试比较器时至少要覆盖：

- 正 vs 负；
- 正 vs 正；
- 负 vs 负；
- 与0比较；
- 两数相等；
- 分数/小数混合表示。

# 第十三部分：错误实验室

## 错误1｜负号越多，数越小

错误。符号外形不能替代数值关系。

## 错误2｜绝对值越大，原数越大

错误。−10 的绝对值大于 −2，但 −10 < −2。

对应：H7/H9。

## 错误3｜两个负数，数字部分大的就大

例如 −8 与 −3，8 > 3，但 −8 < −3。

应回到数轴位置。

## 错误4｜比较 −0.7 与 −2/3 时只看“7和2”

必须统一表示或比较对应正距离。

## 错误5｜排序只做相邻比较，没有检查漏项

最后必须核对：

> 每个原数是否恰好出现一次？

对应：H5/H10。

## 错误6｜“位于 −4 与 −3 之间”只检查一边

必须同时满足：

```text
−4 < x < −3
```

这是双边条件。

> **至少有2个负数。**

6. 现在共有多少种可能的原数集合？
7. 分别写出它们从小到大的顺序。
8. 说明为什么你已经列完，没有遗漏。

## 第三层｜一般化

设：

```text
0 < c < a < b
```

5个互不相同有理数的绝对值为：

```text
c，a，a，b，b
```

9. 为什么绝对值为 a 和 b 的数必须分别成相反数对？
10. 若恰好有2个负数，绝对值为 c 的那个数必须是什么符号？
11. 写出一般的从小到大顺序。
12. 如果恰好有3个负数，一般顺序又是什么？

### Final Challenge 的核心

这题不靠复杂计算。真正需要发现：

```text
重复绝对值
→ 相反数成对
→ 负数个数提供符号条件
→ 数轴顺序完成排序
→ 最后证明唯一/穷尽
```

Hint 1～3、完整解答与一般化见：[Ceiling / Mastery 答案](./solutions/07-rational-number-comparison-ceiling-v2.2.md)。
