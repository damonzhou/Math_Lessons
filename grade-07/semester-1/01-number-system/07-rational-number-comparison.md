# 3｜Concept Deepening｜两个坐标系统同时存在

## 3.1 原数大小看“左右”

数轴上的根本规则只有一个：

> **越靠右，数越大。**

因此：

```text
−100 < −2 < 0 < 0.1 < 20
```

## 3.2 绝对值大小看“离0多远”

例如：

```text
−10 < 3
```

但：

```text
|−10| > |3|
```

所以：

```text
原数顺序 ≠ 距离顺序
```

除非再知道符号区间。

## 3.3 为什么负数区会反向

在0右边：

```text
2 < 5
```

关于原点镜像后：

```text
−5 < −2
```

这不是口诀，而是几何顺序被镜像反转。

到这里停止。**不要先学习后面“绝对值更大的那个数控制相对顺序”的一般结构。先做 T0。**

# 4｜Ceiling Diagnostic｜T0 冷启动

## 三个标签只有绝对值顺序，还能有多少种真实顺序？

> **DESIGNED · Ceiling Diagnostic · ★★★★**  
> **首次独立25～30分钟，不看 Hint。**

有三个互不相同的非零有理数 a、b、c，只知道：

```text
0 < |a| < |b| < |c|
```

不知道 a、b、c 各自是正数还是负数。

回答：

1. a、b、c 从小到大的排列一共有多少种**不同的结构**？请全部写出。
2. 三个不同标签理论上共有6种排列。哪两种排列永远不可能出现？
3. 不要用“我试了8种正负号”作为最终证明。找一个更短的结构理由解释：为什么 c 永远不可能排在中间？
4. 在每一种可能排列中，能否唯一判断 b、c 的正负？逐一说明。
5. a 的正负能否由 a、b、c 的相对顺序唯一确定？如果不能，为每一种排序结构给出两个只改变 a 符号、排序仍不变的例子或一般说明。
6. 为什么8种符号组合最后只产生4种标签排序？指出“丢失”的那一位信息是什么。
7. 写出一个不枚举8种符号组合的完整证明，说明你的4种排序**不重不漏**。

### T0 首个卡点编码

```text
A 仍停留在逐个代数试值，无法发现极端结构
B 发现 c 在两端，但不能继续确定 b 的作用
C 能得到4种排序，但枚举/分类漏项
D 能列全，但不会证明另外2种不可能
E 能证明4种，但看不出为什么 a 的符号不可由排序恢复
F 能独立完成并推广到4个变量
```

Hint / Full Solution：[Ceiling v2.3](./solutions/07-rational-number-comparison-ceiling-v2.3.md)。

# 5｜Ceiling Builder｜从 T0 提炼控制全局的结构

## Builder A｜只看两个数，谁真正控制顺序

已知：

```text
0 < |a| < |b|
```

不要先讨论 a 的符号，只研究 b：

1. 若 b > 0，证明无论 a 正负，都有 a < b；
2. 若 b < 0，证明无论 a 正负，都有 a > b；
3. 用一句话总结：在绝对值不同的两个非零数中，谁的符号决定相对顺序？

得到本讲一个关键结构：

> **绝对值更大的那个数在0右侧，它就是较大者；在0左侧，它就是较小者。**

这是数轴事实，不作为不等式变形公式背诵。

## Builder B｜为什么最大绝对值一定占据一个极端位置

若：

```text
|c| > |a|，|c| > |b|
```

证明：

- c > 0 时，c 一定比 a、b 都大；
- c < 0 时，c 一定比 a、b 都小。

因此 c 不可能处于三者中间。

**训练能力**：局部比较 → 全局极值。

## Builder C｜逆向：从排序反推符号

仍有：

```text
0 < |a| < |b| < |c|
```

若实际排序为：

```text
c < a < b
```

回答：

1. c 必须是什么符号？
2. b 必须是什么符号？
3. a 的符号能否确定？
4. 为什么只知道排序恰好能恢复 b、c，却恢复不了 a？

## Builder D｜不可能结构

分别判断是否可能存在满足 `0 < |a| < |b| < |c|` 的数，使：

```text
a < c < b
```

或：

```text
b < c < a
```

若不可能，不得只说“试不出来”，必须用“c 必须在一端”证明。

## Builder E｜四变量预备

已知：

```text
0 < |a| < |b| < |c| < |d|
```

不要列16种符号组合。

先回答：

1. d 只能排在哪里？
2. 去掉 d 后，剩下三个标签仍满足什么结构？
3. 能否通过“先放 d，再放 c，再放 b”的方法构造全部排序？

这就是 Final Challenge 的突破口。

# 6｜School Advanced｜部分信息到底能推出多少

## A1｜必要充分条件雏形

已知：

```text
0 < |a| < |b|
```

判断下面哪些结论必然成立，并证明：

```text
b > 0  → a < b
b < 0  → a > b
a < b  → b > 0
a > b  → b < 0
```

最后用中文总结“a < b”和“b > 0”在这个前提下是什么关系。

## A2｜三变量顺序反推

已知：

```text
0 < |a| < |b| < |c|
```

实际排序是：

```text
b < a < c
```

确定 b、c 的符号；说明 a 为什么仍有两种可能。

然后自己构造两组不同数值验证。

## A3｜最少附加信息

在 A2 中，如果还想唯一恢复 a、b、c 三者的正负，允许额外问一次：

> “某一个指定变量是否大于0？”

最应该问谁？为什么问其他已经能由排序确定符号的变量是冗余信息？

## A4｜构造一道“不可能排序”

自己给出三个标签 p、q、r，规定：

```text
0 < |p| < |q| < |r|
```

然后写一个看似合理但实际不可能的 p、q、r 排序，交给同学证明不可能。

要求你的证明只用当前知识。

# 8｜Informatics｜比较器升级为“排序信息恢复器”

基础比较器只需要输出 x < y、x = y、x > y。

本讲进一步问：

> 如果程序只保存变量之间的排序，而丢掉原值，它还能反推出哪些符号信息？

对于：

```text
0 < |a| < |b| < |c|
```

排序结果可以恢复 b、c 的符号，却恢复不了 a 的符号。

这是一个很典型的信息学问题：

```text
输入信息
→ 经过变换只保存“排名”
→ 哪些信息仍可恢复？
→ 哪些信息已经不可逆地丢失？
```

# 9｜Elite / Final Challenge｜四个标签的顺序密码

> **SYNTHESIS · Elite / Final Challenge · ★★★★～★★★★★**  
> **无单一原题。**  
> 结构依据：当前人教版“数轴 + 相反数 + 绝对值 + 大小比较”，并使用 CEMC 2018 G7 Q6 的顺序/区间意识与 CEMC 2026 G7 Q3 的“数值大小 ≠ 距离大小”作为 Bridge。  
> 官方结构来源：[CEMC 2018 G7 Q6](https://cemc.uwaterloo.ca/sites/default/files/documents/2024/2018Gauss7Contest.html)、[CEMC 2026 G7 Q3](https://cemc.uwaterloo.ca/sites/default/files/documents/2026/2026Gauss7Contest.html)。

有四个互不相同的非零有理数 a、b、c、d，只知道：

```text
0 < |a| < |b| < |c| < |d|
```

不知道任何一个数的符号。

## 第一层｜不枚举16种符号组合

1. 证明 d 一定是四个数中最小的或最大的，不可能排在中间。
2. 去掉 d 后，证明 c 在剩余三个数中也一定处于一个极端位置。
3. 利用“从最大绝对值开始逐层剥离”的方法，写出 a、b、c、d **全部可能的从小到大标签顺序**。
4. 证明一共只有这些顺序，不允许以“我试完了16种符号”为唯一证明。

## 第二层｜从排名反推符号

5. 对你得到的每一种标签顺序，说明 b、c、d 的符号如何被唯一确定。
6. 证明：仅知道四个标签的相对顺序，a 的符号仍然无法确定。
7. 解释为什么 a 是唯一具有这种“符号不可见性”的标签。

## 第三层｜指定排名

某次记录得到：

```text
d < b < a < c
```

8. 确定 b、c、d 的符号。
9. 写出 a 的全部符号可能，并分别构造一组具体有理数验证。

## 第四层｜最少信息

现在除了标签排序外，只允许再问一次“某个指定变量是否大于0”。

10. 问谁可以恢复四个变量的全部符号？
11. 为什么这一次询问足够？
12. 为什么完全不询问一定不够？也就是说，证明这条额外信息是必要的。

## 第五层｜一般化

再增加一个非零有理数 e，并满足：

```text
0 < |a| < |b| < |c| < |d| < |e|
```

13. 不列32种符号组合，说明怎样从外到内构造所有可能标签顺序。
14. 仅凭最终标签顺序，哪些变量的符号可以恢复？哪个变量仍然不能？为什么？
15. 观察2个、3个、4个、5个标签时不同排序结构数量的变化，描述一般规律；不要求使用尚未正式学习的乘方记号。

### Final Challenge 的真正突破口

```text
绝对值最大的标签
→ 符号决定它放最左还是最右
→ 删除它
→ 对剩余标签重复同一结构
→ 最小绝对值标签最后落在“负数区/正数区交界”
→ 它变号却不改变标签排名
```

这道题即使完全去掉复杂计算，思维任务仍然存在。

Hint 1～3、完整解答、方法提炼与进一步推广见：[Ceiling / Final v2.3](./solutions/07-rational-number-comparison-ceiling-v2.3.md)。

# 12｜固定复盘问题

每道高阶排序题结束后问：

```text
① 哪个条件控制全局？
② 最大绝对值的对象能处在中间吗？
③ 我是在枚举，还是找到了一种保证不漏的方法？
④ 哪些符号能由排名反推？
⑤ 哪条信息已经丢失？
⑥ 为什么答案只有这些？
```

下一讲：

> **Lesson 8《数轴综合》——位置、距离、未知尺度、未知原点与动点结构。**
