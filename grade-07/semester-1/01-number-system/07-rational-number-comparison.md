# R0｜本讲真正的增量

基础比较法则默认已经学过，只做 Gap Check。

本讲向上走：

```text
原数大小 vs 到0距离
→ 绝对值更大的数为什么占更外侧
→ 从绝对值结构推全部可能顺序
→ 从最终顺序反推符号
→ 重复绝对值为什么强迫相反数对
→ 哪些符号能从排名恢复，哪些天然不可见
→ 推广到任意“单点组 / 相反数对”混合结构
```

最高层要求的不是“排更多数”，而是建立**生成全部合法顺序的结构定理**。

---

# R0.5｜教材覆盖与边界

必须稳定掌握：

- 数轴右边的数更大；
- 正数 > 0 > 负数；
- 两个负数比较：离0更远者更小；
- 多个有理数排序；
- 分数、小数等不同表示的比较；
- 原数大小与绝对值大小不是同一个问题。

本讲不正式使用：

- 有理数加减法则；
- 系统不等式变形；
- 函数单调性；
- 排列组合公式。

计数只使用“每个独立结构有几种选择”的小学乘法直觉。

# 3｜Concept Deepening

## 3.1 大小只看数轴左右

根本规则：

> **越靠右，数越大。**

## 3.2 绝对值只看离0远近

例如：

```text
−10 < 3
但 |−10| > |3|
```

因此：

```text
原数排序 ≠ 距离排序
```

## 3.3 为什么负数区反向

`2<5` 关于0镜像后变成 `−5<−2`。负数比较“绝对值越大反而越小”来自镜像反序，不是孤立口诀。

## 3.4 两个数的控制结构

若：

```text
0 < |a| < |b|
```

则：

- b>0 时，b 比 a 大，无论 a 正负；
- b<0 时，b 比 a 小，无论 a 正负。

所以在两个绝对值不同的非零数中：

> **绝对值更大的那个数的符号，决定它位于这两个数的哪一端。**

这一结构用于 School Advanced；但不要提前讲 Final 的一般“组生成定理”。

# 4｜School Advanced

## A1｜三变量极端位置

若：

```text
0<|a|<|b|<|c|
```

证明 c 不可能排在中间。

## A2｜从顺序反推

在同一条件下若：

```text
c < a < b
```

判断 b、c 的符号；说明 a 的符号为什么可能仍不可确定。

## A3｜不可能结构

判断 `a<c<b`、`b<c<a` 是否可能，并用“最大绝对值一定占一端”证明，不用8种符号表暴力枚举。

# 5｜Ceiling Diagnostic｜T0：重复绝对值会怎样改变排序结构？

> **DESIGNED · Ceiling Diagnostic · ★★★★**  
> 建议首次独立25～35分钟。

五个两两不同的非零有理数 A、B、C、D、E 满足：

```text
0 < |A| = |B| < |C| < |D| = |E|
```

不知道任何一个数的正负。

回答：

1. 为什么 A、B 必须互为相反数？D、E 呢？
2. D、E 在五个数从小到大的排名中一定占哪两个位置？为什么？
3. A、B 与 C 的相对位置有哪些可能？不要先枚举所有符号。
4. 写出所有**结构模板**。建议先不用具体标签正负，记：

```text
小绝对值负点 / 小绝对值正点
大绝对值负点 / 大绝对值正点
```

5. 一共有多少种不同的**标签排序**？证明不重不漏。
6. 给定任意一种合法标签排序，能否把 A、B、C、D、E 五个数的正负全部恢复？证明。
7. 这一结论和旧的 `0<|a|<|b|<|c|` 三个单点组有什么不同？为什么旧问题中最小绝对值那个数的符号可能不可见，而这里不会？

### 首个卡点

```text
P1 未把重复绝对值 + 互异转成相反数对
P2 知道成对，但看不出最大绝对值对占两端
P3 会画图，不能抽象成结构模板
P4 能列排序，不会证明完整
P5 会计数，不理解哪些符号由排名可恢复
P6 能独立发现一般规律
```

# 6｜Ceiling Builder

## Builder A｜固定正距离最多两个位置

若两个不同数绝对值都是 r>0，它们只能是：

```text
−r，r
```

所以“重复组”天然是一对一负一正。

## Builder B｜从最大绝对值组开始放

若当前最大绝对值组：

- 只有1个标签：它只能放当前最左或最右；
- 有2个标签：它们必须同时占当前最左和最右。

处理后把这一层“剥掉”，继续看下一绝对值组。

## Builder C｜最小组为什么特殊

当所有更大绝对值组都已经放到外层，最小组位于最中心：

- 若它只有1个标签，只剩一个位置，正负不会改变**标签排名**；
- 若它有2个标签，还剩两个中心位置，谁负谁正在标签排名中仍可见。

这正是 Final 计数规律的关键。

# 8｜Elite / Final Challenge｜任意绝对值组怎样生成全部合法排序？

> **DESIGNED · Elite / Final · ★★★★★**  
> 无单一原题；建议30～45分钟。

有若干个两两不同的非零有理数。把它们按绝对值分组，同组绝对值相等；不同组绝对值不同。

因为所有原数两两不同，所以每个正绝对值组最多含2个标签。

把不同正绝对值从小到大记为：

```text
r1 < r2 < ... < rk
```

每组可能是：

```text
单点组：只有一个标签
相反数对：两个标签
```

完成：

1. 证明：从最大组 rk 开始向内处理，可以生成所有合法标签排序。
2. 证明：若当前组是单点组，它有“放当前最左 / 最右”两种结构选择；若是相反数对，两个标签必须占当前两端，但“谁左谁右”也有两种选择。
3. 解释为什么这个递归过程不会遗漏，也不会重复。
4. 最小绝对值组 r1 若是**单点组**，证明它的正负无法从最终标签排序恢复。
5. r1 若是**相反数对**，证明两者正负可以由最终排名恢复。
6. 推出合法标签排序总数：
   - 若最小组是单点组：`2^(k−1)`；
   - 若最小组是相反数对：`2^k`。
   不允许只报公式，必须解释最后一组为什么少/多一个二选一。
7. 给出一个含4个绝对值组、且单点组/相反数对混合的自造例子，验证你的结论。
8. 反向问题：从一个合法标签排序和各标签绝对值出发，哪些符号一定可恢复？写出一般结论。

### Final 的核心

```text
最大绝对值控制外层
→ 一层层向内剥离
→ 每个“可见的左右选择”产生一个二选一
→ 最中心单点的符号不改变标签排名
```

这不是排列组合课；计数只是结构发现后的结果。

# 9｜错误实验室

重点防止：

- 把“绝对值大”直接当“原数大”；
- 看到重复绝对值却没使用“互异 → 相反数对”；
- 暴力枚举全部符号而没有结构证明；
- 找到若干排序就停止，不证明完整；
- 公式 `2^...` 会写，却说不清最小单点组为什么不贡献可见二选一。

# 一句话总结

> **真正的大小比较能力，不只是给两个数判断谁大，而是能从距离结构生成所有可能顺序，并从顺序反推出隐藏符号。**
