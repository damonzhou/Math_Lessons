# 3. Ceiling Diagnostic｜为什么使用 DESIGNED

## D0｜一个点同时满足两种“等距”条件

**标签**：`DESIGNED · Ceiling Diagnostic`

给 A = −6、B = 4，M 到 A、B 等距；X 到 M 距离3。

要求：

- 不用中点公式找 M；
- 列出 X 的全部位置；
- 证明为什么只有两个；
- 加方向条件后判断唯一性；
- 检查“M 位于 A、B 之间”是否其实是必要条件；
- 推广到任意两端点。

### 为什么不直接使用竞赛原题

本讲 T0 需要同时诊断 D1～D5 多个维度：

1. 中点结构发现；
2. 固定距离的双向性；
3. 完整性证明；
4. 条件必要性审查；
5. 一般化。

S3～S5 均提供真实迁移结构，但没有单题同时覆盖这些诊断目标。

因此 T0 明确标记为 DESIGNED，不伪装真题。

### 当前知识可解性

只依赖 Lesson 1～7：

- 数轴位置；
- 绝对值距离意义；
- 大小比较；
- 等距直觉。

不需要：

- `|a-b|`；
- `(a+b)/2`；
- 有理数加减法则；
- 方程。

# 5. Mastery / Final Challenge

## M0｜脱落标签、隐藏中心与两个候选点

**标签**：`SYNTHESIS · Mastery / Final Challenge`  
**无单一原题。**

具体结构来源：

- CEMC 2016 Gauss G7 Q10：中点/等距反推；
- CEMC 2020 Gauss G7 Q8：连续等距数轴；
- 当前课程 Lesson 3～7：顺序、尺度、相反数、绝对值、大小比较；
- v2.2：删条件、唯一性、完整性和一般化。

官方结构来源：

- https://cemc.uwaterloo.ca/sites/default/files/documents/2016/2016Gauss7Contest.html
- https://cemc.uwaterloo.ca/sites/default/files/documents/2020/2020Gauss7Contest.html

### Final 的思维链

```text
左右顺序
→ 标签归属唯一
→ 两锚点 + 等距恢复尺度
→ 中点定位
→ 固定距离左右两候选
→ 方向条件唯一化
→ 删除等距检查哪些结论失效
→ 一般化尺度恢复
```

### 与 T0 的差异

T0 重点：

```text
中点 + 固定距离
→ 多解与唯一性
```

Final 增加：

```text
标签歧义
+ 尺度恢复
+ 中点
+ 多解
+ 删条件
+ 一般化
```

因此不是换数字重复 T0。

```text
不正式教 |a-b|
不正式教 (a+b)/2

```

Lesson 9～10 学完加减后，可以回看本讲并理解：

> 公式是在压缩已经理解的数轴结构，而不是替代结构理解。
