# 3. Ceiling Diagnostic 来源与原创必要性

## D1｜四张卡片：a、−a、|a|、−|a|

**标签**：`DESIGNED`  
**角色**：Ceiling Diagnostic / T0

### 诊断目标

学生在 Core 已学会分类规则、但 Advanced 的“稳定关系/操作复合”尚未完整教学时，需要独立发现：

1. a > 0、a < 0、a = 0 的配对结构不同；
2. a ≠ 0 时四个表达式恰好只有两个不同值；
3. 两个值互为相反数；
4. `|a|` / `−|a|` 是与原始符号无关的稳定表示；
5. 第一次做绝对值后，继续做“绝对值/取相反数”只剩两个状态。

### 为什么不用现成竞赛原题代替

本题需要同时控制：

- 当前知识可解；
- 字母符号分类；
- 边界0；
- −a 符号角色；
- 操作复合；
- 一般化区分度。

已审查的适龄 CEMC/AMC/UKMT 资源中，没有找到一题能以同样紧密的结构完成上述全部诊断目标而不引入额外知识。

因此透明使用 `DESIGNED`，不伪装为竞赛真题。

# 4. Ceiling Builder 来源与训练增益

Builder 以 `TEXTBOOK-MODEL + DESIGNED` 为主。

| Builder | 标签 | 针对卡点 | 训练能力 |
|---|---|---|---|
| 删除 a < 0 条件 | DESIGNED | H3/H10 | 条件充分性、反例 |
| 从 `|a|=a` / `|a|=−a` 反推 | TEXTBOOK-MODEL + DESIGNED | H5 | 逆向、边界0 |
| `|a|=|b|` 构造正反例 | DESIGNED | H10 | 穷尽可能、对称结构 |
| 设计 `abs(x)` 两分支 | DESIGNED | H5/H6 | 分类→算法、边界测试 |
| `|a|=t` 从4/0/−4推广 | DESIGNED | H9 | 特殊到一般、参数意识 |

Builder 的训练目标不是提高绝对值计算量，而是让学生形成：

> **条件决定规则；分界点必须检查；条件不足就构造反例或保留原式。**

# 5. Mastery / Final Challenge 来源与结构

## M1｜参数距离与互不相同

**标签**：`SYNTHESIS`  
**角色**：Mastery Challenge / T1

条件结构：

```text
|x| = t
|y| = t
x ≠ y
|z| = z
|z| = −z
```

### 综合依据

- 教育部/人教社绝对值距离意义；
- Lesson 6 的符号分类与边界；
- CEMC 数轴距离结构；
- 本课程长期 H5/H10“分类不漏/结果唯一性”诊断模型。

### 为什么标 `SYNTHESIS`

题面不是某场赛事原题，也不宣称是真题；它把多个已核验概念结构组合成参数问题。

### 与 T0 的结构差异

T0：

```text
四个表达式
→ 正负分类
→ 卡片配对
→ 操作复合
```

T1：

```text
参数 t
→ 先判断 t 的可行符号
→ t=0 边界
→ 同距离的不同位置数量
→ 互不相同筛选
→ 从2个变量推广“最多几个”
```

不是换数字版。

# 8. 知识边界审查

Lesson 6 正式覆盖：

- 含字母绝对值的符号分类；
- 0边界；
- `|a|=a` / `|a|=−a` 的逆向符号条件；
- `|−a|=|a|`；
- `||a||=|a|`；
- `|a|=|b|` 的同点/相反点结构；
- `|a|=t` 的简单距离逆向和0/1/2可能数量；
- 分类与程序分支的迁移。

不正式覆盖：

- 完整有理数大小比较法则（Lesson 7）；
- 两点距离 `|a-b|`（Lesson 8）；
- 复杂绝对值方程；
- 绝对值不等式；
- 绝对值函数图象；
- 高中分段函数形式化。
