# 4｜v2.4 Ceiling 为什么采用 DESIGNED

T0 / Final 使用两种操作：

```text
A：取绝对值
R：取相反数
```

无单一原题。

设计依据来自：

- 人教版绝对值与相反数的稳定概念链；
- Lesson 4 的相反数操作；
- Lesson 5 的“绝对值会丢掉方向信息”；
- v2.4 对最高层“灵活应用 + 至少两个非显然突破 + 完整证明 + 一般化”的要求。

最高层不是为了引入新知识，而是问：

> 已经会的“相反数”和“绝对值”连续复合后，是否能发现所有长过程实际上只剩极少数规则？

---

# 5｜最高层结构审查

Final 的核心不是“操作串更长”，而是：

```text
突破1：识别 A 会抹掉此前方向历史
突破2：发现关键不是第一次A，而是最后一次A
突破3：用“有没有A + 最后阶段R奇偶”证明任意串只有4类
突破4：黑箱识别要同时证明2次足够、1次一定不够
```

即使把操作串长度缩短，结构仍然存在，因此不是伪难度。

# 6｜知识边界

本讲不使用：

- 正式函数复合术语作为解题前提；
- 群/半群/自动机；
- 有理数加减法则；
- 系统不等式；
- 复杂绝对值方程。

教师可以在课后备注“这类思想以后会出现在函数复合/状态机”，但学生解题不依赖这些术语。
