### 原结构

原题要求判断哪一个数位于3与4之间。

### 本讲改编

把区间改为负数区间，并要求：

- 把“位于两数之间”翻译成双边大小关系；

### 教学价值

```text

→ 数轴区间
→ 两个同时成立的大小条件
```

重点是条件完整性，不是计算量。

# 3. Ceiling Diagnostic｜为什么使用 DESIGNED

## D0｜镜像四卡片

**标签**：`DESIGNED · Ceiling Diagnostic`

题目：已知 0 < a < b，对 a、b、−a、−b 排序，并分析最近/最远是否唯一、删掉正数条件后是否仍成立。

### 为什么不直接使用竞赛原题

本讲 T0 需要同时诊断：

1. 是否主动把符号条件转成数轴位置；
2. 是否发现关于原点对称会反转顺序；
3. 是否区分原数大小和绝对值/距离；
4. 是否检查“最近/最远”可能不唯一；
5. 是否能删除条件并构造反例；
6. 是否能从 0 < a < b 推广出一般结构。

S3/S4 能提供真实迁移，但不同时承担这些诊断功能。

因此 T0 明确为 DESIGNED，不冒充竞赛原题。

### 当前知识可解性

只使用 Lesson 1～6 已学：

- 正负数；
- 数轴；
- 相反数；
- 绝对值距离意义；
- 基本大小概念。

不需要有理数加减、不等式变形或未来公式。

# 4. Ceiling Builder 设计依据

Builder 均为 `DESIGNED / TEXTBOOK-MODEL`，核心不是增加题量，而是改变比较行为。

| Builder | 目标 | D维度 |
|---|---|---|
| 绝对值关系 + 不同符号条件 | 判断条件是否足够 | D2/D3 |
| 删除“同为负数” | 找规则边界、反例 | D2/D3 |
| 构造三个负数 | 从例子走向一般规律 | D1/D5 |
| 六数完整排序 | 分区、排序、核对穷尽性 | D4 |
| 比较器算法 | 数学分类转决策树 | D6 |

成功标准不是“题做得更多”，而是学生以后会主动先判断符号区间和信息是否充分。

# 5. Mastery / Final Challenge

## M0｜排序器丢掉了符号

**标签**：`SYNTHESIS · Mastery / Final Challenge`  
**无单一原题。**

结构依据：

- 当前人教版：数轴、相反数、绝对值、大小比较；
- S3：区间/顺序条件意识；
- S4：数值大小与到0距离的区别；
- 本课程 v2.2：条件筛选、唯一性、穷尽性、一般化。

具体官方结构来源：

- https://cemc.uwaterloo.ca/sites/default/files/documents/2024/2018Gauss7Contest.html
- https://cemc.uwaterloo.ca/sites/default/files/documents/2026/2026Gauss7Contest.html

### 与 T0 的结构差异

T0：

```text
参数 a,b + 镜像
→ 发现顺序反向
→ 检查条件
```

Final：

```text
无符号的绝对值多重集
→ 重复值恢复相反数对
→ 负数数量筛选剩余符号
→ 排序
→ 证明唯一/穷尽
→ c,a,b 一般化
```

不是换数字重复 T0。

### v2.2 深度

- D1：发现重复绝对值意味着相反数对；
- D2：负数个数是筛选条件；
- D3：删条件后出现第二种可能；
- D4：证明唯一、列全所有可能；
- D5：推广到 0 < c < a < b；
- D6：T2 迁移到海拔高度差。
