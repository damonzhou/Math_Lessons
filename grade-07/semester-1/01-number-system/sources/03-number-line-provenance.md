# 1. R0 主线定位依据

## P0｜教育部《义务教育数学课程标准（2022年版）》

官方 PDF：

https://www.moe.gov.cn/srcsite/A26/s8001/202204/W020220420582346895190.pdf

第四学段“数与式—有理数”明确要求：

- 理解负数的意义；
- 理解有理数的意义；
- **能用数轴上的点表示有理数**；
- 能比较有理数的大小；
- **借助数轴理解相反数和绝对值的意义**。

因此数轴不是一般性的拓展，而是后续相反数、绝对值和大小比较的直接前置。

# 2. 权威竞赛题源

## G1｜2026 CEMC Gauss Grade 7, Question 3

官方原题：

https://cemc.uwaterloo.ca/sites/default/files/documents/2026/2026Gauss7Contest.html

官方解答：

https://cemc.uwaterloo.ca/sites/default/files/documents/2026/2026GaussSolution.html

原题核心：在若干正负整数中判断哪个数在数轴上离0最远。

官方解答明确解释：

- −10 在0左侧10个单位；
- 9在0右侧9个单位；
- 比较的是“离0多远”。

### 本讲用途

支持：

- 位置方向与距离大小的区别；
- 为绝对值建立直觉；
- 主课第17节与当堂/课后相关训练。

主课训练数字做了改写时标记：

> `ADAPTED · CEMC 2026 Gauss Grade 7 Q3 structure`

若直接讨论官方题的数学思想，则只作为 `SOURCE` 窗口说明，不大段复制原题。

# 4. 知识边界

本讲**不正式教授**：

- 相反数；
- 绝对值符号；
- 两点距离公式 $|a-b|$；
- 中点公式；
- 高中“实数与数轴上的点一一对应”的完整理论。

允许的伏笔：

- 两点到0距离相同；
- 中间位置两边等距；
- 每个有理数都可以对应数轴上的点；
- 以后还有无理数点。

# 5. Final Challenge 审计

题型：损坏的等距数轴。

已知：

- 7个等距刻度 A～G；
- 正方向向右；
- B、F分别对应两张脱落标签 $-\frac32$ 与 $\frac12$；
- 原点、单位长度丢失。

要求恢复：

- 标签归属；
- 单位刻度；
- 全部坐标；
- 原点；
- 等距点对；
- 为什么信息足够唯一恢复。

### 结构来源

- G4：等距刻度数轴结构；
- G3：中间/等距推理；
- 本讲：正方向、顺序、刻度恢复。

### 当前知识可解性

只需要：

- 有理数大小；
- 分数基本运算/差值直觉；
- 等距；
- 数轴方向。

不依赖：

- 相反数定义；
- 绝对值公式；
- 集合 Extension；
- 高阶代数。

### 六项质量检查

- [x] 当前知识可解；
- [x] 题面不直接给恢复公式；
- [x] 突破口是“先顺序、再尺度、再整体恢复”；
- [x] 有权威竞赛结构依据；
- [x] Hint 1 → Hint 2 → Hint 3；
- [x] 解后改变标签，检查原点是否仍落在刻度上。
