# Lesson 2 v2.0 题源补充｜Ceiling Diagnostic / Builder

本文件补充原 `02-rational-number-classification-provenance.md`。

## 1. Ceiling Diagnostic

类型：`TEXTBOOK-MODEL + DESIGNED-DIAGNOSTIC`

题目采用七年级可理解的“四舍五入显示2.4”结构，目标不是训练计算，而是测试：

- 显示形式与精确数学对象是否混淆；
- 是否主动寻找反例；
- 是否能从若干例子走向完整边界；
- 规则变化后是否重新分析，而不是套原区间。

题面不是某一道竞赛真题，不标 `SOURCE`。

## 2. Ceiling Builder

类型：`DESIGNED · TRAINING`

训练链：

1. 同一有理数的多表示与表示选择；
2. 用反例推翻“显示相同→精确值相同”；
3. 四舍五入 vs 截断的条件变化；
4. 从1位小数推广到一般保留位数。

## 3. Mastery Challenge

原“显示0.38，反推精确值范围”继续保留，定位为 `MASTERY`。

它在教学后检查边界、精确/近似和规则变化，不再作为唯一上限诊断。
