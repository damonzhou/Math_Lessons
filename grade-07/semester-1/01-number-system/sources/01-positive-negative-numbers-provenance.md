# 4. Final Challenge

类型：

> `SYNTHESIS · CEMC平均数结构 + 本讲基准平移模型`

核心突破口：基准提高5后，每个偏差都减少5，因此总偏差按“个数×5”变化。

知识边界：只需偏差、平均数直觉、整体求和和简单方程关系。

质量检查：

- [x] 当前知识可解
- [x] 服务本讲核心
- [x] 有真实竞赛结构依据
- [x] 有三级提示
- [x] 解后一般化
