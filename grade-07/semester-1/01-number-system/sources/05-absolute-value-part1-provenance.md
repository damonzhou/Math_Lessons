# 3｜v2.4 为什么重做旧高阶层

旧 v2.3 T0 / Final 的主要结构是：

```text
更多标签
→ 重复绝对值形成相反数对
→ 条件筛选
→ 若干独立二选一
→ 数状态
→ 问最少几个方向问题
```

它有完整性和最少性训练，但存在明显“教学泄露”：前文已经明确讲了：

```text
绝对值丢方向
正距离对应 ±
重复绝对值 + 原数互异 → 相反数对
```

因此继续增加标签数量，更多是在增加组织负担，而不是增加新的结构突破。

v2.4 按“有效难度”重新校准：

```text
有效难度
=
原始结构难度
−
前文同构模板/提示带来的降难度
```

所以 Lesson 5 的最高层改为：

```text
相对方向关系
→ 整体镜像不变
→ 信息类型本身无法唯一化
→ 关系能否把独立方向组联系成整体
→ 一个绝对方向锚点
→ 最少关系数的下界证明
→ k组一般化
```

# 4｜Ceiling Diagnostic v2.4

## D0｜六点相对方向系统

**标签**：`DESIGNED · Ceiling Diagnostic`

题面只给：

- 每个标签的绝对值；
- 一条连续的同侧/异侧关系链；
- 不给任何绝对方向。

目标不是枚举符号，而是让学生自行发现：

1. 一个起点方向可以沿关系传播到全部标签；
2. 因此只有两组合法配置；
3. 两组恰好是整体关于0镜像；
4. 绝对值和同侧/异侧关系在整体镜像下全部不变；
5. 因此“再多同类信息”也无法打破这类二义性；
6. 删除中间关系后，整体裂成两个可独立翻转的部分；
7. 1个绝对方向锚点的充分性与必要性。

### 为什么达到更高有效难度

T0 前只讲：

```text
单点绝对值丢失方向
相对方向 vs 绝对方向
```

不提前讲：

```text
整体镜像不变性
关系链传播
多个独立翻转部分
```

因此关键突破仍需学生自己发现。

# 5｜Elite / Final Challenge v2.4

## M0｜重复绝对值 + 最少关系设计

**标签**：`DESIGNED · Elite / Final Challenge · ★★★★★`

**无单一原题。**

知识只使用：

- 绝对值的距离意义；
- 相反数；
- 数轴左右方向；
- “同侧/异侧”自然语言关系；
- 之前已训练的完整性、必要性、反例、一般化思维。

不依赖：

- 方程；
- 系统不等式；
- 图论定理；
- 组合数学公式；
- 信息论公式。

### 第一个非显然突破

重复正绝对值 + 原数互异不是“两个自由符号”，而是自动形成一对相反数，因此8个标签只剩5个真正独立方向组。

### 第二个非显然突破

只允许1个绝对方向锚点时，相对关系必须把5个方向组联系成一个整体。

### 第三个非显然突破

证明“4条最少”必须包含下界：

> 一条有效相对关系最多把两个原本独立的方向部分合成一个，所以从5部分变成1部分至少要4次有效连接。

### 第四个非显然突破

即使所有方向组已经通过相对关系联系成整体，没有绝对方向锚点时仍存在整体镜像二义性。

### 一般化

k 个不同正绝对值组：

```text
k个初始独立方向组
→ 最少 k−1 条有效相对关系把它们联系成整体
→ 再需要1条绝对方向信息定向
```

同时可以推广为多个独立部分各需要一个绝对方向锚点。

# 6｜Homework Elite Transfer

Homework 不重复主课“标签—绝对值对应关系已知”的模型。

它进一步删除：

```text
标签 ↔ 绝对值对应关系
```

学生必须发现：

> 即使知道每个标签的正负，也可能仍不能恢复坐标，因为还丢了“哪个幅度属于哪个标签”。

这用于检查 H9：是否把“问方向”机械当作所有信息恢复问题的万能方法。

# 9｜知识边界

本讲最高层虽然思维很深，但不正式教授：

- 含字母绝对值完整分类；
- 绝对值方程/不等式体系；
- 两点距离公式；
- 函数图象；
- 图论术语或定理；
- 正式组合数学/信息论。

“关系链”“独立方向部分”“每条有效关系最多合并两个部分”都用七年级可理解的自然语言论证。
