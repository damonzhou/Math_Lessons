# 3｜为什么 v2.3 的高阶核心使用 DESIGNED

v2.3 的能力目标不是“找一个较远/较近的数”，而是同时诊断：

1. 逆向绝对值；
2. 重复距离与相反数对；
3. 多条件筛选；
4. 独立自由选择；
5. 完整枚举；
6. 唯一性/穷尽性证明；
7. 最少附加信息；
8. 冗余条件；
9. 从具体状态推广到 k 个不同距离组。

在已核验的适龄 CEMC 直接绝对值/数轴题中，没有一题同时承担上述诊断功能。

因此本讲遵循：

> **宁可透明设计高区分度题，也不把简单真题包装成高难题。**

# 4｜Ceiling Diagnostic｜T0

## D0｜七标签折叠恢复

**标签**：`DESIGNED · Ceiling Diagnostic`

结构：

```text
7个标签
+ 两组重复绝对值
+ 三个单次绝对值
+ 多个大小/方向条件
→ 压缩自由选择
→ 完整恢复4种状态
→ 求最少左/右询问
```

### 当前知识可解性

只需要：

- 数轴左右；
- 相反数；
- 绝对值的距离意义；
- 基本大小关系；
- 小学阶段基本乘法计数直觉。

不需要 Lesson 6 的字母绝对值分类、不需要有理数加法、不需要组合数学公式。

### 诊断区分度

首个卡点可区分：

```text
A 逆向模型
B 条件筛选
C 枚举完整
D 完整性证明
E 最少信息证明
F 一般化
```

这比旧 v2.2 T0 的4对象记录器具有更高能力区分度。

# 5｜Ceiling Builder｜按短板分流

Builder 不再要求所有学生机械完成同一组题。

| 分支 | 针对短板 | 核心训练 |
|---|---|---|
| A | H3/H7/H9 | 正距离 → 左右候选 → 重复距离成对 |
| B | H1/H3/C5 | 每条条件具体排除哪个自由选择 |
| C | H5/C6 | 独立选择 × 独立选择 → 完整状态表 |
| D | H10/C8 | “足够” + “更少不够”的最少性证明 |
| E | T0 C5-A/B | k 个不同绝对值组的一般化 |

Builder 成功标准：

> 同类陌生题中，首个卡点提前消失。

# 6｜Elite / Final Challenge

## M0｜8标签 + 冗余条件 + 最少信息

**标签**：`DESIGNED · Elite / Final Challenge`

无单一原题。

结构依据：

- 当前人教版绝对值/相反数/数轴；
- S3/S4 的“距离对象辨析”；
- v2.3 能力上限要求；
- 本课程长期 H3/H5/H10 诊断模型。

核心结构：

```text
8标签
→ 3组重复绝对值
→ 大小条件锁定部分方向
→ 识别冗余条件
→ 剩3个独立二选一
→ 8种状态
→ 证明最少3次询问
→ 推广到 k 组距离
```

为什么达到 Elite：

- 计算量低；
- 需要持续组织多层信息；
- 逐个猜不能替代完整证明；
- 需要同时证明“足够”和“更少不够”；
- 需要判断条件必要性；
- 最终需要一般化。

# 7｜Homework Elite Transfer

## H0｜无序距离记录

**标签**：`DESIGNED · Elite Transfer`

主课保留：

```text
标签 ↔ 绝对值对应关系
```

只丢方向。

Homework 则同时丢失：

```text
方向
+
标签 ↔ 绝对值对应关系
```

因此即使不断询问“标签在左还是右”，也可能无法唯一恢复。

目的：检查学生是否真正理解“缺失了什么信息”，而不是机械套用“问方向即可恢复”。

# 10｜知识边界

本讲仍不正式教授：

- 含字母绝对值完整分类；
- 多层绝对值方程；
- 两点距离公式；
- 绝对值不等式；
- 函数图象；
- 正式组合数学/信息论术语。

“最少询问”只使用学生能理解的二选一状态区分，不依赖编码理论。
