# 2. 竞赛题源

## A1｜2023 MAA AMC 8, Problem 18

官方题目/解答入口：

https://maa.org/resource/sample-competition-2023-amc-8/

官方解答 PDF：

https://maa.org/wp-content/uploads/2024/08/2023_AMC8_Solutions_.pdf

该题是一个三类字母周期排列问题。官方解答中使用了“按3的周期/余数”分析，并利用：

$$
400=3\times133+1
$$

解释三类数量之间的差异。

### 本讲用途

不是照搬原题，而是用于支持：

- 按余数分类；
- 分类不重不漏；
- 周期问题中按模分类的竞赛价值。

本讲 Q13、Final Challenge 只借鉴“余数分类作为结构工具”，因此标记为 `ADAPTED / SYNTHESIS`，不标记为 AMC 原题。

## G1｜2026 CEMC Gauss Grade 7, Question 19

官方页面：

https://cemc.uwaterloo.ca/sites/default/files/documents/2026/2026Gauss7Contest.html

原题从100～199的正整数中，要求同时满足：

- 能被4整除；
- 数位和达到给定条件；

然后统计符合条件的整数数量。

### 本讲用途

支持“逐层筛选集合”的真实竞赛结构：

```text
全集
↓
满足整除条件
↓
再满足第二条件
```

主课 Q14 和课后 Q11 均做了明显简化和数值改写，所以属于 `ADAPTED`，不是 Gauss 原题。

# 5. Final Challenge审计

标记：

> **SYNTHESIS · A1/G1 + 本讲分类思想**

题目使用 $1,2,\ldots,N$，给出偶数数量和3的倍数数量，再要求用模6分类解释重叠，并思考模12为什么更细。

## 结构来源

- A1：AMC 8中的模3/周期分类；
- G1：Gauss中的整除条件逐层筛选；
- 本讲：同一批对象可以按不同标准分类，不同集合可能包含、互斥或相交。

## 知识边界检查

学生只需要：

- 倍数；
- 奇偶；
- 简单除法；
- 分类；
- 1到N的顺序数意识。

不要求正式同余符号，不要求容斥公式，不要求高级数论。

## 六项审核

- [x] 当前知识可解；
- [x] 题面没有提示“用最小公倍数/模6”；
- [x] 关键突破口是把两个性质统一到余数分类；
- [x] 有AMC/Gauss真实竞赛结构依据；
- [x] 有Hint 1～3；
- [x] 解后推广到模12和 $\mathrm{lcm}(a,b)$ 的直觉。

### 一个有意保留的开放性

由条件可得到：

$$
N=100\quad\text{或}\quad101
$$

而不是唯一值。

这是有意设计的 `DIAGNOSTIC-H10` 特征：学生不能因为题目问“N是多少”就默认答案唯一，必须回到所有条件检查。

# 7. 原创题保留理由

Lesson 2 的 `DESIGNED` 主要用于三个公开真题难以精确覆盖的教学目标：

1. 区分“一个数”与“这个数的写法”；
2. 暴露分类标准混用、集合重叠等概念错误；
3. 将分类思想迁移到程序条件分支。

这些属于概念诊断和迁移，不应为了追求真题比例而删除。
