## 1. Ceiling Diagnostic

类型：`SYNTHESIS · CEMC equal-spacing structure + opposite symmetry + DESIGNED-DIAGNOSTIC`

冷启动题使用5个等距点 P～T：Q 与 T 互为相反数，P = −8。

该题不是赛事原题，不标 `SOURCE`。它专门用于测试学生能否在“隐藏原点”方法正式教学前自行发现：

- 互为相反数 → 原点是对称中心；
- 原点可以落在 R、S 中间；
- 对称关系负责定位中心，等距条件负责恢复尺度；
- 删除等距条件后答案不唯一。

## 2. Ceiling Builder

类型：`DESIGNED · TRAINING`

训练链：

1. 用正、0、负三类反例/边界检查“−a 一定是负数”；
2. 删除等距条件，区分结构结论与尺度结论；
3. 逆向构造隐藏原点数轴；
4. 把“求相反数”抽象为操作 R，研究奇偶次复合。

## 3. Mastery Challenge

v2.0 把最终综合题改为“相反变换机器”，与 T0 的隐藏原点结构保持明显差异。

类型：`DESIGNED · MASTERY`。

目标是检查：

- 相反数是否真正理解为变换；
- 能否从具体次数推广到奇偶规律；
- 能否发现唯一不动点0。
