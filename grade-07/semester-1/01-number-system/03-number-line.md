# R0. 为什么有理数之后必须进入数轴

Lesson 2 回答了“有理数是什么”。

下一步要解决：

> **一个数除了写成符号，还能不能变成一个位置？**

数轴建立：

$$
\boxed{\text{数}\longleftrightarrow\text{直线上的位置}}
$$

这是后续相反数、绝对值、大小比较、距离、坐标和数形结合的共同基础。

# 第一部分：数轴为什么需要三个要素

## 3. 只有一条直线不够

想把数放到直线上，至少要知道：

- 从哪里开始计：**原点**；
- 哪边表示增大：**正方向**；
- 多长表示1个单位：**单位长度**。

缺少任何一个要素，数字位置都会不确定。

## 4. 数轴三要素｜MUST

```text
原点 + 正方向 + 单位长度
```

示意：

```text
←────|────|────|────|────|────→
    −2   −1    0    1    2
                  正方向 →
```

注意：示意图可以不按真实物理长度绘制；数学关系来自题设和刻度规则，不来自“看起来差不多”。

---

# 第二部分：数怎样变成点

## 5. 正数、负数和0的位置

规定正方向向右时：

- 正数在原点右侧；
- 负数在原点左侧；
- 0对应原点。

## 6. 分数和小数同样可以上数轴

例如 1/2 应在0与1的中间；1.5 应在1和2之间。

重点不是“整数刻度”，而是：

> **单位长度确定后，一个有理数就能对应到相应位置。**

## 7. 点与数不是同一个对象

一个点是几何对象；它在数轴上对应的数叫这个点的坐标。

因此应说：

> “点 A 表示数3”或“点 A 的坐标是3”。

不要把“点 A”和“数3”当成完全同一种对象。

---

# 第三部分：左右位置与大小

数轴正方向向右时：

> **右边的数大，左边的数小。**

例如 −2 在 −5 的右边，所以：

```text
−2 > −5
```

这里不要只背“负数绝对值越大越小”——绝对值还没正式学习。

先建立更根本的数轴直觉：

> **位置越靠右，数越大。**

---

# 第四部分：坐标与到0的距离不是同一个量

点表示 −4：

- 坐标是 −4；
- 它位于原点左边；
- 到0的距离是4个单位。

距离没有“向左/向右”的符号信息，而坐标有。

这一区分会直接帮助后面的相反数和绝对值。

# 第七部分：Ceiling Builder｜提升数形结构发现能力

## Builder 1｜两锚点恢复尺度

一条等距数轴上，点 P 表示 −7，点 S 表示2，P 到 S 之间正好隔3个相等间隔。

要求：

1. 不画“每格1”的默认图；
2. 先算一格代表多少；
3. 再恢复中间各点。

**训练能力**：先建立整体尺度，再读局部位置。

## Builder 2｜删掉“等距”会发生什么

把 Builder 1 的“等距”删除。

问：

- 中间点还唯一吗？
- 请画两条都满足端点坐标、但中间点数值不同的数轴。

**训练能力**：条件充分性 + 反例。

## Builder 3｜逆向构造一条非单位刻度数轴

自己设计5个等距点，使：

- 原点不在任何一个点上；
- 至少有2个负数点和2个正数点；
- 相邻刻度不是1；
- 给出两个锚点后，别人能够唯一恢复整条数轴。

**训练能力**：逆向构造 + 条件设计。

## Builder 4｜一般化

等距点从左到右编号为0、1、2、……。

若第 i 个点表示数 u，第 j 个点表示数 v，怎样用语言说明“一格代表多少”？

再说明第 k 个点的数值怎样由“起点 + 间隔数 × 每格变化”得到。

**训练能力**：从具体刻度走向一般线性结构。

# 第八部分：Advanced——非单位刻度与损坏数轴

## 8. 每格不一定是1

数轴只要求单位长度统一，并不要求题目每个标记点之间恰好相差1。

看到图先读刻度信息，不能凭小学经验补条件。

## 9. 两个锚点为什么足以恢复等距尺度

若两个已知点之间跨若干相等间隔，那么：

$$
\text{每格变化}=\frac{\text{两个已知数的差}}{\text{间隔数}}
$$

这不是要背一个新公式，而是：

> **总变化被相同的小段平均分配。**

## 10. 原点不一定已经画成一个刻度点

如果恢复后的0落在两个标记之间，这完全合法。

“原点必须是现成标记点”是 H3：擅自补隐藏条件。

# 第九部分：Olympiad / Informatics

## 11. 数轴恢复的三步结构

遇到损坏或缺标数轴：

```text
先确定顺序
→ 再恢复尺度
→ 最后恢复所有位置
```

这是 CEMC Gauss 等适龄题中常见且有迁移价值的结构。

## 12. 一维坐标与程序 offset

```cpp
int origin = 100;
int position = 97;
int offset = position - origin;
```

得到 offset = −3。

程序中的数组下标、存储编号和数学坐标不是同一概念。

能力迁移点：

> **先问数字代表位置、编号还是相对偏移。**

# 第十部分：错误实验室

1. **“数轴每格一定是1。”**——错，必须看单位长度或锚点。
2. **“图上看起来在中间，所以一定是中点。”**——错，示意图不能替代条件。
3. **“点的坐标是 −4，所以距离也是 −4。”**——错，坐标与距离不同。
4. **“原点必须是已有刻度。”**——错，0可以落在两刻度之间。
5. **“知道两个点就一定能恢复所有点。”**——只有在等距或其他尺度条件充分时才成立。
6. **“无法唯一确定就不用证明。”**——应构造两个不同合法模型。
