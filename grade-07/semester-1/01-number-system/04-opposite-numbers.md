# R0. 为什么相反数必须紧接数轴

Lesson 3 已建立：

$$
\boxed{\text{数}\longleftrightarrow\text{数轴上的位置}}
$$

现在观察 −4 与4：

```text
←────●────────────0────────────●────→
    −4                         4
```

它们：

- 到0距离相同；
- 位于0两侧；
- 关于原点对称。

因此相反数不是“字符变号游戏”，而是一个**关于原点的对称关系**。

# 第一部分：从数轴发现相反数

## 3. 一对特殊位置

```text
←────●────────0────────●────→
    −3                 3
```

−3 和3到0距离相同、方向相反。

1.5 与 −1.5 也有同样结构。

所以相反数的核心不是整数、小数还是分数，而是：

$$
\boxed{\text{关于原点对称}}
$$

## 4. 正式定义｜MUST

两个数在数轴上位于原点两侧，并且到原点距离相同，那么它们互为相反数。

例如：

- 5 与 −5；
- −2.4 与2.4；
- 3/7 与 −3/7。

“只有符号不同”是数轴对称在书写形式上的结果，不应取代几何理解。

---

# 第二部分：0为什么特殊

0就在原点。

原点关于自己对称以后仍然是原点，所以：

> **0的相反数是0。**

0是唯一与自己的相反数相同的数。

这也说明不能说“0没有正负号，所以没有相反数”。

---

# 第三部分：字母与负号

## 5. 数 a 的相反数

数 a 的相反数记作 −a。

这里“−”应该理解成：

> **取 a 的相反数。**

它不保证结果为负。

## 6. 为什么 −a 不一定是负数

必须分情况：

- a 为正数时，−a 为负数；
- a = 0 时，−a = 0；
- a 为负数时，−a 为正数。

例如 a = −6 时，−a = 6。

所以：

> **−a 的符号取决于 a 本身。**

这一步是从“具体数字”进入代数语言的重要转折。

---

# 第四部分：双重负号不是乘法里的“负负得正”

## 7. 连续求两次相反数

−(−5) 的意思是：

> 求 −5 的相反数。

因此结果为5。

一般地：

$$
\boxed{-(-a)=a}
$$

真正原因是：

> 一个点关于原点对称一次到另一侧，再对称一次回到原位置。

## 8. 多次求相反数

```text
3 → −3 → 3 → −3 → …
```

因此：

- 偶数次求相反数回到原数；
- 奇数次求相反数得到原数的相反数。

先理解操作，再总结规律。

# 第六部分：Ceiling Diagnostic｜T0 冷启动

> **SYNTHESIS · Ceiling Diagnostic · 无单一原题**

数轴上从左到右有5个等距点：P、Q、R、S、T。

已知：

- Q 与 T 表示的数互为相反数；
- P 表示 −8。

# 第七部分：Ceiling Builder｜提升对称与条件意识

## Builder 1｜反例训练：−a 一定是负数吗

对断言：

> “−a 一定是负数。”

要求分别给出：

1. 一个让它为真的 a；
2. 一个让它为假的 a；
3. 一个边界情况；
4. 用一句一般性语言说明何时为负、何时为0、何时为正。

**训练能力**：反例 + 边界 + 参数意识。

## Builder 2｜删条件：对称够不够恢复尺度

只知道两个点互为相反数，但不知道它们之间的刻度是否等距。

问：

- 能否恢复所有中间点数值？
- 哪些结论仍然成立？
- 哪些结论依赖等距？

**训练能力**：区分“结构结论”和“尺度结论”。

## Builder 3｜逆向构造隐藏原点

自己设计5个等距点，要求：

- 原点不在任何已标点上；
- 至少有一对点互为相反数；
- 给出另一个点的数值后，别人能唯一恢复全部点。

然后交换给别人求解。

**训练能力**：逆向构造 + 条件设计。

## Builder 4｜把“求相反数”看成一种变换

定义操作 R：输入一个数，输出它的相反数。

不要先写公式，回答：

1. 连续做2次会怎样？
2. 连续做3次呢？
3. 做2026次呢？
4. 哪个数做1次后不发生变化？
5. 为什么这个不动点只有一个？

**训练能力**：操作复合 + 奇偶结构 + 一般化 + 唯一性。

# 第八部分：Advanced

## 9. 隐藏原点

一对相反数在数轴上的对称中心一定是原点。

因此原点可能：

- 是一个已有刻度；
- 落在两个刻度之间；
- 在题目损坏后完全没有标出来。

不能因为“看不到0”就认为无法推理。

## 10. 负号的不同角色

负号至少会出现两种角色：

- 负数表示的一部分，如 −3；
- 取相反数的运算，如 −a。

以后减法和乘法中还会出现新的符号语义，因此现在必须建立“先看角色”的习惯。

## 11. 逆向问题

若一个数的相反数为7，则原数为 −7。

逆向题不要机械“再加一个负号”，而应回到：

> 哪个点关于原点对称后会到7？

---

# 第九部分：Olympiad / Informatics

## 12. 对称中心 + 尺度

在等距数轴中，一对相反数可以帮助定位原点；另一个已知坐标可以帮助恢复尺度。

这是“几何结构 + 数值尺度”组合，而不是单一公式题。

## 13. Informatics：unary negation

程序中的单目负号可以看成“取相反数”的操作。

```cpp
int x = -7;
int y = -x;
```

得到 y = 7。

但程序中的固定宽度整数存在溢出等机器边界；本讲只讨论数学意义，不提前展开机器整数细节。

# 第十部分：错误实验室

1. **“−a 一定是负数。”**——错，必须看 a 的符号。
2. **“0没有相反数。”**——错，0的相反数是0。
3. **“两个数一正一负就是相反数。”**——错，还要大小对应、关于原点对称。
4. **“−(−a)=a 是因为负负得正。”**——本讲错误解释；这里是连续求两次相反数。
5. **“相反数的对称中心一定已经画成0刻度。”**——错，原点可能隐藏。
6. **“只知道互为相反数就能恢复整条数轴。”**——尺度还需要足够条件。
7. **“条件不足就凭图补等距。”**——典型 H3，应构造不同模型检查。

# 第十一部分：Mastery Challenge｜相反变换机器

> **DESIGNED · Mastery Challenge**

定义一个数学操作 R：每次把输入数变成它的相反数。

回答：

1. 输入 −7，连续执行 R 2026次，输出什么？

4. 解释为什么执行偶数次一定回到原数，奇数次一定得到原数的相反数。
5. 为什么第3问的答案只有0？请用数轴对称或代数语言证明唯一性。
