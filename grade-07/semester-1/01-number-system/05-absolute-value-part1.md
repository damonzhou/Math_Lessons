# 3｜Concept Deepening｜绝对值到底做了什么

## 3.1 绝对值是“信息压缩”

一个数的坐标同时包含：

```text
离0多远
+
在0左边还是右边
```

绝对值只留下第一项。

例如：

```text
−5 → 5
 5 → 5
```

可以理解为：

> **把数轴关于原点折叠，只保留到原点的距离。**

由此直接理解：

1. 相反数绝对值相同；
2. 一个正距离通常对应左右两个原位置；
3. 0是唯一只对应一个原位置的距离。

## 3.2 正向与逆向不是同一个问题

```text
已知位置 → 求距离
```

通常唯一。

```text
已知距离 → 恢复位置
```

通常不唯一。

以后看到绝对值题先问：

> **现在是在压缩信息，还是在恢复已经丢掉的信息？**

## 3.3 为什么固定正距离最多只有两个位置

一维数轴上，从0出发固定距离：

- 向左一个位置；
- 向右一个位置。

只有两个方向，所以没有第三个不同位置。

# 4｜School Advanced｜从一个绝对值升级到多对象恢复

## A1｜重复绝对值意味着什么

4个互不相同的整数，绝对值依次为：

```text
4，1，4，6
```

回答：

1. 两个绝对值为4的原数是什么关系？
2. 绝对值为1和6的原数各有几个方向选择？
3. 一共有多少种可能的有序四元组？
4. 怎样证明已经列完？

**目标**：从“逐个猜”升级到“找独立选择”。

## A2｜顺序条件怎样消除方向

点 A、B 的绝对值分别为5和2，且：

```text
A < B
```

1. 列出全部合法 `(A,B)`；
2. 哪些方向组合被 `A < B` 排除了？
3. 再增加 `B > 0`，为什么答案唯一？
4. 如果增加的是 `B < 0`，是否也能唯一？
5. 如果反而增加 `A > 0`，为什么会变成无解？

**目标**：新增条件可能筛选到唯一，也可能与原条件冲突；必须逐条判断。

# 5｜Ceiling Diagnostic｜T0 冷启动

## 七个标签被“折叠”以后

> **DESIGNED · Ceiling Diagnostic · ★★★★**  
> **首次独立20～25分钟。禁止先看 Hint。**

有7个互不相同的整数位置 P、Q、R、S、T、U、V。

距离记录器只保存到原点0的距离：

```text
|P| = 6
|Q| = 3
|R| = 6
|S| = 1
|T| = 3
|U| = 4
|V| = 2
```

另外知道：

```text
P < Q
R > S
T < U
V > 0
```

回答：

1. 哪些坐标可以直接确定？
2. 列出全部合法 `(P,Q,R,S,T,U,V)`。
3. 证明答案不重不漏。
4. 最终还剩哪两个彼此独立的二选一信息？
5. 如果只能询问“某个指定点在0左边还是右边”，最少再问几次才能唯一恢复？给出方案。
6. 为什么少问一次一定不够？
7. 删除 `V > 0` 后，合法情况数怎样变化？先找结构，不逐个乱猜。
8. 哪一步是你的首个卡点：候选、条件、枚举、完整性证明、最少信息，还是一般化？

### T0 首个卡点编码

```text
A 不能从重复绝对值看出相反数对
B 会列候选，但不会利用大小条件
C 条件会用，但枚举漏情况
D 能列全，但不会证明完整
E 能恢复，但不会证明最少附加信息
F 能独立解决并抽象“独立二选一”结构
```

短板分流见：[能力诊断](./diagnostics/05-absolute-value-part1-habits.md)。

# 6｜Ceiling Builder｜按首个短板分流

## Builder A｜逆向模型弱

适用：A型 / H7 / H9。

训练：

```text
正距离
→ 左候选
→ 右候选
→ 重复距离 + 原数互异
→ 相反数对
```

## Builder B｜条件筛选弱

适用：B型 / H1 / H3。

每加入一条条件都写：

```text
加入前多少可能
→ 排除什么
→ 加入后多少可能
```

## Builder C｜枚举不完整

适用：C/D型 / H5 / H10。

改用：

```text
选择1：Q/T谁在左
选择2：S在左还是右
```

形成 2 × 2 完整表，并证明没有第三个自由选择。

## Builder D｜最少信息判断弱

适用：E型。

把4种候选画成状态卡，设计两问决策树，同时证明一问不够。

## Builder E｜T0 已达到 C5-A/B

不做机械求值题，直接推广：

> 对一组互不相同非零数，如果已知每个标签的绝对值，怎样判断还剩几个独立方向选择？

推广到 k 个不同正距离组。

# 8｜Elite / Final Challenge｜8个标签与最少信息

> **DESIGNED · Elite / Final Challenge · ★★★★～★★★★★**  
> **无单一原题；结构依据见 provenance。**  
> 建议完整独立思考20～30分钟。

8个互不相同的非零整数 A、B、C、D、E、F、G、H 满足：

```text
|A| = 8
|B| = 3
|C| = 1
|D| = 8
|E| = 5
|F| = 3
|G| = 1
|H| = 2
```

另外知道：

```text
A < B
D > E
F < G
```

回答：

1. 不先枚举全部情况，哪些标签被条件强迫确定？
2. 哪些绝对值组仍保留方向不确定性？
3. 用结构化方式描述全部合法配置，并证明为什么恰好有8种。
4. `A < B` 与 `D > E` 是否都不可缺少？分别删除其中一个，合法配置是否增加？
5. `F < G` 是否不可缺少？删除后合法配置怎样变化？
6. 如果继续询问“指定标签在0左边还是右边”，最少还要问几次才能唯一恢复？给出方案。
7. 证明不可能用更少询问完成恢复。
8. 一般化：有 n 个互不相同的非零数，已知每个标签的绝对值。若共有 k 个不同的正距离，而且没有其他顺序信息，那么最坏情况下至少需要多少个“左/右”询问才能唯一恢复？说明理由。

### Final 评价重点

不是只看“8种”“3问”是否算对。

真正检查：

- 是否先识别相反数对；
- 是否把自由度压缩成独立选择；
- 是否识别冗余条件；
- 是否能证明不重不漏；
- 是否能证明“最少”；
- 是否能一般化。

Hint / Full Solution：[Ceiling v2.3](./solutions/05-absolute-value-part1-ceiling-v2.3.md)。

# 9｜错误实验室

## 错误1｜已知绝对值就默认正数

对应 H3。

检查：原点另一侧是否也满足？

## 错误2｜发现相反数对后就停止

对应 H10。

还要检查：

- 哪个标签在左；
- 哪些单次绝对值仍有方向选择；
- 是否还有独立自由度。

## 错误3｜逐个猜，没有建立独立选择

对应 H5/H9。

先找自由选择，再组合。

## 错误4｜用了条件，却不知道条件是否必要

高阶解题必须问：

> **这条条件具体排除了什么？是不是冗余？**

## 错误5｜只证明“这么多问够了”，没有证明“更少不够”

对应 H10。

最少性需要：

```text
上界：给方案
+
下界：证明更少不够
```
