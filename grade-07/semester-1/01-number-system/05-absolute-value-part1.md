# 3｜Concept Deepening｜绝对值到底做了什么

## 3.1 从“求值”升级到“信息变化”

一个数的坐标同时包含：

```text
离0多远
+
在0左边还是右边
```

绝对值只留下第一项。

例如：

```text
−5 → 5
 5 → 5
```

所以绝对值可以理解成：

> **把数轴关于原点折叠，只保留到原点的距离。**

这解释了三个事实：

1. 相反数绝对值相同；
2. 一个正距离通常对应左右两个原位置；
3. 0是唯一只对应一个原位置的距离。

## 3.2 正向与逆向不是同一个问题

正向：

```text
已知位置
→ 求距离
```

通常唯一。

逆向：

```text
已知距离
→ 恢复位置
```

通常不唯一。

以后看到绝对值题，先明确：

> **现在是在压缩信息，还是在尝试恢复已经丢掉的信息？**

## 3.3 为什么同一个正距离最多只有两个位置

在一条数轴上，从原点出发：

- 向左走固定距离得到一个点；
- 向右走同样距离得到一个点。

只有两个方向，所以不会出现第三个不同点还与原点保持同一固定距离。

这不是“背 ±”，而是数轴的一维结构。

# 4｜School Advanced｜从一个绝对值升级到多对象恢复

## A1｜重复绝对值意味着什么

4个互不相同的整数，绝对值依次为：

```text
4，1，4，6
```

回答：

1. 两个绝对值为4的原数之间是什么关系？
2. 绝对值为1和6的原数各有几个方向选择？
3. 不增加任何方向条件时，一共有多少种可能的有序四元组？
4. 怎样证明已经列完？

**目标**：从“每个数单独想”升级到“识别独立选择”。

## A2｜顺序条件怎样消除方向

点 A、B 的绝对值分别为5和2，且 A < B。

1. 列出全部合法 `(A,B)`；
2. 哪些方向组合被 A < B 排除了？
3. 再增加“A > 0”，为什么立即唯一？
4. 如果增加的是“B < 0”，是否也能唯一？

**目标**：条件不是装饰；要说清它具体排除了哪些情况。

# 5｜Ceiling Diagnostic｜T0 冷启动

## 七个标签被“折叠”以后

> **DESIGNED · Ceiling Diagnostic · ★★★★**  
> **首次独立20～25分钟。禁止先看 Hint。**

有7个互不相同的整数位置 P、Q、R、S、T、U、V。

距离记录器只保存它们到原点0的距离：

```text
|P| = 6
|Q| = 3
|R| = 6
|S| = 1
|T| = 3
|U| = 4
|V| = 2
```

另外知道：

```text
P < Q
R > S
T < U
V > 0
```

回答：

1. 哪些坐标可以不分类就直接确定？
2. 列出全部合法的 `(P,Q,R,S,T,U,V)`。
3. 证明你的答案不重不漏。
4. 最终还剩下哪两个彼此独立的二选一信息？
5. 如果允许询问“某个指定点在0左边还是右边？”这种只能回答“左/右”的问题，最少再问几次才能唯一恢复全部7个坐标？设计具体询问方案。
6. 为什么少问一次一定不够？
7. 删除条件 `V > 0` 后，合法情况数怎样变化？不要逐个乱猜，先找结构。
8. 这道题最难的部分对你来说是哪一步：建立候选、使用条件、完整枚举、证明最少信息，还是一般化？

### T0 观察重点

教师/家长不要只记最终对错，记录**第一个真正卡点**：

```text
A 不能从重复绝对值看出相反数对
B 能列候选，但不会利用大小条件
C 条件会用，但枚举漏情况
D 能列全，但不会证明完整
E 能恢复，但不会判断最少附加信息
F 能独立解决并抽象“独立二选一”结构
```

对应短板训练见：[能力诊断](./diagnostics/05-absolute-value-part1-habits.md)。

Hint 1～3 与完整解答见：[Ceiling v2.3](./solutions/05-absolute-value-part1-ceiling-v2.3.md)。

# 6｜Ceiling Builder｜不再所有学生做同一套

T0 后只训练暴露出来的短板。

## Builder A｜逆向模型弱

适用：T0-A / H7 / H9。

对每个正距离先写：

```text
距离
→ 左候选
→ 右候选
```

再处理重复距离为什么会强迫两个不同标签占据左右两点。

## Builder B｜条件筛选弱

适用：T0-B / H1 / H3。

把每条条件逐条加入，记录：

```text
加入前有多少可能
→ 这条条件排除哪些
→ 加入后剩多少
```

训练“不跳过条件作用”。

## Builder C｜枚举不完整

适用：T0-C/D / H5 / H10。

不用“凭感觉列”，改用选择表：

```text
选择1：Q/T谁在左
选择2：S在左还是右
```

形成 2 × 2 的完整表，再证明没有第三个自由选择。

## Builder D｜最少信息判断弱

适用：T0-E。

先把4种候选写成4张状态卡。

每次“左/右”询问最多把当前候选分成两组。

要求自己设计两问决策树，并解释为什么一问不可能区分4种状态。

## Builder E｜T0 已达到 C5-A/B

不做机械求绝对值题，直接推广：

> 对一组互不相同的非零数，如果已知每个标签的绝对值，怎样判断还剩几个独立的“方向选择”？

先从3组绝对值开始，再推广到 k 组不同正距离。

# 8｜Elite / Final Challenge｜8个标签与最少信息

> **DESIGNED · Elite / Final Challenge · ★★★★～★★★★★**  
> **无单一原题。结构依据见 provenance。**  
> 建议完整独立思考20～30分钟。

8个互不相同的非零整数位置 A、B、C、D、E、F、G、H 的绝对值分别为：

```text
|A| = 8
|B| = 3
|C| = 1
|D| = 8
|E| = 5
|F| = 3
|G| = 1
|H| = 2
```

另外知道：

```text
A < B
D > E
F < G
```

回答：

1. 先不要枚举全部情况。哪些标签的坐标被这些条件直接强迫确定？
2. 哪些绝对值组仍保留方向不确定性？
3. 用结构化方式描述全部合法配置，并说明为什么恰好有8种。
4. 条件 `A < B` 与 `D > E` 是否都不可缺少？分别删除其中一个，合法配置是否增加？解释原因。
5. 条件 `F < G` 是否不可缺少？删除后合法配置会怎样变化？
6. 如果此时允许继续询问“指定标签在0左边还是右边”，最少还要问几次才能唯一恢复全部坐标？给出具体方案。
7. 证明不可能用更少的询问完成恢复。
8. 一般化：有 n 个互不相同的非零数，已知每个标签的绝对值。若这些绝对值中共有 k 个不同的正距离，而且没有其他顺序信息，那么最坏情况下至少需要多少个“左/右”询问才能唯一恢复所有标签？说明理由。

### Final Challenge 评价标准

不是只看“8种”或“3次”是否算对。

真正检查：

- 是否先发现成对绝对值对应相反位置；
- 是否把自由选择压缩成少数独立变量；
- 是否识别冗余条件；
- 是否能证明枚举完整；
- 是否能证明“最少询问”；
- 是否能从具体8个标签推广到一般 k 组距离。

Hint / Full Solution：[Ceiling v2.3](./solutions/05-absolute-value-part1-ceiling-v2.3.md)。

# 9｜错误实验室

## 错误1｜已知绝对值就默认正数

对应 H3。

检查：原点另一侧是否同样满足？

## 错误2｜发现相反数对后就停止

对应 H10。

还必须检查：

- 哪个标签对应左边；
- 哪些单次出现的绝对值仍有方向选择；
- 是否还有独立自由度。

## 错误3｜逐个猜配置，没有建立独立选择

对应 H5/H9。

改进：先找“自由选择变量”，再组合。

## 错误4｜把条件都用了，但说不出哪条条件真正有用

对应 H1/H3。

高阶解题不仅要会用条件，还要判断：

> **这条条件必要吗？它排除了什么？它是不是冗余的？**

## 错误5｜说“至少需要3问”，但没有证明

对应 H10 / D4。

最少性必须同时证明：

```text
3问足够
+
2问不够
```
