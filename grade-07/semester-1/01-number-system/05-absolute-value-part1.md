# R0.5｜教材覆盖底线

当前人教版“绝对值”节点至少保证：

- 绝对值表示数轴上对应点到原点0的距离；
- 会求正数、负数、0的绝对值；
- 绝对值不为负；
- 相反数绝对值相等；
- 正距离通常对应原点左右两个位置；
- 0是特殊边界。

这些是**必须会**，不是本讲难度上限。

# 3｜Concept Deepening｜绝对值到底保留了什么

## 3.1 一个坐标含两类信息

一个非零位置至少同时告诉你：

```text
离0多远
+
在0左边还是右边
```

绝对值只保留第一类。

例如：

```text
−5 → 5
 5 → 5
```

所以绝对值不是简单“改写符号”，而是把两个不同位置压到同一个距离记录上。

## 3.2 正向容易，逆向会丢信息

```text
坐标 → 绝对值
```

通常唯一。

但：

```text
正绝对值 → 原坐标
```

通常有左右两个候选。

这说明一个重要思想：

> **一个操作可以容易正向计算，却不一定能够唯一逆向恢复。**

## 3.3 0为什么特殊

距离为0只能停在原点，因此：

```text
|x| = 0
```

只能对应：

```text
x = 0
```

而正距离 d 通常对应：

```text
−d 和 d
```

# 4｜School Advanced｜从单点恢复走向相对方向

这里仍然属于教学层，不承担最终能力上限。

## A1｜“同侧”能告诉我们多少

已知两个非零点 A、B：

```text
|A| = 2
|B| = 5
```

并知道 A、B 在0同一侧。

回答：

1. 全部 `(A,B)` 是什么？
2. “同侧”相比只知道两个绝对值，排除了哪些情况？
3. 为什么仍然不能唯一恢复？
4. 再增加哪一条最简单的方向信息可以唯一恢复？

## A2｜“异侧 + 一个方向锚点”

已知：

```text
|P| = 3
|Q| = 7
```

P、Q 位于0两侧，并且 P > 0。

1. 求 P、Q；
2. 如果删除 `P > 0`，还剩几种？
3. 比较“P、Q异侧”和“P>0”两类信息的作用：哪一个告诉相对方向，哪一个告诉绝对方向？

## A3｜条件是否真的增加信息

已知：

```text
|M| = |N| = 6
```

且 M、N 是两个不同的数。

有人再补充：“M、N 在0两侧。”

问：

1. 这条新条件有没有排除任何候选？
2. 它是不是冗余条件？
3. 什么条件才真正能决定 M、N 谁在右侧？

答案见：[Gap Check / 当堂答案](./solutions/05-absolute-value-part1-classroom.md)。

# 5｜Ceiling Diagnostic｜T0 冷启动

## 六个点只留下“相对方向”

> **DESIGNED · Ceiling Diagnostic · ★★★★**  
> **首次独立25～35分钟。不要先看 Hint。**

六个互不相同的非零整数 A、B、C、D、E、F 满足：

```text
|A| = 1
|B| = 3
|C| = 4
|D| = 6
|E| = 8
|F| = 10
```

另外只知道下面5条关系：

```text
A 与 B 在0同一侧
B 与 C 在0两侧
C 与 D 在0同一侧
D 与 E 在0两侧
E 与 F 在0同一侧
```

没有告诉任何一个点究竟在0左边还是右边。

### 问题

1. 不枚举64种正负号，求出全部可能的 `(A,B,C,D,E,F)`。
2. 证明答案**恰好只有两组**，不是“我试出来只有两组”。
3. 比较这两组答案。你能发现一个把整组答案互相变换的操作吗？
4. 为什么所有绝对值条件和5条“同侧/异侧”关系在这个操作后都保持成立？
5. 假设继续补充任意多条信息，但这些信息仍然只谈：
   - 某点的绝对值；
   - 两点同侧还是异侧。
   能不能最终区分这两组？给出证明。
6. 如果允许再问一次：

   > “某个指定点是否在0右侧？”

   最少问几次可以唯一恢复全部6个点？给出方案，并证明更少不够。
7. 删除关系 `C 与 D 在0同一侧` 后，不逐项枚举，判断合法配置会变成多少组，并解释为什么。
8. 你认为本题真正的突破口是什么？是“绝对值有正负两种”还是更深的结构？

### T0 首个卡点

```text
A 只能逐个试正负，无法沿关系传播
B 能找到两组，但看不出它们是整体镜像
C 看出整体镜像，但不会证明这类信息永远无法区分镜像
D 不会分析删除一条关系后为什么出现两个可独立翻转的部分
E 能解具体题，但不会证明最少1位绝对方向信息
F 能独立完成并形成一般化猜想
```

# 6｜Ceiling Builder｜只补首个真实卡点

## Builder A｜从关系传播，而不是枚举

若已假设 A 在右侧，就沿：

```text
同侧 → 保持方向
异侧 → 翻转方向
```

一路推出 B、C、D、E、F。

目标：把64种暴力尝试压缩成“选一个起点方向 → 全部传播”。

## Builder B｜发现整体镜像

把一组合法配置中的每个坐标都换成相反数。

检查：

- 每个绝对值变了吗？
- 任意两点“同侧/异侧”关系变了吗？

目标不是记结论，而是理解：

> **有些信息只描述相对关系，因此无法提供整个系统朝左还是朝右的绝对方向。**

## Builder C｜从“一条链”到“两个独立部分”

删除 T0 中间的一条关系后，六个点被分成两个互不联系的部分。

分别问：

- 左边这一部分能否整体翻转？
- 右边这一部分能否独立整体翻转？

目标：从“整体只有一个翻转自由度”升级到“多个部分各自有翻转自由度”。

## Builder D｜最少性不是只给方案

统一写法：

```text
充分：给出1个方向询问，说明怎样恢复全部点
必要：没有任何绝对方向信息时，整体镜像两组始终同时合法
```

两部分都写完，才能叫“最少1问”。

## Builder E｜高水平学生直接一般化

不要再做换数字题。研究：

> n 个标签的绝对值都已知，若若干“同侧/异侧”关系能够把所有标签联系成一个整体，那么为什么所有符号通常只剩“整组翻转”的两种？

再研究：

> 如果这些关系把标签分成 c 个彼此没有联系的部分，会留下多少个可以独立翻转的方向选择？

不要求使用图论术语。

# 8｜Elite / Final Challenge｜怎样用最少关系恢复所有方向

> **DESIGNED · Elite / Final Challenge · ★★★★★**  
> **无单一原题；设计与候选题源审查见 provenance。**  
> 建议完整独立思考30～45分钟。题面不提示“关系网络”“连接”等方法。

有8个互不相同的非零整数 A、B、C、D、E、F、G、H，已知：

```text
|A| = |B| = 1
|C| = |D| = 4
|E| = 6
|F| = 9
|G| = |H| = 12
```

现在要设计一种“低成本记录方案”。系统已经保存上面的绝对值信息。你还可以额外保存两种信息：

```text
类型Ⅰ：指定两个标签，记录它们在0同侧还是异侧
类型Ⅱ：指定一个标签，记录它在0左侧还是右侧
```

系统规定：**最终只允许保存1条类型Ⅱ信息。**

### 第一层｜先找真正的自由度

1. 不添加任何新记录时，一共有多少种不同的有标签坐标配置？不要从 `2^8` 开始暴力枚举。
2. 为什么 A/B、C/D、G/H 各自已经天然知道“异侧”，却仍然各保留一个方向选择？
3. 经过这些强制关系以后，真正彼此独立的“方向组”有几个？说明它们分别是什么。

### 第二层｜设计最少记录

4. 为了让“1条类型Ⅱ信息”最终足以恢复全部8个坐标，最少还要保存多少条类型Ⅰ信息？
5. 给出一套具体记录方案，并演示怎样从这些记录唯一恢复全部坐标。
6. 证明你的类型Ⅰ信息数量**不能再少**。证明不能只说“我觉得不够”，要解释每增加一条类型Ⅰ关系最多能消除什么不确定性。

### 第三层｜为什么绝对方向不能完全省掉

7. 即使类型Ⅰ关系已经设计得足够好，如果完全不允许类型Ⅱ信息，能否唯一恢复？为什么？
8. 给任意一组满足全部类型Ⅰ关系的配置，构造另一组无法被所有类型Ⅰ信息区分的配置。

### 第四层｜一般化

9. 推广：若一批互不相同的非零有理数中，共出现 k 个不同的正绝对值，并且每个绝对值最多出现两次。只保存“标签—绝对值对应关系”后，为什么可以把问题看成 k 个独立方向组？
10. 若最终只允许1条绝对方向信息，为了保证所有方向唯一恢复，最少需要多少条有效的“同侧/异侧”关系把这些方向组联系起来？给出一般结论并证明充分性与必要性。
11. 如果不限制类型Ⅱ信息的数量，你能设计另一种总记录数同样最少、但结构不同的方案吗？比较两种方案。

### Final 真正考察

```text
重复绝对值
→ 自动产生相反方向约束
→ 识别真正独立的方向组
→ 设计相对关系把它们联系起来
→ 用1个绝对方向锚点定向
→ 证明方案足够
→ 证明更少一定不够
→ 解释整体镜像为什么要求至少一个绝对方向锚点
→ 推广到 k 组
```

注意：如果只是把8个标签逐项列正负号，即使最后算对，也没有达到本题目标。

# 9｜错误实验室

## 错误1｜知道绝对值就默认正数

对应 H3。

检查：原点另一侧是否也满足？

## 错误2｜“同侧/异侧关系很多，所以一定唯一”

错误。

相对方向信息再多，也可能缺少整个系统的绝对方向。

检查：把所有点同时换成相反数后，条件是否全部仍成立？

## 错误3｜给出一套可行记录方案，就说“最少”

错误。

```text
最少性
=
充分性：这么多确实够
+
必要性：再少一定不够
```

## 错误4｜把“标签个数”当成“独立方向个数”

重复正绝对值并且原数互不相同时，两标签已经被强制成一对相反数。

真正应数的是仍可独立翻转的方向组。

## 错误5｜前面学过信息丢失，就机械做 ± 枚举

v2.4 的要求是先找结构、对称和自由度，而不是把所有符号组合列完。
