# Lesson 7 Release Review｜有理数大小比较｜v2.2

> **课程标准**：v2.2  
> **结论**：PASS

## R0｜Mainline 定位
PASS。大小比较是当前人教版“有理数”正式主线节点，必须在数轴、相反数、绝对值之后完成，才能进入数轴综合和有理数运算。

## R0.5｜教材映射
PASS。当前人教版七上 · 有理数 · 有理数大小比较；DIRECT。

## R1｜课程逻辑
PASS。数轴顺序 → 正/0/负 → 同正比较 → 同负比较 → 混合表示 → 条件问题 → 镜像一般化 → 排序/唯一性。

## R2｜教材完整覆盖
PASS。覆盖数轴左右顺序、正负与0、两个负数借绝对值比较、多数排序、分数小数混合表示。

## R3｜概念深度
PASS。所有规则回到“右大左小”；负数比较通过原点镜像解释，不把“绝对值大的反而小”作为无理由口令；明确原数大小与到0距离不同。

## R3.5｜Ceiling Diagnostic
PASS。T0“镜像四卡片”在 Advanced 一般化前测试：结构发现、顺序反向、距离与数值辨析、删条件反例和一般化。

## R3.6｜Ceiling Builder
PASS。Builder 覆盖条件变化、规则边界、逆向构造、完整排序和比较器决策树，目标是改变比较行为而非增加题量。

## R3.7｜思维深度，而非计算难度
PASS。

覆盖 D1～D6：

- D1：从 0 < a < b 自行发现镜像后 −b < −a；
- D2：研究 |x| 与 |y| 的关系在不同符号条件下是否足够；
- D3：反驳“绝对值大则原数大”等错误规则；
- D4：Final Challenge 要求证明排序唯一，删条件后完整列举；
- D5：从具体绝对值列表推广到 0 < c < a < b；
- D6：数轴 ↔ 绝对值 ↔ 区间 ↔ 比较器 ↔ 海拔迁移。

高阶部分即使把数字计算大幅降低，仍保留结构发现、条件筛选、唯一性和一般化，因此通过 v2.2。

## R4｜知识边界
PASS。不提前系统教授有理数加减、不等式变形、复杂绝对值不等式、两点距离公式或函数语言。

## R5｜应用场景
PASS。区间、比较器、海拔高度差分别承担双边条件、算法分支和陌生迁移，不是只换故事。
