# R3｜概念深度

**结论：PASS**

没有把绝对值规则退化成“去符号”。

本讲明确处理：

```text
条件 → 分类
分界点 → 边界0
正向规则 → 逆向条件
具体数 → 字母参数
一个例子 → 反例/全部情况
```

特别强调：

- −a 不一定为负；
- 条件不足时允许“不能进一步化简”；
- a = 0 同时满足两种逆向关系；
- 同绝对值不等于原数必相等。
