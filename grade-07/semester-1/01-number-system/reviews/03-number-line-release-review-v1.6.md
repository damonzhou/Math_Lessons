# R0｜主线定位

2022课标明确要求“能用数轴上的点表示有理数”，并借助数轴理解相反数和绝对值。

因此：

$$
\text{有理数}\rightarrow\text{数轴}\rightarrow\text{相反数}\rightarrow\text{绝对值}
$$

是强知识依赖链。

原集合/分类/余数专题已迁入 `extensions/`，旧 Mainline 文件已删除。

**PASS**。

# R3｜概念理解深度

学生不仅要会画数轴，还要解释：

1. 三个要素为什么缺一不可；
2. 点与数为什么不是同一个对象；
3. 坐标与距离为什么不同；
4. 为什么负数越靠右越大；
5. 单位长度改变为什么不改变数值关系；
6. 为什么“每个有理数有对应点”不能反推“所有点都是有理数”。

# R5｜应用场景

不同场景承担不同数学功能：

- 温度计 → 原点/方向/刻度；
- 海拔 → 基准两侧位置；
- 测量刻度 → 数值与位置映射；
- 一维机器人 → signed coordinate；
- world coordinate 与数组下标 → 坐标和存储编号区别。

不是简单换故事背景。

**PASS**。

# R11｜Markdown / LaTeX 渲染稳健性
