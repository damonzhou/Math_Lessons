# R0｜主线定位

2022课标第四学段“有理数”明确要求：

- 能用数轴上的点表示有理数；
- 借助数轴理解相反数和绝对值。

所以：

$$
\text{有理数}\rightarrow\text{数轴}\rightarrow\text{相反数}\rightarrow\text{绝对值}
$$

是强知识依赖链。

原“集合/分类/余数”专题虽然数学价值高，但不是这里更强的主线依赖，已迁入 `extensions/`。

数轴应作为正式 Lesson 3。

**PASS**。

# R3｜概念理解深度

重点不是只会画轴，而是解释：

1. 三个要素为什么缺一不可；
2. 点与数为什么不是同一个对象；
3. 坐标与距离为什么不同；
4. 为什么负数越靠右越大；
5. 单位长度改变为什么不改变数值关系；
6. 为什么“每个有理数有对应点”不能反推“所有点都是有理数”。

概念边界完整。

**PASS**。

# R4｜知识边界

没有正式教授：

- 相反数定义；
- $|a|$；
- $|a-b|$；
- 中点公式；
- 高中实数—数轴完整一一对应理论。

允许的伏笔仅为：

- 到0的距离；
- 两边等距；
- 以后还有无理数点。

**PASS**。

---

# R5｜应用场景

不同场景承担不同数学功能：

- 温度计 → 原点/方向/刻度；
- 海拔 → 基准两侧位置；
- 测量刻度 → 数值与位置映射；
- 一维机器人 → signed coordinate；
- world coordinate 与数组下标 → 数学坐标和存储编号区别。

不是机械换故事。

**PASS**。

# R9｜Final Challenge

- 标签先利用左右顺序归位；
- 两个锚点求单位刻度；
- 恢复所有点；
- 找原点；
- 观察等距点对；
- 改变标签后判断0是否仍落在刻度。

真正突破口：

$$
\boxed{\text{顺序}\rightarrow\text{尺度}\rightarrow\text{整体恢复}}
$$

不依赖相反数、绝对值公式或集合 Extension。

**PASS**。
