# R8｜错误与做题习惯

**结论：PASS**

重点错误：

- 把绝对值当位置；
- 距离写成负数；
- 默认正方向；
- 同绝对值误判原数相等；
- 原数大小与距离大小混淆；
- 逆向漏另一侧；
- 找到一个答案后不检查唯一性。

对应 H3/H5/H7/H9/H10，并有专门 diagnostics 文件。

与历史真实“条件不足却默认位置关系”的 H3 问题形成迁移训练。
