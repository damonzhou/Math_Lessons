## R2｜教材完整覆盖

PASS。

- 0边界；

基础采用 Gap Check，不重复占用高阶课时。

```text

```

不是从零重复绝对值定义。

## R3｜概念深度

PASS。

绝对值被解释为：

```text
坐标信息
→ 只保留到0距离
→ 可能丢失左右方向
```

进一步区分：

- 相对方向信息；
- 绝对方向信息；
- 标签—距离对应关系。

这为 T0/Final 提供知识基础，但没有提前泄露整体镜像结论。

## R3.5｜Ceiling Diagnostic

PASS。

T0 不再使用旧版“多标签 ± 枚举”。

新 T0：六个绝对值两两不同，只给连续的同侧/异侧关系，不给任何绝对方向。

至少包含两个非显然节点：

1. 选定一个起点方向后，可沿关系传播全部方向，从64种表面组合压缩到2种；
2. 两种配置是整体关于0镜像，且绝对值、同侧/异侧信息在整体镜像下全部不变，因此任意多同类信息都不能唯一化。

删除中间关系后，还要求发现两个部分可独立翻转。

## R3.6｜Ceiling Builder

PASS。

Builder 分流针对：

- 暴力枚举 → 关系传播；
- 得到两解但不见结构 → 整体镜像；
- 会观察不会证明 → 不变性/不可辨识证明；
- 不会处理断开关系 → 独立方向部分；
- 只会给方案 → 最少性下界；
- 具体题稳定 → k组一般化。

不堆同构练习。

## R3.7｜思维深度

PASS。

覆盖：

- D1 结构发现：整体镜像、方向组；
- D2 必要/充分：什么信息能够真正打破镜像；
- D3 反例/边界：纯相对信息无法定绝对朝向，0特殊；
- D4 完整性：两组/四组配置、最少关系下界；
- D5 一般化：k个方向组、k−1关系 + 1锚点；
- D6 迁移：传感器误差、标签对应关系丢失。

计算量降到最低后，核心难度仍完整存在。

## R3.8｜Highest-Ceiling Authenticity

PASS。

### 1. 是否逼近当前知识边界内的最高灵活应用

是。

最高层不再要求“更多绝对值求值”，而要求学生把绝对值、相反数、数轴方向自然组合到一个陌生的信息恢复/设计问题中。

### 2. 是否扣除了教学泄露

是。

T0 前只讲单点信息丢失和相对/绝对方向区别；没有提前讲：

```text
整体镜像不变性
关系链连接
多个独立可翻转部分
k−1最少关系
```

因此最高层关键结构未被前文直接暴露。

### 3. 是否至少两个非显然突破

是。T0 至少2个，Final 至少3个：

```text
重复绝对值把8标签压成5个方向组
→ 相对关系必须联系全部方向组
→ 每条有效关系最多合并两个部分，因此4条是下界
→ 即使全部联系，仍需1个绝对方向锚点破整体镜像
```

### 4. 是否需要自行选择/组合知识

是。

题面不提示“整体镜像”“关系网络”“k−1”。学生必须自行选择：

- 相反数；
- 左右方向；
- 同侧/异侧传播；
- 对称；
- 必要性/充分性；
- 最少性证明。

### 5. 是否只是增加对象数量

否。

旧版8标签被判定有效难度不足；新版对象数量只是承载结构，核心难度来自不可辨识与最少连接证明。

### 6. 是否错误使用未来知识

否。

不依赖方程、不等式体系、图论定理、组合数学公式或信息论公式。所有下界均用自然语言证明。
