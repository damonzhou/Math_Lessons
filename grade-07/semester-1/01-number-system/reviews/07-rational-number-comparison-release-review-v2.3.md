## R3｜概念深度

PASS。

课程继续坚持：

```text
原数大小 = 数轴左右顺序
绝对值大小 = 到0距离
```

并进一步发现：

> 在 `0 < |a| < |b|` 下，绝对值更大的 b 的符号控制 a、b 的相对顺序。

这把普通负数比较提升为一般顺序结构。

## R3.5｜Ceiling Diagnostic

PASS。

新 T0：

```text
0 < |a| < |b| < |c|
```

但未知三者符号。

要求：

- 找出全部可能标签排序；
- 证明 c 不能在中间；
- 证明只有4种而不是机械列8个符号组合；
- 从排序反推 b、c；
- 发现 a 的符号不可恢复。

能够区分“会比较具体数”和“能发现结构”。

```text

→ 排名反推
→ 不可能结构
→ 四变量递归预备
```

不是增加同模板题量。

## R3.7｜思维深度，而非计算难度

PASS。

D1～D6 全覆盖：

- D1 结构发现：最大绝对值标签必在端点；
- D2 条件充分性/必要性：`a < b` 与 b 的符号互相反推；
- D3 反例/边界：绝对值次序不能无条件决定原数次序；严格不等条件是递归结构关键；
- D4 唯一性/穷尽性：4种/8种排序不重不漏；证明给定排列不可能；
- D5 一般化：2变量 → 3变量 → 4变量 → 5变量；
- D6 表示/陌生迁移：数轴顺序 ↔ 标签排名 ↔ 信息恢复。

删除全部复杂计算以后，核心问题仍然完整存在，因此高阶难度来自结构。
