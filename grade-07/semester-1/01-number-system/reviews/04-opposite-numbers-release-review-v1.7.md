# R3｜概念理解深度

本讲不把“改符号”当作最终理解，而要求学生解释：

1. 为什么相反数对应原点对称；
2. 为什么0的相反数仍是0；
3. 为什么 $-a$ 不一定为负数；
4. 为什么 $-(-a)=a$ 与乘法“负负得正”不是同一件事；
5. 为什么方向相反但大小不同的量不是相反数；
6. 为什么一对相反数可以帮助确定隐藏原点。

概念从“会改符号”提升到几何结构和代数语言统一。

**PASS**。
