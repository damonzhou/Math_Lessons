# 2. 诊断题

## D1｜H9 默认每格1

相邻刻度代表0.25，原点左侧第6格表示什么？

若答 −6，说明把“格数”和“坐标变化”混淆。

## D2｜H7 对象层级

点 P 的坐标为 −5。

分别说出：P、−5、P到原点的距离是什么对象。

## D3｜H3 图形外观

图上 B 看起来在 A、C 正中间，但题干只说 A、B、C 在同一直线上。

能否写 AB = BC？要求说明证据。

## D4｜H10 条件充分性

等距数轴上两个锚点能恢复尺度；删除“等距”后还能吗？

要求构造两种不同合法模型。

## D5｜H8 回代验证

恢复某数轴后得到“每格3”。必须用另一个已知点验证一次，而不是算出后直接接受。
