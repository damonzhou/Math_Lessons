# Lesson 7 做题习惯与能力诊断｜有理数大小比较｜v2.3

> 目标：不仅记录“比较对没对”，而要定位学生是否会发现极端结构、反推符号、证明不可能和证明最少信息。

---

# 1｜本讲重点错误/习惯

## H1｜条件读取不完整

典型：忽略 `0 < |a| < |b| < |c|` 中“严格递增”和“非零”。

检查：

```text
哪个绝对值最大？是否相等？是否可能为0？
```

## H2｜没有确认所求

典型：题目问标签排名，却去比较绝对值排名；题目问符号恢复，却只给具体数值例子。

检查：

```text
现在问的是原数、绝对值、排名，还是符号信息？
```

## H3｜擅自补符号

典型：见 |a| < |b| 就默认 a、b 同号。

检查：

```text
哪个符号是题设给的，哪个只是我想象的？
```

## H5｜枚举不完整

典型：三变量只列3种排序；四变量漏掉某个“左/右”分支。

检查：

```text
我是否有一种系统生成全部情况的方法？
```

## H7｜原数与距离混淆

典型：认为 |c| 最大就一定 c 最大。

检查：

```text
|c| 最大只说明离0最远；c 正才在最右，c 负则在最左。
```

## H9｜过早模板/暴力枚举

典型：立刻画8格或16格正负号表，却没有发现“最大绝对值在端点”。

检查：

```text
能否先找控制全局的极端元素？
```

## H10｜缺少完整性/最少性证明

典型：

- 列出4种排序但不证明另外2种不可能；
- 给出“问 a 的符号”方案，却不证明为什么0问不够；
- 找到一个构造就说“所以一定”。

检查：

```text
为什么只有这些？
为什么更少信息不行？
```

# 2｜新的能力标签

本讲除 C1～C8/H1～H10 外，额外记录以下“高阶动作”，但不新增永久 H 编号：

```text
P1 是否主动找最大绝对值对象
P2 是否发现其只能占最左/最右
P3 是否会删除极端元素递归处理
P4 是否能从排名反推符号
P5 是否识别最小绝对值符号不可见
P6 是否会做“不可能性”证明

```

# 3｜T0 首个卡点记录

题目：

```text
0 < |a| < |b| < |c|
```

要求全部可能标签排序。

记录：

```text
C5等级：A / B / C / D / E / F
P1 最大绝对值：独立发现 / 提示后 / 未发现
P2 c 必在端点：会证明 / 只会猜 / 不会
P3 是否避免8格暴力枚举：是 / 否
排序数量：正确4种 / 漏项 / 多项
P4 b、c 符号反推：完整 / 部分 / 无
P5 a 符号不可恢复：独立 / 提示 / 未发现
P6 两种不可能排列证明：完整 / 部分 / 无
首个真实卡点：________
```

### C5解释

```text
A：独立完成全部结构、证明与信息恢复
B：核心结构独立，完整性说明略弱
C：Hint 1 后完成
D：Hint 2 后完成
E：Hint 3 后完成
F：完整解答后才能理解
```

# 4｜Ceiling Builder 分流

## 若卡在 P1/P2

训练两个变量：

```text
0 < |a| < |b|
```

只看 b 的符号如何决定 a、b 顺序。

## 若卡在 P3/H9

禁止列正负号全表，强制执行：

```text
最大绝对值
→ 放端点
→ 删除
→ 重复
```

## 若卡在 P4

给已知排名，反向逐层删除端点，恢复对应符号。

## 若卡在 P5

固定 b、c、d 的符号，只让最小绝对值 a 变号，观察排名为何不变。

## 若卡在 P6/H10

训练：

```text
假设最大绝对值对象在中间
→ 分正/负两种
→ 都与“最远”位置矛盾
```

## 若卡在 P7/H10

必须分别写：

```text
上界：给出1问可恢复的方案
下界：构造0问时仍不可区分的两种状态
```

# 5｜T1 Final 记录

四变量：

```text
0 < |a| < |b| < |c| < |d|
```

记录：

```text
是否独立发现 d 在端点：是 / 提示 / 否
是否能递归处理 c、b：是 / 提示 / 否
是否不用16格表得到8种：是 / 否
是否证明8种不重不漏：完整 / 部分 / 无
是否从排名恢复 b,c,d：完整 / 部分 / 无
是否发现 a 符号不可恢复：是 / 提示 / 否
最少信息证明：充分+必要 / 只有方案 / 无
5变量推广：独立 / 提示 / 未完成
```

# 6｜T2 陌生迁移标准

若换成传感器、海拔、误差排名等表面，不提示“绝对值排序”：

```text
是否主动找绝对值最大对象：是 / 否
是否从排名端点恢复方向：是 / 否
是否逐层剥离：是 / 否
是否识别最小幅度对象方向不可见：是 / 否
是否证明最少额外方向位：是 / 否
```

# 7｜能力提升判定

## 明显提升

以下至少5项稳定出现：

- 不再把绝对值大等同原数大；
- 遇到多变量先找最大绝对值；
- 能证明最大绝对值标签只能在端点；
- 会用“删除极端元素”避免暴力枚举；
- 会从最终排名反推符号；
- 能主动指出某些信息无法恢复；
- 会证明某种排序不可能；
- 会证明枚举不重不漏；
- 最少信息问题会同时写充分性和必要性；
- 能推广到更多变量。

## 仍偏低阶

若学生主要表现仍是：

```text
会比较具体数
会背负数规则
会做普通排序
```

但 P1～P7 多数不能独立完成，则说明“教材技能稳定，但高阶结构能力尚未建立”。

# 8｜固定复盘句

```text
① 绝对值最大的对象是谁？
② 它能不能在中间？为什么？
③ 删除它后，剩下问题有没有同样结构？
④ 哪些符号能由排名反推？
⑤ 哪个信息仍不可恢复？
⑥ 我为什么已经列完？
⑦ 如果说“最少”，下界证明在哪里？
```
