# 1. 本讲重点习惯

## H1｜条件读取不准确

典型表现：

- 把“位于 −4 与 −3 之间”只检查一侧；
- 忽略“都为负数”“0 < a < b”等关键条件。

检查动作：

```text
先圈出符号条件、区间条件和是否互不相同。
```

## H2｜没有确认所求

典型表现：

- 题目问“最大数”，却去找“离0最远”；
- 题目问“最近”，却按原数从小到大排序。

检查动作：

```text
我比较的是原数大小，还是距离大小？
```

## H3｜擅自补条件

典型表现：

- 只知道 |a| > |b| 就默认 a、b 同号；
- 只知道 a < b 就套用 0 < a < b 的镜像排序。

检查动作：

```text
条件真的告诉我它们在哪一侧吗？
```

## H5｜分类/穷尽不完整

典型表现：

- 排序漏一个数；
- 只列一个符号可能；
- 忘记0边界；
- “至少2个负数”只写“恰好2个”。

检查动作：

```text
所有原对象是否都恰好出现一次？还有第二个合法分支吗？
```

## H7｜对象层级混淆

典型表现：

- 把原数大小和绝对值大小混为一谈；
- 把坐标位置和到0距离混为一谈。

检查动作：

```text
原数 = 位置；绝对值 = 到0距离。现在题目问哪一个？
```

## H9｜过早套模板

典型表现：

- 看到负号就直接“反着比”，却不知道为什么；
- 不看符号区间就使用“绝对值大反而小”。

检查动作：

```text
先定位到数轴哪一侧，再决定规则。
```

## H10｜没有唯一性/合理性检查

典型表现：

- 找到一种排序就停止；
- 条件不足仍给唯一答案；
- 不解释为什么已列完。

检查动作：

```text
如果我改变一个未确定符号，是否还能满足条件？
```

# 6. 能力提升判断

## 明显提升

出现以下变化中的至少3项：

- 比较前先分符号区间；
- 不再混淆“最大”和“最远”；
- 两个负数能用数轴解释，不只背口诀；
- 条件不足时主动构造反例；
- 排序后主动核对全部对象；
- 主动检查唯一性；
- 能从具体数字推广到 0 < a < b；
- T2 新表面仍能识别同一结构。

## 仍需强化

若出现：

- 连续两次把绝对值大小当原数大小；
- 连续两次排序漏项；
- 删除条件后仍坚持唯一答案；
- 只能背“负数反着比”但不能解释；

则 Lesson 8 前应安排10～15分钟定向复测，而不是重复整套作业。

# 7. 本讲固定复盘句

每道高阶排序/比较题结束后回答：

```text
① 我比较的是原数还是距离？
② 条件是否足够判断符号区间？
③ 我的排序是否包含全部对象且无重复？
④ 有没有第二种合法可能？
⑤ 为什么答案只有这些？
```
