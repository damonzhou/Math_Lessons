# 第7讲 做题习惯与能力诊断｜有理数大小比较｜v2.4

> 重点：是否从“比较两个数”升级到“用绝对值层级恢复全部排序结构”。

---

# 1｜基础错误

| 表现 | 诊断 |
|---|---|
| 把绝对值大直接当原数大 | H9 / C1 |
| 两负数比较方向反了 | H6 |
| 只看符号不看数轴位置 | H7 |
| 找到一个排序就结束 | H10 |
| 重复绝对值未联想到相反数对 | C5 / H9 |

# 4｜Builder 分流

- P1：回到“固定正距离只有±r两个位置”。
- P2：只训练最大绝对值为什么必占当前一端/两端。
- P3：要求用 `H−/H+、L−/L+` 写结构模板，不代具体数。
- P4：强制写“任何合法排序都必须从最大组开始外放”的覆盖证明。
- P5：反向给排名，逐层恢复符号。
- P6：直接 Final，不重复同构题。

---

# 5｜R3.8 有效难度观察

如果学生在 Final 前已经被明确告知：

```text
从最大组向内递归
最小单点不贡献排序二选一
最小相反数对贡献二选一
```

则 Final 难度被教学泄露，应换 T2 陌生表面重测。

高阶判断不能只看“题有多少个标签”。

---

# 6｜真正掌握的标志

不是能算出 `2^(k−1)`，而是能回答：

1. 为什么非最小组无论单点还是相反数对，都恰好贡献一个可见二选一？
2. 为什么最小单点组的符号改变不会改变标签排名？
3. 为什么递归算法覆盖全部排序且不重复？
4. 给一个最终排名，哪些符号能恢复，哪个可能恢复不了？
