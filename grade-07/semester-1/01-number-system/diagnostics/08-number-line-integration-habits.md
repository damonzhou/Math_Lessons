# Lesson 8 做题习惯与能力诊断｜数轴综合｜v2.2

> 目标：识别“算错”背后的结构性原因，而不是只记录正确率。

---

# 1. 本讲重点 H 标签

- **H1 条件读取不准确**：漏掉“等距”“中点”“同速”“方向”等关键词；
- **H2 没确认所求**：把最终位置、直接距离、总路程混在一起；
- **H3 擅自补隐藏条件**：看到图画在中间就默认中点，看到刻度就默认等距；
- **H5 分类/情况不完整**：固定距离只找一侧；
- **H7 局部/整体或对象层级混淆**：坐标、距离、路径混淆；
- **H9 过早套模板**：没分析位置关系就套“同号减异号加”、中点公式；
- **H10 缺少唯一性/合理性检查**：找到一个答案就停止，不证明没有第二/第三种。

# 2. 典型错误 → 诊断

## 错误 A｜“从 −4 到3距离是1”

可能标签：

```text
C7 + H7/H9
```

根因：把数字表面差异代替数轴路径。

纠正动作：

```text
先标0
→ 看是否跨0
→ 按实际线段分段
```

## 错误 B｜“点在 A、B 中间，所以就是中点”

可能标签：

```text
C2 + H1/H3
```

根因：把“between”误当“midpoint”。

纠正动作：

> 强制说出中点的第二条件：到两端距离相等。

## 错误 C｜“X 离 M 5，所以 X = M 右边5”

可能标签：

```text
C6 + H5/H10
```

根因：逆向距离问题只沿一个方向搜索。

纠正动作：

```text
固定正距离
→ 左找一次
→ 右找一次
→ 证明没有第三方向
```

## 错误 D｜“同时相向出发就一定中点相遇”

可能标签：

```text
C2/C5 + H1/H3
```

根因：漏读“同速”这一决定等距的条件。

纠正动作：

> 问：两边走过距离为什么相同？如果答不出，就不能推出中点。

## 错误 E｜“最终位置一样，所以走的路一样”

可能标签：

```text
C7 + H2/H7
```

根因：把状态和历史路径混为一体。

纠正动作：

分别建立：

```text
current_position
travel_total
```

## 错误 F｜删除“等距”后仍沿用原每格变化

可能标签：

```text
C2/C7 + H3/H9/H10
```

根因：没有检查计算依赖哪条条件。

纠正动作：

> 每得到一个数值，反问：“是哪条条件让它唯一？”

# 4. T1 Final Challenge 观察表

重点观察是否形成新的解题顺序：

```text
先顺序
→ 再尺度
→ 再中点/距离
→ 最后唯一性
```

而不是：

```text
看到数字就开始算
```

检查：

- 是否先用 B < F 确定标签归属；
- 是否明确“等距”控制尺度；
- 是否不用公式识别 D 为中点；
- 是否找全 X 两个位置；
- 是否能解释方向条件如何唯一化；
- 删除等距后是否能逐结论判断保留/失效。

# 5. T2 观察重点

地铁巡检题故意换掉“数轴、点 A/B”等表面词。

如果学生仍能主动识别：

```text
里程标 = 坐标
等距站点 = 等距刻度
巡检路线 = 路径长度
起终点间隔 = 直接距离
```

说明 D6 迁移开始稳定。

# 8. 本讲成功标准

不是“所有距离题都做对”，而是学生开始稳定表现出：

1. 先确认所求对象；
2. 主动把条件分角色；
3. 不凭图补中点/等距；
4. 固定距离自动检查左右两侧；
5. 多解题主动证明已经列全；
6. 动点题区分最终状态和历史路径；
7. 删除条件时知道哪些结论会一起失效。
