# Lesson 8 学习诊断｜2026-09-15修订

本讲分别记录三条能力线，不让重建题很强掩盖动点或距离最值的短板。

| 任务 | 典型首个卡点 | 纠正动作 |
|---|---|---|
| G/T | 坐标、距离、路径混淆 | 复述所求并列单位与方向含义 |
| A1/A2 | 找到一点但漏最优区间 | 下界、达到、全部等号条件分开证明 |
| T0 | 一组解就称唯一 | 检查镜像，说明候选配对已穷尽 |
| 锚点 | 两个一定够 | 比较两个端点与端点+内部排名点的区别 |
| M1 | 采样不重合等于全程不相遇 | 指定观察时刻，用4.5秒交叉例检验 |
| M2 | 只记位置不记方向 | 相同位置配不同下一步，找完整状态周期 |
| AMC P18 | 除法取上整后就停 | 还要检查步长替换是否可达，再给最少构造 |
| Gauss Q25 | 将距离列表当无重复集合 | 每条记录逐次扣除，未知n允许补重复值 |
| 研究例 | 相同列表就局部都一样 | 比较固定排名邻点间隔与丢失的点对对应 |

H3擅补图形条件、H5漏分类、H7对象混淆、H9公式模板、H10不证完整继续记录。探索阶段试小例和枚举允许；最终不能以有限试验代替无限时间周期证明。

T0/AMC/Gauss首次独立程度与提示等级分别保存。Research可选，不将没能从零发现经典反例判为基础或奥数能力不合格。学生数据尚未收集前，不使用预计分钟数或自定星级宣称能力达标。
