# 4｜Builder 分流

- P1：只训练“有序点集最大距离=最左到最右”。
- P2：固定端点0和L，练内部点的两端距离 `t` 与 `L−t`。
- P3：强制做一次整体镜像检查。
- P4：写候选来源表，证明所有互补对/内部差都已覆盖。
- P5：用两组具体坐标逐对验证平移/镜像不改变距离。
- P6：区分“一个坐标固定平移”与“形状/朝向歧义仍存在”。

Builder 成功标准：下一道陌生重建题中，学生是否会主动问：

> **我现在证明的是存在，还是唯一？**

---

# 5｜Final 的高阶诊断

主课6点反例要求学生接受并验证：

```text
全部两两距离都知道
仍可能不能唯一恢复点集
```

若学生强烈坚持“15个距离这么多，一定唯一”，说明存在：

```text
信息数量 ≠ 信息充分性
```

的概念盲点。

真正通过 Final 的表现：

1. 完整验证两组距离多重集相同；
2. 主动检查平移、镜像并排除；
3. 能用一个反例否定“所有情况都唯一”的全称命题；
4. 能提出一种额外信息使恢复更可靠。

# 6｜教学泄露检查

T0 前若已经讲出：

```text
最大距离锁端点
内部端点距离要配成和为跨度
镜像必产生第二组
```

则 T0 有效难度下降，应使用不同距离集合重测。

Final 前绝不能先展示：

```text
{0,1,4,10,12,17}
{0,1,8,11,13,17}
```

否则 Final 只剩验证，不再是构造/发现。

# 7｜与用户长期习惯的连接

本讲直接针对：

- H3：不能默认点顺序；
- H5：重建必须列全；
- H7：区分位置、距离、标签和有序信息；
- H9：不能看到“距离很多”就模板匹配成“唯一”；
- H10：必须做唯一性/反例检查。

与此前 AB=12、BC=7 的问题是同一底层习惯：

> **没有给顺序，就不能偷偷补顺序；有一个合法配置，也不能偷偷补“它是唯一配置”。**
