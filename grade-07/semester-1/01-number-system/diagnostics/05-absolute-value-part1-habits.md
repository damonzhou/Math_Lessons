> **辅助标签**：H2、H6

---

# 1. 本讲真正要诊断什么

绝对值的计算本身很简单，真正容易暴露的是：

```text
学生是在理解“距离”，
还是只记住“负号去掉”？
```

以及：

```text
从绝对值反推原数时，
会不会自动补上“在右边”这个隐藏条件？
```

因此本讲错误率不一定高，但诊断价值很高。

---

# 2. 本讲重点习惯

## H7｜坐标、方向、距离混淆

典型表现：

- 把 −6 的绝对值写成 −6；
- 说“机器人离基地 −12 m”；
- 把“位置在左边”与“距离为负”混在一起。

检查动作：

```text
先给当前量命名：
它是坐标？方向？还是距离？
```

如果是距离，结果不能为负。

---

## H3｜擅自补方向条件

典型表现：

> 一个数的绝对值是4，所以这个数是4。

问题：题目没有说它在0右边。

检查动作：

```text
距离4在数轴上有几个位置？
另一侧是否也满足？
```

---

## H5｜逆向情况漏列

典型表现：

- 知道可能有正负两个答案，但只写一个；
- T0 中 P/S 左右交换漏一种；
- 多个独立符号选择组合时漏情况。

检查动作：

```text
每个正距离先写“左/右”两个候选
→ 再用条件筛选
→ 最后检查不重不漏
```

---

## H10｜没有检查唯一性

典型表现：

找到一个合法答案就结束。

例如：

```text
距离6 → 写6 → 停止
```

检查动作：

最后强制问：

> **原点另一侧还有没有合法位置？**

如果有，结论就不是唯一答案。

---

## H9｜看到“绝对值”就套机械规则

典型表现：

- “见负号就去掉”；
- “见绝对值就变正”；
- 不区分题目问正向求值还是逆向恢复。

检查动作：

先问：

```text
这是“已知位置求距离”
还是“已知距离找位置”？
```

两种方向的逻辑完全不同。

# 4. Core 诊断检查点

完成 Core 后至少确认：

- [ ] 能说出“绝对值 = 到原点的距离”；
- [ ] 能求正数、负数、0的具体绝对值；
- [ ] 不用“删负号”作为唯一解释；
- [ ] 知道距离不能为负；
- [ ] 能区分 −5 这个坐标和5这个距离；
- [ ] 知道相反数绝对值相同。

如果前4项不稳定，不进入 T0，先修 Core。


# 7. Ceiling Builder 如何根据卡点分流

## 如果卡在 H3

优先做：

- 距离6找全部位置；
- 删除/添加“在0左边”；
- 构造两个都满足同一绝对值的反例。

目标：不再擅自补方向。

## 如果卡在 H5

优先做：

- T0 全情况树；
- 删除“互不相同”后重新枚举；
- 每个候选先独立列，再组合。

目标：不重不漏。

## 如果卡在 H7

优先做三列表：

```text
坐标 | 方向 | 到0距离
```

让学生对 −5、0、3、−2.5 逐一填写。

目标：对象分层。

## 如果卡在 H10

每道逆向题强制增加一句：

> **答案唯一吗？为什么？**

目标：把唯一性检查变成结尾动作。

## 如果 T0 已 C5-A/B

不增加机械求值题，直接训练：

- 最少附加信息；
- 删除条件；
- 自己设计信息丢失机器；
- 推广“正距离两个位置、0一个位置”。

# 9. 与长期真实错误的连接

本讲直接针对此前反复出现的一个长期问题：

> **条件没有说明时，不应自行假设位置关系。**

这与曾经的线段问题同构：只知道两段长度时，不能擅自假设点的顺序。

在绝对值中表现为：

```text
只知道距离
≠
已经知道方向
```

因此 Lesson 5 是训练 H3/H10 的重要节点，而不只是一个简单定义课。
