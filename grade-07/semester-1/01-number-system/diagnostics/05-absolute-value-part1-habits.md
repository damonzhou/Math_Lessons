# 第5讲 做题习惯与能力诊断｜绝对值（一）｜v2.4

> **课程定位**：最高能力上限诊断 + 短板定向提升  
> **重点 H 标签**：H3、H5、H7、H9、H10  
> **辅助能力**：条件传播、对称不变性、不可辨识证明、最少性下界、一般化

---

# 1｜本讲真正测什么

基础求绝对值几乎不能拉开能力差距。

v2.4 真正诊断：

```text
能否把“绝对值”看成信息保留/丢失
→ 能否区分相对方向与绝对方向
→ 能否沿关系传播而不是暴力枚举
→ 能否发现整体镜像不变性
→ 能否用对称证明“信息类型本身无法唯一化”
→ 能否识别彼此独立的方向部分
→ 能否设计最少关系
→ 能否证明更少一定不够
→ 能否推广到 k 个方向组
```

最终不能只记录“做对/做错”，必须记录：

> **第一次在哪个非显然思维节点卡住。**

---

# 2｜Gap Check 诊断

0～1处非粗心错误：直接进入深化。

2处及以上概念性错误：定点补漏。

| 表现 | 诊断 |
|---|---|
| 把绝对值说成“去负号” | C1 / H9 |
| 把距离写成负数 | C1 / H7 |
| `|x|=5` 只想到5 | C2 / H3 |
| 不知道0为什么特殊 | C1 / C6 |
| 坐标、方向、距离混淆 | H7 |

基础层不稳定时，不用高难题掩盖漏洞。

# 3｜T0 首个卡点编码｜v2.4

T0：六个点 + 绝对值 + 同侧/异侧关系链。

## A｜仍在暴力枚举

表现：

- 想从64种符号组合开始试；
- 没想到选定一个点方向后沿关系传播；
- 不会把“同侧/异侧”转成方向传递。

本质：

```text
没有把局部关系组织成全局结构
```

常见：H9 / H5。

## B｜能得两组，但看不出整体镜像

表现：

- 算出两组；
- 认为只是“碰巧有两组”；
- 没发现第二组是第一组全部取相反数。

本质：D1 结构发现不足。

## C｜看出镜像，但不会证明“同类信息永远区分不了”

表现：

- 会说“这两组对称”；
- 但如果再加10条同侧/异侧关系，会觉得可能就能唯一；
- 不能说明为什么绝对值和同/异侧在整体镜像下都保持不变。

本质：

```text
会观察现象
但不会把不变性升级成不可能性证明
```

## D｜不会处理关系断开后的独立翻转

表现：

- 删除一条中间关系后仍只想到整体翻转；
- 不会发现两部分可以分别独立翻转；
- 不能从“1个整体”升级为“多个方向部分”。

本质：结构分解能力不足。

## E｜会给方向锚点，但不会证明最少

表现：

- 能说“问A正负就够”；
- 但不会证明0问一定不够；
- Final 中能给4条关系方案，却不会证明3条关系必然失败。

本质：缺少下界意识。

固定检查：

```text
我证明了“够用”吗？
我证明了“再少一定不够”吗？
```

## F｜能做具体题，但不会一般化

表现：

- 六点 T0 和八点 Final 都会；
- 但说不清为什么 k 个独立方向组需要 k−1 条有效相对关系 + 1个方向锚点。

本质：D5 一般化不足。

# 4｜能力上限等级

| 等级 | 表现 |
|---|---|
| C5-A | 独立完成 T0 与 Final，主动发现镜像不变性、独立方向组和最少性下界，并完成 k 组一般化 |
| C5-B | 独立完成核心结构，最少性或一般化论证略有缺口 |
| C5-C | Hint 1 后摆脱枚举，能沿关系传播并继续完成 |
| C5-D | Hint 2 后才发现整体镜像 |
| C5-E | Hint 3 后才能理解“多个独立方向部分”和下界 |
| C5-F | 阅读完整解答后才能理解核心结构 |

不把一次等级固化为学生标签。重点看 Builder 后首个卡点是否前移或消失。

# 5｜Builder 分流

## A型 → 关系传播

训练目标：

```text
选一个方向锚点
→ 同侧保持
→ 异侧翻转
→ 一路传播
```

禁止枚举全部正负组合。

## B型 → 对称发现

每次找到两个候选时主动问：

> 能否通过“全部取相反数”把一个候选变成另一个？

## C型 → 不变性证明

强制写三步：

```text
定义整体镜像
→ 检查每类已知信息是否保持
→ 推出任何同类信息都无法区分镜像对
```

## D型 → 独立方向部分

画出“谁与谁有相对关系”。

每个彼此无联系的部分都问：

> 它能不能自己整体翻转，而不影响其他部分？

## E型 → 最少性下界

固定结构：

```text
上界：构造一套够用方案
下界：证明每条新关系最多减少一个独立方向部分
```

## F型 / C5-A/B → 一般化

直接研究：

```text
k个独立方向组
c个彼此独立的已连接部分
相对关系数
绝对方向锚点数
```

目标是自己推出一般规律，而不是记公式。

# 6｜长期习惯映射

## H3｜擅自补方向

典型：

```text
知道 |x|=5
→ 默认 x=5
```

统一检查：

> 题目真的给了方向吗？

## H5｜分类/结构不完整

v2.4 不再鼓励先枚举。

优先问：

```text
真正独立的自由选择有几个？
哪些对象已经被关系绑定？
```

## H7｜对象层级混淆

必须区分：

```text
坐标
距离
绝对方向
相对方向
标签—距离对应关系
```

Homework Elite Transfer 专门检查最后一层。

## H9｜过早套模板

典型：

- 看见绝对值就机械写 ±；
- 主课学会“问方向”，作业中即使标签—距离对应也丢了，仍只会问方向。

检查：

> 这道题真正丢失的是哪一种信息？

## H10｜没有完整性/最少性检查

固定结束动作：

```text
还有整体镜像吗？
还有独立可翻转部分吗？
我的方案只是足够，还是已经最少？
```

# 8｜何时说明最高层仍偏低

如果学生首次接触、不看 Hint 即可：

- 15分钟内完成 T0；
- 主动给出整体镜像不可能性证明；
- Final 20分钟内推出4条最少并完成一般化；
- 能自行提出“k−c + c”一类更一般结构；

则 Lesson 5 仍未触及她的上限。

下一步不是加更多标签，而是进入更远迁移：

```text
无序幅度
标签对应丢失
多种信息类型混合
设计最优恢复策略
```

并在 Lesson 6 提高参数与多层绝对值的最高层。

---

# 9｜何时说明是知识漏洞而不是“题太难”

若 Gap Check 稳定，但 T0 25分钟无法启动，且 Hint 1 后仍不会沿同/异侧关系传播，说明问题不是绝对值定义，而是：

```text
关系组织 / 结构建模
```

若能传播却始终看不出整体镜像，则是：

```text
对称结构发现
```

若能看出镜像但不会证明“任意多同类信息仍无效”，则是：

```text
从观察到证明
```

诊断后只补对应 Builder，不整体降难度。
