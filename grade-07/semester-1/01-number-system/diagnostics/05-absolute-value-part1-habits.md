> **课程定位**：能力上限诊断 + 短板定向提升  
> **重点 H 标签**：H3、H5、H7、H9、H10  
> **辅助**：H1、H2、C2、C5、C6、C7、C8

# 1｜本讲不只测“会不会绝对值”

基础求值很难拉开能力差距。

Lesson 5 真正要测的是：

```text
能否从“距离信息”逆向建模
→ 能否找到独立自由选择
→ 能否正确使用条件筛选
→ 能否不重不漏地枚举
→ 能否证明答案完整/唯一
→ 能否判断最少还缺多少信息
→ 能否识别冗余条件
```

因此最终结果不能只记录“做对/做错”。

必须记录：

> **第一次在哪一步卡住。**

---

# 2｜基础层：先确认是否需要补漏

## Gap Check 通过标准

0～1处非粗心错误：直接进入深化。

2处及以上概念性错误：定点补漏。

### 基础短板类型

| 表现 | 诊断 |
|---|---|
| 把绝对值说成“去负号” | C1 / H9 |
| 把距离写成负数 | C1 / H7 |
| `|x|=5` 只想到5 | C2 / H3 |
| 不知道0为什么特殊 | C1 / C6 |
| 坐标、方向、距离混淆 | H7 |

基础层不稳定时，不急着用难题掩盖漏洞。

---

# 3｜T0 首个卡点编码

T0：7标签距离恢复。

第一次尝试记录以下最早发生的一项。

## A｜逆向模型没有建立

表现：

- 看见 `|P|=6` 只写 P=6；
- 重复绝对值6没有联想到 −6、6；
- 不理解“互不相同”为什么会强迫相反位置。

常见标签：

```text
H3 + H7 + H9
```

### 短板本质

仍在机械正向求值，没有把绝对值看成信息丢失后的逆向恢复。

---

## B｜会列候选，但不会利用条件

表现：

- 写出 P/R 是 ±6，却没有用 `P<Q`；
- 所有条件抄了一遍，但不知道哪条先用；
- 不会判断某条条件排除了什么。

常见标签：

```text
H1 + H3 + C5
```

### 短板本质

条件阅读停留在“看到”，没有转成筛选动作。

---

## C｜条件会用，但枚举漏解

表现：

- 得到 Q/T 两种、S 两种，却只列2～3种；
- 混乱地逐个试，缺少选择表；
- 重复或漏掉组合。

常见标签：

```text
H5 + C6
```

### 短板本质

缺少“独立选择 → 组合”的结构化枚举能力。

---

## D｜列全，但不会证明完整

表现：

- 恰好写出4种，但解释不了为什么不会有第5种；
- 用“我都试过了”代替数学证明。

常见标签：

```text
H10 + C8
```

### 短板本质

会得到答案，但没有形成“穷尽性证明”习惯。

---

## E｜不会判断“最少信息”

表现：

- 能说问 Q 和 S 就够，但解释不了为什么一问不够；
- 把“给出一种可行方案”误当成“证明最少”。

常见标签：

```text
H10 + C5
```

### 短板本质

缺少下界意识：

```text
证明最少
=
证明这么多足够
+
证明更少不够
```

---

## F｜能完整解决，但不能一般化

表现：

- T0 全对；
- 换数字仍会；
- 但说不出“每个不同正绝对值组留下一个方向选择”。

常见标签：

```text
C7 / D5不足
```

### 短板本质

停留在具体题，没有提炼结构。

---

# 4｜C5-A～F 能力上限等级

| 等级 | 表现 |
|---|---|
| C5-A | 独立完成4种恢复、最少2问、冗余条件，并能一般化 |
| C5-B | 独立完成恢复和最少2问，一般化略弱 |
| C5-C | Hint 1 后建立绝对值组模型并完成 |
| C5-D | Hint 2 后才会利用大小条件 |
| C5-E | Hint 3 后才能建立完整选择表 |
| C5-F | 完整解答后才能理解 |

不要把一次等级固定成“学生能力标签”。

真正关注：

> Builder 后相同类型卡点是否提前消失。

# 5｜Builder 按首个卡点分流

## A型短板 → Builder A

目标：建立：

```text
正距离
→ 左右候选
→ 重复距离 + 互异
→ 相反数对
```

训练量少而精，不刷20道绝对值求值。

## B型短板 → Builder B

使用“条件作用表”：

| 条件 | 加入前 | 排除什么 | 加入后 |
|---|---|---|---|
| P < Q |  |  |  |
| T < U |  |  |  |
| V > 0 |  |  |  |

目标：以后看到条件立即问：

> 它能消除哪个自由度？

## C型短板 → Builder C

强制改用：

```text
独立选择1
×
独立选择2
→ 完整状态表
```

目标：从“逐个猜”转成“系统枚举”。

## D型短板 → Builder C + 完整性句式

每次最后强制写：

> 剩余只有……个彼此独立的选择；每个选择所有取值均已覆盖，因此没有其他情况。

## E型短板 → Builder D

训练最少性：

```text
上界：给出具体询问方案
下界：说明更少询问为什么无法区分全部状态
```

## F型短板 / C5-A/B → Builder E

直接做参数化：

> k 个不同正绝对值组，在没有顺序信息时留下多少个独立方向选择？

不再回到基础机械题。

# 6｜长期习惯映射

## H3｜擅自补条件

绝对值问题中的典型表现：

```text
知道距离
→ 默认在右边
```

与此前线段问题中：

```text
知道长度
→ 默认点的顺序
```

本质相同。

统一检查动作：

> **题目真的给了这个位置/方向条件吗？**

## H5｜分类/枚举不完整

检查动作：

```text
先找独立选择
→ 再做选择表
→ 最后证明不漏
```

## H7｜对象层级混淆

检查动作：

```text
当前量是坐标？
方向？
距离？
标签？
还是标签与距离的对应关系？
```

Homework Elite Transfer 专门检查这一层。

## H9｜过早模板匹配

表现：主课学会“问左右方向”后，Homework Q12 仍机械认为只问左右一定可以恢复。

如果出现，说明迁移不足。

## H10｜不做唯一性/最少性检查

固定结束动作：

```text
还有别的合法状态吗？
为什么没有？
我证明的是“足够”还是“最少”？
```

# 8｜什么时候说明 Lesson 5 难度仍偏低

如果学生：

- T0 在10分钟内完全独立解决；
- 能主动识别冗余条件；
- 能证明2问最少；
- Final Challenge 也在15分钟内完成并一般化；

则 Lesson 5 对她的能力上限仍然偏低。

处理方式不是增加基础题，而是：

1. 直接进入 Builder E；
2. Homework Q12；
3. 把“方向丢失”升级成“标签对应关系也丢失”；
4. Lesson 6 提前提高参数/多层绝对值的 Ceiling 难度。

---

# 9｜什么时候说明跨度过大

如果学生 Gap Check 稳定，但 T0：

- 20分钟完全无法启动；
- Hint 1 仍不知道重复绝对值意味着什么；
- 完整解答后仍无法解释2 × 2 的来源；

这不是简单“题太难”，而说明逆向建模存在真实短板。

此时先做 Builder A/C，再重新测一个不同数字的小型问题，不直接降低整门课程难度。
