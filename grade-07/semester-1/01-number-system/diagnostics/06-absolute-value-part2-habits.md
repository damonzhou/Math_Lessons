# 2｜T0 首个卡点 P1～P6

## P1｜只会逐步模拟

看到长 A/R 串从头算到尾，没有寻找“哪些历史已失效”。

短板：结构压缩不足。

## P2｜知道 A 会丢方向，但抓错关键点

例如盯第一次 A，而不是最后一次 A。

短板：不会识别“最后一次状态重置”。

## P3｜找到了最后一次 A，但不会用奇偶压缩后续 R

短板：局部结构不能继续抽象。

## P4｜得到四类，但不会证明覆盖所有串

表现：“我试了很多串，都是这四种。”

短板：穷尽性/完整性证明不足。

## P5｜四类会列，但不会证明两两不同

短板：只会分类，不会验证分类真的区分不同规则。

## P6｜T0 完整，最少测试也可独立推进

进入 Final，不做重复 Builder。

# 4｜Builder 分流

```text
P1 → 训练“哪一步后历史失效”
P2 → 比较第一次A与最后一次A
P3 → 只练R奇偶，不增加串长度
P4 → 强制写“无A / 有A”的覆盖证明
P5 → 训练用测试输入区分规则
P6 → 直接Final / T2
```

Builder 成功标准不是多做5个同类串，而是：

> 下一条陌生日志中，学生是否会主动删除最后一次A以前的无效方向历史。

---

# 5｜Final 的最高层诊断

Final 需要独立完成三种证明：

1. **完整性**：任意有限操作串都进入四类之一；
2. **区别性**：四类并非同一规则；
3. **最少性**：两次测试足够，任何一次测试都不够。

若只做到前两项，说明“规则分类”强，但下界思维仍需训练。

若只找到正负两个测试，却不能证明一次一定不够，标记：

```text
H10 + 最少性下界不足
```

# 6｜教学泄露检查

若学生在 T0 前已被明确告知：

```text
看最后一次A
四类只有 x、−x、|x|、−|x|
```

则 T0 不再是有效 Ceiling Diagnostic，必须更换陌生表面重测。

v2.4 记录“有效难度”，不是题库原始难度。
