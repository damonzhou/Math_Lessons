> **课程标准**：v2.0  
> **主题**：含字母绝对值、分类、边界、条件充分性、同绝对值结构

---

# 1. 本讲重点 H 标签

## H1｜条件读取不准确

典型表现：

- 题目只给“a 是有理数”，却自行补成 a > 0；
- 忽略“a ≠ 0”“a 与 b 不相等”等关键限制。

检查动作：

> **把所有能决定符号/边界的条件单独圈出来。**

---

## H3｜擅自补隐藏条件

典型表现：

- `|a| = 5` 只写 a = 5；
- 不知道 a 的符号时，直接写 `|a| = a`。

检查动作：

```text
条件真的能唯一确定方向吗？
如果不能，能否构造正、负两个例子？
```

---

## H5｜分类讨论不完整

本讲最重点习惯。

典型表现：

```text
a > 0
或
a < 0
```

然后结束，漏掉 a = 0。

纠正：

```text
先找分界点0
→ 左侧
→ 边界
→ 右侧
→ 再看是否可以合并边界
```

---

## H6｜符号检查不足

典型表现：

> 看见 −a 就认为它是负数。

纠正：

先判断 a：

```text
a > 0 → −a < 0

a = 0 → −a = 0

a < 0 → −a > 0
```

负号外形不能代替符号判断。

---

## H7｜对象角色混淆

本讲容易混淆：

```text
a        原数/位置
−a       a 的相反数
|a|      到0的距离
−|a|     距离的相反数
```

纠正：每个表达式先说“它表示什么对象”，再操作。

---

## H10｜没有检查全部可能与边界

典型表现：

- `|a| = t` 找到 a = t 就结束；
- `|a| = |b|` 只写 a = b；
- 没有检查 t = 0 或 t < 0。

纠正：

> **数轴上所有符合距离条件的位置是否全部列完？边界是否单独检查？**

# 2. 本讲知识错因 C 标签

| 错误 | 典型表现 | 标签 |
|---|---|---|
| 概念错误 | 把绝对值理解为“删负号” | C1 |
| 条件遗漏 | 忽略 a 的符号条件 | C2 |
| 符号错误 | 把 −a 固定判断为负 | C3 |
| 分类遗漏 | 漏 a = 0 | C6 |
| 方法选择 | 条件不足仍强行化简 | C7 |
| 表达不规范 | 只给答案，不写分类依据 | C8 |

常见组合：

```text
C6 + H5
C3 + H6
C2 + H3
C7 + H9
C6 + H10
```

“四张卡片”问题重点记录：

# 4. Ceiling Builder 如何按卡点分流

## 若主要卡在 H5｜漏0

重点做：

- Builder 2：从结论反推条件；
- Homework Q5～8；
- 每次分类先写“分界点是什么”。

目标：形成“边界先检查”的习惯。

## 若主要卡在 H6｜−a 符号混乱

重点做：

- 对 a = 3、0、−3 分别计算 a 与 −a；
- 再做主课 T0 的卡片配对。

目标：从“看符号外形”转成“根据 a 的取值判断”。

## 若主要卡在 H3/H10｜条件不足仍唯一化

重点做：

- Builder 1 删除条件；
- Builder 3 同绝对值反例；
- Homework Q9～17。

目标：主动构造反例验证条件是否足够。

## 若 T0 已独立完成

不要增加机械计算量，继续：

- 推广 `|u| = t` 的0/1/2结构；
- 自己设计一个分类程序；
- 尝试把“绝对值折叠数轴”用自己的话证明。

# 6. 24小时复盘问题

不看笔记回答：

1. 为什么 `|a|` 不能总写成 a？
2. 为什么 a = 0 同时满足 `|a|=a` 和 `|a|=−a`？
3. `|a|=|b|` 为什么有两个位置关系？
4. 如果 `|a|=t`，为什么必须先检查 t 是否为负？

如果第2、4题解释不清，说明边界意识仍未稳定。

# 8. 阶段性意义

Lesson 6 是第一次把“分类讨论”明确提升为主训练对象之一。

后续会反复出现：

```text
绝对值
→ 有理数大小比较
→ 去括号/符号
→ 方程分类
→ 几何位置关系
→ 程序 if/else
```

如果本讲能稳定建立：

> **先找分界点 → 分类不漏 → 检查边界 → 验证条件充分性**

后续多个模块都会直接受益。
