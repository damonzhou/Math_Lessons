# R0. 为什么第一讲从负数开始

小学已经能处理大量非负数问题，但现实中会自然出现：

$$
3-5
$$

如果数只能停留在非负范围，这个运算就无法完整表达现实结果。

因此本讲不是从“背负数定义”开始，而是回答：

> **为什么旧的数不够用？负号到底表达什么？**

主线保持：

```text
现实需要
→ 数系扩张
→ 正数 / 负数 / 0
→ 相反意义
→ 状态 / 变化 / 位置 / 偏差
→ 基准与约定
→ 陌生迁移
```

# 第一部分：为什么需要负数

## 3. 温度把旧数系推开了一扇门

早晨气温为3 ℃，夜间比早晨降低5 ℃。

现实结果对应：

$$
3-5=-2
$$

−2 ℃不是“错误结果”，而是低于0 ℃的一个真实温度状态。

这说明：

> **新数不是为了制造复杂符号，而是为了表达旧数系表达不了的现实与运算。**

## 4. 不同场景为什么可以用同一种数学结构

- 地上3层记 +3，地下2层记 −2；
- 盈利5万元记 +5，亏损3万元记 −3；
- 高于标准0.2 mm记 +0.2，低于标准0.1 mm记 −0.1。

表面场景不同，但都有：

```text
共同基准
   ↓
基准的一侧
   ↓
基准的另一侧
```

这就是数学抽象。

# 第二部分：正数、负数与0

## 5. 正式定义｜MUST

大于0的数叫正数；小于0的数叫负数。

例如：

$$
3,\quad 2.5,\quad \frac78
$$

是正数；

$$
-3,\quad -2.5,\quad -\frac78
$$

是负数。

0既不是正数，也不是负数。

## 6. 0并不等于“什么都没有”

0可以表示：

- 一个真实温度：0 ℃；
- 一个基准面：海拔0 m；
- 一个位置：数轴原点；
- 偏差为0：实际值恰等于标准；
- 变化量为0：没有变化。

所以0常常承担**基准、分界、起点或平衡状态**。

---

# 第三部分：相反意义的量

## 7. “不同”不等于“相反”

判断两个量是否具有相反意义，至少检查：

1. 是不是同一种量；
2. 是否相对同一个参照；
3. 方向或意义是否真正相反。

典型相反意义：

- 收入 / 支出；
- 上升 / 下降；
- 向东 / 向西；
- 高于标准 / 低于标准。

反例：

- 身高160 cm和170 cm只是大小不同；
- 身高增加2 cm与体重减少2 kg不是同一种量。

# 第四部分：同一个负数可以承担不同角色

## 8. −3 到底表示什么

| 场景 | −3 的角色 | 数学意义 |
|---|---|---|
| 气温 −3 ℃ | 状态值 | 当前状态低于基准0 |
| 地下3层 | 位置 | 在基准层下方 |
| 账户 −3元 | 余额状态 | 处于欠款状态 |
| 温度变化 −3 ℃ | 变化量 | 朝负方向变化3 |
| 标准100，偏差 −3 | 偏差 | 实际值比标准低3 |

核心结论：

> **负数本身不等于“减少”。**

“减少”描述的是变化过程；负数还可以描述状态、位置和偏差。

## 9. 状态值与变化量必须分开

早晨温度 −5 ℃，中午比早晨升高3 ℃。

- −5 ℃是原状态；
- +3 ℃是变化量；
- 最终状态是 −2 ℃。

如果学生把“−5 ℃”直接解释成“降温5 ℃”，就是 H7：对象层级混淆。

---

# 第五部分：正负号依赖约定

## 10. 正号不等于“好”，负号不等于“坏”

某跑步测试规定“比目标慢记为正，比目标快记为负”。

那么：

- +2 s表示慢2秒；
- −2 s表示快2秒。

所以：

> **正负号是一套表示规则，不是价值判断。**

## 11. 同一个现实状态可以因规则不同而符号相反

现实状态：比预算多花5万元。

- 若规定“超预算为正”，记录 +5；
- 若规定“节约为正”，记录 −5。

现实没变，编码规则变了。

---

# 第六部分：标准值、实际值与偏差

设标准值、实际值、偏差之间满足“超过标准记正”。

核心关系是：

$$
\text{偏差}=\text{实际值}-\text{标准值}
$$

因此：

$$
\text{实际值}=\text{标准值}+\text{偏差}
$$

例：标准质量500 g，偏差 −4 g，则实际质量496 g。

这里必须区分：

- −4 g：偏差；
- 496 g：实际质量。

# 第八部分：Ceiling Diagnostic｜T0 冷启动

> **首次尝试不要看 Hint 或答案。建议独立15分钟。**

某实验室有若干个真实测量值，具体数值全部未知。

系统A以50为基准记录每个测量值的偏差，所有偏差的总和为 +18。

系统B改用52为基准记录**同一批测量值**，所有偏差的总和为 −6。

回答：

1. 这批测量值共有多少个？
2. 不求任何一个具体测量值，解释你是怎样得到的。
3. 如果有人说“必须先把所有真实测量值求出来才能回答”，请说明为什么不需要。
4. 仅知道“系统A偏差总和为 +18”，能不能确定这批数据的具体值？请构造两个不同数据组说明你的判断。

### T0 诊断目标

观察学生是否会自己发现：

- 基准从50变52，每一个记录都统一减少2；
- 个体统一变化会累积成整体变化；
- 总体信息不等于个体信息；
- “不能唯一确定”时能否主动构造反例。

记录等级：C5-A～F，见 [Ceiling 答案与记录表](./solutions/01-positive-negative-numbers-ceiling-v2.0.md)。

# 第九部分：Ceiling Builder｜真正训练能力上限

完成 T0 后再学习本部分。

## Builder 1｜换表示：从一串数据变成“共同基准 + 偏差”

计算：

$$
98+103+101+97+102
$$

不要立即竖式计算。先把每个数写成：

```text
100 + 一个小偏差
```

然后回答：

1. 为什么100是合适的基准？
2. 如果换成99，方法还能用吗？
3. 哪个基准更方便？“能用”与“更优”有什么区别？

**训练能力**：表示转换 + 方法选择。

## Builder 2｜删条件：总偏差够不够确定每个数据

已知5个数相对20的偏差总和为0。

有人断言：“这5个数一定都是20。”

要求：

1. 判断真伪；
2. 如果错误，构造至少两个反例；
3. 增加什么额外条件后，可以保证5个数都等于20？

**训练能力**：条件充分性 + 反例构造。

## Builder 3｜逆向构造

请自己设计一组4个数，使它们：

- 相对100的偏差总和为 +8；
- 至少包含一个小于100的数；
- 四个数不能全部相同。

再设计另一组完全不同的数据，满足同样条件。

**训练能力**：逆向建模 + 理解“整体条件不能唯一决定个体”。

## Builder 4｜从具体到一般

若有 n 个数据，基准整体提高 k，每个数据本身不变。

不要先背公式，先用语言解释：

> 每个偏差怎样变化？全部偏差的总和怎样变化？

最后再写出一般关系。

**训练能力**：特殊到一般。

# 第十部分：Advanced / Olympiad / Informatics

## 12. 基准改变是一个整体操作

当共同基准改变时，不需要知道每个真实数据，也可以研究整体偏差如何变化。

这是后续平均数、数据分析、估算和算法 offset 思想的重要入口。

## 13. 科学模型｜ADAPTED · AMC structure

风寒等科学模型中计算结果可能为负。关键不是“负号看起来奇怪”，而是解释变量的实际意义。

例如模型：

$$
W=T-0.7v
$$

如果结果小于0，应先解释 W 代表的物理量，而不是怀疑负数本身。

## 14. Informatics：delta 与 offset

```cpp
int baseline = 100;
int current = 97;
int delta = current - baseline;
```

`delta = -3` 表示相对差值。

数学能力迁移点：

> **变量的数值相同，不代表语义相同。**

`temperature = -5` 与 `delta = -5` 都是 −5，但一个可能是状态，一个是变化/偏差。

# 第十一部分：错误实验室

1. **“负数一定表示不好。”**——错，符号依赖编码规则。
2. **“0是最小的正数。”**——错，0既非正也非负。
3. **“−5一定表示减少5。”**——错，先判断它是什么对象。
4. **“偏差 −3 就是实际值 −3。”**——错，偏差与实际值不是同一对象。
5. **“知道总偏差就知道每个数据。”**——错，整体信息一般不足以唯一恢复个体。
6. **“不能确定就只写‘无法确定’。”**——不够；高水平回答应尝试构造两个反例证明不唯一。
